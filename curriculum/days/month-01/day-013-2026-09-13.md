## ✍️ 09:00 – 13:00 | Long-Form Technical Essay
* **Essay Number**: **Essay 02**
* **Title**: *"Breaking Dependency Chains: Multi-Register Accumulator Unrolling and Port Saturation in AVX2/AVX-512"*
* **Target File**: `~/personal/goals/essays/essay_02.md`
* **5-Part Standard Structure**:
  1. **Mathematical Foundation**:
     * Non-associativity of floating-point addition in IEEE 754: $(a + b) + c \ne a + (b + c)$. Why fast-math (`-ffast-math`) enables compiler accumulator reassociation.
     * Calculus of finite differences and Taylor expansions.
  2. **The Systems Bottleneck**:
     * Hardware execution latency: An FMA operation takes 4 clock cycles to complete, but new independent FMAs can be issued every 0.5 cycles across Port 0 and Port 1.
     * **Little's Law for Instruction Pipelines**:
       $$\text{Required Concurrency} = \text{Throughput} \times \text{Latency} = 2 \frac{\text{instructions}}{\text{cycle}} \times 4 \text{ cycles} = 8 \text{ independent accumulators}$$
     * Why 1-accumulator loops leave $75\%$ of ALU execution slots completely vacant.
  3. **The Engine Architecture**:
     * `secan` multi-accumulator kernel layout: 4-way and 8-way `__m256` / `__m512` register allocation with logarithmic tree-reduction tail.
  4. **Empirical Benchmarks**:
     * Benchmark table showing IPC progression: 1-acc (1.18 IPC) $\to$ 2-acc (2.15 IPC) $\to$ 4-acc (3.28 IPC) $\to$ 8-acc (3.45 IPC).
  5. **Key Takeaway**:
     * The hardware pipeline is a queue: if your inner loop doesn't maintain independent instruction streams matching the latency-bandwidth product, you are paying for silicon you never use.

* **Implementation Tasks**:
  1. **Grouped-Query Attention (GQA) & Multi-Head Attention** in `src/gqa.py`:
     ```python
     import torch
     import torch.nn as nn
     import math

     class GroupedQueryAttention(nn.Module):
         def __init__(self, d_model: int, num_q_heads: int, num_kv_heads: int):
             super().__init__()
             self.d_model = d_model
             self.num_q_heads = num_q_heads
             self.num_kv_heads = num_kv_heads
             self.head_dim = d_model // num_q_heads
             self.num_queries_per_kv = num_q_heads // num_kv_heads

             self.q_proj = nn.Linear(d_model, d_model, bias=False)
             self.k_proj = nn.Linear(d_model, num_kv_heads * self.head_dim, bias=False)
             self.v_proj = nn.Linear(d_model, num_kv_heads * self.head_dim, bias=False)
             self.out_proj = nn.Linear(d_model, d_model, bias=False)

         def forward(self, x: torch.Tensor, is_causal: bool = True) -> torch.Tensor:
             B, S, D = x.shape
             # Projections
             q = self.q_proj(x).view(B, S, self.num_q_heads, self.head_dim).transpose(1, 2)
             k = self.k_proj(x).view(B, S, self.num_kv_heads, self.head_dim).transpose(1, 2)
             v = self.v_proj(x).view(B, S, self.num_kv_heads, self.head_dim).transpose(1, 2)

             # Repeat KV heads to match Q heads
             k = torch.repeat_interleave(k, self.num_queries_per_kv, dim=1)
             v = torch.repeat_interleave(v, self.num_queries_per_kv, dim=1)

             scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.head_dim)
             if is_causal:
                 mask = torch.triu(torch.full((S, S), float("-inf"), device=x.device), diagonal=1)
                 scores = scores + mask

             attn = torch.softmax(scores, dim=-1)
             out = torch.matmul(attn, v).transpose(1, 2).contiguous().view(B, S, D)
             return self.out_proj(out)
     ```
  2. **Pre-LN vs Post-LN Transformer Block** in `src/transformer_block.py`:
     ```python
     class TransformerBlock(nn.Module):
         def __init__(self, d_model: int, num_q_heads: int, num_kv_heads: int, d_ff: int, pre_ln: bool = True):
             super().__init__()
             self.pre_ln = pre_ln
             self.ln1 = nn.LayerNorm(d_model)
             self.attn = GroupedQueryAttention(d_model, num_q_heads, num_kv_heads)
             self.ln2 = nn.LayerNorm(d_model)
             self.mlp = nn.Sequential(
                 nn.Linear(d_model, d_ff),
                 nn.GELU(),
                 nn.Linear(d_ff, d_model)
             )

         def forward(self, x: torch.Tensor) -> torch.Tensor:
             if self.pre_ln:
                 x = x + self.attn(self.ln1(x))
                 x = x + self.mlp(self.ln2(x))
             else:
                 x = self.ln1(x + self.attn(x))
                 x = self.ln2(x + self.mlp(x))
             return x
     ```
