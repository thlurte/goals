## ✍️ 06:30 – 08:30 | Morning Builder Track: Technical Essay / Lab-Note Drafting (120 min)
* **Essay Number**: **Essay 02**
* **Title**: *"Breaking Dependency Chains: Multi-Register Accumulator Unrolling and Port Saturation in AVX2/AVX-512"*
* **Target File**: `~/personal/goals/essays/essay_02.md`
* **5-Part Standard Structure**:
  1. **Mathematical Foundation**:
     * Non-associativity of floating-point addition in IEEE 754: $(a + b) + c \ne a + (b + c)$. Why fast-math (`-ffast-math`) enables compiler accumulator reassociation.
     * Calculus of finite differences and Taylor expansions.
  2. **The Systems Bottleneck**:
     * Hardware execution latency: An FMA operation takes 4 clock cycles to complete, but new independent FMAs can be issued every 0.5 cycles across Port 0 and Port 1.
     * **Little's Law for Instruction Pipelines**:
       $$\text{Required Concurrency} = \text{Throughput} \times \text{Latency} = 2 \frac{\text{instructions}}{\text{cycle}} \times 4 \text{ cycles} = 8 \text{ independent accumulators}$$
     * Why 1-accumulator loops leave $75\%$ of ALU execution slots completely vacant.
  3. **The Engine Architecture**:
     * `secan` multi-accumulator kernel layout: 4-way and 8-way `__m256` / `__m512` register allocation with logarithmic tree-reduction tail.
  4. **Empirical Benchmarks**:
     * Benchmark table showing IPC progression: 1-acc (1.18 IPC) $\to$ 2-acc (2.15 IPC) $\to$ 4-acc (3.28 IPC) $\to$ 8-acc (3.45 IPC).
  5. **Key Takeaway**:
     * The hardware pipeline is a queue: if your inner loop doesn't maintain independent instruction streams matching the latency-bandwidth product, you are paying for silicon you never use.

* **Tasks & Implementation**:
  1. **Implement AVX-512 Distance Kernel** in `src/distance_avx512.cpp`:
     ```cpp
     #include <immintrin.h>
     #include <cstddef>

     namespace secan {
     #ifdef __AVX512F__
     inline float l2_squared_avx512(const float* a, const float* b, size_t dim) {
         __m512 sum0 = _mm512_setzero_ps();
         __m512 sum1 = _mm512_setzero_ps();

         size_t i = 0;
         // Process 32 elements per iteration using 2 ZMM registers
         for (; i + 32 <= dim; i += 32) {
             __m512 va0 = _mm512_loadu_ps(a + i);
             __m512 vb0 = _mm512_loadu_ps(b + i);
             __m512 d0  = _mm512_sub_ps(va0, vb0);
             sum0 = _mm512_fmadd_ps(d0, d0, sum0);

             __m512 va1 = _mm512_loadu_ps(a + i + 16);
             __m512 vb1 = _mm512_loadu_ps(b + i + 16);
             __m512 d1  = _mm512_sub_ps(va1, vb1);
             sum1 = _mm512_fmadd_ps(d1, d1, sum1);
         }

         __m512 sum = _mm512_add_ps(sum0, sum1);
         float total = _mm512_reduce_add_ps(sum);

         for (; i < dim; ++i) {
             float d = a[i] - b[i];
             total += d * d;
         }
         return total;
     }
     #endif
     }
     ```
