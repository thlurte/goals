## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *The Art of Writing Efficient Programs* — Fedor G. Pikus
* **Chapter**: Chapter 2 (*Performance Measurements*)
* **Core Microarchitectural Concepts**:
  1. **Noise Floor in Modern OSs**: Why `std::chrono::high_resolution_clock` wall-clock measurements fluctuate due to dynamic CPU frequency scaling (Intel SpeedStep / AMD Cool'n'Quiet), OS timer tick interrupts, and thread migrations.
  2. **Sampling vs. Instrumentation Profilers**: Trade-offs between sampling profilers (`perf record` with statistical sampling) and instrumentation profilers (gprof / Valgrind Callgrind adding $10\times$ overhead).
  3. **Compiler Dead-Code Elimination (DCE)**: In microbenchmarks, if the return value of a vector distance loop is not consumed, the compiler's optimizer (`-O3`) optimizes away the entire loop, resulting in a false $0.0\text{ ns}$ benchmark.
  4. **The `benchmark::DoNotOptimize` Barrier**: Using inline assembly memory clobbering (`asm volatile("" : : "g"(var) : "memory")`) to force the compiler to write values to memory or registers without deleting the computation.

  3. **Naive Scalar Distance Kernel**: Create `include/secan/distance.h` and `src/distance.cpp`:
     ```cpp
     namespace secan {
     inline float l2_squared_scalar(const float* a, const float* b, size_t dim) {
         float sum = 0.0f;
         for (size_t i = 0; i < dim; ++i) {
             float diff = a[i] - b[i];
             sum += diff * diff;
         }
         return sum;
     }
     }
     ```
  4. **Google Benchmark Harness**: Create `benchmarks/bench_distance.cpp`:
     ```cpp
     #include <benchmark/benchmark.h>
     #include "secan/distance.h"
     #include <vector>

     static void BM_L2_Scalar(benchmark::State& state) {
         size_t dim = state.range(0);
         std::vector<float> a(dim, 1.0f);
         std::vector<float> b(dim, 2.0f);
         for (auto _ : state) {
             float dist = secan::l2_squared_scalar(a.data(), b.data(), dim);
             benchmark::DoNotOptimize(dist);
             benchmark::ClobberMemory();
         }
         state.SetBytesProcessed(state.iterations() * dim * sizeof(float) * 2);
     }
     BENCHMARK(BM_L2_Scalar)->Arg(64)->Arg(128)->Arg(768)->Arg(1536);
     BENCHMARK_MAIN();
     ```
  5. **Compile & Execute**:
     ```bash
     cmake -B build -DCMAKE_BUILD_TYPE=Release
     cmake --build build -j$(nproc)
     ./build/benchmarks/bench_distance
     ```
