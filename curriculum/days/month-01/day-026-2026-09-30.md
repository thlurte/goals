## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *The Art of Writing Efficient Programs* — Fedor G. Pikus
* **Chapter**: Chapter 6 (*Concurrency, Thread Pools & Hardware Affinity*)
* **Core Microarchitectural Concepts**:
  1. **CPU Thread Affinity & Cache Locality**:
     * When the OS scheduler migrates an active thread to a different physical CPU core, all L1/L2 cache state is lost, causing hundreds of cycles in cache reload stalls.
     * Pinning worker threads to fixed physical cores with `pthread_setaffinity_np` binds execution to dedicated L1/L2 caches, slashing tail latency ($p99$).
  2. **Multi-Probe Inverted File Query Routing**:
     * Given a query $q$ and $K$ coarse centroids, compute distances to all centroids and pick the top $P = \text{nprobe}$ closest Voronoi cells.
     * Only scan the vectors contained in these $P$ inverted lists ($\frac{P}{K}$ fraction of the database).

     ```python
     class SGDMomentum:
         def __init__(self, params, lr: float = 1e-3, momentum: float = 0.9):
             self.params = list(params)
             self.lr = lr
             self.momentum = momentum
             self.velocities = [torch.zeros_like(p.data) for p in self.params]

         def step(self):
             with torch.no_grad():
                 for p, v in zip(self.params, self.velocities):
                     if p.grad is None:
                         continue
                     # v_t = momentum * v_{t-1} + grad
                     v.mul_(self.momentum).add_(p.grad)
                     # theta_t = theta_{t-1} - lr * v_t
                     p.add_(v, alpha=-self.lr)

         def zero_grad(self):
             for p in self.params:
                 if p.grad is not None:
                     p.grad.detach_()
                     p.grad.zero_()
     ```

  1. **Implement Multi-Probe IVF Search** in `src/index/ivf_flat.cpp`:
     ```cpp
     #include "secan/index/ivf_flat.h"
     #include "secan/distance_avx2.h"
     #include <queue>
     #include <algorithm>

     namespace secan {
     TopKQueryResult ivf_search(
         const IvfFlatIndex& index,
         const float* query,
         size_t k,
         size_t nprobe
     ) {
         // Step 1: Find top nprobe coarse centroids
         std::vector<std::pair<float, size_t>> centroid_dists(index.nlist);
         for (size_t c = 0; c < index.nlist; ++c) {
             float dist = l2_squared_avx2_unrolled4(query, index.centroids.data() + c * index.dim, index.dim);
             centroid_dists[c] = {dist, c};
         }
         std::partial_sort(
             centroid_dists.begin(),
             centroid_dists.begin() + nprobe,
             centroid_dists.end()
         );

         // Step 2: Scan postings lists of the top nprobe centroids
         std::priority_queue<std::pair<float, int32_t>> heap;

         for (size_t p = 0; p < nprobe; ++p) {
             size_t list_id = centroid_dists[p].second;
             const auto& inv_list = index.lists[list_id];
             size_t list_size = inv_list.size();
             const float* list_data = inv_list.data.data();
             const int32_t* list_ids = inv_list.ids.data();

             for (size_t i = 0; i < list_size; ++i) {
                 const float* vec = list_data + i * index.dim;
                 float dist = l2_squared_avx2_unrolled4(query, vec, index.dim);

                 if (heap.size() < k) {
                     heap.emplace(dist, list_ids[i]);
                 } else if (dist < heap.top().first) {
                     heap.pop();
                     heap.emplace(dist, list_ids[i]);
                 }
             }
         }

         TopKQueryResult result;
         result.indices.resize(heap.size());
         result.distances.resize(heap.size());
         for (int i = static_cast<int>(heap.size()) - 1; i >= 0; --i) {
             result.distances[i] = heap.top().first;
             result.indices[i] = heap.top().second;
             heap.pop();
         }
         return result;
     }
     }
     ```
