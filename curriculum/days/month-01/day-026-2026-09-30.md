* **Core Microarchitectural Concepts**:
  1. **CPU Thread Affinity & Cache Locality**:
     * When the OS scheduler migrates an active thread to a different physical CPU core, all L1/L2 cache state is lost, causing hundreds of cycles in cache reload stalls.
     * Pinning worker threads to fixed physical cores with `pthread_setaffinity_np` binds execution to dedicated L1/L2 caches, slashing tail latency ($p99$).
  2. **Multi-Probe Inverted File Query Routing**:
     * Given a query $q$ and $K$ coarse centroids, compute distances to all centroids and pick the top $P = \text{nprobe}$ closest Voronoi cells.
     * Only scan the vectors contained in these $P$ inverted lists ($\frac{P}{K}$ fraction of the database).

2. **SGD Optimizer with Momentum from Scratch** in `src/optimizer.py`:
     ```python
     class SGDMomentum:
         def __init__(self, params, lr: float = 1e-3, momentum: float = 0.9):
             self.params = list(params)
             self.lr = lr
             self.momentum = momentum
             self.velocities = [torch.zeros_like(p.data) for p in self.params]

         def step(self):
             with torch.no_grad():
                 for p, v in zip(self.params, self.velocities):
                     if p.grad is None:
                         continue
                     # v_t = momentum * v_{t-1} + grad
                     v.mul_(self.momentum).add_(p.grad)
                     # theta_t = theta_{t-1} - lr * v_t
                     p.add_(v, alpha=-self.lr)

         def zero_grad(self):
             for p in self.params:
                 if p.grad is not None:
                     p.grad.detach_()
                     p.grad.zero_()
     ```
