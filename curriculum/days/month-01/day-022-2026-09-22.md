## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *The Art of Writing Efficient Programs* — Fedor G. Pikus
* **Chapter**: Chapter 5 (*Data Structures and Memory Layout for Cache Locality: False Sharing & Coherence*)
* **Core Microarchitectural Concepts**:
  1. **The False Sharing Hazard in Multi-Threaded Partitioning**:
     * When multiple CPU cores write to independent thread-local counters that happen to reside within the same 64-byte cache line, the CPU's MESI cache coherence protocol repeatedly invalidates the cache line on every core, degrading performance by $>10\times$.
     * Solution: Align thread-local data structures to 64-byte boundaries with `alignas(64)`.
  2. **Flat Inverted Lists vs. Pointer Chains**:
     * Avoid storing inverted lists as linked lists of pointer nodes `Node { float* vec; Node* next; }`.
     * Use contiguous flat memory buffers: `std::vector<int32_t> ids` and `std::vector<float> data` for each Voronoi cell to ensure sequential SIMD streaming and zero pointer indirection.

* **Tasks & Implementation**:
  1. **Define IVF Index Data Structures** in `include/secan/index/ivf_flat.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <cstdint>
     #include <cstddef>

     namespace secan {
     struct alignas(64) InvertedList {
         std::vector<int32_t> ids;
         std::vector<float> data; // Contiguous: num_vectors * dim floats

         void reserve(size_t n_vecs, size_t dim) {
             ids.reserve(n_vecs);
             data.reserve(n_vecs * dim);
         }

         void add(int32_t id, const float* vec, size_t dim) {
             ids.push_back(id);
             data.insert(data.end(), vec, vec + dim);
         }

         size_t size() const { return ids.size(); }
     };

     struct IvfFlatIndex {
         size_t dim{0};
         size_t nlist{0}; // Number of Voronoi partitions (coarse centroids)
         std::vector<float> centroids; // Contiguous nlist * dim floats
         std::vector<InvertedList> lists; // Array of inverted posting lists

         explicit IvfFlatIndex(size_t dimension, size_t num_lists)
             : dim(dimension), nlist(num_lists), centroids(num_lists * dimension, 0.0f), lists(num_lists) {}
     };
     }
     ```
