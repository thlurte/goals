* **Theorems & Mathematical Concepts**:

     $$\int u(x) v'(x) dx = u(x)v(x) - \int v(x) u'(x) dx \quad \iff \quad \int u \, dv = uv - \int v \, du$$

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Optimizing software in C++* — Agner Fog
* **Chapter**: Chapter 9 (*Memory Access, Streaming Stores & Data Layout*)
* **Core Microarchitectural Concepts**:
  1. **Write-Allocate vs. Non-Temporal Streaming Stores**:
     * Standard Stores (`_mm256_storeu_ps`): Cause a "Read-For-Ownership" (RFO) transaction that reads the destination cache line from DRAM into L1 before modifying it.
     * Non-Temporal Stores (`_mm256_stream_ps`): Write directly to DRAM via internal Write-Combining (WC) buffers, bypassing L1/L2/L3 caches completely and eliminating $50\%$ of memory bus traffic during index construction.
  2. **The Geometric Equivalence of Cosine and Inner Product**:
     * For vectors normalized to unit length on the hypersphere $S^{d-1}$ ($\|u\|_2 = \|v\|_2 = 1$):
       $$d_{\text{cosine}}(u, v) = 1 - \langle u, v \rangle = \frac{1}{2}\|u - v\|_2^2$$
     * Offline pre-normalization converts costly runtime cosine queries ($2\times \text{norms} + 1\times \text{sqrt} + 1\times \text{division}$) into pure, blazing-fast SIMD inner products (`ip_avx2_unrolled4`).

     ```cpp
     namespace secan {
     void normalize_dataset_avx2(float* data, size_t num_vectors, size_t dim) {
         for (size_t i = 0; i < num_vectors; ++i) {
             float* vec = data + i * dim;
             // Compute norm squared using AVX2
             float norm_sq = 0.0f;
             __m256 sum = _mm256_setzero_ps();
             for (size_t d = 0; d + 8 <= dim; d += 8) {
                 __m256 v = _mm256_loadu_ps(vec + d);
                 sum = _mm256_fmadd_ps(v, v, sum);
             }
             norm_sq = horizontal_sum_avx2(sum);
             for (size_t d = (dim / 8) * 8; d < dim; ++d) {
                 norm_sq += vec[d] * vec[d];
             }

             if (norm_sq > 1e-12f) {
                 float inv_norm = 1.0f / std::sqrt(norm_sq);
                 __m256 vinv = _mm256_set1_ps(inv_norm);
                 for (size_t d = 0; d + 8 <= dim; d += 8) {
                     __m256 v = _mm256_loadu_ps(vec + d);
                     _mm256_storeu_ps(vec + d, _mm256_mul_ps(v, vinv));
                 }
                 for (size_t d = (dim / 8) * 8; d < dim; ++d) {
                     vec[d] *= inv_norm;
                 }
             }
         }
     }
     }
     ```
