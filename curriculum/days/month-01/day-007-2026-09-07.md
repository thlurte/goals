     > *"Microbenchmarking vector distance loops with unconstrained memory boundaries and default compiler alignment underestimates real-world cache line split penalties by $\ge 25\%$ compared to strided memory access in flat datasets."*
  2. **Implement Benchmark Sweep Harness** in `scripts/sweep_microbenchmark.py`:
     ```python
     import subprocess
     import json

     def run_alignment_sweep():
         dims = [64, 128, 256, 512, 768, 1024, 1536]
         results = {}
         for d in dims:
             cmd = f"./build/benchmarks/bench_distance --benchmark_filter=BM_L2_Scalar/{d} --benchmark_format=json"
             out = subprocess.check_output(cmd, shell=True)
             results[d] = json.loads(out)
         with open("research/2026-09-measurement-protocol/notes/week1_baseline.json", "w") as f:
             json.dump(results, f, indent=2)

     if __name__ == "__main__":
         run_alignment_sweep()
     ```
