## ✍️ 09:00 – 13:00 | Long-Form Technical Essay
* **Essay Number**: **Essay 04**
* **Title**: *"From Complex Rotations to RoPE and Voronoi Cells: The Geometry of Spherical Inverted Files"*
* **Target File**: `~/personal/goals/essays/essay_04.md`
* **5-Part Standard Structure**:
  1. **Mathematical Foundation**:
     * Complex rotations in 2D Euclidean planes: $z e^{i\theta} \iff \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix}$.
     * **Rotary Position Embedding (RoPE)** formulation: Encoding relative position $m - n$ into inner products across orthogonal 2D subspaces:
       $$\langle \mathbf{R}_{\Theta, m}^d \mathbf{q}, \mathbf{R}_{\Theta, n}^d \mathbf{k} \rangle = \operatorname{Re}\left( \sum_{i=1}^{d/2} (q_{2i-1} + i q_{2i})(k_{2i-1} - i k_{2i}) e^{i(m-n)\theta_i} \right)$$
     * Spherical Voronoi tessellation on hypersphere $\mathbb{S}^{d-1}$.
  2. **The Systems Bottleneck**:
     * Why exact search fails at scale: $10^8$ vectors $\times 128\text{ floats} \times 4\text{ B} = 51.2\text{ GB}$ (cannot be scanned in under $1\text{ second}$ on memory bus).
     * The IVF solution: Pruning $95\%\text{--}99\%$ of vector evaluations via coarse centroid routing.
  3. **The Engine Architecture**:
     * `secan` `IvfFlatIndex` design: Flat contiguous posting lists, spherical $k$-means coarse quantizer, and multi-probe query router.
  4. **Empirical Benchmarks**:
     * Pareto curve (Recall@10 vs QPS) across $K=1024$ and $\text{nprobe} \in \{1, 2, 4, 8, 16, 32, 64\}$ on SIFT1M.
  5. **Key Takeaway**:
     * Modern vector retrieval is geometric routing: by structuring high-dimensional space into Voronoi cells, we replace exhaustive memory sweeps with localized cache bursts.

* **Implementation Tasks**:
  1. **Rotary Position Embedding (RoPE) & SwiGLU** in `src/llama_layers.py`:
     ```python
     import torch
     import torch.nn as nn
     import torch.nn.functional as F

     def precompute_freqs_cis(dim: int, end: int, theta: float = 10000.0) -> torch.Tensor:
         freqs = 1.0 / (theta ** (torch.arange(0, dim, 2)[: (dim // 2)].float() / dim))
         t = torch.arange(end, device=freqs.device)
         freqs = torch.outer(t, freqs).float()
         freqs_cis = torch.polar(torch.ones_like(freqs), freqs)  # complex64: e^(i * freqs)
         return freqs_cis

     def apply_rotary_emb(xq: torch.Tensor, xk: torch.Tensor, freqs_cis: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
         # Reshape to complex pairs
         xq_ = torch.view_as_complex(xq.float().reshape(*xq.shape[:-1], -1, 2))
         xk_ = torch.view_as_complex(xk.float().reshape(*xk.shape[:-1], -1, 2))
         freqs_cis = freqs_cis[:xq.shape[1]].unsqueeze(0).unsqueeze(2)  # [1, seq_len, 1, dim//2]
         xq_out = torch.view_as_real(xq_ * freqs_cis).flatten(3)
         xk_out = torch.view_as_real(xk_ * freqs_cis).flatten(3)
         return xq_out.type_as(xq), xk_out.type_as(xk)

     class SwiGLU(nn.Module):
         def __init__(self, d_model: int, hidden_dim: int):
             super().__init__()
             self.w1 = nn.Linear(d_model, hidden_dim, bias=False)
             self.w2 = nn.Linear(hidden_dim, d_model, bias=False)
             self.w3 = nn.Linear(d_model, hidden_dim, bias=False)

         def forward(self, x: torch.Tensor) -> torch.Tensor:
             return self.w2(F.silu(self.w1(x)) * self.w3(x))
     ```
  2. **SGD Optimizer with Momentum from Scratch** in `src/optimizer.py`:
     ```python
     class SGDMomentum:
         def __init__(self, params, lr: float = 1e-3, momentum: float = 0.9):
             self.params = list(params)
             self.lr = lr
             self.momentum = momentum
             self.velocities = [torch.zeros_like(p.data) for p in self.params]

         def step(self):
             with torch.no_grad():
                 for p, v in zip(self.params, self.velocities):
                     if p.grad is None:
                         continue
                     # v_t = momentum * v_{t-1} + grad
                     v.mul_(self.momentum).add_(p.grad)
                     # theta_t = theta_{t-1} - lr * v_t
                     p.add_(v, alpha=-self.lr)

         def zero_grad(self):
             for p in self.params:
                 if p.grad is not None:
                     p.grad.detach_()
                     p.grad.zero_()
     ```
