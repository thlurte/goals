## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *C++ High Performance for Financial Systems* — Ariel Silahian
* **Systems Profiling Reference**: Brendan Gregg, *Systems Performance: Enterprise and the Cloud* (2nd ed) — CPU hardware counters and PMU event profiling with `perf stat`.
* **Chapter**: Chapter 6 (*Virtual Memory, Page Tables & HugePages*)
* **Core Microarchitectural Concepts**:
  1. **Translation Lookaside Buffer (TLB) Page Faults**:
     * Standard Linux Page Size = $4\text{ KB}$.
     * A $512\text{ MB}$ vector dataset (SIFT1M) requires $\frac{512\text{ MB}}{4\text{ KB}} = 131{,}072$ page table entries.
     * The hardware L1 Data TLB holds only 64 entries. Streaming through millions of vectors causes continuous TLB misses, forcing a 4-level x86 page table walk ($4\times$ memory lookups per vector!).
  2. **2MB Transparent HugePages (THP)**:
     * A $512\text{ MB}$ dataset requires only $\frac{512\text{ MB}}{2\text{ MB}} = 256$ HugePage entries, fitting entirely into the L2 TLB (1536 entries) with **zero page table walks**.
  3. **POSIX Memory Advise Calls**:
     * `madvise(addr, size, MADV_HUGEPAGE)`: Hints the Linux kernel memory manager to coalesce $4\text{ KB}$ pages into $2\text{ MB}$ hugepages.
     * `madvise(addr, size, MADV_WILLNEED | MADV_SEQUENTIAL)`: Asynchronously pre-populates page table mappings.

* **Tasks & Implementation**:
  1. **Implement Zero-Copy Memory-Mapped Loader with HugePages** in `src/utils/io.cpp`:
     ```cpp
     #include "secan/utils/io.h"
     #include <sys/mman.h>
     #include <sys/stat.h>
     #include <fcntl.h>
     #include <unistd.h>
     #include <stdexcept>

     namespace secan {
     struct MmapFloatDataset {
         int fd{-1};
         void* mmap_ptr{nullptr};
         size_t file_size{0};
         size_t num_vectors{0};
         size_t dim{0};
         const float* data{nullptr};

         ~MmapFloatDataset() {
             if (mmap_ptr && mmap_ptr != MAP_FAILED) {
                 munmap(mmap_ptr, file_size);
             }
             if (fd != -1) {
                 close(fd);
             }
         }
     };

     MmapFloatDataset load_fvecs_mmap(const std::string& path) {
         int fd = open(path.c_str(), O_RDONLY);
         if (fd == -1) throw std::runtime_error("Could not open: " + path);

         struct stat sb;
         if (fstat(fd, &sb) == -1) {
             close(fd);
             throw std::runtime_error("fstat failed on: " + path);
         }
         size_t file_size = sb.st_size;

         void* addr = mmap(nullptr, file_size, PROT_READ, MAP_SHARED | MAP_POPULATE, fd, 0);
         if (addr == MAP_FAILED) {
             close(fd);
             throw std::runtime_error("mmap failed on: " + path);
         }

         // Request 2MB transparent hugepages and sequential prefetch
         madvise(addr, file_size, MADV_HUGEPAGE);
         madvise(addr, file_size, MADV_SEQUENTIAL | MADV_WILLNEED);

         int32_t d = *reinterpret_cast<const int32_t*>(addr);
         size_t record_size = sizeof(int32_t) + d * sizeof(float);
         size_t n = file_size / record_size;

         MmapFloatDataset ds;
         ds.fd = fd;
         ds.mmap_ptr = addr;
         ds.file_size = file_size;
         ds.num_vectors = n;
         ds.dim = static_cast<size_t>(d);
         ds.data = reinterpret_cast<const float*>(static_cast<const char*>(addr) + sizeof(int32_t));
         return ds;
     }
     }
     ```
