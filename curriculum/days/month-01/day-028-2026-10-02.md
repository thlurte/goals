## ✍️ 06:30 – 08:30 | Morning Builder Track: Technical Essay / Lab-Note Drafting (120 min)
* **Essay Number**: **Essay 04**
* **Title**: *"From Complex Rotations to RoPE and Voronoi Cells: The Geometry of Spherical Inverted Files"*
* **Target File**: `~/personal/goals/essays/essay_04.md`
* **5-Part Standard Structure**:
  1. **Mathematical Foundation**:
     * Complex rotations in 2D Euclidean planes: $z e^{i\theta} \iff \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix}$.
     * **Rotary Position Embedding (RoPE)** formulation: Encoding relative position $m - n$ into inner products across orthogonal 2D subspaces:
       $$\langle \mathbf{R}_{\Theta, m}^d \mathbf{q}, \mathbf{R}_{\Theta, n}^d \mathbf{k} \rangle = \operatorname{Re}\left( \sum_{i=1}^{d/2} (q_{2i-1} + i q_{2i})(k_{2i-1} - i k_{2i}) e^{i(m-n)\theta_i} \right)$$
     * Spherical Voronoi tessellation on hypersphere $\mathbb{S}^{d-1}$.
  2. **The Systems Bottleneck**:
     * Why exact search fails at scale: $10^8$ vectors $\times 128\text{ floats} \times 4\text{ B} = 51.2\text{ GB}$ (cannot be scanned in under $1\text{ second}$ on memory bus).
     * The IVF solution: Pruning $95\%\text{--}99\%$ of vector evaluations via coarse centroid routing.
  3. **The Engine Architecture**:
     * `secan` `IvfFlatIndex` design: Flat contiguous posting lists, spherical $k$-means coarse quantizer, and multi-probe query router.
  4. **Empirical Benchmarks**:
     * Pareto curve (Recall@10 vs QPS) across $K=1024$ and $\text{nprobe} \in \{1, 2, 4, 8, 16, 32, 64\}$ on SIFT1M.
  5. **Key Takeaway**:
     * Modern vector retrieval is geometric routing: by structuring high-dimensional space into Voronoi cells, we replace exhaustive memory sweeps with localized cache bursts.

## 💻 20:30 – 23:00 | Night Hands-On Implementation (2.5 hrs)
* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Comprehensive Recall@10 Sweep Harness** in `benchmarks/bench_ivf_pareto.cpp`:
     ```cpp
     #include "secan/index/ivf_flat.h"
     #include "secan/index/kmeans.h"
     #include "secan/utils/io.h"
     #include "secan/utils/metrics.h"
     #include <chrono>
     #include <iostream>

     int main() {
         auto base = secan::load_fvecs_mmap("data/sift/sift_base.fvecs");
         auto query = secan::load_fvecs_mmap("data/sift/sift_query.fvecs");
         auto groundtruth = secan::load_ivecs("data/sift/sift_groundtruth.ivecs");

         size_t nlist = 1024;
         secan::IvfFlatIndex index(base.dim, nlist);
         // Train coarse quantizer
         index.centroids = secan::train_spherical_kmeans(base.data, 50000, base.dim, nlist, 15);
         // Populate posting lists
         for (size_t i = 0; i < base.num_vectors; ++i) {
             const float* vec = base.data + i * base.dim;
             // Assign to nearest centroid
             float min_dist = 1e9f;
             size_t best_c = 0;
             for (size_t c = 0; c < nlist; ++c) {
                 float d = secan::l2_squared_avx2_unrolled4(vec, index.centroids.data() + c * base.dim, base.dim);
                 if (d < min_dist) { min_dist = d; best_c = c; }
             }
             index.lists[best_c].add(static_cast<int32_t>(i), vec, base.dim);
         }

         // Pareto sweep
         std::vector<size_t> nprobes = {1, 2, 4, 8, 16, 32, 64};
         for (size_t np : nprobes) {
             auto t0 = std::chrono::high_resolution_clock::now();
             double total_recall = 0.0;
             for (size_t q = 0; q < 1000; ++q) {
                 auto res = secan::ivf_search(index, query.data + q * query.dim, 10, np);
                 total_recall += secan::recall_at_k(res.indices.data(), groundtruth.data.data() + q * 100, 10);
             }
             auto t1 = std::chrono::high_resolution_clock::now();
             double elapsed_ms = std::chrono::duration<double, std::milli>(t1 - t0).count();
             double qps = 1000.0 / (elapsed_ms / 1000.0);
             std::cout << "nprobe=" << np << " | Recall@10=" << (total_recall / 1000.0) << " | QPS=" << qps << std::endl;
         }
         return 0;
     }
     ```
