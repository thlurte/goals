## ✍️ 09:00 – 13:00 | Long-Form Technical Essay
* **Essay Number**: **Essay 03**
* **Title**: *"Integrals, Accumulation, and CPU Cache Hierarchies: Cache Tiling and Autograd from Scratch"*
* **Target File**: `~/personal/goals/essays/essay_03.md`
* **5-Part Standard Structure**:
  1. **Mathematical Foundation**:
     * Definite Riemann integration as continuous accumulation.
     * The multivariable Chain Rule governing reverse-mode automatic differentiation (backpropagation):
       $$\frac{\partial \mathcal{L}}{\partial w_j} = \sum_{i} \frac{\partial \mathcal{L}}{\partial y_i} \frac{\partial y_i}{\partial w_j}$$
  2. **The Systems Bottleneck**:
     * The CPU Cache Hierarchy: L1 ($1\text{ ns}$) vs L2 ($3\text{ ns}$) vs L3 ($12\text{ ns}$) vs DRAM ($60\text{ ns}$).
     * Why brute-force vector scans are bandwidth-starved: SIMD ALUs operate at $<20\%$ utilization while waiting on memory bus round-trips.
  3. **The Engine Architecture**:
     * Cache-blocked batching in `secan`: Holding $1\text{MB}$ vector database chunks in L2/L3 cache while sweeping multiple query vectors, amortizing DRAM bandwidth over batch size $Q$.
  4. **Empirical Benchmarks**:
     * Latency & QPS curves across query batch sizes $Q \in \{1, 8, 32, 64, 128\}$ on SIFT1M.
     * TLB hit rate improvement ($90\% \to 99.9\%$) via 2MB Transparent HugePages.
  5. **Key Takeaway**:
     * In deep learning and vector retrieval systems, compute is free; data movement is expensive. Algorithms that maximize arithmetic intensity per byte moved dominate hardware efficiency.

  1. **Scalar Autograd Engine (`Value`)** in `src/engine.py`:
     ```python
     import math

     class Value:
         def __init__(self, data: float, _children=(), _op=''):
             self.data = float(data)
             self.grad = 0.0
             self._backward = lambda: None
             self._prev = set(_children)
             self._op = _op

         def __add__(self, other):
             other = other if isinstance(other, Value) else Value(other)
             out = Value(self.data + other.data, (self, other), '+')
             def _backward():
                 self.grad += out.grad
                 other.grad += out.grad
             out._backward = _backward
             return out

         def __mul__(self, other):
             other = other if isinstance(other, Value) else Value(other)
             out = Value(self.data * other.data, (self, other), '*')
             def _backward():
                 self.grad += other.data * out.grad
                 other.grad += self.data * out.grad
             out._backward = _backward
             return out

         def __pow__(self, other: float):
             assert isinstance(other, (int, float))
             out = Value(self.data ** other, (self,), f'**{other}')
             def _backward():
                 self.grad += (other * (self.data ** (other - 1))) * out.grad
             out._backward = _backward
             return out

         def exp(self):
             out = Value(math.exp(self.data), (self,), 'exp')
             def _backward():
                 self.grad += out.data * out.grad
                 out._backward = _backward
             return out

         def tanh(self):
             x = self.data
             t = (math.exp(2*x) - 1) / (math.exp(2*x) + 1)
             out = Value(t, (self,), 'tanh')
             def _backward():
                 self.grad += (1.0 - t**2) * out.grad
             out._backward = _backward
             return out

         def backward(self):
             # Topological sort
             topo = []
             visited = set()
             def build_topo(v):
                 if v not in visited:
                     visited.add(v)
                     for child in v._prev:
                         build_topo(child)
                     topo.append(v)
             build_topo(self)

             self.grad = 1.0
             for v in reversed(topo):
                 v._backward()

         def __repr__(self):
             return f"Value(data={self.data:.4f}, grad={self.grad:.4f})"
     ```

     import torch
     from src.engine import Value

     def test_autograd_parity():
         # Custom engine
         x = Value(-4.0)
         z = 2 * x + 2 + x
         q = z.tanh() + z * x
         h = (z * z).tanh()
         y = h + q + q * x
         y.backward()
         x_grad_custom = x.grad

         # PyTorch reference
         x_pt = torch.tensor([-4.0], dtype=torch.float64, requires_grad=True)
         z_pt = 2 * x_pt + 2 + x_pt
         q_pt = z_pt.tanh() + z_pt * x_pt
         h_pt = (z_pt * z_pt).tanh()
         y_pt = h_pt + q_pt + q_pt * x_pt
         y_pt.backward()
         x_grad_pt = x_pt.grad.item()

         assert math.isclose(x_grad_custom, x_grad_pt, rel_tol=1e-6)
