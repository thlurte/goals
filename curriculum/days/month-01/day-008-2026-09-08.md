## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Trigonometry* — I.M. Gelfand & Mark Saul
* **Chapter**: Chapter 4 (*Addition Formulas*)
* **Theorems & Mathematical Concepts**:
  1. **Geometric Proof of the Cosine Subtraction Formula**:
     * Points $P = (\cos\alpha, \sin\alpha)$ and $Q = (\cos\beta, \sin\beta)$ on unit circle $S^1$.
     * Euclidean chord distance squared:
       $$d^2(P, Q) = (\cos\alpha - \cos\beta)^2 + (\sin\alpha - \sin\beta)^2 = 2 - 2(\cos\alpha\cos\beta + \sin\alpha\sin\beta)$$
     * Rotating the chord so $Q' = (1, 0)$ and $P' = (\cos(\alpha-\beta), \sin(\alpha-\beta))$ gives $d^2(P', Q') = 2 - 2\cos(\alpha-\beta)$.
     * Equating both distances establishes the fundamental identity:
       $$\cos(\alpha - \beta) = \cos\alpha \cos\beta + \sin\alpha \sin\beta$$
  2. **The Complete Addition Family**:
     $$\cos(\alpha + \beta) = \cos\alpha \cos\beta - \sin\alpha \sin\beta$$
     $$\sin(\alpha \pm \beta) = \sin\alpha \cos\beta \pm \cos\alpha \sin\beta$$
     $$\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha \tan\beta}$$

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Optimizing software in C++* — Agner Fog
* **Chapter**: Chapter 12 (*Vector Programming & SIMD Architecture*)
* **Core Microarchitectural Concepts**:
  1. **x86 SIMD Architecture & YMM Registers**: 16 architectural 256-bit registers (`ymm0`–`ymm15`), each operating on 8 packed single-precision `float32` values simultaneously.
  2. **AVX2 & FMA3 Instruction Set**:
     * `_mm256_loadu_ps`: Unaligned 256-bit load from memory to register.
     * `_mm256_sub_ps`: 8 parallel subtractions in 1 cycle.
     * `_mm256_fmadd_ps`: Fused Multiply-Add computing $a \cdot b + c$ with a single rounding step and 4-cycle latency.
  3. **Floating-Point State Control (FTZ/DAZ)**: Setting the Flush-To-Zero (FTZ) and Denormals-Are-Zero (DAZ) bits in the MXCSR register:
     ```cpp
     _MM_SET_FLUSH_ZERO_MODE(_MM_FLUSH_ZERO_ON);
     _MM_SET_DENORMALS_ZERO_MODE(_MM_DENORMALS_ZERO_ON);
     ```
     This prevents denormal floating point numbers from trapping to CPU microcode.

  2. **Implement Baseline AVX2 Distance Kernel** in `include/secan/distance_avx2.h` and `src/distance_avx2.cpp`:
     ```cpp
     #include <immintrin.h>
     #include <cstddef>

     namespace secan {
     inline float l2_squared_avx2_single(const float* a, const float* b, size_t dim) {
         __m256 sum = _mm256_setzero_ps();
         size_t i = 0;
         for (; i + 8 <= dim; i += 8) {
             __m256 va = _mm256_loadu_ps(a + i);
             __m256 vb = _mm256_loadu_ps(b + i);
             __m256 diff = _mm256_sub_ps(va, vb);
             sum = _mm256_fmadd_ps(diff, diff, sum); // 1 accumulator
         }
         // Horizontal reduction
         __m128 lo = _mm256_castps256_ps128(sum);
         __m128 hi = _mm256_extractf128_ps(sum, 1);
         __m128 sum128 = _mm_add_ps(lo, hi);
         sum128 = _mm_hadd_ps(sum128, sum128);
         sum128 = _mm_hadd_ps(sum128, sum128);
         float total = _mm_cvtss_f32(sum128);

         // Scalar tail cleanup
         for (; i < dim; ++i) {
             float d = a[i] - b[i];
             total += d * d;
         }
         return total;
     }
     }
     ```
