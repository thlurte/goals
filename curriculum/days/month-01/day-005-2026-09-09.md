## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *Computer Systems: A Programmer's Perspective (3rd Edition)* (CS:APP) — R. Bryant & D. O'Hallaron
* **Section**: §5.7 (*Understanding Modern Processor Microarchitectures: Superscalar Pipelines & Execution Ports*)
* **Core Microarchitectural Concepts**:
  1. **Instruction-Level Parallelism (ILP)**: Modern CPUs (x86 Skylake/Zen) fetch, decode, and dispatch 4–6 instructions per cycle into a Reservation Station.
  2. **Execution Port Contention**: Execution units are distributed behind specific execution ports (e.g. Port 0/1 for Vector ALU/FMA, Port 2/3 for Vector Loads). If an algorithm requires 3 vector additions per cycle, it is bottlenecked by the 2 available ALU ports.
  3. **Latency vs. Throughput (Issue Time)**:
     * **Latency**: Clock cycles from operand arrival to result availability (e.g. 4 cycles for `vfmadd213ps`).
     * **Reciprocal Throughput (Issue Time)**: Clock cycles between consecutive independent instruction dispatches (e.g. 0.5 cycles = 2 instructions per cycle).

  2. **Formula Implementations in `src/utils/metrics.cpp`**:
     ```cpp
     #include "secan/utils/metrics.h"
     #include <unordered_set>
     #include <cmath>

     namespace secan {
     double recall_at_k(const std::vector<int32_t>& retrieved,
                        const std::vector<int32_t>& ground_truth,
                        size_t k) {
         size_t eval_k = std::min(k, std::min(retrieved.size(), ground_truth.size()));
         if (eval_k == 0) return 0.0;

         std::unordered_set<int32_t> gt_set(ground_truth.begin(), ground_truth.begin() + eval_k);
         size_t hits = 0;
         for (size_t i = 0; i < eval_k; ++i) {
             if (gt_set.count(retrieved[i])) hits++;
         }
         return static_cast<double>(hits) / eval_k;
     }

     double ndcg_at_k(const std::vector<int32_t>& retrieved,
                      const std::vector<int32_t>& ground_truth,
                      size_t k) {
         size_t eval_k = std::min(k, retrieved.size());
         std::unordered_set<int32_t> gt_set(ground_truth.begin(), ground_truth.begin() + eval_k);
         double dcg = 0.0, idcg = 0.0;
         for (size_t i = 0; i < eval_k; ++i) {
             if (gt_set.count(retrieved[i])) {
                 dcg += 1.0 / std::log2(i + 2);
             }
             idcg += 1.0 / std::log2(i + 2);
         }
         return (idcg > 0.0) ? (dcg / idcg) : 0.0;
     }
     }
     ```
