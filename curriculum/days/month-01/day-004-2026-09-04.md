* **Book**: *Optimizing software in C++* — Agner Fog
* **Sections**: Chapter 3 (*Finding Bottlenecks*) & Chapter 7.1–7.3 (*Floating Point Optimization & Numeric Precision*)
* **Core Microarchitectural Concepts**:
  1. **Floating-Point Latency vs. Throughput**:
     * FP Addition & Fused Multiply-Add (FMA): 3–4 cycle latency, 0.5 cycle reciprocal throughput (pipelined).
     * FP Division (`divss`) & Square Root (`sqrtss`): 12–20 cycle latency, non-pipelined hardware divider blocking the execution unit.
  2. **Denormal / Subnormal Floating Point Hazards**: Numbers between $0 < |x| < 2^{-126}$ in single precision cannot be represented with normal mantissas and trigger CPU microcode exception traps, degrading throughput by up to $100\times$.
  3. **Fast Reciprocal Approximations**: Utilizing reciprocal square root approximations ($r \approx \frac{1}{\sqrt{x}}$) with Newton-Raphson refinement steps to eliminate hardware division stalls.

     ```cpp
     #include "secan/distance.h"
     #include <cmath>

     namespace secan {
     float inner_product_scalar(const float* a, const float* b, size_t dim) {
         float sum = 0.0f;
         for (size_t i = 0; i < dim; ++i) {
             sum += a[i] * b[i];
         }
         return sum;
     }

     float cosine_distance_scalar(const float* a, const float* b, size_t dim) {
         float ip = 0.0f, norm_a = 0.0f, norm_b = 0.0f;
         for (size_t i = 0; i < dim; ++i) {
             ip += a[i] * b[i];
             norm_a += a[i] * a[i];
             norm_b += b[i] * b[i];
         }
         float denom = std::sqrt(norm_a) * std::sqrt(norm_b);
         return (denom > 1e-12f) ? (1.0f - ip / denom) : 0.0f;
     }
     }
     ```
  3. **Benchmark Inner Product vs L2** in `benchmarks/bench_distance.cpp`:

         size_t dim = state.range(0);

             benchmark::ClobberMemory();
         }
         state.SetBytesProcessed(state.iterations() * dim * sizeof(float) * 2);
     }
