## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *Computer Systems: A Programmer's Perspective (3rd Edition)* (CS:APP) — R. Bryant & D. O'Hallaron
* **Advanced Architecture Reference**: John L. Hennessy & David A. Patterson, *Computer Architecture: A Quantitative Approach* (6th ed).
* **Sections**: §6.1–6.3 (*Memory Technologies, SRAM vs. DRAM, and Locality Principles*)
* **Core Microarchitectural Concepts**:
  1. **The Modern CPU Memory Hierarchy Latency Gap**:
     * **CPU Registers**: 0 cycles ($<0.5\text{ ns}$).
     * **L1 Data Cache (32–48 KB / core)**: 4–5 cycles ($\approx 1.0\text{ ns}$).
     * **L2 Cache (512 KB–1.25 MB / core)**: 12–14 cycles ($\approx 3.0\text{ ns}$).
     * **L3 Shared Cache (16–64 MB)**: 40–60 cycles ($\approx 12\text{ ns}$).
     * **Main Memory (DRAM)**: 150–250 cycles ($\approx 60\text{ ns}$).
  2. **Vector Working Set Math**:
     * $N=10^4$ vectors ($D=128$, float32) = $5.12\text{ MB}$ (Fits cleanly in L3 cache).
     * $N=10^5$ vectors = $51.2\text{ MB}$ (Exceeds L3 cache; begins spilling to DRAM).
     * $N=10^6$ vectors (SIFT1M) = $512\text{ MB}$ (Entirely DRAM-bandwidth bound).
  3. **The Memory Wall**: The CPU SIMD execution units can process $128 \text{ GFLOPS/core}$, but memory bandwidth is capped at $\approx 40\text{--}60 \text{ GB/s}$, causing compute units to stall $80\%$ of the time during flat brute-force scanning.

     ```cpp
     #include <benchmark/benchmark.h>
     #include "secan/distance_avx2.h"
     #include "secan/utils/io.h"

     static void BM_ExactScan_WorkingSet(benchmark::State& state) {
         size_t n = state.range(0);
         size_t dim = 128;
         std::vector<float> data(n * dim, 0.5f);
         std::vector<float> query(dim, 1.0f);

         for (auto _ : state) {
             float min_dist = std::numeric_limits<float>::max();
             for (size_t i = 0; i < n; ++i) {
                 float d = secan::l2_squared_avx2_unrolled4(query.data(), data.data() + i * dim, dim);
                 if (d < min_dist) min_dist = d;
             }
             benchmark::DoNotOptimize(min_dist);
         }
         state.SetBytesProcessed(state.iterations() * n * dim * sizeof(float));
     }
     // Sweep from L1 cache (100 vectors = 51KB) to DRAM (1,000,000 vectors = 512MB)
     BENCHMARK(BM_ExactScan_WorkingSet)->Arg(100)->Arg(1000)->Arg(10000)->Arg(100000)->Arg(1000000);
     ```
