### 🔹 Part 2: Properties & Geometric Symmetries (Tuesday Syllabus)
* **Book**: *Trigonometry* — I.M. Gelfand & Mark Saul
* **Chapter**: Chapter 3 (*Relationships in a Triangle: The Law of Cosines & The Law of Sines*)
* **Theorems & Mathematical Concepts**:
  1. **The Law of Cosines Derivation**:
     For any triangle $\triangle ABC$ with sides $a, b, c$: drop an altitude $h = b \sin C$ from vertex $C$ to side $c$ (or its extension). The foot of the altitude partitions the base, yielding via Pythagorean theorem:
     $$a^2 = h^2 + (c - b\cos C)^2 = b^2\sin^2 C + c^2 - 2bc\cos C + b^2\cos^2 C = b^2 + c^2 - 2bc\cos C$$
     $$c^2 = a^2 + b^2 - 2ab\cos C$$
  2. **The Generalized Pythagorean Theorem**:
     - Right triangle ($C = 90^\circ$): $\cos 90^\circ = 0 \implies c^2 = a^2 + b^2$.
     - Acute triangle ($C < 90^\circ$): $\cos C > 0 \implies c^2 < a^2 + b^2$.
     - Obtuse triangle ($C > 90^\circ$): $\cos C < 0 \implies c^2 > a^2 + b^2$.
  3. **The Law of Sines & Circumradius**:
     $$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R \quad (R = \text{circumradius})$$
     Triangle area: $\text{Area}(\triangle ABC) = \frac{1}{2}ab \sin C = \frac{1}{2}bc \sin A = \frac{1}{2}ac \sin B$.
  4. **Bridge to Vector Search & High-Dimensional Geometry**:
     In vector space $\mathbb{R}^d$, the Law of Cosines establishes the fundamental distance-to-inner-product relationship:
     $$\|\mathbf{u} - \mathbf{v}\|_2^2 = \|\mathbf{u}\|_2^2 + \|\mathbf{v}\|_2^2 - 2 \langle \mathbf{u}, \mathbf{v} \rangle = \|\mathbf{u}\|_2^2 + \|\mathbf{v}\|_2^2 - 2\|\mathbf{u}\|_2 \|\mathbf{v}\|_2 \cos\theta$$
     On the unit hypersphere $\mathcal{S}^{d-1}$ ($\|\mathbf{u}\| = \|\mathbf{v}\| = 1$), this directly links Euclidean distance and cosine similarity:
     $$\|\mathbf{u} - \mathbf{v}\|_2 = \sqrt{2 - 2\cos\theta} = 2\sin\left(\frac{\theta}{2}\right)$$
* **Pencil & Paper Problem Set**:
  - [x] **Proof 1**: Derive the Law of Cosines $c^2 = a^2 + b^2 - 2ab\cos C$ step-by-step for both acute and obtuse triangles using an altitude and the Pythagorean theorem.
  - [x] **Problem 2**: In $\triangle ABC$, side $a = 5$, side $b = 8$, and included angle $C = 60^\circ$. Compute the exact length of side $c$ in radical form, and find $\cos A$.
  - [x] **Proof 3**: Using the vector Law of Cosines for unit vectors $\mathbf{u}, \mathbf{v} \in \mathcal{S}^{d-1}$ with angle $\theta$, prove that the squared Euclidean distance is $\|\mathbf{u} - \mathbf{v}\|_2^2 = 2(1 - \cos\theta) = 4\sin^2(\frac{\theta}{2})$, demonstrating why nearest-neighbor search under Euclidean metric is strictly equivalent to maximizing cosine similarity on normalized embeddings.

### 🔹 Part 3: Core Theorems & Derivations (Wednesday Syllabus)
* **Book**: *Calculus* — Gilbert Strang
* **Sections**: §1.1–1.5 (*Introduction to Calculus: Limits, Continuity, and the Intermediate Value Theorem*)
* **Theorems & Mathematical Concepts**:
  1. **The Formal $\epsilon$-$\delta$ Definition of a Limit**:
     $$\lim_{x \to c} f(x) = L \iff \forall \epsilon > 0, \exists \delta > 0 \text{ such that } 0 < |x - c| < \delta \implies |f(x) - L| < \epsilon$$
  2. **One-Sided Limits & Existence**: $\lim_{x \to c} f(x) = L$ if and only if $\lim_{x \to c^+} f(x) = \lim_{x \to c^-} f(x) = L$.
  3. **Definition of Continuity**: A function $f$ is continuous at $x=c$ iff: (1) $f(c)$ is defined, (2) $\lim_{x \to c} f(x)$ exists, and (3) $\lim_{x \to c} f(x) = f(c)$.
  4. **Intermediate Value Theorem (IVT)**: If $f$ is continuous on $[a, b]$ and $u$ is any value between $f(a)$ and $f(b)$, then there exists at least one $c \in [a, b]$ such that $f(c) = u$.
* **Pencil & Paper Problem Set**:
  - [x] **Proof 1**: Using the formal $\epsilon$-$\delta$ definition, prove that $\lim_{x \to 3} (2x + 5) = 11$. Explicitly show the construction of $\delta(\epsilon) = \frac{\epsilon}{2}$.
  - [x] **Problem 2**: Evaluate the limit algebraically without L'Hôpital's Rule:
    $$\lim_{x \to 0} \frac{\sqrt{x^2 + 9} - 3}{x^2}$$
  - [x] **Proof 3**: (Intermediate Value Theorem & Algebraic Root Bounding): Prove that the continuous polynomial $P(x) = x^3 - 3x - 1$ must have at least one real root in the open interval $(1, 2)$ using IVT, and use interval bisection to bound the root within an interval of length $\le 0.25$.
