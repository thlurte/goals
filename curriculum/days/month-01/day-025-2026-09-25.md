* **Book**: *Calculus* — Gilbert Strang
* **Sections**: §8.4–8.6 (*Taylor Polynomials, Taylor Series & Lagrange Remainder Theorem*)
* **Theorems & Mathematical Concepts**:
  1. **Taylor Series Centered at $x = a$**:
     $$f(x) = \sum_{n=0}^\infty \frac{f^{(n)}(a)}{n!} (x - a)^n$$
  2. **Taylor's Theorem with Lagrange Remainder Form**:
     $$f(x) = P_n(x) + R_n(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x - a)^k + \frac{f^{(n+1)}(c)}{(n+1)!}(x - a)^{n+1} \quad (c \in [a, x])$$
  3. **Canonical Maclaurin Expansions**:
     $$e^x = \sum_{n=0}^\infty \frac{x^n}{n!}, \quad \cos x = \sum_{n=0}^\infty \frac{(-1)^n x^{2n}}{(2n)!}, \quad \ln(1 + x) = \sum_{n=1}^\infty \frac{(-1)^{n-1} x^n}{n} \quad (|x| < 1)$$

* **Core Microarchitectural Concepts**:
  1. **Inverted List Imbalance & The Tail Latency Problem**:
     * In standard $k$-means, vector density variations produce severe cluster skew: median list length may be $\approx 900$ vectors, but dense clusters can exceed $8{,}000$ vectors.
     * Queries routing to dense clusters suffer an $8\times\text{--}10\times$ query latency spike, causing catastrophic $p99$ tail latency violations in production search systems.
  2. **List Rebalancing via Recursive 2-Means**:
     * Identify any cluster where $|L_k| > 2 \times \operatorname{median}(|L|)$.
     * Run a fast 2-means split on the vectors within that cluster, replacing the single centroid with 2 specialized sub-centroids to equalize posting list lengths.

     IvfStats compute_ivf_stats(const IvfFlatIndex& index) {
         std::vector<size_t> lengths(index.nlist);
         for (size_t i = 0; i < index.nlist; ++i) {
             lengths[i] = index.lists[i].size();
         }
         std::sort(lengths.begin(), lengths.end());

         double mean = std::accumulate(lengths.begin(), lengths.end(), 0.0) / index.nlist;

         for (size_t len : lengths) {
