* **Book**: *Calculus* — Gilbert Strang
* **Sections**: §5.1–5.3 (*Integration by Substitution & Change of Variables*)
* **Theorems & Mathematical Concepts**:
  1. **The Substitution Rule for Indefinite Integrals**:
     $$\int f(g(x)) g'(x) dx = \int f(u) du \quad \text{where } u = g(x), \quad du = g'(x)dx$$
  2. **Change of Limits for Definite Integrals**:
     $$\int_a^b f(g(x)) g'(x) dx = \int_{g(a)}^{g(b)} f(u) du$$
  3. **Integrals of Symmetric Functions on $[-a, a]$**:
     * If $f(-x) = -f(x)$ (odd function): $\int_{-a}^a f(x)dx = 0$.
     * If $f(-x) = f(x)$ (even function): $\int_{-a}^a f(x)dx = 2 \int_0^a f(x)dx$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Computer Systems: A Programmer's Perspective (3rd Edition)* (CS:APP §6.6) & *The Art of Writing Efficient Programs* (Pikus Ch 4)
* **Core Microarchitectural Concepts**:
  1. **Hardware Stream Prefetcher vs. Software Explicit Prefetching**:
     * Hardware Stream Prefetchers automatically detect linear sequential memory strides.
     * Software Prefetching (`_mm_prefetch`) explicitly commands the memory controller to fetch cache lines into SRAM before the CPU begins executing the loop body.
  2. **SIMD Cache Hints (`_MM_HINT_*`)**:
     * `_MM_HINT_T0`: Fetch data into all cache levels (L1, L2, L3) with temporal locality.
     * `_MM_HINT_T1` / `_MM_HINT_T2`: Fetch into L2/L3 (bypassing L1 to avoid eviction of hot query registers).
     * `_MM_HINT_NTA`: Non-Temporal Access (stream into a transient cache buffer; evicts immediately to avoid polluting cache lines on datasets $>1\text{ GB}$).
  3. **Calculating Optimal Lookahead Distance**:
     $$K_{\text{lookahead}} = \left\lceil \frac{\text{Memory Latency (cycles)}}{\text{Loop Kernel Execution Time (cycles)}} \right\rceil$$
