  2. **Taylor Series Derivation**:
     $$e^{i\theta} = \sum_{n=0}^\infty \frac{(i\theta)^n}{n!} = \sum_{k=0}^\infty \frac{(-1)^k \theta^{2k}}{(2k)!} + i \sum_{k=0}^\infty \frac{(-1)^k \theta^{2k+1}}{(2k+1)!} = \cos\theta + i\sin\theta$$
  3. **Spherical Voronoi Geometry on Hypersphere $\mathbb{S}^{d-1}$**:

       $$\arg\min_k \|x - c_k\|_2^2 = \arg\min_k (2 - 2\langle x, c_k \rangle) = \arg\max_k \langle x, c_k \rangle$$

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Text**: *Faiss: A Library for Efficient Similarity Search* (Johnson et al., 2019) & CS:APP §5.13
* **Core Microarchitectural Concepts**:
  1. **Spherical Lloyd's Algorithm for Maximum Inner Product Search (MIPS)**:
     * **Assignment Phase**: For each training vector $x_i$, compute inner products against all $K$ centroids using `ip_avx2_unrolled4` and select $k^* = \arg\max_k \langle x_i, c_k \rangle$.
     * **Update Phase**: Accumulate assigned vectors into unnormalized centroids $\tilde{c}_k = \sum_{i: a(i)=k} x_i$, then project back onto the unit sphere via SIMD normalization: $c_k = \frac{\tilde{c}_k}{\|\tilde{c}_k\|_2}$.
  2. **Multi-Threaded Centroid Assignment**:
     * Parallelizing assignment across CPU cores using OpenMP (`#pragma omp parallel for`) while keeping the centroid matrix resident in shared L3 cache.

* **Tasks & Implementation**:
  1. **Implement Spherical K-Means Trainer** in `src/index/kmeans.cpp`:
     ```cpp
     #include "secan/index/kmeans.h"
     #include "secan/distance_avx2.h"
     #include "secan/utils/normalize.h"
     #include <random>
     #include <cstring>
     #include <cmath>

     namespace secan {
     std::vector<float> train_spherical_kmeans(
         const float* data, size_t num_vectors, size_t dim,
         size_t k, size_t max_iters
     ) {
         std::vector<float> centroids(k * dim);
         std::mt19937 rng(42);
         std::uniform_int_distribution<size_t> dist(0, num_vectors - 1);

         // Randomly initialize centroids from training vectors
         for (size_t c = 0; c < k; ++c) {
             size_t idx = dist(rng);
             std::memcpy(centroids.data() + c * dim, data + idx * dim, dim * sizeof(float));
         }
         normalize_dataset_avx2(centroids.data(), k, dim);

         std::vector<float> accum(k * dim, 0.0f);
         std::vector<size_t> counts(k, 0);

         for (size_t iter = 0; iter < max_iters; ++iter) {
             std::fill(accum.begin(), accum.end(), 0.0f);
             std::fill(counts.begin(), counts.end(), 0);

             // Assignment step
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* vec = data + i * dim;
                 float max_ip = -1e9f;
                 size_t best_c = 0;

                 for (size_t c = 0; c < k; ++c) {
                     float ip = ip_avx2_unrolled4(vec, centroids.data() + c * dim, dim);
                     if (ip > max_ip) {
                         max_ip = ip;
                         best_c = c;
                     }
                 }

                 counts[best_c]++;
                 for (size_t d = 0; d < dim; ++d) {
                     accum[best_c * dim + d] += vec[d];
                 }
             }

             // Update step
             for (size_t c = 0; c < k; ++c) {
                 if (counts[c] > 0) {
                     std::memcpy(centroids.data() + c * dim, accum.data() + c * dim, dim * sizeof(float));
                 }
             }
             normalize_dataset_avx2(centroids.data(), k, dim);
         }

         return centroids;
     }
     }
     ```
