## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Primary Systems Reading**:
  * [Denis Bakhvalov, *Performance Analysis and Tuning on Modern CPUs*](https://github.com/dendibakh/perf-book) — **Ch 2 (*Performance Measurements, Warm-Up Effects & RDTSC Timings*)**
  * [Fedor G. Pikus, *The Art of Writing Efficient Programs*](https://www.packtpub.com/product/the-art-of-writing-efficient-programs/9781800208117) (Packt 2021) — **Ch 2 (*Measuring Performance Without Deceiving Yourself*)**
* **Seminal Systems Paper / Specification**:
  * [Travis Downs, *Where Do Interrupts Happen?*](https://travisdowns.github.io/blog/2019/08/20/interrupts.html) — Analyzing skid and skid-free sampling with Intel PEBS / AMD IBS.
* **Core Microarchitectural Concepts**:
  1. **Register Spilling (§5.10)**: When accumulator unrolling exceeds the CPU's architectural register file (16 YMM on x86-64), the compiler spills intermediate values to the stack, converting register-to-register operations into slower memory load/store pairs.
  2. **Branch Prediction & Conditional Moves (§5.11)**: Modern CPUs speculatively execute one branch path; mispredictions flush 15–20 in-flight instructions. Branchless `cmov` instructions eliminate misprediction penalties for simple conditionals.
  3. **Store Forwarding & Load Penalties (§5.12)**: The store buffer can forward a recently written value directly to a subsequent load without waiting for the write to reach L1 cache—but only if the load address and width match exactly.
  4. **Memory Aliasing Overhead (§5.13)**: The compiler cannot assume that `float* a` and `float* b` point to non-overlapping memory, forcing conservative load/store ordering that prevents vectorization.
  5. **Hardware Performance Monitoring Units (§5.14 + Gregg Ch 6)**: Dedicated silicon registers inside CPU cores that count microarchitectural events (IPC, cache misses, branch mispredictions) with zero overhead via `perf stat`.
