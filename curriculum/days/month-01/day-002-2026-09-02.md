## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Trigonometry* — I.M. Gelfand & Mark Saul
* **Chapter**: Chapter 3 (*Radians and Periodic Functions*)
* **Theorems & Mathematical Concepts**:
  1. **Periodicity & Fundamental Periods**:
     $$\sin(\theta + 2k\pi) = \sin\theta, \quad \cos(\theta + 2k\pi) = \cos\theta \quad (\forall k \in \mathbb{Z})$$
     $$\tan(\theta + k\pi) = \tan\theta \quad (\text{Period } T = \pi)$$
  2. **Parity (Symmetry)**:
     $$\cos(-\theta) = \cos\theta \quad (\text{Even Symmetry}), \quad \sin(-\theta) = -\sin\theta \quad (\text{Odd Symmetry})$$
  3. **Phase Shifts & Co-Function Identities**:
     $$\sin\left(\frac{\pi}{2} - \theta\right) = \cos\theta, \quad \cos\left(\frac{\pi}{2} - \theta\right) = \sin\theta$$
  4. **Sinusoidal Parameterization**: $f(t) = A \sin(\omega t + \phi)$, where amplitude is $|A|$, angular frequency is $\omega$, period is $T = \frac{2\pi}{\omega}$, and phase shift is $-\frac{\phi}{\omega}$.
* **Pencil & Paper Problem Set**:

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Computer Systems: A Programmer's Perspective (3rd Edition)* (CS:APP) — R. Bryant & D. O'Hallaron
* **Sections**: §5.1–5.6 (*Optimizing Program Performance: Loop Inefficiencies & Memory Aliasing*)
* **Core Microarchitectural Concepts**:
  1. **Cycles Per Element (CPE)**: The primary metric for quantifying inner-loop compute efficiency. How to calculate $\text{CPE} = \frac{\text{Total CPU Cycles}}{\text{Number of Elements Processed}}$.
  2. **The Memory Aliasing Bottleneck**: Why the compiler is forced to emit repeated memory loads (`movss`) inside loops when two pointers `float* a` and `float* b` might refer to overlapping memory addresses.
  3. **Loop-Invariant Code Motion**: Identifying redundant calculations inside loop conditions (e.g. repeated `vec.size()` calls) that inhibit compiler hoisting.
  4. **The `__restrict__` Compiler Contract**: Using the `__restrict__` qualifier to promise the compiler that pointers do not alias, enabling registers to cache vector elements across loop iterations.

* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Binary Vector Format Specification**:
     * `.fvecs`: Stored as repeated records: `[int32_t dim] [float32_0, ..., float32_{dim-1}]`. Total size = $N \times (4 + 4 \times d)$ bytes.
     * `.bvecs`: `[int32_t dim] [uint8_0, ..., uint8_{dim-1}]`. Total size = $N \times (4 + 1 \times d)$ bytes.
     * `.ivecs`: `[int32_t dim] [int32_0, ..., int32_{dim-1}]`. Total size = $N \times (4 + 4 \times d)$ bytes.
  2. **Implement Vector Dataset Struct & Loader** in `include/secan/utils/io.h` and `src/utils/io.cpp`:
     ```cpp
     namespace secan {
     struct FloatDataset {
         size_t num_vectors{0};
         size_t dim{0};
         std::vector<float> data; // Flat row-major contiguous memory

         const float* get(size_t index) const {
             return data.data() + index * dim;
         }
     };

     FloatDataset load_fvecs(const std::string& path);
     std::vector<std::vector<int32_t>> load_ivecs(const std::string& path);
     }
     ```
  3. **Implementation in `src/utils/io.cpp`**:
     ```cpp
     #include "secan/utils/io.h"
     #include <fstream>
     #include <stdexcept>

     namespace secan {
     FloatDataset load_fvecs(const std::string& path) {
         std::ifstream file(path, std::ios::binary);
         if (!file.is_open()) {
             throw std::runtime_error("Failed to open fvecs file: " + path);
         }
         int32_t d = 0;
         file.read(reinterpret_cast<char*>(&d), sizeof(int32_t));
         if (file.gcount() != sizeof(int32_t) || d <= 0) {
             throw std::runtime_error("Invalid fvecs header in: " + path);
         }
         file.seekg(0, std::ios::end);
         size_t file_size = file.tellg();
         size_t record_size = sizeof(int32_t) + d * sizeof(float);
         size_t n = file_size / record_size;

         FloatDataset ds;
         ds.num_vectors = n;
         ds.dim = static_cast<size_t>(d);
         ds.data.resize(n * ds.dim);

         file.seekg(0, std::ios::beg);
         for (size_t i = 0; i < n; ++i) {
             file.seekg(sizeof(int32_t), std::ios::cur); // skip dimension prefix
             file.read(reinterpret_cast<char*>(ds.data.data() + i * ds.dim), ds.dim * sizeof(float));
         }
         return ds;
     }
     }
     ```
  4. **SIFT1M Ingestion & Validation** in `tests/test_io.cpp`:
