## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §5.1–5.4 (*Lagrangian Duality, Weak/Strong Duality & Slater's Condition*)
* **Theorems & Mathematical Concepts**:
  1. **The Lagrangian & Dual Function**:
     * Lagrangian: $L(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{i=1}^p \nu_i h_i(x)$ ($\lambda \succeq 0$).
     * Lagrange Dual Function: $g(\lambda, \nu) = \inf_{x \in \mathcal{D}} L(x, \lambda, \nu)$.
     * **Theorem**: The dual function $g(\lambda, \nu)$ is concave on its domain, even if the primal problem is non-convex!
  2. **Weak Duality Theorem**:
     * For any primal feasible $\tilde{x}$ and dual feasible $(\lambda, \nu)$ ($\lambda \succeq 0$):
       $$g(\lambda, \nu) \le f_0(\tilde{x}) \implies d^* = \sup_{\lambda \succeq 0, \nu} g(\lambda, \nu) \le p^* = \inf_{x \text{ feas}} f_0(x)$$
     * Duality gap: $\Delta = p^* - d^* \ge 0$.
  3. **Strong Duality & Slater's Condition**:
     * Strong duality ($p^* = d^*$) holds for convex problems if there exists a strictly feasible point:
       $$\exists x \in \operatorname{relint}(\mathcal{D}) \quad \text{such that} \quad f_i(x) < 0 \; (i=1,\dots,m), \quad A x = b$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive Weak Duality $d^* \le p^*$: For feasible $\tilde{x}$, $f_i(\tilde{x}) \le 0$ and $h_i(\tilde{x}) = 0$, so $\sum \lambda_i f_i(\tilde{x}) + \sum \nu_i h_i(\tilde{x}) \le 0$, yielding $g(\lambda, \nu) \le L(\tilde{x}, \lambda, \nu) \le f_0(\tilde{x})$.
  - [ ] **Proof 2**: Derive the Lagrange dual of standard Linear Program $\min c^T x \text{ s.t. } A x = b, x \ge 0$: show $L(x, \lambda, \nu) = (c - A^T \nu - \lambda)^T x + b^T \nu$, giving dual $\max b^T \nu \text{ s.t. } A^T \nu \le c$.
  - [ ] **Problem 3**: For minimum-energy vector projection $\min \frac{1}{2}\|x\|_2^2 \text{ s.t. } A x = b$, compute $g(\nu) = -\frac{1}{2}\nu^T A A^T \nu - b^T \nu$, solve $\nabla_\nu g(\nu^*) = 0 \implies \nu^* = -(A A^T)^{-1}b$, and reconstruct primal optimal vector $x^* = A^T(A A^T)^{-1}b$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Degree-Constrained Graph Sparsification: Converting NN-Descent Graphs to 32-Degree CAGRA Layouts*
* **Core Microarchitectural Concepts**:
  1. **Fixed-Degree Graph Pruning**:
     * Raw NN-Descent produces variable-degree graphs ($K \in [32, 64]$) with redundant transitive edges.
     * Fixed degree $d_{\text{out}} = 32$ is strictly required on GPU so that one warp of 32 threads loads all outgoing neighbor pointers in a single coalesced 128-byte memory transaction.
  2. **Relative Neighborhood Graph (RNG) $\alpha$-Pruning**:
     * Retain edge $(u, v)$ only if $\operatorname{dist}(u, v) \le \alpha \cdot \max(\operatorname{dist}(u, w), \operatorname{dist}(w, v))$ for all common neighbors $w$.
     * Prunes clustered redundant edges while preserving global graph diameter.
