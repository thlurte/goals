## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Degree-Constrained Graph Sparsification: Converting NN-Descent Graphs to 32-Degree CAGRA Layouts*
* **Core Microarchitectural Concepts**:
  1. **Fixed-Degree Graph Pruning**:
     * Raw NN-Descent produces variable-degree graphs ($K \in [32, 64]$) with redundant transitive edges.
     * Fixed degree $d_{\text{out}} = 32$ is strictly required on GPU so that one warp of 32 threads loads all outgoing neighbor pointers in a single coalesced 128-byte memory transaction.
  2. **Relative Neighborhood Graph (RNG) $\alpha$-Pruning**:
     * Retain edge $(u, v)$ only if $\operatorname{dist}(u, v) \le \alpha \cdot \max(\operatorname{dist}(u, w), \operatorname{dist}(w, v))$ for all common neighbors $w$.
     * Prunes clustered redundant edges while preserving global graph diameter.
