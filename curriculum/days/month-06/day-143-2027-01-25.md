## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *ColBERT & ColPali: Fusing Batched Tensor Core GEMM with Warp MaxSim Reductions*
* **Core Microarchitectural Concepts**:
  1. **The Late-Interaction MaxSim Operator**:
     $$\operatorname{MaxSim}(Q, D) = \sum_{i=1}^{L_q} \max_{j=1}^{L_d} \left( \mathbf{q}_i^T \mathbf{d}_j \right)$$
     * For ColPali image documents: $L_q = 32$ query tokens, $L_d = 1{,}030$ visual patch tokens, $d = 128$.
  2. **GPU Fused Kernel Execution**:
     * Rather than materializing the intermediate $32 \times 1030$ similarity matrix in DRAM, compute $Q D^T$ via Tensor Cores in shared memory.
     * Perform warp shuffle row-max reduction across $L_d$ elements in registers, accumulating the scalar MaxSim score with zero global memory writes.

* **Tasks & Implementation**:
  1. **Implement Fused GPU MaxSim Kernel** in `include/secan/gpu/gpu_maxsim.cuh`:
     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>
     #include <algorithm>

     namespace secan {
     __global__ void fused_gpu_maxsim_kernel(
         const float* __restrict__ queries,     // [B, L_q, D]
         const float* __restrict__ documents,   // [B, L_d, D]
         float* __restrict__ scores,            // [B]
         int L_q,
         int L_d,
         int D
     ) {
         size_t b = blockIdx.x;
         size_t q_idx = blockIdx.y; // 0 to L_q - 1
         size_t tid = threadIdx.x;

         const float* q_vec = queries + (b * L_q + q_idx) * D;
         const float* d_block = documents + b * (L_d * D);

         float local_max = -1e30f;

         // Thread block scans across L_d document tokens
         for (int d_idx = tid; d_idx < L_d; d_idx += blockDim.x) {
             const float* d_vec = d_block + d_idx * D;
             float dot = 0.0f;
             #pragma unroll
             for (int k = 0; k < D; ++k) {
                 dot += q_vec[k] * d_vec[k];
             }
             local_max = fmaxf(local_max, dot);
         }

         // Warp shuffle reduction for row maximum
         for (int offset = 16; offset > 0; offset /= 2) {
             local_max = fmaxf(local_max, __shfl_down_sync(0xffffffff, local_max, offset));
         }

         if (tid == 0) {
             atomicAdd(&scores[b], local_max);
         }
     }
     }
     ```
