* **Core Microarchitectural Concepts**:
  1. **Visual Document Token Geometry**:
     * Input page image ($448 \times 448$) produces $32 \times 32 = 1{,}024$ spatial patch tokens $+ 6$ prefix tokens $= 1{,}030$ multi-vector embeddings per document.
     * In FP16 ($d = 128$), one document occupies $1{,}030 \times 128 \times 2\text{ bytes} = 263.7\text{ KB}$.
  2. **Multi-Stream Asynchronous Pipeline**:
     * Stream 0: Transfer next candidate document token chunk from Host pinned memory to Device VRAM (`cudaMemcpyAsync`).
     * Stream 1: Execute `fused_gpu_maxsim_kernel` on current resident document tokens.
     * Overlaps PCIe transfer with Tensor Core MaxSim computation, eliminating data movement stalls.

     ```python
     import torch
     import torch.nn as nn
     import torch.nn.functional as F

     class ColPaliProjector(nn.Module):
         def __init__(self, vision_dim: int = 768, proj_dim: int = 128):
             super().__init__()
             self.linear_proj = nn.Linear(vision_dim, proj_dim, bias=False)

         def forward(self, vision_patch_tokens: torch.Tensor) -> torch.Tensor:
             """
             Project raw ViT visual patch embeddings to normalized ColPali multi-vector space.
             """
             projected = self.linear_proj(vision_patch_tokens) # [B, 1030, 128]
             return F.normalize(projected, p=2, dim=-1)

     def compute_colpali_maxsim(
         query_tokens: torch.Tensor,   # [B_q, L_q, D]
         doc_page_tokens: torch.Tensor # [B_d, L_d, D]
     ) -> torch.Tensor:
         """
         Compute exact ColPali late-interaction MaxSim score matrix [B_q, B_d].
         """
         # [B_q, L_q, D] x [B_d, L_d, D] -> [B_q, B_d, L_q, L_d]
         sim_matrix = torch.einsum("qid,pjd->qpid", query_tokens, doc_page_tokens)
         max_scores_per_query_token = sim_matrix.max(dim=-1).values # [B_q, B_d, L_q]
         return max_scores_per_query_token.sum(dim=-1) # [B_q, B_d]
     ```
