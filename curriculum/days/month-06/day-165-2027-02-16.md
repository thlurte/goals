## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Guide**: *CUDA Occupancy Tuning: Register Allocation, Shared Memory Limits & `__launch_bounds__`*
* **Core Microarchitectural Concepts**:
  1. **Streaming Multiprocessor (SM) Resource Allocation**:
     * SM Limits (Ada Lovelace / Hopper): 64K 32-bit registers, 100 KB shared memory, 48 active warps (1536 threads).
     * If a kernel uses 48 registers/thread $\implies 1536 \times 48 = 73{,}728 > 65{,}536 \implies$ occupancy collapses to 32 warps ($66\%$).
  2. **`__launch_bounds__(maxThreadsPerBlock, minBlocksPerMultiprocessor)`**:
     * Enforces compiler register ceiling, preventing spilled registers while guaranteeing $\ge 2$ active blocks per SM for complete memory latency hiding.

     ```python
     import torch
     import torch.nn as nn
     import torch.nn.functional as F
     from typing import List, Tuple

     class DualEncoder(nn.Module):
         def __init__(self, vocab_size: int = 10000, embed_dim: int = 128):
             super().__init__()
             self.token_embed = nn.Embedding(vocab_size, embed_dim)
             self.proj = nn.Linear(embed_dim, embed_dim, bias=False)

         def forward(self, token_ids: torch.Tensor) -> torch.Tensor:
             # Mean-pooled token embeddings normalized to unit sphere
             embeds = self.token_embed(token_ids)
             pooled = torch.mean(embeds, dim=1)
             return F.normalize(self.proj(pooled), p=2, dim=-1)

     def compute_infonce_loss(q_embeds: torch.Tensor, k_pos_embeds: torch.Tensor, tau: float = 0.07) -> torch.Tensor:
         # [B, B] similarity logits
         logits = torch.matmul(q_embeds, k_pos_embeds.T) / tau
         labels = torch.arange(q_embeds.shape[0], device=q_embeds.device)
         return F.cross_entropy(logits, labels)
     ```
