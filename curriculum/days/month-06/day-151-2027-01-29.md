* **Core Microarchitectural Concepts**:
  1. **NUMA Memory Allocation Policies**:
     * Linux default `first-touch` allocates pages on the node executing the initialization thread, causing all other CPU sockets to incur remote UPI read stalls ($>2\times$ latency penalty).
     * Solution: Duplicate index or partition vector segments across sockets using explicit `numa_alloc_onnode(size, socket_id)`.
  2. **Core Affinity & Thread Pinning**:
     * Bind worker thread pools to specific socket CPU cores via `pthread_setaffinity_np()`, eliminating thread migration across socket boundaries.
  3. **False Sharing Detection via `perf c2c`**:
     * Measure HITM (Hit in Modified Cache) cache-line bouncing across sockets via `perf c2c record -- ./bin/bench_hnsw_search --threads=32`. Pad thread accumulators with `alignas(64)`.

  1. **Implement NUMA-Aware Vector Allocator & Thread Pool** in `include/secan/numa/numa_allocator.h`:
     ```cpp
     #pragma once
     #include <numa.h>
     #include <numaif.h>
     #include <pthread.h>
     #include <vector>
     #include <stdexcept>

     namespace secan {
     class NumaVectorStorage {
     private:
         int numa_node;
         size_t total_bytes;
         float* data_ptr{nullptr};

     public:
         NumaVectorStorage(size_t num_vectors, size_t dim, int node) 
             : numa_node(node), total_bytes(num_vectors * dim * sizeof(float)) {
             if (numa_available() < 0) {
                 data_ptr = static_cast<float*>(std::aligned_alloc(64, total_bytes));
             } else {
                 data_ptr = static_cast<float*>(numa_alloc_onnode(total_bytes, numa_node));
                 if (!data_ptr) throw std::runtime_error("NUMA allocation failed!");
             }
         }

         ~NumaVectorStorage() {
             if (data_ptr) {
                 if (numa_available() < 0) std::free(data_ptr);
                 else numa_free(data_ptr, total_bytes);
             }
         }

         float* get() { return data_ptr; }
         const float* get() const { return data_ptr; }

         static void pin_current_thread_to_node(int node) {
             if (numa_available() >= 0) {
                 struct bitmask* mask = numa_allocate_cpumask();
                 numa_node_to_cpus(node, mask);
                 numa_bind(mask);
                 numa_free_cpumask(mask);
             }
         }
     };
     }
     ```
