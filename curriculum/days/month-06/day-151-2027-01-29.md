## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §10.1–10.3 (*Equality Constrained Minimization & The Constrained Newton Step*)
* **Theorems & Mathematical Concepts**:
  1. **Equality-Constrained Convex Problem**:
     $$\min_{x} f(x) \quad \text{subject to} \quad A x = b$$
     * Optimality condition: $A x^* = b$ and $\nabla f(x^*) + A^T \nu^* = \mathbf{0}$.
  2. **The KKT Matrix System for Constrained Newton Step**:
     $$\begin{bmatrix} \nabla^2 f(x) & A^T \\ A & 0 \end{bmatrix} \begin{bmatrix} \Delta x_{\text{nt}} \\ \nu \end{bmatrix} = \begin{bmatrix} -\nabla f(x) \\ 0 \end{bmatrix}$$
     * **Non-singularity Theorem**: The KKT matrix is invertible if $\nabla^2 f(x) \succ 0$ on $\operatorname{null}(A)$ and $A$ has full row rank.
  3. **NUMA Interconnect Latency & Congestion Model**:
     * Socket-local DRAM access: $T_{\text{local}} \approx 65\text{ ns}$ at $204.8\text{ GB/s}$ peak bandwidth.
     * Cross-socket UPI / QPI remote DRAM access: $T_{\text{remote}} \approx 140\text{ ns}$ at $41.6\text{ GB/s}$ interconnect limit.
     * Effective memory access time with local hit fraction $\rho$:
       $$T_{\text{eff}} = \rho T_{\text{local}} + (1 - \rho) T_{\text{remote}}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the constrained Newton KKT system by setting the gradient of the quadratic Taylor approximation Lagrangian $L(\Delta x, \nu) = f(x) + \nabla f(x)^T \Delta x + \frac{1}{2}\Delta x^T \nabla^2 f(x) \Delta x + \nu^T (A(x + \Delta x) - b)$ to zero.
  - [ ] **Proof 2**: Prove that eliminating equality constraints via $x = F z + \hat{x}$ produces reduced gradient $\nabla \tilde{f}(z) = F^T \nabla f(F z + \hat{x})$ and reduced Hessian $\nabla^2 \tilde{f}(z) = F^T \nabla^2 f(F z + \hat{x}) F \succ 0$.
  - [ ] **Problem 3**: On a 2-socket server running 64 concurrent query threads, compute $T_{\text{eff}}$ under (a) interleaved memory $\rho = 0.50$ ($T_{\text{eff}} = 102.5\text{ ns}$) vs (b) NUMA-pinned local memory $\rho = 0.98$ ($T_{\text{eff}} = 66.5\text{ ns}$), showing a $35\%$ latency speedup.

* **Tasks & Implementation**:
  1. **Implement NUMA-Aware Vector Allocator & Thread Pool** in `include/secan/numa/numa_allocator.h`:
     ```cpp
     #pragma once
     #include <numa.h>
     #include <numaif.h>
     #include <pthread.h>
     #include <vector>
     #include <stdexcept>

     namespace secan {
     class NumaVectorStorage {
     private:
         int numa_node;
         size_t total_bytes;
         float* data_ptr{nullptr};

     public:
         NumaVectorStorage(size_t num_vectors, size_t dim, int node) 
             : numa_node(node), total_bytes(num_vectors * dim * sizeof(float)) {
             if (numa_available() < 0) {
                 data_ptr = static_cast<float*>(std::aligned_alloc(64, total_bytes));
             } else {
                 data_ptr = static_cast<float*>(numa_alloc_onnode(total_bytes, numa_node));
                 if (!data_ptr) throw std::runtime_error("NUMA allocation failed!");
             }
         }

         ~NumaVectorStorage() {
             if (data_ptr) {
                 if (numa_available() < 0) std::free(data_ptr);
                 else numa_free(data_ptr, total_bytes);
             }
         }

         float* get() { return data_ptr; }
         const float* get() const { return data_ptr; }

         static void pin_current_thread_to_node(int node) {
             if (numa_available() >= 0) {
                 struct bitmask* mask = numa_allocate_cpumask();
                 numa_node_to_cpus(node, mask);
                 numa_bind(mask);
                 numa_free_cpumask(mask);
             }
         }
     };
     }
     ```
