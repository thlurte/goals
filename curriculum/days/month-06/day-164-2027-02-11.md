## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §11.8 (*Primal-Dual Line Search*) & Discrete Fourier Analysis (*Circulant Matrices & Convolutions*)
* **Theorems & Mathematical Concepts**:
  1. **Primal-Dual Line Search & Residual Descent**:
     * Maximum step size preserving $\lambda \succ 0$: $\alpha_{\max} = \min \left\{ 1, \; \min_{i: \Delta \lambda_i < 0} \left( -\frac{\lambda_i}{\Delta \lambda_i} \right) \right\}$.
     * Backtrack $\alpha \leftarrow \beta \alpha$ until:
       $$\|r(x + \alpha \Delta x, \lambda + \alpha \Delta \lambda, \nu + \alpha \Delta \nu)\|_2 \le (1 - \gamma \alpha) \|r(x, \lambda, \nu)\|_2$$
     * **Descent Property**: The primal-dual direction satisfies $\left. \frac{d}{d\alpha} \|r\|_2^2 \right|_{\alpha=0} = -2 \|r\|_2^2 < 0$.
  2. **Circulant Matrix Diagonalization Theorem**:
     * Circular convolution $\mathbf{y} = \mathbf{h} * \mathbf{x} \iff \mathbf{y} = C(\mathbf{h})\mathbf{x}$.
     * Every circulant matrix $C(\mathbf{h})$ is diagonalized by the Discrete Fourier Transform matrix $F$:
       $$C(\mathbf{h}) = F^{-1} \operatorname{diag}(F \mathbf{h}) F$$
     * Transforms $\mathcal{O}(n^2)$ matrix-vector products into $\mathcal{O}(n \log n)$ point-wise multiplications in the frequency domain.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Circulant Diagonalization Theorem: Show that DFT basis vectors $\mathbf{v}_k = \frac{1}{\sqrt{n}}[1, \omega^k, \dots, \omega^{(n-1)k}]^T$ ($\omega = e^{-i 2\pi/n}$) are exact eigenvectors of $C(\mathbf{h})$ with eigenvalues $\lambda_k = (F \mathbf{h})_k$.
  - [ ] **Proof 2**: Prove that the derivative of the squared residual norm along the primal-dual direction is strictly negative: $\nabla \|r\|_2^2 \cdot \Delta = -2 r^T r = -2 \|r\|_2^2$.
  - [ ] **Problem 3**: For vector $\mathbf{h} = [2, 1, 0, 1]^T$, write down the $4 \times 4$ circulant matrix $C(\mathbf{h})$ and compute all 4 eigenvalues $\lambda \in \{4, 2, 0, 2\}$ using the 4-point DFT.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Fused GPU Operators: Eliminating Intermediate DRAM Traffic with Warp Bitonic Selection*
* **Core Microarchitectural Concepts**:
  1. **The Intermediate VRAM Memory Wall**:
     * Traditional pipeline: Distance kernel writes $N \times 4\text{ bytes}$ intermediate scores to VRAM $\to$ Top-$k$ kernel reads $N \times 4\text{ bytes}$ back to sort.
     * At $N = 10^6$ vectors, $8\text{ MB}$ DRAM traffic stalls the GPU memory bus on every query.
  2. **Fused Register-Level Bitonic Top-$k$**:
     * Threads evaluate vector distances directly in FP32 registers.
     * Thread warps maintain a running local top-$k$ min-heap or bitonic sort network in registers using `__shfl_xor_sync`, completely bypassing global memory roundtrips ($>2.8\times$ latency speedup).
