## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Spectral Graph Theory* — Daniel A. Spielman / Fan Chung
* **Sections**: §1.4–1.6 (*The Normalized Graph Laplacian, Eigenvalue Bounds & Bipartiteness*)
* **Theorems & Mathematical Concepts**:
  1. **The Normalized Graph Laplacian**:
     $$\mathcal{L} = D^{-1/2} L D^{-1/2} = I - D^{-1/2} A D^{-1/2}$$
     * Quadratic Form:
       $$\mathbf{x}^T \mathcal{L} \mathbf{x} = \sum_{(u, v) \in E} \left( \frac{x_u}{\sqrt{d_u}} - \frac{x_v}{\sqrt{d_v}} \right)^2$$
  2. **Universal Eigenvalue Bounds**:
     $$0 = \lambda_1 \le \lambda_2 \le \dots \le \lambda_n \le 2$$
     * Trivial lower eigenpair: $\lambda_1 = 0$ with eigenvector $\mathbf{v}_1 = D^{1/2}\mathbf{1}$.
  3. **Bipartite Spectrum Theorem**:
     * **Theorem**: $\lambda_n = 2 \iff G$ contains a non-trivial bipartite connected component.
     * For bipartite graphs, the spectrum is symmetric around $1$: $\lambda_k = 2 - \lambda_{n-k+1}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the quadratic form identity $\mathbf{x}^T \mathcal{L} \mathbf{x} = \sum_{(u, v) \in E} \left( \frac{x_u}{\sqrt{d_u}} - \frac{x_v}{\sqrt{d_v}} \right)^2$ by setting $\mathbf{y} = D^{-1/2}\mathbf{x}$ in the standard Laplacian quadratic form $\mathbf{y}^T L \mathbf{y}$.
  - [ ] **Proof 2**: Prove the upper bound $\lambda_n \le 2$: use $(a - b)^2 \le 2(a^2 + b^2)$ to show $\mathbf{x}^T \mathcal{L} \mathbf{x} \le 2 \sum_{(u, v) \in E} \left( \frac{x_u^2}{d_u} + \frac{x_v^2}{d_v} \right) = 2 \sum_{u \in V} x_u^2 = 2 \|\mathbf{x}\|_2^2$.
  - [ ] **Problem 3**: On the complete bipartite graph $K_{m, n}$, write down the $A$ and $D$ matrices and derive the spectrum of $\mathcal{L}$: show that $\lambda_1 = 0$, $\lambda_2 = \dots = \lambda_{m+n-1} = 1$, and $\lambda_{m+n} = 2$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Guide**: *ARM NEON Instruction Pipeline Optimization: Overcoming FMA Latency with 4-Way Accumulator Unrolling*
* **Core Microarchitectural Concepts**:
  1. **FMA Instruction Latency & Port Saturation**:
     * `vfmaq_f32` has a latency of 4 cycles and a throughput of 1 instruction/cycle per NEON pipe.
     * Accumulating into a single `float32x4_t` variable introduces a 4-cycle loop-carried dependency stall.
  2. **4-Way Register Unrolling**:
     * Maintain 4 independent accumulator vectors (`acc0`, `acc1`, `acc2`, `acc3`), processing 16 floats (64 bytes = 1 full cache line) per loop iteration.
     * Interleaves FMAs without stalling execution ports, achieving peak theoretical FLOPS on ARM64.

     ```cpp
     #pragma once
     #if defined(__ARM_NEON) || defined(__aarch64__)
     #include <arm_neon.h>
     #include <cstddef>

     namespace secan::simd {
     inline float l2_squared_neon(const float* a, const float* b, size_t dim) {
         float32x4_t acc0 = vdupq_n_f32(0.0f);
         float32x4_t acc1 = vdupq_n_f32(0.0f);
         float32x4_t acc2 = vdupq_n_f32(0.0f);
         float32x4_t acc3 = vdupq_n_f32(0.0f);

         size_t i = 0;
         for (; i + 15 < dim; i += 16) {
             float32x4_t va0 = vld1q_f32(a + i);
             float32x4_t vb0 = vld1q_f32(b + i);
             float32x4_t diff0 = vsubq_f32(va0, vb0);
             acc0 = vfmaq_f32(acc0, diff0, diff0);

             float32x4_t va1 = vld1q_f32(a + i + 4);
             float32x4_t vb1 = vld1q_f32(b + i + 4);
             float32x4_t diff1 = vsubq_f32(va1, vb1);
             acc1 = vfmaq_f32(acc1, diff1, diff1);

             float32x4_t va2 = vld1q_f32(a + i + 8);
             float32x4_t vb2 = vld1q_f32(b + i + 8);
             float32x4_t diff2 = vsubq_f32(va2, vb2);
             acc2 = vfmaq_f32(acc2, diff2, diff2);

             float32x4_t va3 = vld1q_f32(a + i + 12);
             float32x4_t vb3 = vld1q_f32(b + i + 12);
             float32x4_t diff3 = vsubq_f32(va3, vb3);
             acc3 = vfmaq_f32(acc3, diff3, diff3);
         }

         float32x4_t acc = vaddq_f32(vaddq_f32(acc0, acc1), vaddq_f32(acc2, acc3));
         float sum = vaddvq_f32(acc);

         // Handle scalar tail
         for (; i < dim; ++i) {
             float d = a[i] - b[i];
             sum += d * d;
         }
         return sum;
     }
     }
     #endif
     ```
