## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §3.1–3.4 (*Convex Functions, First/Second-Order Conditions & Epigraphs*)
* **Theorems & Mathematical Concepts**:
  1. **Convex Function Definition**:
     * $f: \mathbb{R}^n \to \mathbb{R}$ is convex if $\operatorname{dom} f$ is convex and $\forall x, y \in \operatorname{dom} f, \theta \in [0, 1]$:
       $$f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y)$$
  2. **First-Order & Second-Order Conditions**:
     * **First-Order (Differentiable)**: $f(y) \ge f(x) + \nabla f(x)^T (y - x)$ for all $x, y$. (Tangent hyperplane is a global underestimator).
     * **Second-Order (Twice Differentiable)**: $\nabla^2 f(x) \succeq 0$ for all $x \in \operatorname{dom} f$.
  3. **Epigraph & Sublevel Sets**:
     * $\operatorname{epi} f = \{(x, t) \in \mathbb{R}^{n+1} \mid x \in \operatorname{dom} f, f(x) \le t\}$.
     * **Theorem**: $f$ is convex $\iff \operatorname{epi} f$ is a convex set.
     * All $\alpha$-sublevel sets $S_\alpha = \{x \in \operatorname{dom} f \mid f(x) \le \alpha\}$ of a convex function are convex.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the first-order condition: from $f(x + \theta(y-x)) \le (1-\theta)f(x) + \theta f(y)$, divide by $\theta > 0$ to get $\frac{f(x + \theta(y-x)) - f(x)}{\theta} \le f(y) - f(x)$, and take the limit $\theta \to 0^+$.
  - [ ] **Proof 2**: Prove that the quadratic function $f(x) = \frac{1}{2} x^T P x + q^T x + r$ is convex if and only if the matrix $P$ is positive semidefinite ($P \succeq 0$).
  - [ ] **Problem 3**: In InfoNCE / softmax contrastive loss, the log-sum-exp function is $f(\mathbf{x}) = \ln\left(\sum_{i=1}^m e^{x_i}\right)$. Prove that $f$ is convex by computing its Hessian $\nabla^2 f(\mathbf{x}) = \operatorname{diag}(\mathbf{z}) - \mathbf{z}\mathbf{z}^T$ (where $z_i = \frac{e^{x_i}}{\sum e^{x_k}}$) and using Cauchy-Schwarz to show $\mathbf{v}^T \nabla^2 f(\mathbf{x}) \mathbf{v} = \sum z_i v_i^2 - (\sum z_i v_i)^2 \ge 0$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *ColPali: Efficient Document Retrieval with Vision Language Models & GPU MaxSim*
* **Core Microarchitectural Concepts**:
  1. **Visual Document Token Geometry**:
     * Input page image ($448 \times 448$) produces $32 \times 32 = 1{,}024$ spatial patch tokens $+ 6$ prefix tokens $= 1{,}030$ multi-vector embeddings per document.
     * In FP16 ($d = 128$), one document occupies $1{,}030 \times 128 \times 2\text{ bytes} = 263.7\text{ KB}$.
  2. **Multi-Stream Asynchronous Pipeline**:
     * Stream 0: Transfer next candidate document token chunk from Host pinned memory to Device VRAM (`cudaMemcpyAsync`).
     * Stream 1: Execute `fused_gpu_maxsim_kernel` on current resident document tokens.
     * Overlaps PCIe transfer with Tensor Core MaxSim computation, eliminating data movement stalls.
