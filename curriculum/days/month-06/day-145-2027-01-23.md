## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §5.5 (*The Karush-Kuhn-Tucker (KKT) Optimality Conditions*)
* **Theorems & Mathematical Concepts**:
  1. **The Four KKT Conditions**:
     * **Primal Feasibility**: $f_i(x^*) \le 0 \; (i=1,\dots,m), \quad A x^* = b$.
     * **Dual Feasibility**: $\lambda_i^* \ge 0 \; (i=1,\dots,m)$.
     * **Complementary Slackness**: $\lambda_i^* f_i(x^*) = 0 \; (i=1,\dots,m) \implies (\lambda_i^* > 0 \implies f_i(x^*) = 0)$.
     * **Stationarity**: $\nabla f_0(x^*) + \sum_{i=1}^m \lambda_i^* \nabla f_i(x^*) + A^T \nu^* = \mathbf{0}$.
  2. **Sufficiency & Necessity Theorems**:
     * **Sufficiency**: If $f_0, \dots, f_m$ are convex and $(x^*, \lambda^*, \nu^*)$ satisfy KKT, then $x^*$ is guaranteed to be a **global primal optimum** ($p^* = d^*$).
     * **Necessity**: If a convex problem satisfies Slater's condition, any optimal $x^*$ must satisfy KKT for some $(\lambda^*, \nu^*)$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove KKT sufficiency: Show that since $L(x, \lambda^*, \nu^*)$ is convex in $x$ and $\nabla_x L(x^*) = 0$, $x^*$ minimizes $L$. Then for any feasible $x$: $f_0(x) \ge L(x, \lambda^*, \nu^*) \ge L(x^*, \lambda^*, \nu^*) = f_0(x^*) + \sum \lambda_i^* f_i(x^*) = f_0(x^*)$.
  - [ ] **Proof 2**: Use KKT conditions to derive the analytical **Water-Filling Solution** for optimal resource allocation: $\min -\sum_{i=1}^n \ln(\alpha_i + x_i) \text{ s.t. } x_i \ge 0, \sum x_i = P$, showing $x_i^* = \max\left(0, \frac{1}{\nu^*} - \alpha_i\right)$.
  - [ ] **Problem 3**: Solve the constrained Euclidean vector projection $\min \frac{1}{2}\|x - y\|_2^2 \text{ s.t. } a^T x \le b$ using KKT stationarity $\nabla_x L = x - y + \lambda a = 0 \implies x = y - \lambda a$, proving that $x^* = y - \max\left(0, \frac{a^T y - b}{\|a\|_2^2}\right) a$.
