## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §9.5–9.7 (*Newton's Method, The Newton Decrement & Affine Invariance*)
* **Theorems & Mathematical Concepts**:
  1. **The Newton Step & Decrement**:
     * Newton Step: $\Delta x_{\text{nt}} = -(\nabla^2 f(x))^{-1} \nabla f(x)$.
     * Newton Decrement:
       $$\lambda(x) = \left( \nabla f(x)^T (\nabla^2 f(x))^{-1} \nabla f(x) \right)^{1/2} = \|\nabla f(x)\|_{\nabla^2 f(x)^{-1}}$$
     * **Suboptimality Bound**: $f(x) - p^* \le \frac{1}{2}\lambda(x)^2$, yielding the universal stopping criterion $\frac{1}{2}\lambda(x)^2 \le \epsilon$.
  2. **Affine Invariance Theorem**:
     * Let $y = T x$ ($T$ invertible) and define $\bar{f}(y) = f(T^{-1}y)$.
     * The Newton step transforms contravariantly: $\Delta y_{\text{nt}} = T \Delta x_{\text{nt}}$.
     * The Newton decrement is strictly invariant: $\bar{\lambda}(y) = \lambda(x)$.
     * (Newton's method is immune to coordinate scaling and ill-conditioning).
  3. **Amortized Graph Deletion Theory**:
     * Immediate edge repair upon deletion costs $\mathcal{O}(M^2)$ distance evaluations.
     * Soft-deletion via atomic tombstone bitset costs $\mathcal{O}(1)$.
     * Periodic background vacuuming at tombstone threshold $\tau = 10\%$ restores optimal graph connectivity with amortized $\mathcal{O}(M)$ cost per deleted node.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Affine Invariance Theorem: Compute $\nabla \bar{f}(y) = T^{-T}\nabla f(x)$ and $\nabla^2 \bar{f}(y) = T^{-T}\nabla^2 f(x) T^{-1}$. Invert the Hessian to show $\Delta y_{\text{nt}} = -(\nabla^2 \bar{f}(y))^{-1}\nabla \bar{f}(y) = T \Delta x_{\text{nt}}$.
  - [ ] **Proof 2**: Prove that the quadratic Taylor approximation error $f(x) - \inf_y \left( f(x) + \nabla f(x)^T(y-x) + \frac{1}{2}(y-x)^T \nabla^2 f(x)(y-x) \right)$ is exactly equal to $\frac{1}{2}\lambda(x)^2$.
  - [ ] **Problem 3**: In an HNSW index with $N = 10^6$ vectors and degree $M = 32$, compare total computational operations for 100K deletions: (a) Immediate graph edge rewiring ($10^5 \times 32^2 \approx 1.02 \times 10^8$ operations), vs (b) Atomic bitset tombstones with a single batch vacuum pass ($3.2 \times 10^7$ operations, $>3.1\times$ computational reduction).

* **Tasks & Implementation**:
  1. **Implement Tombstone Manager & Vacuum Rewirer** in `include/secan/hnsw/tombstone_vacuum.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <atomic>
     #include <cstdint>
     #include <memory>

     namespace secan {
     class TombstoneManager {
     private:
         size_t total_capacity;
         std::vector<std::atomic<uint64_t>> tombstone_words;
         std::atomic<size_t> deleted_count{0};

     public:
         TombstoneManager(size_t capacity) 
             : total_capacity(capacity), tombstone_words((capacity + 63) / 64) {
             for (auto& w : tombstone_words) w.store(0, std::memory_order_relaxed);
         }

         void mark_deleted(uint32_t node_id) {
             size_t word_idx = node_id / 64;
             uint64_t bit_mask = 1ULL << (node_id % 64);
             uint64_t prev = tombstone_words[word_idx].fetch_or(bit_mask, std::memory_order_relaxed);
             if (!(prev & bit_mask)) {
                 deleted_count.fetch_add(1, std::memory_order_relaxed);
             }
         }

         inline bool is_deleted(uint32_t node_id) const {
             size_t word_idx = node_id / 64;
             uint64_t bit_mask = 1ULL << (node_id % 64);
             return (tombstone_words[word_idx].load(std::memory_order_relaxed) & bit_mask) != 0;
         }

         float tombstone_ratio() const {
             return static_cast<float>(deleted_count.load()) / total_capacity;
         }
     };
     }
     ```
