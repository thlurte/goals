## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §9.1–9.3 (*Unconstrained Minimization, Descent Methods & Strong Convexity*)
* **Theorems & Mathematical Concepts**:
  1. **Strong Convexity & Hessian Bounds**:
     * $f$ is strongly convex on $S$ if $\exists m > 0$ such that $\nabla^2 f(x) \succeq m I$ for all $x \in S$.
     * Upper bound on curvature: $\exists M \ge m$ such that $\nabla^2 f(x) \preceq M I$.
     * Condition Number of sublevel sets: $\kappa = \frac{M}{m} \ge 1$.
  2. **Suboptimality Bound Theorem**:
     $$f(x) - p^* \le \frac{1}{2m} \|\nabla f(x)\|_2^2$$
     * **Derivation**: Strong convexity gives $f(y) \ge f(x) + \nabla f(x)^T (y - x) + \frac{m}{2} \|y - x\|_2^2$. Minimizing over $y$ yields $\tilde{y} = x - \frac{1}{m}\nabla f(x)$, giving $p^* \ge f(x) - \frac{1}{2m}\|\nabla f(x)\|_2^2$.
  3. **Mathematical Model of Filtered Graph Recall Collapse**:
     * In a regular graph of degree $d$, under independent Bernoulli filter selectivity $\sigma = P(\text{pass})$, the probability that a node has zero valid outgoing edges is:
       $$P(\text{Isolated}) = (1 - \sigma)^d$$
     * For $d = 32$ and $\sigma = 0.01$ ($1\%$), $P(\text{Isolated}) = (0.99)^{32} \approx 72.5\%$, proving why post-filtering graph search terminates prematurely.
* **Pencil & Paper Problem Set**:

  - [ ] **Proof 2**: Prove that the condition number $\kappa = M/m$ bounds the ratio of the major to minor axes of the sublevel set ellipsoids: $\sqrt{M/m}$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *ACORN: Performant and Predicate-Aware Vector Search* (Patel et al., SIGMOD 2024) §1–3
* **Core Microarchitectural Concepts**:
  1. **The Filtered Search Dilemma**:
     * **Pre-Filtering (Payload First)**: Scans B-tree / inverted list for matching metadata IDs, then runs brute-force SIMD distance scan over matching vectors. Highly efficient for selective queries ($\sigma < 0.1\%$), but prohibitively slow at high selectivity ($\sigma > 10\%$).
     * **Post-Filtering (Vector First)**: Runs standard HNSW beam search to find $K'$ nearest vectors, discarding points failing the predicate mask. Fails completely when $\sigma < 1\%$ because graph edges do not follow predicate partitions.
  2. **Memory Access Bottlenecks in Metadata Filtering**:
     * Intersecting document IDs with vector registers requires tight cache locality: 64-bit word bitmasks aligned to 64-byte L1 cache lines avoid branch mispredictions.

  1. **Implement Metadata Payload Index in C++20** in `include/secan/predicate/payload_index.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <unordered_map>
     #include <cstdint>
     #include <algorithm>

     namespace secan {
     class PayloadIndex {
     private:
         std::unordered_map<uint32_t, std::vector<uint32_t>> tag_to_ids; // Attribute -> vector IDs

     public:
         void insert_payload(uint32_t vec_id, uint32_t tag) {
             tag_to_ids[tag].push_back(vec_id);
         }

         const std::vector<uint32_t>& get_matching_ids(uint32_t tag) const {
             static const std::vector<uint32_t> empty;
             auto it = tag_to_ids.find(tag);
             return (it != tag_to_ids.end()) ? it->second : empty;
         }

         std::vector<uint8_t> create_predicate_bitset(uint32_t tag, size_t total_vectors) const {
             std::vector<uint8_t> bitset((total_vectors + 7) / 8, 0);
             auto it = tag_to_ids.find(tag);
             if (it != tag_to_ids.end()) {
                 for (uint32_t id : it->second) {
                     bitset[id / 8] |= (1 << (id % 8));
                 }
             }
             return bitset;
         }
     };
     }
     ```
