* **Core Microarchitectural Concepts**:
  1. **FMA Instruction Latency & Port Saturation**:
     * `vfmaq_f32` has a latency of 4 cycles and a throughput of 1 instruction/cycle per NEON pipe.
     * Accumulating into a single `float32x4_t` variable introduces a 4-cycle loop-carried dependency stall.
  2. **4-Way Register Unrolling**:
     * Maintain 4 independent accumulator vectors (`acc0`, `acc1`, `acc2`, `acc3`), processing 16 floats (64 bytes = 1 full cache line) per loop iteration.
     * Interleaves FMAs without stalling execution ports, achieving peak theoretical FLOPS on ARM64.

     inline float l2_squared_neon(const float* a, const float* b, size_t dim) {
         float32x4_t acc0 = vdupq_n_f32(0.0f);
         float32x4_t acc1 = vdupq_n_f32(0.0f);
         float32x4_t acc2 = vdupq_n_f32(0.0f);
         float32x4_t acc3 = vdupq_n_f32(0.0f);

         size_t i = 0;
         for (; i + 15 < dim; i += 16) {
             float32x4_t va0 = vld1q_f32(a + i);
             float32x4_t vb0 = vld1q_f32(b + i);
             float32x4_t diff0 = vsubq_f32(va0, vb0);
             acc0 = vfmaq_f32(acc0, diff0, diff0);

             float32x4_t va1 = vld1q_f32(a + i + 4);
             float32x4_t vb1 = vld1q_f32(b + i + 4);
             float32x4_t diff1 = vsubq_f32(va1, vb1);
             acc1 = vfmaq_f32(acc1, diff1, diff1);

             float32x4_t va2 = vld1q_f32(a + i + 8);
             float32x4_t vb2 = vld1q_f32(b + i + 8);
             float32x4_t diff2 = vsubq_f32(va2, vb2);

             float32x4_t vb3 = vld1q_f32(b + i + 12);
