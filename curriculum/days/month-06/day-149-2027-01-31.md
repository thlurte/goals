### 🔹 Part 1: Advanced Theorems & Derivations (Thursday Syllabus)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §10.1–10.3 (*Equality Constrained Minimization & The Constrained Newton Step*)
* **Theorems & Mathematical Concepts**:
  1. **Equality-Constrained Convex Problem**:
     $$\min_{x} f(x) \quad \text{subject to} \quad A x = b$$
     * Optimality condition: $A x^* = b$ and $\nabla f(x^*) + A^T \nu^* = \mathbf{0}$.
  2. **The KKT Matrix System for Constrained Newton Step**:
     $$\begin{bmatrix} \nabla^2 f(x) & A^T \\ A & 0 \end{bmatrix} \begin{bmatrix} \Delta x_{\text{nt}} \\ \nu \end{bmatrix} = \begin{bmatrix} -\nabla f(x) \\ 0 \end{bmatrix}$$
     * **Non-singularity Theorem**: The KKT matrix is invertible if $\nabla^2 f(x) \succ 0$ on $\operatorname{null}(A)$ and $A$ has full row rank.
  3. **NUMA Interconnect Latency & Congestion Model**:
     * Socket-local DRAM access: $T_{\text{local}} \approx 65\text{ ns}$ at $204.8\text{ GB/s}$ peak bandwidth.
     * Cross-socket UPI / QPI remote DRAM access: $T_{\text{remote}} \approx 140\text{ ns}$ at $41.6\text{ GB/s}$ interconnect limit.
     * Effective memory access time with local hit fraction $\rho$:
       $$T_{\text{eff}} = \rho T_{\text{local}} + (1 - \rho) T_{\text{remote}}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the constrained Newton KKT system by setting the gradient of the quadratic Taylor approximation Lagrangian $L(\Delta x, \nu) = f(x) + \nabla f(x)^T \Delta x + \frac{1}{2}\Delta x^T \nabla^2 f(x) \Delta x + \nu^T (A(x + \Delta x) - b)$ to zero.
  - [ ] **Proof 2**: Prove that eliminating equality constraints via $x = F z + \hat{x}$ produces reduced gradient $\nabla \tilde{f}(z) = F^T \nabla f(F z + \hat{x})$ and reduced Hessian $\nabla^2 \tilde{f}(z) = F^T \nabla^2 f(F z + \hat{x}) F \succ 0$.
  - [ ] **Problem 3**: On a 2-socket server running 64 concurrent query threads, compute $T_{\text{eff}}$ under (a) interleaved memory $\rho = 0.50$ ($T_{\text{eff}} = 102.5\text{ ns}$) vs (b) NUMA-pinned local memory $\rho = 0.98$ ($T_{\text{eff}} = 66.5\text{ ns}$), showing a $35\%$ latency speedup.

### 🔹 Part 2: Core Proofs & Problem Sets (Friday Syllabus)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §11.1–11.3 (*Interior-Point Methods, The Logarithmic Barrier & The Central Path*)
* **Theorems & Mathematical Concepts**:
  1. **The Logarithmic Barrier Function**:
     * For inequality constraints $f_i(x) \le 0 \; (i=1,\dots,m)$:
       $$\phi(x) = -\sum_{i=1}^m \ln(-f_i(x)) \quad (\operatorname{dom} \phi = \{x \mid f_i(x) < 0\})$$
     * Gradient: $\nabla \phi(x) = \sum_{i=1}^m \frac{1}{-f_i(x)} \nabla f_i(x)$.
     * Hessian: $\nabla^2 \phi(x) = \sum_{i=1}^m \frac{1}{f_i(x)^2} \nabla f_i(x) \nabla f_i(x)^T + \sum_{i=1}^m \frac{1}{-f_i(x)} \nabla^2 f_i(x) \succ 0$.
  2. **The Central Path & Duality Gap Bound**:
     * $x^*(t)$ minimizes $t f_0(x) + \phi(x)$ subject to $A x = b$.
     * **Theorem**: For any point $x^*(t)$ on the central path, the suboptimality is bounded by:
       $$f_0(x^*(t)) - p^* \le \frac{m}{t}$$
       (Setting $t = m / \epsilon$ guarantees $\epsilon$-optimality).
  3. **Continuous Range Predicate Geometry**:
     * For numerical attributes $v \in [v_{\min}, v_{\max}]$, range query $[a, b]$ defines an intersection of two affine halfspaces: $x \ge a \land x \le b$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the Central Path Duality Gap bound: Set dual variables $\lambda_i^*(t) = -\frac{1}{t f_i(x^*(t))} > 0$ and show that $\nabla f_0(x^*(t)) + \sum \lambda_i^*(t) \nabla f_i(x^*(t)) + A^T \nu^*(t) = \mathbf{0}$, establishing dual feasibility with duality gap $\sum -\lambda_i^*(t) f_i(x^*(t)) = \frac{m}{t}$.
  - [ ] **Proof 2**: Prove that the Logarithmic Barrier Hessian $\nabla^2 \phi(x)$ is strictly positive definite for strictly convex $f_i$.
  - [ ] **Problem 3**: In numeric metadata filtering with uniform timestamps $t \sim \operatorname{Uniform}(0, T)$, let query specify range $[t_1, t_2]$. Compute selectivity $\sigma = \frac{t_2 - t_1}{T}$ and calculate the number of candidate vectors evaluated across $N = 10^7$ vectors under pre-filtering vs ACORN.
