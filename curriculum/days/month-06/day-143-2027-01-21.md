## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §4.1–4.4 (*Convex Optimization Problems: Standard Form, LP, QP & SOCP*)
* **Theorems & Mathematical Concepts**:
  1. **Standard Form Convex Problem**:
     $$\min_{x} f_0(x) \quad \text{subject to} \quad f_i(x) \le 0 \; (i=1,\dots,m), \quad A x = b$$
     * $f_0, f_1, \dots, f_m$ are convex functions; equality constraints must be strictly affine.
  2. **Global Optimality Theorem**:
     * For any convex optimization problem, **every locally optimal point is globally optimal**.
     * Furthermore, if the objective $f_0$ is strictly convex, the global optimum is unique.
  3. **Convex Problem Hierarchy**:
     * **Linear Program (LP)**: $\min c^T x \text{ s.t. } G x \preceq h, A x = b$.
     * **Quadratic Program (QP)**: $\min \frac{1}{2} x^T P x + q^T x \text{ s.t. } G x \preceq h, A x = b$ ($P \succeq 0$).
     * **Second-Order Cone Program (SOCP)**: $\min f^T x \text{ s.t. } \|A_i x + b_i\|_2 \le c_i^T x + d_i$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Global Optimality Theorem: Suppose $x^*$ is a local optimum, and $\exists y$ feasible with $f_0(y) < f_0(x^*)$. Show that $z = (1-\theta)x^* + \theta y$ is feasible for all $\theta \in [0, 1]$ and satisfies $f_0(z) \le (1-\theta)f_0(x^*) + \theta f_0(y) < f_0(x^*)$ for all $\theta \in (0, 1]$, contradicting local optimality.
  - [ ] **Proof 2**: Cast the maximum-margin vector hyperplane problem (SVM) $\min \frac{1}{2}\|\mathbf{w}\|_2^2 \text{ s.t. } y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1$ explicitly as a standard Quadratic Program (QP).
  - [ ] **Problem 3**: In optimal vector quantization bit allocation, formulate the problem of minimizing total mean-squared reconstruction error $\sum_{j=1}^m \sigma_j^2 2^{-2 b_j}$ subject to total bit budget $\sum_{j=1}^m b_j \le B$ and non-negativity $b_j \ge 0$ as a convex program, and show that its objective Hessian is strictly positive diagonal.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *GPU NN-Descent: Efficient $k$-NN Graph Construction via Warp-Level Neighbor Exchanges*
* **Core Microarchitectural Concepts**:
  1. **The NN-Descent Principle**:
     * *"A friend of my friend is likely my friend."*
     * Iteratively refine an approximate $k$-NN graph by evaluating distances between all neighbor-pairs $(v, w) \in \mathcal{N}(u) \times \mathcal{N}(u)$.
  2. **GPU Thread Block Neighborhood Joins**:
     * Assign one thread block per vertex $u$. Load current $k$-nearest neighbors into shared memory.
     * Cooperative warp threads evaluate cross-neighbor distances in parallel, updating top-$k$ heaps in registers with $>98\%$ recall in only 8–10 iterations.
