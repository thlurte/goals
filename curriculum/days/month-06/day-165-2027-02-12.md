## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Elements of Information Theory* — Thomas M. Cover & Joy A. Thomas
* **Sections**: §2.1–2.6 (*Cross-Entropy Decomposition, KL Divergence & InfoNCE Mutual Information*)
* **Theorems & Mathematical Concepts**:
  1. **Cross-Entropy Decomposition Theorem**:
     $$H(P, Q) = -\sum_{x \in \mathcal{X}} P(x) \ln Q(x) = H(P) + D_{KL}(P \parallel Q)$$
     * Since $D_{KL}(P \parallel Q) \ge 0$ (Gibbs' inequality), $H(P, Q) \ge H(P)$ with equality iff $P = Q$.
  2. **InfoNCE as a Mutual Information Lower Bound**:
     $$\mathcal{L}_{\text{InfoNCE}} = -\mathbb{E}\left[ \ln \frac{e^{\mathbf{q}^T \mathbf{k}^+ / \tau}}{e^{\mathbf{q}^T \mathbf{k}^+ / \tau} + \sum_{j=1}^K e^{\mathbf{q}^T \mathbf{k}_j^- / \tau}} \right]$$
     * **Theorem**: $I(Q; K^+) \ge \ln(K + 1) - \mathcal{L}_{\text{InfoNCE}}$.
  3. **Alignment & Uniformity Asymptotics**:
     * As negative samples $K \to \infty$, minimizing InfoNCE asymptotically optimizes:
       * **Alignment**: $\mathbb{E}[\|f(x) - f(x^+)\|_2^2] \to 0$.
       * **Uniformity**: Representations distribute uniformly on the unit sphere $\mathcal{S}^{d-1}$ maximizing entropy.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive $H(P, Q) = H(P) + D_{KL}(P \parallel Q)$ by writing $\ln Q(x) = \ln P(x) + \ln \frac{Q(x)}{P(x)}$.
  - [ ] **Proof 2**: Derive the Mutual Information bound $I(X; Y) \ge \ln(K + 1) - \mathcal{L}_{\text{InfoNCE}}$ using the optimal critic $f^*(x, y) = \ln \frac{p(x, y)}{p(x)p(y)}$.
  - [ ] **Problem 3**: For temperature $\tau = 0.05$ and batch negative count $K = 32{,}768$, compute the theoretical maximum mutual information capacity $\ln(32769) \approx 10.397\text{ nats} \approx 15.0\text{ bits}$.

     #include <random>

     int main() {
         std::cout << "=== Secan Vector Search Engine v1.6 ===\n";
         auto dispatch = secan::simd::detect_and_dispatch();
         std::cout << "[Info] Active SIMD Backend Initialized.\n";

         const size_t D = 128;
         std::vector<float> data(N * D);
         std::mt19937 rng(42);
         std::normal_distribution<float> dist(0.0f, 1.0f);
         for (auto& val : data) val = dist(rng);

         secan::AcornGraphIndex index(N, D);
         for (uint32_t i = 0; i < N; ++i) {
             index.add_vector(i, &data[i * D], i % 10);
         }

         std::vector<float> query(D);
         for (auto& val : query) val = dist(rng);
         auto results = index.search_filtered(query.data(), 3, 10, 64);
         std::cout << "[Success] Found " << results.size() << " nearest filtered vectors.\n";
         return 0;
     }
