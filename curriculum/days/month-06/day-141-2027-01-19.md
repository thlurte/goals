## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §2.1–2.4 (*Convex Sets, Affine Sets, Hyperplanes, Halfspaces & Polyhedra*)
* **Theorems & Mathematical Concepts**:
  1. **Affine vs Convex Sets**:
     * An affine set contains the entire line passing through any two points: $\theta x_1 + (1-\theta)x_2 \in C$ ($\forall \theta \in \mathbb{R}$).
     * A convex set contains the line segment between any two points: $\theta x_1 + (1-\theta)x_2 \in C$ ($\forall \theta \in [0, 1]$).
  2. **Hyperplanes, Halfspaces & Polyhedra**:
     * Hyperplane: $\{x \in \mathbb{R}^n \mid a^T x = b\}$ ($a \ne 0$). Both affine and convex.
     * Halfspace: $\{x \in \mathbb{R}^n \mid a^T x \le b\}$. Convex, but not affine.
     * Polyhedron: Intersection of finitely many halfspaces and hyperplanes:
       $$\mathcal{P} = \{x \in \mathbb{R}^n \mid A x \preceq b, \; C x = d\}$$
  3. **Preservation of Convexity**:
     * The intersection of any arbitrary (possibly infinite) family of convex sets $\bigcap_{\alpha \in A} C_\alpha$ is convex.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that the intersection of any collection of convex sets $C = \bigcap_{\alpha} C_\alpha$ is convex: let $x, y \in C$, then for any $\theta \in [0, 1]$, $\theta x + (1-\theta)y \in C_\alpha$ for all $\alpha$, hence $\theta x + (1-\theta)y \in C$.
  - [ ] **Proof 2**: Prove that the Euclidean ball $B(x_c, r) = \{x \mid \|x - x_c\|_2 \le r\}$ is convex using the triangle inequality for norms: $\|\theta x + (1-\theta)y - x_c\|_2 \le \theta\|x - x_c\|_2 + (1-\theta)\|y - x_c\|_2 \le r$.
  - [ ] **Problem 3**: In vector quantization partitioning with $K$ centroids $\{c_1, \dots, c_K\}$, prove that each Voronoi cell $V_i = \{x \mid \|x - c_i\|_2 \le \|x - c_j\|_2, \; \forall j \ne i\}$ is a convex polyhedron by expanding the squared norm inequality into halfspaces $2(c_j - c_i)^T x \le \|c_j\|^2 - \|c_i\|^2$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *ColBERT & ColPali: Fusing Batched Tensor Core GEMM with Warp MaxSim Reductions*
* **Core Microarchitectural Concepts**:
  1. **The Late-Interaction MaxSim Operator**:
     $$\operatorname{MaxSim}(Q, D) = \sum_{i=1}^{L_q} \max_{j=1}^{L_d} \left( \mathbf{q}_i^T \mathbf{d}_j \right)$$
     * For ColPali image documents: $L_q = 32$ query tokens, $L_d = 1{,}030$ visual patch tokens, $d = 128$.
  2. **GPU Fused Kernel Execution**:
     * Rather than materializing the intermediate $32 \times 1030$ similarity matrix in DRAM, compute $Q D^T$ via Tensor Cores in shared memory.
     * Perform warp shuffle row-max reduction across $L_d$ elements in registers, accumulating the scalar MaxSim score with zero global memory writes.

* **Tasks & Implementation**:
  1. **Implement Fused GPU MaxSim Kernel** in `include/secan/gpu/gpu_maxsim.cuh`:
     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>
     #include <algorithm>

     namespace secan {
     __global__ void fused_gpu_maxsim_kernel(
         const float* __restrict__ queries,     // [B, L_q, D]
         const float* __restrict__ documents,   // [B, L_d, D]
         float* __restrict__ scores,            // [B]
         int L_q,
         int L_d,
         int D
     ) {
         size_t b = blockIdx.x;
         size_t q_idx = blockIdx.y; // 0 to L_q - 1
         size_t tid = threadIdx.x;

         const float* q_vec = queries + (b * L_q + q_idx) * D;
         const float* d_block = documents + b * (L_d * D);

         float local_max = -1e30f;

         // Thread block scans across L_d document tokens
         for (int d_idx = tid; d_idx < L_d; d_idx += blockDim.x) {
             const float* d_vec = d_block + d_idx * D;
             float dot = 0.0f;
             #pragma unroll
             for (int k = 0; k < D; ++k) {
                 dot += q_vec[k] * d_vec[k];
             }
             local_max = fmaxf(local_max, dot);
         }

         // Warp shuffle reduction for row maximum
         for (int offset = 16; offset > 0; offset /= 2) {
             local_max = fmaxf(local_max, __shfl_down_sync(0xffffffff, local_max, offset));
         }

         if (tid == 0) {
             atomicAdd(&scores[b], local_max);
         }
     }
     }
     ```
