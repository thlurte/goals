## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic & Mathematical Foundation**: Random Hyperplane LSH, Collision Probabilities & IEEE 754 Floating-Point Formats
* **Theorems & Mathematical Concepts**:
  1. **Random Hyperplane Locality-Sensitive Hashing (LSH)**:
     * Draw random normal vector $\mathbf{r} \sim \mathcal{N}(0, \mathbf{I}_D)$. Hash function: $h_{\mathbf{r}}(\mathbf{u}) = \operatorname{sign}(\langle \mathbf{r}, \mathbf{u} \rangle) \in \{-1, +1\}$.
     * **Cosine Collision Probability Theorem**:
       $$\mathbb{P}\left[ h_{\mathbf{r}}(\mathbf{u}) = h_{\mathbf{r}}(\mathbf{v}) \right] = 1 - \frac{\theta(\mathbf{u}, \mathbf{v})}{\pi} = 1 - \frac{1}{\pi}\arccos\left( \frac{\langle \mathbf{u}, \mathbf{v} \rangle}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} \right)$$
  2. **IEEE 754 Floating-Point Formats**:
     * **FP32**: 1 sign bit, 8 exponent bits, 23 mantissa bits (range $10^{\pm 38}$, precision $\sim 7$ digits).
     * **FP16**: 1 sign bit, 5 exponent bits, 10 mantissa bits (range $10^{\pm 4.5}$, prone to overflow).
     * **BF16**: 1 sign bit, 8 exponent bits, 7 mantissa bits (identical range to FP32, lower precision).
  3. **Kahan Compensated Summation Algorithm**:
     * Maintains a running low-order error compensation variable $c$, reducing cumulative floating point summation error from $\mathcal{O}(n\epsilon)$ to $\mathcal{O}(\epsilon + n\epsilon^2)$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the random hyperplane collision probability $\mathbb{P}[h_{\mathbf{r}}(\mathbf{u}) = h_{\mathbf{r}}(\mathbf{v})] = 1 - \frac{\theta}{\pi}$ by projecting $\mathbf{r}$ onto the 2D plane spanned by $\mathbf{u}$ and $\mathbf{v}$ and evaluating the probability that $\mathbf{r}$ falls between their perpendiculars.
  - [ ] **Proof 2**: Write out the step-by-step arithmetic proof of Kahan summation showing why $(t - \text{sum}) - y$ recovers the lost least-significant bits.
  - [ ] **Problem 3**: For two vectors with cosine similarity $\cos\theta = 0.866$ ($\theta = \pi/6$), compute the collision probability for a single bit $p$, and the probability that all $k=16$ independent random bits match ($p^{16}$).

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Computer Systems: A Programmer's Perspective (3rd Edition)* — R. Bryant & D. O'Hallaron
* **Section**: §2.4 (*Floating-Point Representation, Rounding Modes & Subnormals*)
* **Core Microarchitectural Concepts**:
  1. **4-Bit Scalar Quantization (`SQ4`) Cache Alignment**:
     * Packing 2 4-bit values per byte compresses a $D=128$ vector into **exactly 64 bytes** (the exact size of **1 single CPU cache line**!).
     * Fetching a 128-D vector now requires only 1 single L1/L2 cache request with zero cache line splitting.
  2. **SIMD Nibble Unpacking Mechanics**:
     * Low nibble mask: `_mm256_and_si256(bytes, _mm256_set1_epi8(0x0F))`.
     * High nibble shift: `_mm256_srli_epi16(_mm256_and_si256(bytes, _mm256_set1_epi8(0xF0)), 4)`.
  3. **2-Stage Fast Retrieval Pipeline (SQ4/SQ8 $\to$ FP32 Re-ranking)**:
     * Stage 1: Fast approximate scan over SQ4/SQ8 dataset to retrieve $M = 100$ candidates.
     * Stage 2: Exact FP32 distance re-ranking over the 100 candidate vectors, achieving $100\%$ accuracy with $95\%$ memory bandwidth savings.

* **Tasks & Implementation**:
  1. **Implement 4-Bit Scalar Quantization (`SQ4`)** in `src/quantization/scalar_quantizer_4bit.cpp`:
     ```cpp
     #include "secan/quantization/scalar_quantizer.h"
     #include <vector>
     #include <algorithm>

     namespace secan {
     struct ScalarQuantizer4 {
         size_t dim{0};
         float min_val{0.0f};
         float max_val{0.0f};
         float step{0.0f};
         float inv_step{0.0f};

         void train(const float* data, size_t num_vectors, size_t dimension) {
             dim = dimension;
             size_t total = num_vectors * dim;
             std::vector<float> sample(data, data + std::min(total, size_t(100000)));
             std::sort(sample.begin(), sample.end());
             min_val = sample[sample.size() * 5 / 10000];
             max_val = sample[sample.size() * 9995 / 10000];
             step = (max_val - min_val) / 15.0f; // 4-bit = [0..15]
             inv_step = 1.0f / step;
         }

         void encode(const float* src, uint8_t* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* vec = src + i * dim;
                 uint8_t* out = dst + i * (dim / 2);
                 for (size_t d = 0; d < dim; d += 2) {
                     float v0 = std::clamp(vec[d], min_val, max_val);
                     float v1 = std::clamp(vec[d + 1], min_val, max_val);
                     uint8_t q0 = static_cast<uint8_t>((v0 - min_val) * inv_step + 0.5f) & 0x0F;
                     uint8_t q1 = static_cast<uint8_t>((v1 - min_val) * inv_step + 0.5f) & 0x0F;
                     out[d / 2] = (q1 << 4) | q0; // Pack 2 nibbles into 1 byte
                 }
             }
         }
     };
     }
     ```
