## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Advanced Systems Reference**: * [Denis Bakhvalov, *Performance Analysis and Tuning on Modern CPUs*](https://book.easyperf.net/) — **Ch 5 (§5.1–5.4)** (*Top-Down Microarchitecture Analysis (TMAM) for Vector Scan Stalls*)
* **Paper**: *"Efficient and Robust Approximate Nearest Neighbor Search Using Hierarchical Navigable Small World Graphs"* (Malkov & Yashunin, TPAMI 2020) §1–3
* **Core Microarchitectural Concepts**:
  1. **Graph Traversal Cache Locality**:
     * Graph beam search traverses nodes via pointer jumping, causing frequent L1/L2 cache misses.
     * Storing adjacency as `std::vector<std::vector<uint32_t>>` fragments memory into $N$ tiny heap allocations with 24-byte vector headers and pointer-indirection penalties.
  2. **Flat CSR (Compressed Sparse Row) Memory Layout**:
     * Store all graph edges in one single contiguous `std::vector<uint32_t> neighbors` array with `offsets[node_id]`.
     * Fetching the neighbor list for node $u$ requires a single contiguous 64-byte L1 cache-line read.

  1. **Implement Flat CSR Multi-Layer HNSW Graph Structure** in `include/secan/graph/hnsw_index.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <cstdint>
     #include <cstddef>
     #include <span>

     namespace secan {
     class HnswLayerCSR {
     public:
         size_t max_elements{0};
         size_t max_m{16}; // Maximum edges per node
         std::vector<uint32_t> neighbors; // Size: max_elements * max_m
         std::vector<uint16_t> degrees;   // Size: max_elements

         HnswLayerCSR(size_t n_elements, size_t M)
             : max_elements(n_elements), max_m(M),
               neighbors(n_elements * M, 0), degrees(n_elements, 0) {}

         [[nodiscard]] std::span<const uint32_t> get_neighbors(uint32_t node_id) const noexcept {
             return std::span<const uint32_t>(neighbors.data() + node_id * max_m, degrees[node_id]);
         }

         void add_neighbor(uint32_t u, uint32_t v) noexcept {
             if (degrees[u] < max_m) {
                 neighbors[u * max_m + degrees[u]++] = v;
             }
         }
     };

     struct HnswIndex {
         size_t dim;
         size_t max_elements;
         size_t M{16};
         size_t ef_construction{200};
         size_t ef_search{64};
         int max_level{-1};
         uint32_t enter_node{0};
         std::vector<HnswLayerCSR> layers;
         std::vector<int> element_levels;

         HnswIndex(size_t dimension, size_t capacity, size_t M_edges)
             : dim(dimension), max_elements(capacity), M(M_edges),
               element_levels(capacity, -1) {
             // Up to 16 hierarchical skip-list layers
             for (size_t l = 0; l < 16; ++l) {
                 layers.emplace_back(capacity, (l == 0) ? 2 * M : M);
             }
         }
     };
     }
     ```
