* **Core Microarchitectural Concepts**:
  1. **$64\times$ Compression & L3 Cache Residency**:
     * Uncompressed SIFT1M: $1{,}000{,}000 \times 128 \times 4\text{ B} = \mathbf{512\text{ MB}}$ (Spills to slow DRAM).
     * PQ8 Compressed SIFT1M ($M=8$ bytes/vector): $1{,}000{,}000 \times 8\text{ B} = \mathbf{8\text{ MB}}$ (Fits entirely inside **L3 CPU Cache**!).
     * Streaming through $8\text{ MB}$ achieves memory throughput $>150\text{ GB/s}$, executing scans $>20\times$ faster than DRAM-bound FP32 search.
  2. **Contiguous Codebook Storage**:
     * Store codebooks as a flat contiguous array of size $M \times K^* \times d_s \times 4\text{ bytes}$ ($128\text{ KB}$), mapped directly into L1/L2 cache during training and search.

     ```python
     import torch
     import torch.nn as nn
     import torch.nn.functional as F

     class InfoNCELoss(nn.Module):
         def __init__(self, temperature: float = 0.05):
             super().__init__()
             self.temperature = temperature

         def forward(self, query_embs: torch.Tensor, doc_embs: torch.Tensor) -> torch.Tensor:
             # Normalize embeddings to unit sphere
             q_norm = F.normalize(query_embs, p=2, dim=1)
             d_norm = F.normalize(doc_embs, p=2, dim=1)

             # Similarity matrix: [B, B]
             sim_matrix = torch.matmul(q_norm, d_norm.T) / self.temperature

             # Diagonal elements are the positive pairs
             labels = torch.arange(query_embs.shape[0], device=query_embs.device)
             loss = F.cross_entropy(sim_matrix, labels)
             return loss
     ```

     ```cpp
     #include "secan/quantization/product_quantizer.h"
     #include "secan/distance_avx2.h"
     #include <vector>
     #include <cstring>
     #include <stdexcept>

     namespace secan {
     class ProductQuantizer {
     public:
         size_t dim;
         size_t M;
         size_t d_sub;
         size_t k_sub{256};
         std::vector<float> codebooks; // M * k_sub * d_sub floats

         ProductQuantizer(size_t dimension, size_t num_subspaces)
             : dim(dimension), M(num_subspaces), d_sub(dimension / num_subspaces),
               codebooks(num_subspaces * 256 * (dimension / num_subspaces), 0.0f) {
             if (dimension % num_subspaces != 0) {
                 throw std::invalid_argument("Dimension must be divisible by M");
             }
         }

         void train(const float* train_data, size_t num_train) {
             std::vector<float> sub_data(num_train * d_sub);
             for (size_t m = 0; m < M; ++m) {
                 // Extract m-th subspace slices
                 for (size_t i = 0; i < num_train; ++i) {
                     std::memcpy(sub_data.data() + i * d_sub,
                                 train_data + i * dim + m * d_sub,
                                 d_sub * sizeof(float));
                 }
                 // Train k-means on m-th subspace
                 auto cb = train_subspace_kmeans(sub_data.data(), num_train, d_sub, k_sub, 15);
                 std::memcpy(codebooks.data() + m * k_sub * d_sub, cb.data(), cb.size() * sizeof(float));
             }
         }

         void encode(const float* src, uint8_t* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* vec = src + i * dim;
                 uint8_t* code = dst + i * M;

                 for (size_t m = 0; m < M; ++m) {
                     const float* sub_vec = vec + m * d_sub;
                     const float* sub_cb = codebooks.data() + m * k_sub * d_sub;

                     float min_d = 1e9f;
                     uint8_t best_c = 0;
                     for (size_t c = 0; c < k_sub; ++c) {
                         float d = l2_squared_avx2_unrolled4(sub_vec, sub_cb + c * d_sub, d_sub);
                         if (d < min_d) {
                             min_d = d;
                             best_c = static_cast<uint8_t>(c);
                         }
                     }
                     code[m] = best_c;
                 }
             }
         }
     };
     }
     ```
