* **Quantization & Retrieval Theory Reference**:
  * [Hervé Jégou, Matthijs Douze, Cordelia Schmid (IEEE TPAMI 2011), *"Product Quantization for Nearest Neighbor Search"*](https://hal.inria.fr/inria-00514462/document) — **§3.1–3.3 (*Asymmetric Distance Computation (ADC) vs Symmetric Distance Computation (SDC)*)**:
    * Theoretical error bound analysis: $\mathbb{E}[\|\mathbf{q} - \hat{\mathbf{x}}\|^2] < \mathbb{E}[\|\hat{\mathbf{q}} - \hat{\mathbf{x}}\|^2]$; why keeping query unquantized and scaling database integer codes in the inner loop halves quantization noise variance without increasing memory footprint.
  * [Samuel Williams et al., *Roofline: An Insightful Visual Performance Model for Multicore Architectures*](https://cacm.acm.org/research/roofline-an-insightful-visual-performance-model-for-multicore-architectures/) (CACM 2009) — Operational intensity analysis under packed Look-Up Tables.
* **Core Microarchitectural Concepts**:
  1. **Saturated Subtraction vs Wrap-Around Hazards**:
     * In unsigned integer difference calculations, standard subtraction (`sub`) wraps underflow modulo 256 ($0 - 5 = 251$).
     * Saturated subtraction (`_mm256_subs_epu8`) clamps underflow strictly to zero, ensuring proper absolute difference computation: $|a - b| = (a \ominus b) \vee (b \ominus a)$.
  2. **Asymmetric Distance Computation (ADC) for Scalar Quantization**:
     * Given unquantized query $\mathbf{q} \in \mathbb{R}^D$ and quantized base vector $\mathbf{x} \in \{0, \dots, 255\}^D$:
       $$\|\mathbf{q} - \hat{\mathbf{x}}\|_2^2 = \sum_{i=1}^D (q_i - (x_{\min} + x_i \cdot \text{step}))^2 = \sum_{i=1}^D (q_i' - x_i \cdot \text{step})^2$$
     * By pre-transforming query elements $q_i' = \frac{q_i - x_{\min}}{\text{step}}$, the inner loop computes differences directly between float queries and integer codes with zero decoding overhead.

  1. **Implement Asymmetric SQ8 Distance Kernel** in `src/quantization/distance_sq8.cpp`:
     ```cpp
     #include "secan/quantization/scalar_quantizer.h"
     #include <immintrin.h>

     namespace secan {
     inline float asymmetric_l2_sq8_avx2(
         const float* query_scaled,
         const uint8_t* base_sq8,
         size_t dim,
         float step_sq
     ) {
         __m256 sum0 = _mm256_setzero_ps();
         __m256 sum1 = _mm256_setzero_ps();

         size_t i = 0;
         for (; i + 16 <= dim; i += 16) {
             // Load 16 uint8 bytes and convert to 16 floats across 2 YMM registers
             __m128i bytes = _mm_loadu_si128(reinterpret_cast<const __m128i*>(base_sq8 + i));
             __m256i ints_lo = _mm256_cvtepu8_epi32(bytes);
             __m256i ints_hi = _mm256_cvtepu8_epi32(_mm_srli_si128(bytes, 8));

             __m256 floats_lo = _mm256_cvtepi32_ps(ints_lo);
             __m256 floats_hi = _mm256_cvtepi32_ps(ints_hi);

             __m256 q_lo = _mm256_loadu_ps(query_scaled + i);
             __m256 q_hi = _mm256_loadu_ps(query_scaled + i + 8);

             __m256 diff_lo = _mm256_sub_ps(q_lo, floats_lo);
             __m256 diff_hi = _mm256_sub_ps(q_hi, floats_hi);

             sum0 = _mm256_fmadd_ps(diff_lo, diff_lo, sum0);
             sum1 = _mm256_fmadd_ps(diff_hi, diff_hi, sum1);
         }

         __m256 sum = _mm256_add_ps(sum0, sum1);
         // Horizontal reduction
         __m128 lo = _mm256_castps256_ps128(sum);
         __m128 hi = _mm256_extractf128_ps(sum, 1);
         __m128 sum128 = _mm_add_ps(lo, hi);
         sum128 = _mm_hadd_ps(sum128, sum128);
         sum128 = _mm_hadd_ps(sum128, sum128);
         float total = _mm_cvtss_f32(sum128);

         for (; i < dim; ++i) {
             float d = query_scaled[i] - static_cast<float>(base_sq8[i]);
             total += d * d;
         }
         return total * step_sq;
     }
     }
     ```
