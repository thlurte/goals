## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *Optimizing software in C++* — Agner Fog (Ch 7.10 & Ch 9)
* **Core Microarchitectural Concepts**:
  1. **Asymmetric Distance Computation (ADC) Look-Up Table (LUT)**:
     $$d_{\text{ADC}}(\mathbf{q}, \mathbf{x}) = \|\mathbf{q} - \hat{\mathbf{x}}\|_2^2 = \sum_{m=1}^M \|\mathbf{q}_m - \mathbf{c}_{m, k_m(\mathbf{x})}\|_2^2 = \sum_{m=1}^M \text{LUT}[m][k_m(\mathbf{x})]$$
  2. **L1 Data Cache Table Residence ($8\text{ KB}$)**:
     * Precomputing `float LUT[8][256]` requires $8 \times 256 \times 4\text{ B} = \mathbf{8\text{ KB}}$.
     * Since modern CPUs possess $32\text{--}48\text{ KB}$ of L1 Data Cache per core, the entire distance table sits permanently in ultra-fast L1 SRAM ($1\text{ ns}$ access latency).
  3. **Converting Floating-Point FLOPS into Table Lookups**:
     * Instead of computing $128$ floating-point multiplications and subtractions per database vector, ADC executes **only 8 byte table lookups and additions**!

     namespace secan {
     // Precompute M x 256 distance LUT: 8KB buffer
     void compute_pq_lut(
         const ProductQuantizer& pq,
         const float* query,
         float* lut_out // Array of size M * 256
     ) {
         for (size_t m = 0; m < pq.M; ++m) {
             const float* q_sub = query + m * pq.d_sub;
             const float* cb_sub = pq.codebooks.data() + m * pq.k_sub * pq.d_sub;
             float* lut_m = lut_out + m * pq.k_sub;

             for (size_t c = 0; c < pq.k_sub; ++c) {
                 lut_m[c] = l2_squared_avx2_unrolled4(q_sub, cb_sub + c * pq.d_sub, pq.d_sub);
             }
         }
     }

     // Compute distance for a single M-byte quantized vector
     inline float pq_distance_adc_scalar(const uint8_t* code, const float* lut, size_t M) {
         float total = 0.0f;
         for (size_t m = 0; m < M; ++m) {
             total += lut[m * 256 + code[m]];
         }
         return total;
     }
     }
