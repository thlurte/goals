## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *The Art of Writing Efficient Programs* — Fedor G. Pikus
* **Chapter**: Chapter 10 (*Compiler Optimizations, Pointer Aliasing `__restrict__` & Link-Time Optimization LTO*)
* **Core Microarchitectural Concepts**:
  1. **Pointer Aliasing & The `__restrict__` Keyword**:
     * In C++, compilers assume any two pointers `float* a` and `float* b` could alias the same memory address, preventing register caching of values across loop iterations.
     * Marking pointers `float* __restrict__` asserts non-overlapping buffers, unlocking compiler auto-vectorization and loop unrolling.
  2. **Asymmetric Binary Quantization (Asymmetric BQ)**:
     * Storing database vectors in 1-bit binary codes $\mathbf{b} \in \{0, 1\}^D$ ($128\text{-D} \to \mathbf{16\text{ bytes}}$).
     * Query remains full precision FP32 $\mathbf{q} \in \mathbb{R}^D$:
       $$\langle \mathbf{q}, \hat{\mathbf{x}} \rangle = \sum_{d=1}^D q_d \cdot (2 b_d - 1) = 2 \sum_{d: b_d = 1} q_d - \sum_{d=1}^D q_d$$
     * By pre-calculating total query sum $S_q = \sum q_d$, the inner loop computes inner products with zero floating point multiplications!

     ```cpp
     #include "secan/quantization/binary_quantizer.h"
     #include <cstdint>
     #include <cstddef>
     #include <numeric>

     namespace secan {
     // Compute inner product between FP32 query and 1-bit database vector (packed into uint64_t words)
     inline float asymmetric_ip_bq(
         const float* __restrict__ query,
         const uint64_t* __restrict__ bq_bits,
         size_t num_u64,
         float query_sum
     ) {
         float pos_sum = 0.0f;
         for (size_t w = 0; w < num_u64; ++w) {
             uint64_t word = bq_bits[w];
             const float* q_word = query + w * 64;

             // Extract set bit positions using bitscan (ctz)
             while (word != 0) {
                 int bit = __builtin_ctzll(word);
                 pos_sum += q_word[bit];
                 word &= (word - 1); // Clear lowest set bit
             }
         }
         return 2.0f * pos_sum - query_sum;
     }
     }
     ```
