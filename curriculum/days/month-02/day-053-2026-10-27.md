## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Advanced Systems Reference**: * [Denis Bakhvalov, *Performance Analysis and Tuning on Modern CPUs*](https://book.easyperf.net/) — **Ch 5 (§5.1–5.4)** (*Top-Down Microarchitecture Analysis (TMAM) for Vector Scan Stalls*)
* **Paper**: *"Efficient and Robust ANN Search Using HNSW Graphs"* (Malkov & Yashunin, 2020) §4–5
* **Core Microarchitectural Concepts**:
  1. **Logarithmic Level Assignment (Hierarchical Skip-List)**:
     $$\text{Level } \ell = \left\lfloor -\ln(\operatorname{uniform}(0, 1)) \cdot m_L \right\rfloor \quad \text{where } m_L = \frac{1}{\ln M}$$
     * Guarantees an exponentially decaying node density: Layer $\ell$ contains approximately $1 / M^\ell$ of the total dataset.
  2. **2-Phase Traversal Strategy**:
     * Phase 1 (Top-down greedy zoom): From $\ell_{\max}$ down to $\ell+1$, perform greedy 1-NN search ($ef=1$) to find the closest entry point to query $\mathbf{q}$.
     * Phase 2 (Dense beam search): From $\ell$ down to layer 0, perform beam search with width $ef_{\text{construction}}$, recording candidates in a priority queue.

  1. **ColBERT MaxSim Late-Interaction Scoring Engine** in `src/maxsim.py`:
     ```python
     import torch
     import torch.nn as nn
     import torch.nn.functional as F

     class ColBERTMaxSim(nn.Module):
         def __init__(self, dim: int = 128):
             super().__init__()
             self.dim = dim

         def forward(self, query_embs: torch.Tensor, doc_embs: torch.Tensor,
                     doc_mask: torch.Tensor = None) -> torch.Tensor:
             # query_embs: [B_q, seq_q, dim]
             # doc_embs:   [B_d, seq_d, dim]
             q_norm = F.normalize(query_embs, p=2, dim=-1)
             d_norm = F.normalize(doc_embs, p=2, dim=-1)

             # Token-level similarity: [B, seq_q, seq_d]
             sim_matrix = torch.einsum("b q d, b k d -> b q k", q_norm, d_norm)

             if doc_mask is not None:
                 sim_matrix = sim_matrix.masked_fill(~doc_mask.unsqueeze(1), -1e9)

             # MaxSim: Maximum similarity per query token
             max_sim_per_q, _ = torch.max(sim_matrix, dim=-1)  # [B, seq_q]

             # Sum across all query tokens
             score = torch.sum(max_sim_per_q, dim=-1)  # [B]
             return score
     ```

     int random_level(double ml, std::mt19937& rng) {
         std::uniform_real_distribution<double> dist(0.0, 1.0);
         double r = dist(rng);
         if (r == 0.0) r = 1e-9;
         return static_cast<int>(-std::log(r) * ml);
     }

     uint32_t greedy_search_layer(
         const float* query,
         uint32_t enter_id,
         const HnswLayerCSR& layer,
         const float* data,
         size_t dim
     ) {
         uint32_t curr = enter_id;
         float curr_dist = l2_squared_avx2_unrolled4(query, data + curr * dim, dim);

         bool changed = true;
         while (changed) {
             changed = false;
             auto neighbors = layer.get_neighbors(curr);
             for (uint32_t neighbor : neighbors) {
                 float d = l2_squared_avx2_unrolled4(query, data + neighbor * dim, dim);
                 if (d < curr_dist) {
                     curr_dist = d;
                     curr = neighbor;
                     changed = true;
                 }
             }
         }
         return curr;
     }
     }
