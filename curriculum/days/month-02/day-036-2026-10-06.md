## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Calculus* — Gilbert Strang
* **Section**: §13.8 (*Constrained Optimization & The Method of Lagrange Multipliers*)
* **Theorems & Mathematical Concepts**:
  1. **The Lagrange Multiplier Theorem**:
     * To maximize or minimize $f(\mathbf{x})$ subject to equality constraint $g(\mathbf{x}) = k$:
       $$\nabla f(\mathbf{x}^*) = \lambda \nabla g(\mathbf{x}^*) \quad (\lambda \ne 0)$$
  2. **Geometric Proof of Tangency**:
     * Let $\mathbf{r}(t)$ be any smooth curve lying on the constraint surface $g(\mathbf{x}) = k$ with $\mathbf{r}(0) = \mathbf{x}^*$.
     * Since $g(\mathbf{r}(t)) = k$, taking the time derivative gives $\nabla g(\mathbf{x}^*) \cdot \mathbf{r}'(0) = 0$. Thus $\nabla g(\mathbf{x}^*)$ is orthogonal to the tangent space of the constraint surface.
     * If $\mathbf{x}^*$ is a local extremum of $f$, then $\frac{d}{dt} f(\mathbf{r}(t))\big|_{t=0} = \nabla f(\mathbf{x}^*) \cdot \mathbf{r}'(0) = 0$.
     * Since $\nabla f(\mathbf{x}^*)$ is orthogonal to every tangent vector $\mathbf{r}'(0)$, it must be collinear with the normal vector $\nabla g(\mathbf{x}^*)$.
  3. **The Lagrangian Formulation**:
     $$\mathcal{L}(\mathbf{x}, \lambda) = f(\mathbf{x}) - \lambda(g(\mathbf{x}) - k) \implies \nabla_{\mathbf{x}, \lambda} \mathcal{L} = \mathbf{0}$$
* **Pencil & Paper Problem Set**:

  - [ ] **Problem 2**: Find the maximum and minimum values of $f(x, y, z) = x + 2y + 3z$ subject to the sphere constraint $x^2 + y^2 + z^2 = 1$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Paper**: *"Product Quantization for Nearest Neighbor Search"* (Jégou, Douze, Schmid, 2011) §1–4
* **Core Microarchitectural Concepts**:
  1. **Subspace Product Decomposition**:
     * Slicing vector space $\mathbb{R}^D$ into $M$ orthogonal subspaces: $\mathbb{R}^D = \mathbb{R}^{d_s} \times \dots \times \mathbb{R}^{d_s}$ with $d_s = D / M$ (e.g. $128\text{-D} \to 8 \times 16\text{-D}$).
     * Each subspace $m$ has a codebook $\mathcal{C}_m = \{c_{m, 1}, \dots, c_{m, 256}\}$ of $K^* = 256$ centroids (1 byte).
  2. **The Cartesian Product Combinatorial Multiplier**:
     $$\text{Total Representable Centroids} = (K^*)^M = 256^8 = 2^{64} \approx 1.84 \times 10^{19} \text{ centroids!}$$
     * Storing $2^{64}$ full centroids is physically impossible ($2.3 \text{ exabytes}$), but storing $M \times K^* = 8 \times 256 = 2{,}048$ sub-centroids requires only $2048 \times 16 \times 4\text{ B} = \mathbf{128\text{ KB}}$, fitting entirely in **L2 CPU Cache**!

  1. **Implement Subspace K-Means Trainer** in `src/quantization/product_quantizer.cpp`:
     ```cpp
     #include "secan/quantization/product_quantizer.h"
     #include "secan/distance_avx2.h"
     #include <random>
     #include <cstring>

     namespace secan {
     std::vector<float> train_subspace_kmeans(
         const float* sub_data,
         size_t num_vectors,
         size_t d_sub,
         size_t k,
         size_t iters = 15
     ) {
         std::vector<float> centroids(k * d_sub);
         std::mt19937 rng(1337);
         std::uniform_int_distribution<size_t> dist(0, num_vectors - 1);

         for (size_t c = 0; c < k; ++c) {
             size_t idx = dist(rng);
             std::memcpy(centroids.data() + c * d_sub, sub_data + idx * d_sub, d_sub * sizeof(float));
         }

         std::vector<float> accum(k * d_sub, 0.0f);
         std::vector<size_t> counts(k, 0);

         for (size_t iter = 0; iter < iters; ++iter) {
             std::fill(accum.begin(), accum.end(), 0.0f);
             std::fill(counts.begin(), counts.end(), 0);

             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* vec = sub_data + i * d_sub;
                 float min_dist = 1e9f;
                 size_t best_c = 0;

                 for (size_t c = 0; c < k; ++c) {
                     float d = l2_squared_avx2_unrolled4(vec, centroids.data() + c * d_sub, d_sub);
                     if (d < min_dist) {
                         min_dist = d;
                         best_c = c;
                     }
                 }

                 counts[best_c]++;
                 for (size_t d = 0; d < d_sub; ++d) {
                     accum[best_c * d_sub + d] += vec[d];
                 }
             }

             for (size_t c = 0; c < k; ++c) {
                 if (counts[c] > 0) {
                     float inv_n = 1.0f / counts[c];
                     for (size_t d = 0; d < d_sub; ++d) {
                         centroids[c * d_sub + d] = accum[c * d_sub + d] * inv_n;
                     }
                 }
             }
         }

         return centroids;
     }
     }
     ```
