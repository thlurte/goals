## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic & Mathematical Foundation**: Spectral Graph Theory: Adjacency, Degree Matrix & The Graph Laplacian
* **Theorems & Mathematical Concepts**:
  1. **Graph Matrices**:
     * For graph $G = (V, E)$ with $|V|=n$: Adjacency matrix $W_{ij} \in \{0, 1\}$, Degree matrix $D_{ii} = \sum_{j} W_{ij}$.
  2. **The Graph Laplacian Matrix**:
     $$L = D - W \in \mathbb{R}^{n \times n}$$
  3. **Quadratic Form & Positive Semi-Definiteness**:
     $$\mathbf{x}^T L \mathbf{x} = \mathbf{x}^T D \mathbf{x} - \mathbf{x}^T W \mathbf{x} = \sum_{i=1}^n d_i x_i^2 - \sum_{i,j} W_{ij} x_i x_j = \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n W_{ij}(x_i - x_j)^2 \ge 0$$
     * Since $\mathbf{x}^T L \mathbf{x} \ge 0$ for all $\mathbf{x}$, $L$ is **symmetric positive semi-definite ($L \succeq 0$)**.
  4. **Algebraic Connectivity & The Fiedler Vector**:
     * Spectrum: $0 = \lambda_1 \le \lambda_2 \le \dots \le \lambda_n$.
     * Multiplicity of $\lambda=0$ equals the exact number of connected components in $G$.
     * The second smallest eigenvalue $\lambda_2$ (Fiedler value) measures graph connectivity / network robustness.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove $\mathbf{x}^T L \mathbf{x} = \frac{1}{2}\sum_{i,j} W_{ij}(x_i - x_j)^2$ by expanding $\sum_{i,j} W_{ij}(x_i^2 - 2x_i x_j + x_j^2)$ and regrouping terms with $d_i = \sum_j W_{ij}$.
  - [ ] **Proof 2**: Prove that $\mathbf{1} = \langle 1, 1, \dots, 1 \rangle^T$ is in the nullspace of $L$ ($L \mathbf{1} = \mathbf{0}$), confirming $\lambda_1 = 0$.
  - [ ] **Problem 3**: For a 4-vertex star graph $S_4$ (center node 1 connected to leaves 2, 3, 4), construct $W, D, L$ and compute the eigenvalues of $L$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Paper**: *"Efficient and Robust Approximate Nearest Neighbor Search Using Hierarchical Navigable Small World Graphs"* (Malkov & Yashunin, TPAMI 2020) §1–3
* **Core Microarchitectural Concepts**:
  1. **Graph Traversal Cache Locality**:
     * Graph beam search traverses nodes via pointer jumping, causing frequent L1/L2 cache misses.
     * Storing adjacency as `std::vector<std::vector<uint32_t>>` fragments memory into $N$ tiny heap allocations with 24-byte vector headers and pointer-indirection penalties.
  2. **Flat CSR (Compressed Sparse Row) Memory Layout**:
     * Store all graph edges in one single contiguous `std::vector<uint32_t> neighbors` array with `offsets[node_id]`.
     * Fetching the neighbor list for node $u$ requires a single contiguous 64-byte L1 cache-line read.

     ```cpp
     #pragma once
     #include <vector>
     #include <cstdint>
     #include <cstddef>
     #include <span>

     namespace secan {
     class HnswLayerCSR {
     public:
         size_t max_elements{0};
         size_t max_m{16}; // Maximum edges per node
         std::vector<uint32_t> neighbors; // Size: max_elements * max_m
         std::vector<uint16_t> degrees;   // Size: max_elements

         HnswLayerCSR(size_t n_elements, size_t M)
             : max_elements(n_elements), max_m(M),
               neighbors(n_elements * M, 0), degrees(n_elements, 0) {}

         [[nodiscard]] std::span<const uint32_t> get_neighbors(uint32_t node_id) const noexcept {
             return std::span<const uint32_t>(neighbors.data() + node_id * max_m, degrees[node_id]);
         }

         void add_neighbor(uint32_t u, uint32_t v) noexcept {
             if (degrees[u] < max_m) {
                 neighbors[u * max_m + degrees[u]++] = v;
             }
         }
     };

     struct HnswIndex {
         size_t dim;
         size_t max_elements;
         size_t M{16};
         size_t ef_construction{200};
         size_t ef_search{64};
         int max_level{-1};
         uint32_t enter_node{0};
         std::vector<HnswLayerCSR> layers;
         std::vector<int> element_levels;

         HnswIndex(size_t dimension, size_t capacity, size_t M_edges)
             : dim(dimension), max_elements(capacity), M(M_edges),
               element_levels(capacity, -1) {
             // Up to 16 hierarchical skip-list layers
             for (size_t l = 0; l < 16; ++l) {
                 layers.emplace_back(capacity, (l == 0) ? 2 * M : M);
             }
         }
     };
     }
     ```
