## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *The Art of Writing Efficient Programs* — Fedor G. Pikus (Ch 7)
* **Core Microarchitectural Concepts**:
  1. **Zero-Allocation Visited Tag Bitset**:
     * Using `std::unordered_set<uint32_t>` for tracking visited nodes in beam search causes heap allocations and cache misses ($>60\text{ ns/lookup}$).
     * Array-of-tags optimization: Allocate a flat `uint16_t visited_tag[N]`. For query $k$, increment query tag `cur_tag++`. If `visited_tag[node] == cur_tag`, it has been visited! This allows instantaneous $\mathcal{O}(1)$ resets with **zero buffer zeroing memory overhead**.
  2. **HNSW Algorithm 4 (Diverse Neighbor Selection Heuristic)**:
     * Greedy $k$-NN graphs form dense clusters with redundant parallel edges.
     * Algorithm 4 prunes candidates that are closer to an already-selected neighbor than to the base node, enforcing diverse angular coverage (Delaunay triangulation approximation).

* **Tasks & Implementation**:
  1. **Implement Algorithm 4 Neighbor Heuristic & Beam Search** in `src/graph/hnsw_index.cpp`:
     ```cpp
     #include "secan/graph/hnsw_index.h"
     #include "secan/distance_avx2.h"
     #include <queue>
     #include <vector>
     #include <algorithm>

     namespace secan {
     struct DistNode {
         float dist;
         uint32_t id;
         bool operator>(const DistNode& o) const { return dist > o.dist; }
         bool operator<(const DistNode& o) const { return dist < o.dist; }
     };

     // HNSW Algorithm 4: Heuristic Diverse Neighbor Selection
     std::vector<uint32_t> select_neighbors_heuristic(
         const float* base_vec,
         std::vector<DistNode>& candidates, // sorted ascending by distance
         size_t max_m,
         const float* data,
         size_t dim
     ) {
         std::vector<uint32_t> result;
         result.reserve(max_m);

         for (const auto& e : candidates) {
             if (result.size() >= max_m) break;
             bool keep = true;
             const float* e_vec = data + e.id * dim;

             // Keep e only if it is closer to base_vec than to any already chosen neighbor
             for (uint32_t r : result) {
                 float dist_to_r = l2_squared_avx2_unrolled4(e_vec, data + r * dim, dim);
                 if (dist_to_r < e.dist) {
                     keep = false;
                     break;
                 }
             }
             if (keep) {
                 result.push_back(e.id);
             }
         }
         return result;
     }
     }
     ```
