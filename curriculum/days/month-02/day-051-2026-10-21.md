## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic & Mathematical Foundation**: The Hubness Phenomenon in High Dimensions, $k$-Occurrence Skewness & Covariance Whitening
* **Theorems & Mathematical Concepts**:
  1. **The Hubness Phenomenon in $\mathbb{R}^d$**:
     * In high-dimensional spaces ($d \ge 100$), the variance of distances to the origin induces extreme asymmetry in $k$-nearest neighbor graphs.
     * Let $N_k(\mathbf{x}_i)$ be the number of times vector $\mathbf{x}_i$ appears in the $k$-NN sets of all dataset points.
     * Universal Sum Rule:
       $$\sum_{i=1}^n N_k(\mathbf{x}_i) = n \cdot k \implies \mathbb{E}[N_k] = k$$
  2. **Skewness of the $k$-Occurrence Distribution**:
     $$S_{N_k} = \frac{\mathbb{E}\left[(N_k - k)^3\right]}{\operatorname{Var}(N_k)^{3/2}} = \frac{\frac{1}{n} \sum_{i=1}^n (N_k(\mathbf{x}_i) - k)^3}{\left( \frac{1}{n} \sum_{i=1}^n (N_k(\mathbf{x}_i) - k)^2 \right)^{3/2}}$$
     * Uncorrelated data has $S_{N_k} \approx 0$. High-dimensional neural embeddings exhibit $S_{N_k} > 3.0$, creating massive "hub" nodes with in-degrees $> 100 \times k$ that trap graph searches.
  3. **Covariance Whitening (Mahalanobis Isotropization)**:
     * Given covariance $\mathbf{\Sigma} = \mathbf{Q} \mathbf{\Lambda} \mathbf{Q}^T$:
       $$\mathbf{x}_{\text{white}} = \mathbf{\Lambda}^{-1/2} \mathbf{Q}^T (\mathbf{x} - \boldsymbol{\mu}) \implies \operatorname{Cov}(\mathbf{x}_{\text{white}}) = \mathbf{I}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove $\sum_{i=1}^n N_k(\mathbf{x}_i) = nk$ by defining the indicator matrix $A_{ij} = \mathbb{I}(\mathbf{x}_j \in \text{kNN}(\mathbf{x}_i))$ and evaluating $\sum_i \sum_j A_{ij}$ across rows and columns.
  - [ ] **Proof 2**: Prove that $\operatorname{Cov}(\mathbf{x}_{\text{white}}) = \mathbf{I}$ by expanding $\mathbb{E}[(\mathbf{\Lambda}^{-1/2}\mathbf{Q}^T \mathbf{x}_c)(\mathbf{\Lambda}^{-1/2}\mathbf{Q}^T \mathbf{x}_c)^T]$ where $\mathbf{x}_c = \mathbf{x} - \boldsymbol{\mu}$.
  - [ ] **Problem 3**: For a dataset of 5 points with $k=2$ neighbor occurrences $N_2 = [0, 0, 1, 1, 8]$, calculate the sample mean, variance, and exact skewness $S_{N_2}$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Paper**: *"Efficient and Robust ANN Search Using HNSW Graphs"* (Malkov & Yashunin, 2020) §4–5
* **Core Microarchitectural Concepts**:
  1. **Logarithmic Level Assignment (Hierarchical Skip-List)**:
     $$\text{Level } \ell = \left\lfloor -\ln(\operatorname{uniform}(0, 1)) \cdot m_L \right\rfloor \quad \text{where } m_L = \frac{1}{\ln M}$$
     * Guarantees an exponentially decaying node density: Layer $\ell$ contains approximately $1 / M^\ell$ of the total dataset.
  2. **2-Phase Traversal Strategy**:
     * Phase 1 (Top-down greedy zoom): From $\ell_{\max}$ down to $\ell+1$, perform greedy 1-NN search ($ef=1$) to find the closest entry point to query $\mathbf{q}$.
     * Phase 2 (Dense beam search): From $\ell$ down to layer 0, perform beam search with width $ef_{\text{construction}}$, recording candidates in a priority queue.

     ```cpp
     int random_level(double ml, std::mt19937& rng) {
         std::uniform_real_distribution<double> dist(0.0, 1.0);
         double r = dist(rng);
         if (r == 0.0) r = 1e-9;
         return static_cast<int>(-std::log(r) * ml);
     }

     uint32_t greedy_search_layer(
         const float* query,
         uint32_t enter_id,
         const HnswLayerCSR& layer,
         const float* data,
         size_t dim
     ) {
         uint32_t curr = enter_id;
         float curr_dist = l2_squared_avx2_unrolled4(query, data + curr * dim, dim);

         bool changed = true;
         while (changed) {
             changed = false;
             auto neighbors = layer.get_neighbors(curr);
             for (uint32_t neighbor : neighbors) {
                 float d = l2_squared_avx2_unrolled4(query, data + neighbor * dim, dim);
                 if (d < curr_dist) {
                     curr_dist = d;
                     curr = neighbor;
                     changed = true;
                 }
             }
         }
         return curr;
     }
     }
     ```
