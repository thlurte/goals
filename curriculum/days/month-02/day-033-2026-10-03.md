## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Calculus* — Gilbert Strang
* **Section**: §13.7 (*Extrema of Multivariable Functions, Critical Points & The Hessian Matrix*)
* **Theorems & Mathematical Concepts**:
  1. **Critical Points in $\mathbb{R}^d$**:
     $$\nabla f(\mathbf{x}_0) = \mathbf{0} \iff \frac{\partial f}{\partial x_1} = \frac{\partial f}{\partial x_2} = \dots = \frac{\partial f}{\partial x_d} = 0$$
  2. **The Hessian Matrix**:
     $$\mathbf{H}_f(\mathbf{x}) \in \mathbb{R}^{d \times d} \quad \text{where } [\mathbf{H}_f]_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$$
  3. **Second Derivative Classification via 2nd-Order Taylor Expansion**:
     $$f(\mathbf{x}_0 + \mathbf{h}) \approx f(\mathbf{x}_0) + \nabla f(\mathbf{x}_0)^T \mathbf{h} + \frac{1}{2} \mathbf{h}^T \mathbf{H}_f(\mathbf{x}_0) \mathbf{h}$$
     * In 2D: Discriminant $D = \det(\mathbf{H}) = f_{xx} f_{yy} - (f_{xy})^2$.
     * $D > 0, f_{xx} > 0 \implies$ Local Minimum.
     * $D > 0, f_{xx} < 0 \implies$ Local Maximum.
     * $D < 0 \implies$ Saddle Point.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the 2D discriminant test $D = f_{xx}f_{yy} - (f_{xy})^2$ by completing the square on the quadratic form $Q(h_1, h_2) = f_{xx} h_1^2 + 2f_{xy} h_1 h_2 + f_{yy} h_2^2$.
  - [ ] **Problem 2**: Find and classify all critical points of $f(x, y) = x^3 + y^3 - 3xy$ using the Hessian matrix.
  - [ ] **Problem 3**: For $f(x, y, z) = x^2 + 2y^2 + 3z^2 + 2xy - 2yz$, evaluate the $3 \times 3$ Hessian matrix at the origin and verify positive-definiteness via Sylvester's Criterion (all principal minors $> 0$).

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *The Art of Writing Efficient Programs* — Fedor G. Pikus
* **Chapter**: Chapter 9 (*High-Performance Modern C++: Move Semantics & `std::span`*)
* **Core Microarchitectural Concepts**:
  1. **Zero-Copy Memory Views with C++20 `std::span`**:
     * Passing `std::vector` or sub-buffers creates heap allocation and reference-counting overhead.
     * `std::span<const uint8_t>` is a 16-byte non-owning wrapper (`pointer + size`) passed by value in 2 CPU registers (`rdi`, `rsi`), enabling zero-overhead buffer slicing.
  2. **Eliminating Allocation in the Search Critical Path**:
     * Pre-allocating scratch buffers and returning lightweight `std::span` views over memory-mapped database regions guarantees **0 malloc/free calls during query execution**.

     ```cpp
     #pragma once
     #include <span>
     #include <vector>
     #include <cstdint>
     #include <cstddef>

     namespace secan {
     class QuantizedDatasetSQ8 {
     public:
         QuantizedDatasetSQ8(size_t num_vectors, size_t dim, std::vector<uint8_t> data)
             : n_(num_vectors), dim_(dim), data_(std::move(data)) {}

         [[nodiscard]] std::span<const uint8_t> get_vector(size_t idx) const noexcept {
             return std::span<const uint8_t>(data_.data() + idx * dim_, dim_);
         }

         [[nodiscard]] std::span<const uint8_t> get_block(size_t start_idx, size_t count) const noexcept {
             return std::span<const uint8_t>(data_.data() + start_idx * dim_, count * dim_);
         }

         [[nodiscard]] size_t size() const noexcept { return n_; }
         [[nodiscard]] size_t dim() const noexcept { return dim_; }

     private:
         size_t n_{0};
         size_t dim_{0};
         std::vector<uint8_t> data_;
     };
     }
     ```
