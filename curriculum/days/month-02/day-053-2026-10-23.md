## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic & Mathematical Foundation**: Small-World Graph Metrics: Clustering Coefficients, Characteristic Path Lengths & Navigability
* **Theorems & Mathematical Concepts**:
  1. **Local Clustering Coefficient $C(v)$**:
     $$C(v) = \frac{2 e(N(v))}{k_v(k_v - 1)} = \frac{|\{(u, w) \in E \mid u, w \in N(v)\}|}{\binom{k_v}{2}}$$
     * Measures the probability that two neighbors of $v$ are also connected to each other (local clique density).
  2. **Watts-Strogatz Small-World Property**:
     $$\text{High Clustering: } C \gg C_{\text{random}} = \frac{\langle k \rangle}{n}, \quad \text{Short Path Length: } L \sim \mathcal{O}(\log n)$$
  3. **Kleinberg's Navigability Theorem in $\mathbb{R}^d$**:
     * In a $d$-dimensional grid with long-range connections drawn with probability $P(u, v) \propto d(u, v)^{-\alpha}$, decentralized greedy routing achieves expected path length $\mathcal{O}(\log^2 n)$ **if and only if $\alpha = d$**.
     * HNSW achieves scale-invariant navigability by embedding exponential hierarchical layers with level scale $m_L = 1/\ln M$.
* **Pencil & Paper Problem Set**:

  - [ ] **Problem 2**: For a wheel graph $W_5$ (center hub connected to a 4-node ring), calculate the clustering coefficient $C(v)$ for every vertex and determine the graph average clustering $\bar{C}$.
  - [ ] **Problem 3**: Explain why random rewiring with probability $p=0.01$ causes the average path length $L$ to drop precipitously while leaving clustering $C$ almost unchanged.

  1. **Implement Automated HNSW Accuracy & Recall Evaluation Harness** in `benchmarks/bench_hnsw.cpp`:
     ```cpp
     #include "secan/graph/hnsw_index.h"
     #include <vector>
     #include <iostream>
     #include <chrono>
     #include <unordered_set>

     namespace secan {
     struct SearchMetrics {
         float recall_at_k;
         double qps;
         double avg_distance_computations;
     };

     SearchMetrics evaluate_hnsw_recall(
         const HnswIndex& index,
         const float* queries,
         size_t num_queries,
         const uint32_t* ground_truth_ids, // num_queries x 100
         size_t k,
         size_t ef_search,
         const float* data
     ) {
         size_t total_hits = 0;
         auto start = std::chrono::high_resolution_clock::now();

         for (size_t q = 0; q < num_queries; ++q) {
             const float* query_vec = queries + q * index.dim;
             const uint32_t* gt = ground_truth_ids + q * 100;

             // Run HNSW search with ef_search
             std::vector<uint32_t> results = search_hnsw(index, query_vec, k, ef_search, data);

             std::unordered_set<uint32_t> gt_set(gt, gt + k);
             for (uint32_t res_id : results) {
                 if (gt_set.contains(res_id)) {
                     total_hits++;
                 }
             }
         }

         auto end = std::chrono::high_resolution_clock::now();
         double seconds = std::chrono::duration<double>(end - start).count();

         return {
             .recall_at_k = static_cast<float>(total_hits) / (num_queries * k),
             .qps = static_cast<double>(num_queries) / seconds,
             .avg_distance_computations = 0.0
         };
     }
     }
     ```
