## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic & Mathematical Foundation**: Automatic Differentiation: Forward-Mode Tangents vs Reverse-Mode Adjoints & Dual Numbers
* **Theorems & Mathematical Concepts**:
  1. **Dual Numbers and Forward-Mode AD**:
     * Define dual unit $\epsilon$ such that $\epsilon \ne 0$ but $\epsilon^2 = 0$.
     * Any differentiable function $f$ evaluated on dual number $x + \dot{x}\epsilon$:
       $$f(x + \dot{x}\epsilon) = f(x) + f'(x)\dot{x}\epsilon$$
     * Arithmetic automatically tracks exact derivatives without truncation error.
  2. **Reverse-Mode AD (Adjoint Accumulation / Backpropagation)**:
     * For a scalar loss $\mathcal{L}$ on a DAG of intermediate nodes $v_1, \dots, v_N$:
       $$\text{Adjoint } \bar{v}_j = \frac{\partial \mathcal{L}}{\partial v_j} = \sum_{i \in \operatorname{Children}(j)} \bar{v}_i \frac{\partial v_i}{\partial v_j}$$
     * Computes the full gradient vector $\nabla_{\mathbf{x}} \mathcal{L} \in \mathbb{R}^P$ in **a single reverse pass ($\mathcal{O}(1)$ backward passes)**, independent of parameter count $P$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove using dual numbers that $(u + \dot{u}\epsilon)(v + \dot{v}\epsilon) = uv + (u\dot{v} + \dot{u}v)\epsilon$ and $\frac{u + \dot{u}\epsilon}{v + \dot{v}\epsilon} = \frac{u}{v} + \frac{\dot{u}v - u\dot{v}}{v^2}\epsilon$, deriving product and quotient rules purely algebraically.
  - [ ] **Proof 2**: Draw the full computational graph and step-by-step adjoint accumulation table for $f(x_1, x_2) = \ln(x_1 x_2) + \sin(x_1 / x_2)$ at $(x_1=2, x_2=1)$, verifying exact parity with analytical derivatives.
  - [ ] **Problem 3**: Contrast the computational complexity of evaluating the gradient $\nabla f$ of $f: \mathbb{R}^{10^9} \to \mathbb{R}$ using: (a) Finite difference approximations ($2 \times 10^9$ forward passes), (b) Forward-mode AD ($10^9$ passes), (c) Reverse-mode AD (1 forward + 1 backward pass).

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Computer Systems: A Programmer's Perspective (3rd Edition)* — R. Bryant & D. O'Hallaron
* **Section**: §5.10–5.12 (*Register Spilling, Store-Load Forwarding & Pipeline Limiting Factors*)
* **Core Microarchitectural Concepts**:
  1. **Register Pressure & Stack Spilling**:
     * x86-64 CPU has 16 YMM registers (`ymm0`..`ymm15`). Exceeding 16 live vector registers forces the compiler to spill variables to the L1 stack frame, introducing load-after-store pipeline stalls.
  2. **Optimized Product Quantization (OPQ)**:
     * Problem: Correlated embedding dimensions create high reconstruction error when split into naive sequential subspaces.
     * Solution: Learn an orthogonal rotation matrix $\mathbf{R} \in \mathbb{R}^{D \times D}$ ($\mathbf{R}^T \mathbf{R} = \mathbf{I}$) to align principal variance uniformly across all $M$ subspaces before quantization.

* **Tasks & Implementation**:
  1. **Implement Optimized Product Quantizer (OPQ)** in `src/quantization/opq.cpp`:
     ```cpp
     #include "secan/quantization/product_quantizer.h"
     #include "secan/distance_avx2.h"
     #include <vector>
     #include <cstring>

     namespace secan {
     class OptimizedProductQuantizer {
     public:
         size_t dim;
         size_t M;
         std::vector<float> R_matrix; // D x D orthogonal matrix
         ProductQuantizer pq;

         OptimizedProductQuantizer(size_t dimension, size_t num_subspaces)
             : dim(dimension), M(num_subspaces),
               R_matrix(dimension * dimension, 0.0f),
               pq(dimension, num_subspaces) {
             // Initialize R to Identity matrix
             for (size_t d = 0; d < dim; ++d) {
                 R_matrix[d * dim + d] = 1.0f;
             }
         }

         // Rotate vectors: y = R * x
         void rotate_data(const float* src, float* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* x = src + i * dim;
                 float* y = dst + i * dim;
                 for (size_t r = 0; r < dim; ++r) {
                     float sum = 0.0f;
                     for (size_t c = 0; c < dim; ++c) {
                         sum += R_matrix[r * dim + c] * x[c];
                     }
                     y[r] = sum;
                 }
             }
         }

         void train(const float* data, size_t num_vectors) {
             std::vector<float> rotated(num_vectors * dim);
             rotate_data(data, rotated.data(), num_vectors);
             pq.train(rotated.data(), num_vectors);
         }

         void encode(const float* src, uint8_t* dst, size_t num_vectors) const {
             std::vector<float> rotated(num_vectors * dim);
             rotate_data(src, rotated.data(), num_vectors);
             pq.encode(rotated.data(), dst, num_vectors);
         }
     };
     }
     ```
