## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *Computer Systems: A Programmer's Perspective (3rd Edition)* — R. Bryant & D. O'Hallaron
* **Section**: §5.10–5.12 (*Register Spilling, Store-Load Forwarding & Pipeline Limiting Factors*)
* **Core Microarchitectural Concepts**:
  1. **Register Pressure & Stack Spilling**:
     * x86-64 CPU has 16 YMM registers (`ymm0`..`ymm15`). Exceeding 16 live vector registers forces the compiler to spill variables to the L1 stack frame, introducing load-after-store pipeline stalls.
  2. **Optimized Product Quantization (OPQ)**:
     * Problem: Correlated embedding dimensions create high reconstruction error when split into naive sequential subspaces.
     * Solution: Learn an orthogonal rotation matrix $\mathbf{R} \in \mathbb{R}^{D \times D}$ ($\mathbf{R}^T \mathbf{R} = \mathbf{I}$) to align principal variance uniformly across all $M$ subspaces before quantization.

     * Proof that $\mathbb{E}[\langle \mathbf{q}, \mathbf{e}_\perp \rangle] = 0$ while $\langle \mathbf{q}, \mathbf{e}_\parallel \rangle$ systematically degrades top-$k$ MIPS ranking.

  2. **The Systems Bottleneck**:
     * Eliminating the L1 Data Cache load bottleneck: Moving from cache-lookup ADC to register-resident FastScan.
     * Port 5 `vpshufb` execution unit saturation (32 lookups/cycle).
  3. **The Engine Architecture**:
     * `secan` implementation: Interleaved 4-bit storage tiles, in-register table lookups, and OPQ rotation pipeline.
  4. **Empirical Benchmarks**:
     * Latency & QPS curves: Standard PQ ADC ($20\text{M vecs/sec}$) vs AVX2 FastScan ($120\text{M vecs/sec}$).
  5. **Key Takeaway**:
     * Maximum performance requires co-designing loss functions with CPU execution ports: anisotropic loss fixes the math, while `vpshufb` saturates the hardware.

  1. **Implement Optimized Product Quantizer (OPQ)** in `src/quantization/opq.cpp`:
     ```cpp
     #include "secan/quantization/product_quantizer.h"
     #include "secan/distance_avx2.h"
     #include <vector>
     #include <cstring>

     namespace secan {
     class OptimizedProductQuantizer {
     public:
         size_t dim;
         size_t M;
         std::vector<float> R_matrix; // D x D orthogonal matrix
         ProductQuantizer pq;

         OptimizedProductQuantizer(size_t dimension, size_t num_subspaces)
             : dim(dimension), M(num_subspaces),
               R_matrix(dimension * dimension, 0.0f),
               pq(dimension, num_subspaces) {
             // Initialize R to Identity matrix
             for (size_t d = 0; d < dim; ++d) {
                 R_matrix[d * dim + d] = 1.0f;
             }
         }

         // Rotate vectors: y = R * x
         void rotate_data(const float* src, float* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* x = src + i * dim;
                 float* y = dst + i * dim;
                 for (size_t r = 0; r < dim; ++r) {
                     float sum = 0.0f;
                     for (size_t c = 0; c < dim; ++c) {
                         sum += R_matrix[r * dim + c] * x[c];
                     }
                     y[r] = sum;
                 }
             }
         }

         void train(const float* data, size_t num_vectors) {
             std::vector<float> rotated(num_vectors * dim);
             rotate_data(data, rotated.data(), num_vectors);
             pq.train(rotated.data(), num_vectors);
         }

         void encode(const float* src, uint8_t* dst, size_t num_vectors) const {
             std::vector<float> rotated(num_vectors * dim);
             rotate_data(src, rotated.data(), num_vectors);
             pq.encode(rotated.data(), dst, num_vectors);
         }
     };
     }
     ```
