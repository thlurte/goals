## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic**: *Vector Jacobians, Activation Derivatives & Softmax-Cross-Entropy Gradients*
* **Core Text & References**: *Deep Learning* (Goodfellow, Bengio, Courville §6.5) / *Neural Network Gradient Foundations*
* **Theorems & Mathematical Concepts**:
  1. **The Vector Jacobian Matrix**:
     * For mapping $\mathbf{f}: \mathbb{R}^N \to \mathbb{R}^M$, the Jacobian $J \in \mathbb{R}^{M \times N}$ is $J_{ij} = \frac{\partial f_i}{\partial x_j}$.
     * For element-wise activations $\mathbf{y} = \sigma(\mathbf{z})$ (e.g. ReLU, GELU, SwiGLU), $J$ is strictly **diagonal**: $J = \operatorname{diag}(\sigma'(z_1), \dots, \sigma'(z_N))$.
  2. **The Softmax Jacobian Derivation**:
     * For $s_i = \frac{e^{z_i}}{\sum_{k=1}^C e^{z_k}}$, the full dense Jacobian is:
       $$\frac{\partial s_i}{\partial z_j} = s_i (\delta_{ij} - s_j) = \begin{cases} s_i(1 - s_i) & \text{if } i = j \\ -s_i s_j & \text{if } i \neq j \end{cases}$$
       In matrix form: $J_{\text{softmax}} = \operatorname{diag}(\mathbf{s}) - \mathbf{s} \mathbf{s}^T$.
  3. **The Softmax-Cross-Entropy Miracle**:
     * For categorical cross-entropy $\mathcal{L}_{\text{CE}} = -\sum_{i=1}^C y_i \ln s_i$ where $\mathbf{y}$ is one-hot ($\sum y_i = 1$):
       $$\frac{\partial \mathcal{L}_{\text{CE}}}{\partial z_j} = s_j - y_j \iff \nabla_{\mathbf{z}} \mathcal{L}_{\text{CE}} = \mathbf{s} - \mathbf{y}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive $\frac{\partial s_i}{\partial z_j} = s_i(\delta_{ij} - s_j)$ using the quotient rule: $\frac{d}{dz_j} \left( \frac{e^{z_i}}{\Sigma} \right) = \frac{\frac{\partial e^{z_i}}{\partial z_j}\Sigma - e^{z_i} \frac{\partial \Sigma}{\partial z_j}}{\Sigma^2}$, noting that $\frac{\partial \Sigma}{\partial z_j} = e^{z_j}$.
  - [ ] **Proof 2**: Derive the combined gradient $\nabla_{\mathbf{z}} \mathcal{L}_{\text{CE}} = \mathbf{s} - \mathbf{y}$ by chaining upstream loss gradient $\frac{\partial \mathcal{L}}{\partial s_i} = -\frac{y_i}{s_i}$ through the Softmax Jacobian: show that $\frac{\partial \mathcal{L}}{\partial z_j} = \sum_{i=1}^C \left( -\frac{y_i}{s_i} \right) s_i (\delta_{ij} - s_j) = -y_j + s_j \sum_{i=1}^C y_i = s_j - y_j$.
  - [ ] **Problem 3**: Compute the exact analytical derivative of the **SwiGLU** activation $\text{SwiGLU}(x, g) = \text{Swish}(x) \cdot g = (x \cdot \sigma(\beta x)) \cdot g$ with respect to inputs $x$ and gate $g$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Intel 64 and IA-32 Architectures Optimization Reference Manual* & *Agner Fog Instruction Tables*
* **Core Microarchitectural Concepts**:
  1. **The `_mm256_shuffle_epi8` (PSHUFB) Table Lookup Engine**:
     * `vpshufb` executes 32 parallel 4-bit table lookups across two 128-bit lanes in **1 single clock cycle on Execution Port 5**.
     * Forms the silicon foundation of ultra-fast 4-bit quantization (FastScan) in Faiss and ScaNN.
  2. **Hardware `popcnt` Throughput & Latency**:
     * Hardware popcount (`__builtin_popcountll` / `_mm_popcnt_u64`): 1 cycle throughput, 3 cycle latency on Port 1.
     * Hamming distance between two 64-bit words: `_mm_popcnt_u64(word_a ^ word_b)`.
  3. **SIMD Bitmask Extraction (`_mm256_movemask_ps`)**:
     * Extracts the sign bit of 8 FP32 values into an 8-bit integer in **1 cycle on Port 0**, enabling zero-overhead floating point to 1-bit quantization.

     #include <immintrin.h>
     #include <cstdint>
     #include <cstddef>

     namespace secan {
     // Encode 128-D float vector into 128-bit binary code (2x uint64_t) using AVX2 movemask
     inline void encode_bq_128d(const float* vec, uint64_t* code_out) {
         uint32_t m0 = _mm256_movemask_ps(_mm256_loadu_ps(vec + 0));
         uint32_t m1 = _mm256_movemask_ps(_mm256_loadu_ps(vec + 8));
         uint32_t m2 = _mm256_movemask_ps(_mm256_loadu_ps(vec + 16));
         uint32_t m3 = _mm256_movemask_ps(_mm256_loadu_ps(vec + 24));
         uint32_t m4 = _mm256_movemask_ps(_mm256_loadu_ps(vec + 32));
         uint32_t m5 = _mm256_movemask_ps(_mm256_loadu_ps(vec + 40));
         uint32_t m6 = _mm256_movemask_ps(_mm256_loadu_ps(vec + 48));
         uint32_t m7 = _mm256_movemask_ps(_mm256_loadu_ps(vec + 56));

         uint64_t low64 = (static_cast<uint64_t>(m0) << 0)  | (static_cast<uint64_t>(m1) << 8)  |
                          (static_cast<uint64_t>(m2) << 16) | (static_cast<uint64_t>(m3) << 24) |
                          (static_cast<uint64_t>(m4) << 32) | (static_cast<uint64_t>(m5) << 40) |
                          (static_cast<uint64_t>(m6) << 48) | (static_cast<uint64_t>(m7) << 56);

         // Process remaining 64 dimensions for high64...
         code_out[0] = low64;
     }

     // 4-Way Unrolled Hamming Distance Scan
     inline void hamming_distance_4way(
         uint64_t q0, uint64_t q1,
         const uint64_t* db_codes, // 2 u64 per vector
         uint32_t* dists_out
     ) {
         // Vector 0
         dists_out[0] = static_cast<uint32_t>(_mm_popcnt_u64(q0 ^ db_codes[0]) + _mm_popcnt_u64(q1 ^ db_codes[1]));
         // Vector 1
         dists_out[1] = static_cast<uint32_t>(_mm_popcnt_u64(q0 ^ db_codes[2]) + _mm_popcnt_u64(q1 ^ db_codes[3]));
         // Vector 2
         dists_out[2] = static_cast<uint32_t>(_mm_popcnt_u64(q0 ^ db_codes[4]) + _mm_popcnt_u64(q1 ^ db_codes[5]));
         // Vector 3
         dists_out[3] = static_cast<uint32_t>(_mm_popcnt_u64(q0 ^ db_codes[6]) + _mm_popcnt_u64(q1 ^ db_codes[7]));
     }
     }
