* **Core Microarchitectural Concepts**:
  1. **Anisotropic Error Decomposition in MIPS**:
     * Let $\mathbf{x}$ be a database vector and $\tilde{\mathbf{x}}$ its quantized approximation. Error $\mathbf{e} = \mathbf{x} - \tilde{\mathbf{x}}$.
     * Split $\mathbf{e}$ into parallel component $\mathbf{e}_\parallel = \frac{\langle \mathbf{e}, \mathbf{x} \rangle}{\|\mathbf{x}\|_2^2} \mathbf{x}$ and orthogonal component $\mathbf{e}_\perp = \mathbf{e} - \mathbf{e}_\parallel$.
     * Inner product error: $\langle \mathbf{q}, \mathbf{x} \rangle - \langle \mathbf{q}, \tilde{\mathbf{x}} \rangle = \langle \mathbf{q}, \mathbf{e}_\parallel \rangle + \langle \mathbf{q}, \mathbf{e}_\perp \rangle$.
  2. **Why Parallel Error Destroys Retrieval Recall**:
     * In high dimensions, random queries are nearly orthogonal to $\mathbf{e}_\perp$, so $\mathbb{E}[\langle \mathbf{q}, \mathbf{e}_\perp \rangle] \approx 0$.
     * However, $\mathbf{e}_\parallel$ directly shrinks or expands the effective length $\|\tilde{\mathbf{x}}\|$, systematically destroying top-ranked inner product candidates.
  3. **The ScaNN Loss Function**:
     $$\ell_{\text{aniso}}(\mathbf{x}, \tilde{\mathbf{x}}) = h \|\mathbf{e}_\parallel\|_2^2 + 1.0 \|\mathbf{e}_\perp\|_2^2 \quad \text{where } h \ge 5.0$$

         const float* x,
         const float* c,
         size_t dim,
         float h_parallel = 5.0f
     ) {
         float x_norm_sq = 0.0f;
         float dot_xe = 0.0f;
         float total_e_sq = 0.0f;

         for (size_t d = 0; d < dim; ++d) {
             float diff = x[d] - c[d];
             x_norm_sq += x[d] * x[d];
             dot_xe += x[d] * diff;
             total_e_sq += diff * diff;
         }

         if (x_norm_sq < 1e-12f) return total_e_sq;

         // e_parallel norm squared = (dot(x, e)^2) / norm(x)^2

         float e_perp_sq = total_e_sq - e_par_sq;

         return h_parallel * e_par_sq + e_perp_sq;
