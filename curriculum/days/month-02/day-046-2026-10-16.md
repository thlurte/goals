## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic & Mathematical Foundation**: Matrix Calculus, Linear Layer Jacobians & The Softmax Derivative
* **Theorems & Mathematical Concepts**:
  1. **Matrix Gradients for Linear Transformations**:
     * For matrix product $\mathbf{Y} = \mathbf{X} \mathbf{W}$ where $\mathbf{X} \in \mathbb{R}^{B \times d_{in}}, \mathbf{W} \in \mathbb{R}^{d_{in} \times d_{out}}$:
       $$\frac{\partial \mathcal{L}}{\partial \mathbf{W}} = \mathbf{X}^T \left( \frac{\partial \mathcal{L}}{\partial \mathbf{Y}} \right), \quad \frac{\partial \mathcal{L}}{\partial \mathbf{X}} = \left( \frac{\partial \mathcal{L}}{\partial \mathbf{Y}} \right) \mathbf{W}^T$$
  2. **The Softmax Jacobian Matrix**:
     * Let $p_i = \frac{e^{z_i}}{\sum_{k=1}^K e^{z_k}}$. Using the quotient rule:
       $$\frac{\partial p_i}{\partial z_j} = \begin{cases} p_i(1 - p_i) & \text{if } i = j \\ -p_i p_j & \text{if } i \ne j \end{cases} = p_i(\delta_{ij} - p_j) \implies \mathbf{J}_{\text{softmax}} = \operatorname{diag}(\mathbf{p}) - \mathbf{p} \mathbf{p}^T$$
  3. **Cross-Entropy Loss Gradient**:
     * For $\mathcal{L}_{\text{CE}} = -\sum_{i=1}^K y_i \ln p_i$:
       $$\frac{\partial \mathcal{L}}{\partial z_j} = \sum_{i=1}^K \frac{\partial \mathcal{L}}{\partial p_i} \frac{\partial p_i}{\partial z_j} = -\sum_{i=1}^K \frac{y_i}{p_i} p_i(\delta_{ij} - p_j) = -y_j + p_j \sum_{i=1}^K y_i = p_j - y_j \implies \nabla_{\mathbf{z}} \mathcal{L} = \mathbf{p} - \mathbf{y}$$

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Agner Fog Instruction Tables* & *Intel Intrinsics Guide*
* **Core Microarchitectural Concepts**:
  1. **Register-Resident Table Lookups (Zero L1 Cache Misses)**:
     * Traditional ADC performs memory reads from `LUT[m][code]`.
     * FastScan eliminates **all L1 cache accesses** during search: the 16 distance values for a 4-bit subspace are held **directly in SIMD register `ymm0`**.
  2. **PSHUFB (`_mm256_shuffle_epi8`) Microarchitecture**:
     * Maps 32 4-bit index nibbles to 32 8-bit table values in **1 clock cycle on Execution Port 5**.
     * Accumulated using saturated integer addition `_mm256_adds_epu8` (Port 0/Port 1/Port 5).

  1. **Implement In-Register AVX2 FastScan Kernel** in `src/quantization/fast_scan.cpp`:
     ```cpp
     #include "secan/quantization/fast_scan.h"
     #include <immintrin.h>
     #include <cstdint>
     #include <cstddef>

     namespace secan {
     // Execute FastScan distance computation for 32 database vectors across M 4-bit subspaces
     inline void fast_scan_32vecs_avx2(
         const uint8_t* interleaved_codes, // 32 vectors interleaved: M * 16 bytes
         const __m256i* lut_registers,      // M 256-bit registers (each holds 16-entry LUT duplicated in both lanes)
         size_t M,
         uint16_t* accum_dists_32           // Output 32 accumulated 16-bit distances
     ) {
         __m256i accum_lo = _mm256_setzero_si256(); // Vectors 0..15 (16-bit)
         __m256i accum_hi = _mm256_setzero_si256(); // Vectors 16..31 (16-bit)
         __m256i low_nibble_mask = _mm256_set1_epi8(0x0F);

         for (size_t m = 0; m < M; m += 2) {
             // Load 32 bytes (codes for 32 vectors across 2 subspaces)
             __m256i raw_codes = _mm256_loadu_si256(reinterpret_cast<const __m256i*>(interleaved_codes + (m / 2) * 32));

             // Extract low nibbles (Subspace m)
             __m256i codes_m0 = _mm256_and_si256(raw_codes, low_nibble_mask);
             __m256i dists_m0 = _mm256_shuffle_epi8(lut_registers[m], codes_m0);

             // Extract high nibbles (Subspace m+1)
             __m256i codes_m1 = _mm256_and_si256(_mm256_srli_epi16(raw_codes, 4), low_nibble_mask);
             __m256i dists_m1 = _mm256_shuffle_epi8(lut_registers[m + 1], codes_m1);

             // Sum 8-bit distances
             __m256i sum8 = _mm256_adds_epu8(dists_m0, dists_m1);

             // Widen and accumulate to 16-bit
             __m256i zero = _mm256_setzero_si256();
             accum_lo = _mm256_add_epi16(accum_lo, _mm256_unpacklo_epi8(sum8, zero));
             accum_hi = _mm256_add_epi16(accum_hi, _mm256_unpackhi_epi8(sum8, zero));
         }

         // Store results
         _mm256_storeu_si256(reinterpret_cast<__m256i*>(accum_dists_32), accum_lo);
         _mm256_storeu_si256(reinterpret_cast<__m256i*>(accum_dists_32 + 16), accum_hi);
     }
     }
     ```
