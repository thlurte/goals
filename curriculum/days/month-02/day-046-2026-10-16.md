## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic**: *Computational DAGs, Topological Sorting & Automatic Differentiation Complexity*
* **Core Text & References**: *Evaluating Derivatives: Principles and Techniques of Algorithmic Differentiation* (Griewank & Walther) / *Automatic Differentiation in Machine Learning: A Survey* (Baydin et al.)
* **Theorems & Mathematical Concepts**:
  1. **Computational Graphs & Topological Order**:
     * A neural network is represented as a Directed Acyclic Graph (DAG) $G = (V, E)$ where nodes $v_i \in V$ are elementary operations and edges carry intermediate tensor values.
     * Nodes are topologically sorted such that if $v_i$ depends on $v_j$, then $j < i$.
  2. **Forward-Mode AD (Jacobian-Vector Products / JVPs)**:
     * Propagates tangent vectors $\dot{\mathbf{x}} = \frac{d\mathbf{x}}{dt}$ forward alongside the primal evaluation: $\dot{\mathbf{y}} = J \dot{\mathbf{x}}$.
     * For a function $f: \mathbb{R}^N \to \mathbb{R}^M$, computing the full Jacobian requires **$N$ forward passes** (1 per input dimension). Highly efficient when $N \ll M$.
  3. **Reverse-Mode AD (Vector-Jacobian Products / VJPs / Backprop)**:
     * Propagates adjoint vectors $\bar{\mathbf{y}} = \frac{\partial \mathcal{L}}{\partial \mathbf{y}}$ backward from scalar loss $\mathcal{L} \in \mathbb{R}$: $\bar{\mathbf{x}} = \bar{\mathbf{y}}^T J$.
     * For a scalar loss $\mathcal{L}: \mathbb{R}^N \to \mathbb{R}$ where $N = 100\text{ Billion}$, reverse-mode computes the exact gradient $\nabla_{\mathbf{x}} \mathcal{L} \in \mathbb{R}^N$ in **1 single backward pass** (time complexity $\le 3\times \text{forward pass}$).
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Griewank-Walther Baur-Strassen Theorem: the computational work $W(\nabla f)$ of evaluating the gradient of a scalar function $f(x_1, \dots, x_N)$ via reverse-mode AD is bounded by $W(\nabla f) \le 4 \cdot W(f)$, strictly independent of input dimension $N$.
  - [ ] **Proof 2**: Construct the computational DAG for $f(x_1, x_2) = \ln(x_1 x_2) + \sin(x_1^2 + x_2)$. Label intermediate nodes $v_1, v_2, \dots, v_6$, write out the forward tape, and execute the reverse adjoint pass step-by-step to compute $\frac{\partial f}{\partial x_1}$ and $\frac{\partial f}{\partial x_2}$.
  - [ ] **Problem 3**: Contrast the memory consumption of Forward-Mode AD ($O(1)$ memory, no tape needed) vs. Reverse-Mode AD ($O(T)$ memory storing all intermediate activations for the backward pass). Explain how **Activation Checkpointing (Rematerialization)** trades recomputation FLOPS for $O(\sqrt{T})$ memory.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Agner Fog Instruction Tables*, *Intel Intrinsics Guide* & Hardware Profiling Playbook ([`roadmap.md#part-3`](../../roadmap.md#part-3-verification--tooling-matrix-the-hardware-profiling-playbook))
* **Core Microarchitectural Concepts**:
  1. **Register-Resident Table Lookups (Zero L1 Cache Misses)**:
     * Traditional ADC performs memory reads from `LUT[m][code]`.
     * FastScan eliminates **all L1 cache accesses** during search: the 16 distance values for a 4-bit subspace are held **directly in SIMD register `ymm0`**.
  2. **PSHUFB (`_mm256_shuffle_epi8`) Microarchitecture & Port 5 Pressure**:
     * Maps 32 4-bit index nibbles to 32 8-bit table values in **1 clock cycle on Execution Port 5**.
     * Accumulated using saturated integer addition `_mm256_adds_epu8` (Port 0/Port 1/Port 5).
     * Profile execution port saturation via `perf stat -e cpu/event=0xa1,umask=0x20,name=UOPS_DISPATCHED_PORT_5/`.

* **Tasks & Implementation**:
  1. **Implement In-Register AVX2 FastScan Kernel** in `src/quantization/fast_scan.cpp`:
     ```cpp
     #include "secan/quantization/fast_scan.h"
     #include <immintrin.h>
     #include <cstdint>
     #include <cstddef>

     namespace secan {
     // Execute FastScan distance computation for 32 database vectors across M 4-bit subspaces
     inline void fast_scan_32vecs_avx2(
         const uint8_t* interleaved_codes, // 32 vectors interleaved: M * 16 bytes
         const __m256i* lut_registers,      // M 256-bit registers (each holds 16-entry LUT duplicated in both lanes)
         size_t M,
         uint16_t* accum_dists_32           // Output 32 accumulated 16-bit distances
     ) {
         __m256i accum_lo = _mm256_setzero_si256(); // Vectors 0..15 (16-bit)
         __m256i accum_hi = _mm256_setzero_si256(); // Vectors 16..31 (16-bit)
         __m256i low_nibble_mask = _mm256_set1_epi8(0x0F);

         for (size_t m = 0; m < M; m += 2) {
             // Load 32 bytes (codes for 32 vectors across 2 subspaces)
             __m256i raw_codes = _mm256_loadu_si256(reinterpret_cast<const __m256i*>(interleaved_codes + (m / 2) * 32));

             // Extract low nibbles (Subspace m)
             __m256i codes_m0 = _mm256_and_si256(raw_codes, low_nibble_mask);
             __m256i dists_m0 = _mm256_shuffle_epi8(lut_registers[m], codes_m0);

             // Extract high nibbles (Subspace m+1)
             __m256i codes_m1 = _mm256_and_si256(_mm256_srli_epi16(raw_codes, 4), low_nibble_mask);
             __m256i dists_m1 = _mm256_shuffle_epi8(lut_registers[m + 1], codes_m1);

             // Sum 8-bit distances
             __m256i sum8 = _mm256_adds_epu8(dists_m0, dists_m1);

             // Widen and accumulate to 16-bit
             __m256i zero = _mm256_setzero_si256();
             accum_lo = _mm256_add_epi16(accum_lo, _mm256_unpacklo_epi8(sum8, zero));
             accum_hi = _mm256_add_epi16(accum_hi, _mm256_unpackhi_epi8(sum8, zero));
         }

         // Store results
         _mm256_storeu_si256(reinterpret_cast<__m256i*>(accum_dists_32), accum_lo);
         _mm256_storeu_si256(reinterpret_cast<__m256i*>(accum_dists_32 + 16), accum_hi);
     }
     }
     ```
