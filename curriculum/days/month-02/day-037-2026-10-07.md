## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Calculus* — Gilbert Strang
* **Section**: §13.8 (*Lagrange Multipliers with Multiple Constraints & Eigenvalue Problems*)
* **Theorems & Mathematical Concepts**:
  1. **Multiple Equality Constraints**:
     * To optimize $f(\mathbf{x})$ subject to $k$ constraints $g_1(\mathbf{x}) = c_1, \dots, g_k(\mathbf{x}) = c_k$:
       $$\nabla f(\mathbf{x}^*) = \lambda_1 \nabla g_1(\mathbf{x}^*) + \lambda_2 \nabla g_2(\mathbf{x}^*) + \dots + \lambda_k \nabla g_k(\mathbf{x}^*)$$
     * Geometric interpretation: The gradient $\nabla f$ lies in the linear subspace spanned by the constraint normals $\operatorname{span}\{\nabla g_1, \dots, \nabla g_k\}$.
  2. **The PCA Eigenvalue Connection via Lagrange Multipliers**:
     * Maximize quadratic variance $f(\mathbf{v}) = \mathbf{v}^T \mathbf{\Sigma} \mathbf{v}$ subject to unit norm constraint $g(\mathbf{v}) = \mathbf{v}^T \mathbf{v} = 1$:
       $$\nabla f(\mathbf{v}) = 2\mathbf{\Sigma}\mathbf{v}, \quad \nabla g(\mathbf{v}) = 2\mathbf{v} \implies 2\mathbf{\Sigma}\mathbf{v} = 2\lambda\mathbf{v} \iff \mathbf{\Sigma}\mathbf{v} = \lambda\mathbf{v}$$
     * The optimal projection directions are the eigenvectors of the covariance matrix $\mathbf{\Sigma}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the two-constraint condition $\nabla f = \lambda_1 \nabla g_1 + \lambda_2 \nabla g_2$ by parameterizing the intersection curve $\mathcal{C} = \{g_1 = c_1\} \cap \{g_2 = c_2\}$ with velocity vector $\mathbf{v} = \nabla g_1 \times \nabla g_2$.
  - [ ] **Problem 2**: Find the point on the intersection of the plane $x + y + z = 1$ and the cylinder $x^2 + y^2 = 1$ that is closest to the origin.
  - [ ] **Problem 3**: For a symmetric positive definite matrix $\mathbf{A} \in \mathbb{R}^{n \times n}$, maximize $\mathbf{x}^T \mathbf{A} \mathbf{x}$ subject to $\|\mathbf{x}\|_2 = 1$ and prove that the maximum value is exactly the spectral radius $\lambda_{\max}(\mathbf{A})$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Topic & Text**: Faiss PQ Architecture: Subspace Memory Layouts & Cache Residence
* **Core Microarchitectural Concepts**:
  1. **$64\times$ Compression & L3 Cache Residency**:
     * Uncompressed SIFT1M: $1{,}000{,}000 \times 128 \times 4\text{ B} = \mathbf{512\text{ MB}}$ (Spills to slow DRAM).
     * PQ8 Compressed SIFT1M ($M=8$ bytes/vector): $1{,}000{,}000 \times 8\text{ B} = \mathbf{8\text{ MB}}$ (Fits entirely inside **L3 CPU Cache**!).
     * Streaming through $8\text{ MB}$ achieves memory throughput $>150\text{ GB/s}$, executing scans $>20\times$ faster than DRAM-bound FP32 search.
  2. **Contiguous Codebook Storage**:
     * Store codebooks as a flat contiguous array of size $M \times K^* \times d_s \times 4\text{ bytes}$ ($128\text{ KB}$), mapped directly into L1/L2 cache during training and search.

  1. **Implement Complete `ProductQuantizer` Class** in `src/quantization/product_quantizer.cpp`:
     ```cpp
     #include "secan/quantization/product_quantizer.h"
     #include "secan/distance_avx2.h"
     #include <vector>
     #include <cstring>
     #include <stdexcept>

     namespace secan {
     class ProductQuantizer {
     public:
         size_t dim;
         size_t M;
         size_t d_sub;
         size_t k_sub{256};
         std::vector<float> codebooks; // M * k_sub * d_sub floats

         ProductQuantizer(size_t dimension, size_t num_subspaces)
             : dim(dimension), M(num_subspaces), d_sub(dimension / num_subspaces),
               codebooks(num_subspaces * 256 * (dimension / num_subspaces), 0.0f) {
             if (dimension % num_subspaces != 0) {
                 throw std::invalid_argument("Dimension must be divisible by M");
             }
         }

         void train(const float* train_data, size_t num_train) {
             std::vector<float> sub_data(num_train * d_sub);
             for (size_t m = 0; m < M; ++m) {
                 // Extract m-th subspace slices
                 for (size_t i = 0; i < num_train; ++i) {
                     std::memcpy(sub_data.data() + i * d_sub,
                                 train_data + i * dim + m * d_sub,
                                 d_sub * sizeof(float));
                 }
                 // Train k-means on m-th subspace
                 auto cb = train_subspace_kmeans(sub_data.data(), num_train, d_sub, k_sub, 15);
                 std::memcpy(codebooks.data() + m * k_sub * d_sub, cb.data(), cb.size() * sizeof(float));
             }
         }

         void encode(const float* src, uint8_t* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* vec = src + i * dim;
                 uint8_t* code = dst + i * M;

                 for (size_t m = 0; m < M; ++m) {
                     const float* sub_vec = vec + m * d_sub;
                     const float* sub_cb = codebooks.data() + m * k_sub * d_sub;

                     float min_d = 1e9f;
                     uint8_t best_c = 0;
                     for (size_t c = 0; c < k_sub; ++c) {
                         float d = l2_squared_avx2_unrolled4(sub_vec, sub_cb + c * d_sub, d_sub);
                         if (d < min_d) {
                             min_d = d;
                             best_c = static_cast<uint8_t>(c);
                         }
                     }
                     code[m] = best_c;
                 }
             }
         }
     };
     }
     ```
