## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic**: *Attention Mechanism Matrix Calculus (Q, K, V Gradients & Adjoint Tensors)*
* **Core Text & References**: *Attention Is All You Need* (Vaswani et al.) / *Matrix Differentiation of Multi-Head Self-Attention*
* **Theorems & Mathematical Concepts**:
  1. **The Scaled Dot-Product Attention Forward Equation**:
     * Given $Q, K, V \in \mathbb{R}^{L \times d_k}$, define pre-softmax logits $S \in \mathbb{R}^{L \times L}$ and attention weights $P \in \mathbb{R}^{L \times L}$:
       $$S = \frac{Q K^T}{\sqrt{d_k}}, \quad P = \operatorname{softmax}(S) \quad (\text{row-wise}), \quad O = P V$$
  2. **Upstream Adjoint Gradients through Attention**:
     * Given upstream loss gradient $\frac{\partial \mathcal{L}}{\partial O} \in \mathbb{R}^{L \times d_v}$:
       * **Gradient w.r.t. Value ($V$)**:
         $$\frac{\partial \mathcal{L}}{\partial V} = P^T \frac{\partial \mathcal{L}}{\partial O}$$
       * **Gradient w.r.t. Pre-Softmax Logits ($S$)**:
         $$\frac{\partial \mathcal{L}}{\partial P} = \frac{\partial \mathcal{L}}{\partial O} V^T, \quad \left[\frac{\partial \mathcal{L}}{\partial S}\right]_{ij} = P_{ij} \left( \left[\frac{\partial \mathcal{L}}{\partial P}\right]_{ij} - \sum_{k=1}^L \left[\frac{\partial \mathcal{L}}{\partial P}\right]_{ik} P_{ik} \right)$$
       * **Gradients w.r.t. Query ($Q$) and Key ($K$)**:
         $$\frac{\partial \mathcal{L}}{\partial Q} = \frac{1}{\sqrt{d_k}} \frac{\partial \mathcal{L}}{\partial S} K, \quad \frac{\partial \mathcal{L}}{\partial K} = \frac{1}{\sqrt{d_k}} \left(\frac{\partial \mathcal{L}}{\partial S}\right)^T Q$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive $\frac{\partial \mathcal{L}}{\partial V} = P^T \frac{\partial \mathcal{L}}{\partial O}$ using the trace identity: $d\mathcal{L} = \operatorname{Tr}\left(\left(\frac{\partial \mathcal{L}}{\partial O}\right)^T dO\right) = \operatorname{Tr}\left(\left(\frac{\partial \mathcal{L}}{\partial O}\right)^T P \, dV\right) = \operatorname{Tr}\left(P^T \frac{\partial \mathcal{L}}{\partial O} \, dV\right)$.
  - [ ] **Proof 2**: Derive $\frac{\partial \mathcal{L}}{\partial Q} = \frac{1}{\sqrt{d_k}} \frac{\partial \mathcal{L}}{\partial S} K$ and $\frac{\partial \mathcal{L}}{\partial K} = \frac{1}{\sqrt{d_k}} \left(\frac{\partial \mathcal{L}}{\partial S}\right)^T Q$ from $dS = \frac{1}{\sqrt{d_k}}(dQ \, K^T + Q \, dK^T)$.
  - [ ] **Problem 3**: For causal autoregressive attention where $P_{ij} = 0$ for $j > i$ (masked upper triangle), verify how the sparsity mask directly zeroes out the corresponding elements in $\frac{\partial \mathcal{L}}{\partial S}$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Paper**: *"Accelerated Nearest Neighbor Search with Quick ADC"* (André et al., 2015) & Faiss FastScan Architecture
* **Core Microarchitectural Concepts**:
  1. **Why 4-Bit PQ ($K^*=16$ Centroids) Dominates Modern SIMD**:
     * A 16-entry 8-bit lookup table occupies **exactly 16 bytes** (the size of a 128-bit XMM register).
     * `_mm256_shuffle_epi8` (PSHUFB) takes this 16-byte table and evaluates **32 simultaneous lookups in 1 single CPU cycle on Port 5**.
  2. **Interleaved Data Layout for FastScan**:
     * Instead of storing vectors sequentially ($v_1, v_2, \dots$), group 32 vectors into a tile and store code bytes interleaved across the 32 vectors, enabling 32 queries/distances to be updated with 1 single SIMD instruction.

     ```cpp
     #include "secan/quantization/product_quantizer.h"
     #include "secan/distance_avx2.h"
     #include <vector>
     #include <cstring>

     namespace secan {
     class ProductQuantizer4 {
     public:
         size_t dim;
         size_t M; // e.g. M=16 or M=32
         size_t d_sub;
         size_t k_sub{16}; // 4-bit = 16 centroids
         std::vector<float> codebooks; // M * 16 * d_sub

         ProductQuantizer4(size_t dimension, size_t num_subspaces)
             : dim(dimension), M(num_subspaces), d_sub(dimension / num_subspaces),
               codebooks(num_subspaces * 16 * (dimension / num_subspaces), 0.0f) {}

         void train(const float* data, size_t num_vectors) {
             std::vector<float> sub_data(num_vectors * d_sub);
             for (size_t m = 0; m < M; ++m) {
                 for (size_t i = 0; i < num_vectors; ++i) {
                     std::memcpy(sub_data.data() + i * d_sub,
                                 data + i * dim + m * d_sub,
                                 d_sub * sizeof(float));
                 }
                 auto cb = train_subspace_kmeans(sub_data.data(), num_vectors, d_sub, 16, 15);
                 std::memcpy(codebooks.data() + m * 16 * d_sub, cb.data(), cb.size() * sizeof(float));
             }
         }

         // Encode vectors into packed 4-bit nibbles: M/2 bytes per vector
         void encode(const float* src, uint8_t* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* vec = src + i * dim;
                 uint8_t* out = dst + i * (M / 2);

                 for (size_t m = 0; m < M; m += 2) {
                     // Subspace m
                     uint8_t c0 = find_nearest_centroid(vec + m * d_sub, codebooks.data() + m * 16 * d_sub);
                     // Subspace m+1
                     uint8_t c1 = find_nearest_centroid(vec + (m + 1) * d_sub, codebooks.data() + (m + 1) * 16 * d_sub);
                     out[m / 2] = (c1 << 4) | (c0 & 0x0F);
                 }
             }
         }

     private:
         uint8_t find_nearest_centroid(const float* sub_vec, const float* cb) const {
             float min_d = 1e9f;
             uint8_t best_c = 0;
             for (size_t c = 0; c < 16; ++c) {
                 float d = l2_squared_avx2_unrolled4(sub_vec, cb + c * d_sub, d_sub);
                 if (d < min_d) {
                     min_d = d;
                     best_c = static_cast<uint8_t>(c);
                 }
             }
             return best_c;
         }
     };
     }
     ```
