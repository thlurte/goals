* **Book**: *Calculus* — Gilbert Strang
* **Section**: §15.4 (*Green's Theorem in the Plane & Planar Area Integrals*)
* **Theorems & Mathematical Concepts**:
  1. **Green's Theorem (Circulation Form)**:
     * Let $\mathcal{C}$ be a positively oriented, piecewise-smooth simple closed curve bounding region $\mathcal{D} \subset \mathbb{R}^2$:
       $$\oint_{\mathcal{C}} (P dx + Q dy) = \iint_{\mathcal{D}} \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dA$$
  2. **Planar Area via Boundary Contour Integrals**:
     $$\operatorname{Area}(\mathcal{D}) = \frac{1}{2} \oint_{\mathcal{C}} (x dy - y dx) = \oint_{\mathcal{C}} x dy = -\oint_{\mathcal{C}} y dx$$
  3. **Green's Theorem (Flux Form / 2D Divergence Theorem)**:
     $$\oint_{\mathcal{C}} \mathbf{F} \cdot \mathbf{n} \, ds = \oint_{\mathcal{C}} (P dy - Q dx) = \iint_{\mathcal{D}} \left( \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} \right) dA$$

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Paper**: *"Accelerated Nearest Neighbor Search with Quick ADC"* (André et al., 2015) & Faiss FastScan Architecture
* **Core Microarchitectural Concepts**:
  1. **Why 4-Bit PQ ($K^*=16$ Centroids) Dominates Modern SIMD**:
     * A 16-entry 8-bit lookup table occupies **exactly 16 bytes** (the size of a 128-bit XMM register).
     * `_mm256_shuffle_epi8` (PSHUFB) takes this 16-byte table and evaluates **32 simultaneous lookups in 1 single CPU cycle on Port 5**.
  2. **Interleaved Data Layout for FastScan**:
     * Instead of storing vectors sequentially ($v_1, v_2, \dots$), group 32 vectors into a tile and store code bytes interleaved across the 32 vectors, enabling 32 queries/distances to be updated with 1 single SIMD instruction.

     ```cpp
     #include "secan/quantization/product_quantizer.h"
     #include "secan/distance_avx2.h"
     #include <vector>
     #include <cstring>

     namespace secan {
     class ProductQuantizer4 {
     public:
         size_t dim;
         size_t M; // e.g. M=16 or M=32
         size_t d_sub;
         size_t k_sub{16}; // 4-bit = 16 centroids
         std::vector<float> codebooks; // M * 16 * d_sub

         ProductQuantizer4(size_t dimension, size_t num_subspaces)
             : dim(dimension), M(num_subspaces), d_sub(dimension / num_subspaces),
               codebooks(num_subspaces * 16 * (dimension / num_subspaces), 0.0f) {}

         void train(const float* data, size_t num_vectors) {
             std::vector<float> sub_data(num_vectors * d_sub);
             for (size_t m = 0; m < M; ++m) {
                 for (size_t i = 0; i < num_vectors; ++i) {
                     std::memcpy(sub_data.data() + i * d_sub,
                                 data + i * dim + m * d_sub,
                                 d_sub * sizeof(float));
                 }
                 auto cb = train_subspace_kmeans(sub_data.data(), num_vectors, d_sub, 16, 15);
                 std::memcpy(codebooks.data() + m * 16 * d_sub, cb.data(), cb.size() * sizeof(float));
             }
         }

         // Encode vectors into packed 4-bit nibbles: M/2 bytes per vector
         void encode(const float* src, uint8_t* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* vec = src + i * dim;
                 uint8_t* out = dst + i * (M / 2);

                 for (size_t m = 0; m < M; m += 2) {
                     // Subspace m
                     uint8_t c0 = find_nearest_centroid(vec + m * d_sub, codebooks.data() + m * 16 * d_sub);
                     // Subspace m+1
                     uint8_t c1 = find_nearest_centroid(vec + (m + 1) * d_sub, codebooks.data() + (m + 1) * 16 * d_sub);
                     out[m / 2] = (c1 << 4) | (c0 & 0x0F);
                 }
             }
         }

     private:
         uint8_t find_nearest_centroid(const float* sub_vec, const float* cb) const {
             float min_d = 1e9f;
             uint8_t best_c = 0;
             for (size_t c = 0; c < 16; ++c) {
                 float d = l2_squared_avx2_unrolled4(sub_vec, cb + c * d_sub, d_sub);
                 if (d < min_d) {
                     min_d = d;
                     best_c = static_cast<uint8_t>(c);
                 }
             }
             return best_c;
         }
     };
     }
     ```
