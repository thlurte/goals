* **Target File**: `~/personal/goals/essays/essay_07.md`
* **5-Part Standard Structure**:
  1. **Mathematical Foundation**:
     * Anisotropic error decomposition: $\mathbf{e} = \mathbf{e}_\parallel + \mathbf{e}_\perp$.
     * Proof that $\mathbb{E}[\langle \mathbf{q}, \mathbf{e}_\perp \rangle] = 0$ while $\langle \mathbf{q}, \mathbf{e}_\parallel \rangle$ systematically degrades top-$k$ MIPS ranking.
     * Formulation of the weighted directional loss: $\ell_{\text{aniso}}(\mathbf{x}, \tilde{\mathbf{x}}) = h \|\mathbf{e}_\parallel\|_2^2 + \|\mathbf{e}_\perp\|_2^2$.
  2. **The Systems Bottleneck**:
     * Eliminating the L1 Data Cache load bottleneck: Moving from cache-lookup ADC to register-resident FastScan.
     * Port 5 `vpshufb` execution unit saturation (32 lookups/cycle).
  3. **The Engine Architecture**:
     * `secan` implementation: Interleaved 4-bit storage tiles, in-register table lookups, and OPQ rotation pipeline.
  4. **Empirical Benchmarks**:
     * Latency & QPS curves: Standard PQ ADC ($20\text{M vecs/sec}$) vs AVX2 FastScan ($120\text{M vecs/sec}$).
  5. **Key Takeaway**:
     * Maximum performance requires co-designing loss functions with CPU execution ports: anisotropic loss fixes the math, while `vpshufb` saturates the hardware.

  1. **Matryoshka Representation Learning (MRL) Loss** in `src/mrl_loss.py`:
     ```python
     import torch
     import torch.nn as nn
     import torch.nn.functional as F

     class MatryoshkaInfoNCELoss(nn.Module):
         def __init__(self, nest_dims: list[int] = [64, 128, 256, 512, 768], temperature: float = 0.05):
             super().__init__()
             self.nest_dims = nest_dims
             self.temperature = temperature

         def forward(self, query_embs: torch.Tensor, doc_embs: torch.Tensor) -> torch.Tensor:
             total_loss = 0.0
             for dim in self.nest_dims:
                 # Slice nested prefix dimensions
                 q_slice = F.normalize(query_embs[:, :dim], p=2, dim=1)
                 d_slice = F.normalize(doc_embs[:, :dim], p=2, dim=1)

                 sim_matrix = torch.matmul(q_slice, d_slice.T) / self.temperature
                 labels = torch.arange(query_embs.shape[0], device=query_embs.device)
                 total_loss += F.cross_entropy(sim_matrix, labels)

             return total_loss / len(self.nest_dims)
     ```
