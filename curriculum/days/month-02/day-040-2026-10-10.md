* **Section**: §14.7 (*Change of Variables in Multiple Integrals & The Jacobian Determinant*)
* **Theorems & Mathematical Concepts**:
  1. **Change of Variables in $\mathbb{R}^n$**:
     $$\int \dots \int_R f(\mathbf{x}) d\mathbf{x} = \int \dots \int_S f(T(\mathbf{u})) \left| \det \mathbf{J}_T(\mathbf{u}) \right| d\mathbf{u}$$
  2. **The 3D Spherical Coordinate Jacobian**:
     $$\mathbf{J} = \begin{pmatrix} \sin\phi\cos\theta & \rho\cos\phi\cos\theta & -\rho\sin\phi\sin\theta \\ \sin\phi\sin\theta & \rho\cos\phi\sin\theta & \rho\sin\phi\cos\theta \\ \cos\phi & -\rho\sin\phi & 0 \end{pmatrix} \implies \left| \det \mathbf{J} \right| = \rho^2 \sin\phi$$
     $$dV = dx dy dz = \rho^2 \sin\phi \, d\rho \, d\phi \, d\theta$$
  3. **Linear Coordinate Transformations**:
     * For linear map $\mathbf{x} = \mathbf{A}\mathbf{u}$, the Jacobian is constant: $\left|\det \mathbf{J}\right| = |\det \mathbf{A}|$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *The Art of Writing Efficient Programs* — Fedor G. Pikus (Ch 11)
* **Core Microarchitectural Concepts**:
  1. **The Composed IVF-PQ Index Architecture**:
     * **Level 1 (Coarse Routing)**: Query evaluated against $K=1024$ coarse centroids to select top `nprobe` inverted lists.
     * **Level 2 (Inverted List Scan)**: Selected lists store $M$-byte PQ codes (e.g. $M=8$ bytes per vector instead of 512 bytes).
  2. **Residual Product Quantization (OPQ / Residual PQ)**:
     * Storing raw vector PQ codes inside Voronoi cells introduces large quantization error.
     * Encoding the **centroid residual** $\mathbf{r} = \mathbf{x} - \mathbf{c}_i$ concentrates vector variance tightly around the origin, improving quantization SNR by $+4.2\text{ dB}$.

  1. **Implement Composed `IvfPqIndex` Architecture** in `src/index/ivf_pq_index.cpp`:
     ```cpp
     #include "secan/index/ivf_flat_index.h"
     #include "secan/quantization/product_quantizer.h"
     #include <vector>

     namespace secan {
     struct IvfPqPostingList {
         std::vector<uint32_t> ids;
         std::vector<uint8_t> pq_codes; // Packed N_list * M bytes
     };

     class IvfPqIndex {
     public:
         size_t dim;
         size_t num_clusters;
         size_t M;
         std::vector<float> coarse_centroids; // K * dim
         ProductQuantizer pq;
         std::vector<IvfPqPostingList> lists;

         IvfPqIndex(size_t dimension, size_t n_clusters, size_t n_subspaces)
             : dim(dimension), num_clusters(n_clusters), M(n_subspaces),
               pq(dimension, n_subspaces), lists(n_clusters) {}

         void train_and_build(const float* data, size_t num_vectors) {
             // 1. Train coarse centroids using spherical k-means
             coarse_centroids = train_spherical_kmeans(data, num_vectors, dim, num_clusters, 20);

             // 2. Train Product Quantizer on residuals
             std::vector<float> residuals(num_vectors * dim);
             for (size_t i = 0; i < num_vectors; ++i) {
                 // Find nearest centroid
                 size_t best_c = find_nearest_centroid(data + i * dim);
                 for (size_t d = 0; d < dim; ++d) {
                     residuals[i * dim + d] = data[i * dim + d] - coarse_centroids[best_c * dim + d];
                 }
             }
             pq.train(residuals.data(), num_vectors);

             // 3. Populate inverted lists with M-byte residual codes
             for (size_t i = 0; i < num_vectors; ++i) {
                 size_t best_c = find_nearest_centroid(data + i * dim);
                 std::vector<uint8_t> code(M);
                 pq.encode(residuals.data() + i * dim, code.data(), 1);
                 lists[best_c].ids.push_back(static_cast<uint32_t>(i));
                 lists[best_c].pq_codes.insert(lists[best_c].pq_codes.end(), code.begin(), code.end());
             }
         }

     private:
         size_t find_nearest_centroid(const float* vec) const {
             // Coarse search over K centroids
             float max_sim = -1e9f;
             size_t best_idx = 0;
             for (size_t c = 0; c < num_clusters; ++c) {
                 float sim = ip_avx2_unrolled4(vec, coarse_centroids.data() + c * dim, dim);
                 if (sim > max_sim) {
                     max_sim = sim;
                     best_idx = c;
                 }
             }
             return best_idx;
         }
     };
     }
     ```
