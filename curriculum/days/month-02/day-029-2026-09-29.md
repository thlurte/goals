## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Topic & Mathematical Foundation**: Probability Primer, Expectation, Variance & The Johnson-Lindenstrauss Lemma
* **Theorems & Mathematical Concepts**:
  1. **Expectation & Variance in $\mathbb{R}^d$**:
     $$\mathbb{E}[X] = \int_{-\infty}^\infty x f_X(x) dx, \quad \operatorname{Var}(X) = \mathbb{E}\left[(X - \mathbb{E}[X])^2\right] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$$
  2. **The Gaussian Distribution**:
     $$f(x) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right)$$
  3. **The Johnson-Lindenstrauss (JL) Lemma**:
     * For any set of $n$ points $V \subset \mathbb{R}^D$ and error tolerance $\epsilon \in (0, 1)$, there exists a linear projection matrix $A \in \mathbb{R}^{d \times D}$ with $d = \mathcal{O}\left( \frac{\ln n}{\epsilon^2} \right)$ such that for all $u, v \in V$:
       $$(1 - \epsilon) \|u - v\|_2^2 \le \left\| \frac{1}{\sqrt{d}} A u - \frac{1}{\sqrt{d}} A v \right\|_2^2 \le (1 + \epsilon) \|u - v\|_2^2$$
* **Pencil & Paper Problem Set**:

  - [ ] **Proof 2**: For $Z \sim \mathcal{N}(0, 1)$, prove that $\mathbb{E}[Z^2] = 1$ and $\mathbb{E}[Z^4] = 3$ using integration by parts on the Gaussian integral.
  - [ ] **Problem 3**: For a database of $n = 10^6$ vectors and distortion $\epsilon = 0.15$, compute the minimum target dimension $d \approx \frac{8 \ln n}{\epsilon^2}$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Optimizing software in C++* (Agner Fog Ch 7.2) & *Computer Systems: A Programmer's Perspective* (CS:APP §2.2–2.3)
* **Core Microarchitectural Concepts**:
  1. **Scalar Quantization (SQ8) Memory Mechanics**:
     * Quantizing 32-bit floats into 8-bit unsigned integers (`uint8_t`) shrinks memory bandwidth demands by **exactly $4\times$** (e.g. SIFT1M decreases from $512\text{ MB} \to 128\text{ MB}$).
     * A $128\text{ MB}$ dataset fits almost entirely within modern shared L3 CPU caches (or across 2 NUMA sockets), transforming DRAM bottlenecks into cache hits.
  2. **Percentile Clipping & Outlier Robustness**:
     * Real-world embeddings (e.g. BERT/CLIP) have heavy-tailed activation distributions.
     * Hard $\min/\max$ quantization causes severe precision loss due to outliers.
     * Percentile clipping (clamping values outside the $0.05\text{th}$ and $99.95\text{th}$ percentiles) restores full 8-bit resolution to $99.9\%$ of coordinate values.

* **Tasks & Implementation**:
  1. **Implement SQ8 Quantizer with Percentile Clipping** in `src/quantization/scalar_quantizer.cpp`:
     ```cpp
     #include "secan/quantization/scalar_quantizer.h"
     #include <algorithm>
     #include <vector>
     #include <cmath>

     namespace secan {
     struct ScalarQuantizer8 {
         size_t dim{0};
         float min_val{0.0f};
         float max_val{0.0f};
         float inv_step{0.0f};
         float step{0.0f};

         void train(const float* data, size_t num_vectors, size_t dimension) {
             dim = dimension;
             size_t total_elements = num_vectors * dim;
             std::vector<float> sample(data, data + std::min(total_elements, size_t(100000)));
             std::sort(sample.begin(), sample.end());

             // 0.05th and 99.95th percentiles
             min_val = sample[sample.size() * 5 / 10000];
             max_val = sample[sample.size() * 9995 / 10000];
             step = (max_val - min_val) / 255.0f;
             inv_step = 1.0f / step;
         }

         void encode(const float* src, uint8_t* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors * dim; ++i) {
                 float val = std::clamp(src[i], min_val, max_val);
                 dst[i] = static_cast<uint8_t>((val - min_val) * inv_step + 0.5f);
             }
         }

         void decode(const uint8_t* src, float* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors * dim; ++i) {
                 dst[i] = min_val + static_cast<float>(src[i]) * step;
             }
         }
     };
     }
     ```
