## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Statistical Inference* — George Casella & Roger L. Berger
* **Sections**: §2.6 (*The Cramér-Rao Lower Bound (CRLB) & Estimator Efficiency*)
* **Theorems & Mathematical Concepts**:
  1. **The Cramér-Rao Inequality for Unbiased Estimators**:
     * Let $W(\mathbf{X})$ be any unbiased estimator of $\theta$ ($E[W(\mathbf{X})] = \theta$).
     * Under regularity conditions allowing derivative-integral interchange:
       $$\operatorname{Var}(W(\mathbf{X})) \ge \frac{1}{I_n(\theta)} = \frac{1}{n I_1(\theta)}$$
  2. **Cauchy-Schwarz Proof via Score Covariance**:
     * Let $S_n(\theta) = \sum_{i=1}^n \frac{\partial \ln f(X_i \mid \theta)}{\partial \theta}$ be the score function ($E[S_n] = 0, \operatorname{Var}(S_n) = I_n(\theta)$).
     * $$\operatorname{Cov}(W, S_n) = E[W S_n] = \int W(\mathbf{x}) \frac{\nabla_\theta f(\mathbf{x})}{f(\mathbf{x})} f(\mathbf{x}) d\mathbf{x} = \frac{d}{d\theta} \int W(\mathbf{x}) f(\mathbf{x}) d\mathbf{x} = \frac{d}{d\theta} E[W] = 1$$
     * By Cauchy-Schwarz: $(\operatorname{Cov}(W, S_n))^2 \le \operatorname{Var}(W) \operatorname{Var}(S_n) \implies 1 \le \operatorname{Var}(W) I_n(\theta) \implies \operatorname{Var}(W) \ge \frac{1}{I_n(\theta)}$.
  3. **Efficiency & UMVUE**:
     * An unbiased estimator is **efficient** if $\operatorname{Var}(\hat{\theta}) = \frac{1}{I_n(\theta)}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the Cramér-Rao Lower Bound step-by-step using Cauchy-Schwarz on $\operatorname{Cov}(W, S_n) = 1$.
  - [ ] **Proof 2**: Derive the generalized CRLB for biased estimators with bias $b(\theta) = E[W] - \theta$: prove that $\operatorname{Var}(W) \ge \frac{(1 + b'(\theta))^2}{I_n(\theta)}$.
  - [ ] **Problem 3**: For Gaussian samples $X_1, \dots, X_n \sim \mathcal{N}(\mu, \sigma^2)$, compute the Fisher Information $I_n(\mu) = n/\sigma^2$. Prove that $\operatorname{Var}(\bar{X}_n) = \sigma^2/n$ achieves the CRLB bound with equality, certifying $\bar{X}_n$ as the UMVUE.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* (Ch 19) — *Heterogeneous CPU+GPU Workload Partitioning*
* **Core Microarchitectural Concepts**:
  1. **Tiered Memory Workload Partitioning**:
     * When dataset size exceeds GPU VRAM capacity (e.g. $10\text{M vectors} = 5.12\text{ GB} > \text{VRAM budget}$):
       * **Hot Partition ($20\%$)**: Pinned in GPU VRAM, evaluated via GPU FastScan ($0.05\text{ ms}$).
       * **Cold Partition ($80\%$)**: Resides in Host DRAM, evaluated via AVX2 SIMD threads ($0.6\text{ ms}$).
  2. **Asynchronous Parallel Execution**:
     * Query is submitted to GPU CUDA stream while CPU thread pool spawns OpenMP tasks in parallel.
     * Lock-free merge step combines top-$k$ heaps once both compute streams finish.

* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement Heterogeneous CPU+GPU Query Engine** in `include/secan/hybrid/heterogeneous_engine.h`:
     ```cpp
     #pragma once
     #include "secan/gpu/gpu_index_unified.cuh"
     #include "secan/simd/distance_avx2.h"
     #include "secan/hnsw/heap.h"
     #include <thread>
     #include <future>

     namespace secan {
     class HeterogeneousVectorEngine {
     private:
         std::unique_ptr<UnifiedGpuIndex> gpu_index;
         const float* cpu_vectors;
         size_t cpu_vector_count;
         size_t dim;

     public:
         HeterogeneousVectorEngine(std::unique_ptr<UnifiedGpuIndex> gpu_idx, const float* host_vecs, size_t n_host, size_t d)
             : gpu_index(std::move(gpu_idx)), cpu_vectors(host_vecs), cpu_vector_count(n_host), dim(d) {}

         std::vector<NeighborPair> search_hybrid(const float* query, size_t top_k) {
             // 1. Launch async GPU search task
             auto gpu_future = std::async(std::launch::async, [&]() {
                 // GPU search
                 return std::vector<NeighborPair>();
             });

             // 2. Concurrently execute CPU AVX2 scanning
             BoundedFlatHeap cpu_heap(top_k);
             for (size_t i = 0; i < cpu_vector_count; ++i) {
                 float dist = l2_distance_avx2(query, cpu_vectors + i * dim, dim);
                 cpu_heap.insert(static_cast<uint32_t>(i), dist);
             }

             // 3. Merge GPU and CPU heaps
             auto gpu_results = gpu_future.get();
             for (const auto& p : gpu_results) {
                 cpu_heap.insert(p.id, p.dist);
             }

             return cpu_heap.to_sorted_vector();
         }
     };
     }
     ```
