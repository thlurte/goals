### 🔹 Part 1: Theory & Concepts (Monday Syllabus)
* **Book**: *Elements of Information Theory* — Thomas M. Cover & Joy A. Thomas
* **Sections**: §1.1–1.3 (*Shannon Entropy, Self-Information & Maximum Entropy*)
* **Theorems & Mathematical Concepts**:
  1. **Self-Information & Shannon Entropy**:
     * Self-Information of event $x$: $I(x) = -\log_2 p(x)$ (measured in bits).
     * Shannon Entropy of discrete random variable $X$:
       $$H(X) = E[I(X)] = -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x)$$
  2. **Bounds on Discrete Entropy**:
     * Non-negativity: $H(X) \ge 0$, with equality $H(X) = 0 \iff \exists x_0 \text{ s.t. } p(x_0) = 1$.
     * Maximum Entropy:
       $$H(X) \le \log_2 |\mathcal{X}|$$
       with equality if and only if $X$ is uniformly distributed ($p(x) = \frac{1}{|\mathcal{X}|}$ for all $x$).
  3. **Binary Entropy Function**:
     * For $\operatorname{Bernoulli}(p)$: $H_b(p) = -p \log_2 p - (1-p) \log_2(1-p)$, strictly concave on $[0, 1]$ with maximum $H_b(1/2) = 1\text{ bit}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the maximum entropy theorem $H(X) \le \log_2 |\mathcal{X}|$ using Jensen's inequality applied to the strictly concave logarithm function:
    $$H(X) = \sum_{x \in \mathcal{X}} p(x) \log_2 \frac{1}{p(x)} \le \log_2 \left( \sum_{x \in \mathcal{X}} p(x) \frac{1}{p(x)} \right) = \log_2 |\mathcal{X}|$$
  - [ ] **Proof 2**: Derive the second derivative of the binary entropy function $\frac{d^2 H_b}{dp^2} = -\frac{1}{\ln 2} \left( \frac{1}{p} + \frac{1}{1-p} \right) < 0$, proving strict concavity for all $p \in (0, 1)$.
  - [ ] **Problem 3**: In 8-bit Product Quantization with $K = 256$ centroids per subspace, code assignment frequencies are observed with empirical entropy $H(C) = 6.0\text{ bits}$. Compute the code redundancy $R = 1 - \frac{H(C)}{\log_2 256} = 25\%$ and calculate the effective number of utilized centroids $2^{H(C)} = 64$.

### 🔹 Part 2: Properties & Geometric Symmetries (Tuesday Syllabus)
* **Book**: *Elements of Information Theory* — Thomas M. Cover & Joy A. Thomas
* **Sections**: §1.4–1.6 (*Joint Entropy, Conditional Entropy & The Entropy Chain Rule*)
* **Theorems & Mathematical Concepts**:
  1. **Joint & Conditional Entropy**:
     * Joint Entropy: $H(X, Y) = -\sum_{x \in \mathcal{X}, y \in \mathcal{Y}} p(x, y) \log_2 p(x, y)$.
     * Conditional Entropy: $H(Y \mid X) = -\sum_{x, y} p(x, y) \log_2 p(y \mid x) = \sum_{x} p(x) H(Y \mid X = x)$.
  2. **The Entropy Chain Rule**:
     $$H(X, Y) = H(X) + H(Y \mid X)$$
     * Generalization to $n$ random variables:
       $$H(X_1, X_2, \dots, X_n) = \sum_{i=1}^n H(X_i \mid X_{i-1}, \dots, X_1)$$
  3. **Conditioning Reduces Entropy (Information Never Hurts)**:
     $$H(Y \mid X) \le H(Y)$$
     * Equality holds if and only if $X$ and $Y$ are strictly independent ($X \perp Y$).
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the chain rule $H(X, Y) = H(X) + H(Y \mid X)$ by expanding $\log_2 p(x, y) = \log_2 p(x) + \log_2 p(y \mid x)$ and splitting the expectation sum.
  - [ ] **Proof 2**: Prove that conditioning reduces entropy $H(Y \mid X) \le H(Y)$ using the non-negativity of Kullback-Leibler divergence $D_{KL}(p(x, y) \parallel p(x)p(y)) = H(Y) - H(Y \mid X) \ge 0$.
  - [ ] **Problem 3**: In Residual Vector Quantization (RVQ) with 2 codebook stages, stage 1 codebook has entropy $H(C_1) = 7.5\text{ bits}$, and stage 2 residual codebook given stage 1 has conditional entropy $H(C_2 \mid C_1) = 6.8\text{ bits}$. Compute total joint entropy $H(C_1, C_2) = 14.3\text{ bits}$ and the residual mutual dependency $I(C_1; C_2)$ if unconditioned $H(C_2) = 7.2\text{ bits}$.

### 🔹 Part 3: Core Theorems & Derivations (Wednesday Syllabus)
* **Book**: *Elements of Information Theory* — Thomas M. Cover & Joy A. Thomas
* **Sections**: §2.1–2.3 (*Relative Entropy (Kullback-Leibler Divergence) & Gibbs' Inequality*)
* **Theorems & Mathematical Concepts**:
  1. **Relative Entropy / KL Divergence**:
     * Measure of inefficiency in assuming distribution $Q$ when the true distribution is $P$:
       $$D_{KL}(P \parallel Q) = \sum_{x \in \mathcal{X}} P(x) \log_2 \frac{P(x)}{Q(x)}$$
  2. **Information Inequality (Gibbs' Inequality)**:
     $$D_{KL}(P \parallel Q) \ge 0$$
     * Equality holds if and only if $P(x) = Q(x)$ for all $x \in \mathcal{X}$.
     * **Proof via Jensen's Inequality**:
       $$-D_{KL}(P \parallel Q) = \sum_{x} P(x) \ln \frac{Q(x)}{P(x)} \le \ln \left( \sum_{x} P(x) \frac{Q(x)}{P(x)} \right) = \ln \left( \sum_{x} Q(x) \right) = \ln(1) = 0$$
       Multiplying by $-1$ establishes $D_{KL}(P \parallel Q) \ge 0$.
  3. **Gaussian KL Divergence**:
     * For $P = \mathcal{N}(\boldsymbol{\mu}_0, \boldsymbol{\Sigma}_0)$ and $Q = \mathcal{N}(\boldsymbol{\mu}_1, \boldsymbol{\Sigma}_1)$:
       $$D_{KL}(P \parallel Q) = \frac{1}{2} \left[ \operatorname{tr}(\boldsymbol{\Sigma}_1^{-1} \boldsymbol{\Sigma}_0) + (\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0)^T \boldsymbol{\Sigma}_1^{-1} (\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0) - d + \ln \frac{\det \boldsymbol{\Sigma}_1}{\det \boldsymbol{\Sigma}_0} \right]$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive Gibbs' inequality $D_{KL}(P \parallel Q) \ge 0$ step-by-step using Jensen's inequality on the strictly concave logarithm function.
  - [ ] **Proof 2**: Derive the Gaussian KL divergence formula for 1D Gaussians $\mathcal{N}(\mu_0, \sigma_0^2)$ vs $\mathcal{N}(\mu_1, \sigma_1^2)$: $D_{KL} = \ln \frac{\sigma_1}{\sigma_0} + \frac{\sigma_0^2 + (\mu_0 - \mu_1)^2}{2\sigma_1^2} - \frac{1}{2}$.
  - [ ] **Problem 3**: In vector quantization loss analysis, empirical vector distribution is $P = \mathcal{N}(0, 1)$ while reconstructed codebook distribution is $Q = \mathcal{N}(0, \sigma^2)$. Derive the relative entropy $D_{KL}(P \parallel Q) = \frac{1}{2}\left(\frac{1}{\sigma^2} - 1 + \ln \sigma^2\right)$ and prove that the minimum information loss occurs at $\sigma = 1$.
