* **Book / Paper**: *TurboQuant: Extreme KV Cache Compression via Polar Quantization & QJL Residual Correction* (Google Research, 2024)
* **Core Microarchitectural Concepts**:
  1. **PolarQuant Orthogonal Random Rotation**:
     * Multiplies key vectors by a randomized Hadamard / Haar orthogonal matrix $H$: $\tilde{\mathbf{k}} = H \mathbf{k}$.
     * Flattens dimensional outliers, ensuring coordinates are identically sub-Gaussian with zero kurtosis.
  2. **1-Bit QJL Residual Attention Correction**:
     * 3-bit uniform scalar quantization followed by a 1-bit sign vector residual $\mathbf{r} = \operatorname{sign}(\tilde{\mathbf{k}} - \hat{\mathbf{k}})$.
     * Replaces expensive FP16 KV cache fetches with 4-bit integer streaming, cutting memory bandwidth by **$75\%$** with zero recall degradation on 128K context benchmarks.
