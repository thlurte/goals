## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* (Ch 19) — *Heterogeneous CPU+GPU Workload Partitioning*
* **Core Microarchitectural Concepts**:
  1. **Tiered Memory Workload Partitioning**:
     * When dataset size exceeds GPU VRAM capacity (e.g. $10\text{M vectors} = 5.12\text{ GB} > \text{VRAM budget}$):
       * **Hot Partition ($20\%$)**: Pinned in GPU VRAM, evaluated via GPU FastScan ($0.05\text{ ms}$).
       * **Cold Partition ($80\%$)**: Resides in Host DRAM, evaluated via AVX2 SIMD threads ($0.6\text{ ms}$).
  2. **Asynchronous Parallel Execution**:
     * Query is submitted to GPU CUDA stream while CPU thread pool spawns OpenMP tasks in parallel.
     * Lock-free merge step combines top-$k$ heaps once both compute streams finish.

     ```cpp
     #pragma once
     #include "secan/gpu/gpu_index_unified.cuh"
     #include "secan/simd/distance_avx2.h"
     #include "secan/hnsw/heap.h"
     #include <thread>
     #include <future>

     namespace secan {
     class HeterogeneousVectorEngine {
     private:
         std::unique_ptr<UnifiedGpuIndex> gpu_index;
         const float* cpu_vectors;
         size_t cpu_vector_count;
         size_t dim;

     public:
         HeterogeneousVectorEngine(std::unique_ptr<UnifiedGpuIndex> gpu_idx, const float* host_vecs, size_t n_host, size_t d)
             : gpu_index(std::move(gpu_idx)), cpu_vectors(host_vecs), cpu_vector_count(n_host), dim(d) {}

         std::vector<NeighborPair> search_hybrid(const float* query, size_t top_k) {
             // 1. Launch async GPU search task
             auto gpu_future = std::async(std::launch::async, [&]() {
                 // GPU search
                 return std::vector<NeighborPair>();
             });

             // 2. Concurrently execute CPU AVX2 scanning
             BoundedFlatHeap cpu_heap(top_k);
             for (size_t i = 0; i < cpu_vector_count; ++i) {
                 float dist = l2_distance_avx2(query, cpu_vectors + i * dim, dim);
                 cpu_heap.insert(static_cast<uint32_t>(i), dist);
             }

             // 3. Merge GPU and CPU heaps
             auto gpu_results = gpu_future.get();
             for (const auto& p : gpu_results) {
                 cpu_heap.insert(p.id, p.dist);
             }

             return cpu_heap.to_sorted_vector();
         }
     };
     }
     ```
