## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Statistical Inference* — George Casella & Roger L. Berger / *All of Statistics* — Larry Wasserman
* **Sections**: §1.1–1.3 (*Point Estimation, Bessel's Correction & MSE Decomposition*)
* **Theorems & Mathematical Concepts**:
  1. **Point Estimators & Unbiasedness**:
     * An estimator $\hat{\theta} = W(X_1, \dots, X_n)$ is unbiased if $\operatorname{Bias}(\hat{\theta}) = E[\hat{\theta}] - \theta = 0$.
     * Sample Mean: $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i \implies E[\bar{X}_n] = \mu, \operatorname{Var}(\bar{X}_n) = \frac{\sigma^2}{n}$.
  2. **Bessel's Correction for Sample Variance**:
     * Naive estimator $S_n^2 = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X}_n)^2$ is biased: $E[S_n^2] = \frac{n-1}{n} \sigma^2$.
     * Unbiased Sample Variance:
       $$S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X}_n)^2 \implies E[S^2] = \sigma^2$$
  3. **Mean Squared Error (MSE) Decomposition**:
     $$\operatorname{MSE}(\hat{\theta}) = E\left[(\hat{\theta} - \theta)^2\right] = \operatorname{Var}(\hat{\theta}) + \left(\operatorname{Bias}(\hat{\theta})\right)^2$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive Bessel's correction from first principles: Expand $\sum_{i=1}^n (X_i - \bar{X}_n)^2 = \sum_{i=1}^n X_i^2 - n \bar{X}_n^2$, use $E[X_i^2] = \sigma^2 + \mu^2$ and $E[\bar{X}_n^2] = \frac{\sigma^2}{n} + \mu^2$, and subtract to prove $E[\sum (X_i - \bar{X}_n)^2] = (n-1)\sigma^2$.
  - [ ] **Proof 2**: Derive the MSE decomposition $\operatorname{MSE}(\hat{\theta}) = \operatorname{Var}(\hat{\theta}) + \operatorname{Bias}(\hat{\theta})^2$ by adding and subtracting $E[\hat{\theta}]$ inside the expectation.
  - [ ] **Problem 3**: For Gaussian samples $X_i \sim \mathcal{N}(\mu, \sigma^2)$, use Cochran's theorem $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$ to calculate the exact variance of the sample variance $\operatorname{Var}(S^2) = \frac{2\sigma^4}{n-1}$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *vLLM: Efficient Memory Management for Large Language Model Serving with PagedAttention* (Kwon et al., SOSP 2023) §1–3
* **Core Microarchitectural Concepts**:
  1. **The KV Cache Memory Bottleneck**:
     * In LLM autoregressive decoding, each token appends Key and Value vectors: $2 \times L \times H \times d \times 2\text{ bytes}$ per token.
     * Traditional serving frameworks pre-allocate contiguous memory for max sequence length (e.g. $8{,}192$ tokens), wasting $60\%–80\%$ of GPU memory on unused capacity (internal fragmentation) and dynamic reservation gaps (external fragmentation).
  2. **PagedAttention Virtual Memory Architecture**:
     * Partitions KV cache into fixed-size physical blocks of 16 tokens ($16 \times 2 \times 4096 \times 2\text{ bytes} = 256\text{ KB}$).
     * Maintains a per-request `BlockTable` mapping logical token positions to physical blocks scattered non-contiguously in VRAM.

* **Tasks & Implementation**:
  1. **Implement `BlockTableManager` in C++20** in `include/secan/llm/block_table.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <deque>
     #include <cstdint>
     #include <stdexcept>

     namespace secan {
     constexpr size_t BLOCK_SIZE = 16; // 16 tokens per physical block

     class BlockTableManager {
     private:
         size_t total_blocks;
         std::deque<uint32_t> free_blocks;

     public:
         BlockTableManager(size_t num_blocks) : total_blocks(num_blocks) {
             for (uint32_t i = 0; i < num_blocks; ++i) {
                 free_blocks.push_back(i);
             }
         }

         uint32_t allocate_block() {
             if (free_blocks.empty()) throw std::runtime_error("Out of GPU KV Blocks!");
             uint32_t block_id = free_blocks.front();
             free_blocks.pop_front();
             return block_id;
         }

         void free_block(uint32_t block_id) {
             free_blocks.push_back(block_id);
         }

         size_t num_free_blocks() const { return free_blocks.size(); }
     };

     struct RequestBlockTable {
         uint32_t request_id;
         std::vector<uint32_t> physical_block_ids;

         void append_token(size_t current_seq_len, BlockTableManager& manager) {
             if (current_seq_len % BLOCK_SIZE == 0) {
                 physical_block_ids.push_back(manager.allocate_block());
             }
         }
     };
     }
     ```
