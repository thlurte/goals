## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §10.3 (*Strong Law of Large Numbers (SLLN) & Borel-Cantelli Lemmas*)
* **Theorems & Mathematical Concepts**:
  1. **Almost Sure Convergence (Convergence with Probability 1)**:
     $$X_n \xrightarrow{a.s.} X \iff P\left( \left\{ \omega \in \Omega : \lim_{n \to \infty} X_n(\omega) = X(\omega) \right\} \right) = 1$$
     * Implies convergence in probability ($X_n \xrightarrow{a.s.} X \implies X_n \xrightarrow{p} X$), but the converse does not hold.
  2. **The First Borel-Cantelli Lemma**:
     * For any arbitrary sequence of events $E_1, E_2, \dots$:
       $$\sum_{n=1}^\infty P(E_n) < \infty \implies P\left( \limsup_{n \to \infty} E_n \right) = P(E_n \text{ infinitely often}) = 0$$
  3. **The Second Borel-Cantelli Lemma**:
     * If events $E_1, E_2, \dots$ are **mutually independent**:
       $$\sum_{n=1}^\infty P(E_n) = \infty \implies P\left( \limsup_{n \to \infty} E_n \right) = 1$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the First Borel-Cantelli Lemma by defining $A_k = \bigcup_{n=k}^\infty E_n$, observing $\limsup E_n = \bigcap_{k=1}^\infty A_k$, bounding $P(A_k) \le \sum_{n=k}^\infty P(E_n)$, and taking the limit as $k \to \infty$.
  - [ ] **Proof 2**: Prove the Strong Law of Large Numbers (SLLN) under the 4th moment assumption $E[X_i^4] < \infty$: Expand $E[(\bar{X}_n - \mu)^4] = \frac{n E[X_1^4] + 3n(n-1)\sigma^4}{n^4} = \mathcal{O}(1/n^2)$, apply Markov's inequality to show $P(|\bar{X}_n - \mu| \ge \epsilon) \le \frac{C}{\epsilon^4 n^2}$, and sum $\sum_{n=1}^\infty \frac{1}{n^2} < \infty$ to invoke Borel-Cantelli 1.
  - [ ] **Problem 3**: In distributed consensus message replication, let $E_n$ be the event of a message checksum failure on transmission $n$. If $P(E_n) = \frac{1}{n^{1.2}}$, prove that checksum errors cease to occur after a finite number of transmissions almost surely.

     #include <cuda_runtime.h>
     #include <cstdint>

     namespace secan {
     template <int NUM_WORDS = 64>
     struct WarpVisitedBitset {
         uint32_t bitset[NUM_WORDS]{0};

         __device__ inline bool test_and_set(uint32_t node_id) {
             uint32_t hash = (node_id * 2654435761u) % (NUM_WORDS * 32);
             uint32_t word_idx = hash / 32;
             uint32_t bit_mask = (1u << (hash % 32));

             bool already_visited = (bitset[word_idx] & bit_mask) != 0;
             bitset[word_idx] |= bit_mask;
             return already_visited;
         }
     };
     }
