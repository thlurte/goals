### 🔹 Part 1: Advanced Theorems & Derivations (Thursday Syllabus)
* **Book**: *Statistical Inference* — George Casella & Roger L. Berger
* **Sections**: §2.6 (*The Cramér-Rao Lower Bound (CRLB) & Estimator Efficiency*)
* **Theorems & Mathematical Concepts**:
  1. **The Cramér-Rao Inequality for Unbiased Estimators**:
     * Let $W(\mathbf{X})$ be any unbiased estimator of $\theta$ ($E[W(\mathbf{X})] = \theta$).
     * Under regularity conditions allowing derivative-integral interchange:
       $$\operatorname{Var}(W(\mathbf{X})) \ge \frac{1}{I_n(\theta)} = \frac{1}{n I_1(\theta)}$$
  2. **Cauchy-Schwarz Proof via Score Covariance**:
     * Let $S_n(\theta) = \sum_{i=1}^n \frac{\partial \ln f(X_i \mid \theta)}{\partial \theta}$ be the score function ($E[S_n] = 0, \operatorname{Var}(S_n) = I_n(\theta)$).
     * $$\operatorname{Cov}(W, S_n) = E[W S_n] = \int W(\mathbf{x}) \frac{\nabla_\theta f(\mathbf{x})}{f(\mathbf{x})} f(\mathbf{x}) d\mathbf{x} = \frac{d}{d\theta} \int W(\mathbf{x}) f(\mathbf{x}) d\mathbf{x} = \frac{d}{d\theta} E[W] = 1$$
     * By Cauchy-Schwarz: $(\operatorname{Cov}(W, S_n))^2 \le \operatorname{Var}(W) \operatorname{Var}(S_n) \implies 1 \le \operatorname{Var}(W) I_n(\theta) \implies \operatorname{Var}(W) \ge \frac{1}{I_n(\theta)}$.
  3. **Efficiency & UMVUE**:
     * An unbiased estimator is **efficient** if $\operatorname{Var}(\hat{\theta}) = \frac{1}{I_n(\theta)}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the Cramér-Rao Lower Bound step-by-step using Cauchy-Schwarz on $\operatorname{Cov}(W, S_n) = 1$.
  - [ ] **Proof 2**: Derive the generalized CRLB for biased estimators with bias $b(\theta) = E[W] - \theta$: prove that $\operatorname{Var}(W) \ge \frac{(1 + b'(\theta))^2}{I_n(\theta)}$.
  - [ ] **Problem 3**: For Gaussian samples $X_1, \dots, X_n \sim \mathcal{N}(\mu, \sigma^2)$, compute the Fisher Information $I_n(\mu) = n/\sigma^2$. Prove that $\operatorname{Var}(\bar{X}_n) = \sigma^2/n$ achieves the CRLB bound with equality, certifying $\bar{X}_n$ as the UMVUE.

### 🔹 Part 2: Core Proofs & Problem Sets (Friday Syllabus)
* **Book**: *Statistical Inference* — George Casella & Roger L. Berger
* **Sections**: §3.1–3.3 (*Hypothesis Testing & The Neyman-Pearson Lemma*)
* **Theorems & Mathematical Concepts**:
  1. **Hypothesis Testing Framework**:
     * Null Hypothesis $H_0: \theta = \theta_0$ vs Alternative $H_1: \theta = \theta_1$.
     * Type I Error ($\alpha$, False Positive): $\alpha = P(\text{Reject } H_0 \mid H_0 \text{ is true})$.
     * Type II Error ($\beta$, False Negative): $\beta = P(\text{Accept } H_0 \mid H_1 \text{ is true})$.
     * Power: $1 - \beta = P(\text{Reject } H_0 \mid H_1 \text{ is true})$.
  2. **The Neyman-Pearson Lemma**:
     * For testing simple hypotheses $H_0: \theta = \theta_0$ vs $H_1: \theta = \theta_1$, the Likelihood Ratio Test with rejection region:
       $$R = \left\{ \mathbf{x} : \frac{L(\theta_1 \mid \mathbf{x})}{L(\theta_0 \mid \mathbf{x})} \ge k \right\}$$
       where $P(\mathbf{X} \in R \mid H_0) = \alpha$, is the **Uniformly Most Powerful (UMP)** test of size $\alpha$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the Neyman-Pearson Lemma: Let $\phi(\mathbf{x}) = \mathbf{1}_{\{\mathbf{x} \in R\}}$ and let $\phi^*(\mathbf{x})$ be any competing test with size $E_0[\phi^*] \le \alpha$. Prove that $\int (\phi(\mathbf{x}) - \phi^*(\mathbf{x})) (f(\mathbf{x} \mid \theta_1) - k f(\mathbf{x} \mid \theta_0)) d\mathbf{x} \ge 0$, and expand to conclude $E_1[\phi] \ge E_1[\phi^*]$.
  - [ ] **Proof 2**: Use the Neyman-Pearson Lemma to derive the most powerful test of size $\alpha$ for Gaussian mean $H_0: \mu = \mu_0$ vs $H_1: \mu = \mu_1$ ($\mu_1 > \mu_0$) with known variance $\sigma^2$, showing the test rejects when $\bar{X}_n \ge \mu_0 + z_\alpha \frac{\sigma}{\sqrt{n}}$.
  - [ ] **Problem 3**: In A/B testing a new vector search index, query latency is $\mathcal{N}(\mu, 4.0\text{ ms}^2)$. Test $H_0: \mu = 5.0\text{ ms}$ vs $H_1: \mu = 4.5\text{ ms}$ with significance level $\alpha = 0.01$ ($z_{0.01} = 2.326$) and power $1-\beta = 0.95$ ($z_{0.05} = 1.645$). Compute the exact sample size $n = \frac{(z_\alpha + z_\beta)^2 \sigma^2}{(\mu_0 - \mu_1)^2} = \frac{(2.326 + 1.645)^2 (4.0)}{(0.5)^2} \approx 253\text{ queries}$.
