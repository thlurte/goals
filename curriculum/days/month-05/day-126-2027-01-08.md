* **Systems Profiling Reference**: Brendan Gregg, *Systems Performance: Enterprise and the Cloud* (2nd ed) — CPU hardware counters and PMU event profiling with `perf stat`.
* **Core Microarchitectural Concepts**:
  1. **Quantization Silicon Roofline Scaling**:
     * **FP32 ($4\text{ bytes/dim}$)**: $1.5\text{ TB/s}$ HBM bus saturates at **$3.75 \times 10^8\text{ vecs/s}$**.
     * **FP16 ($2\text{ bytes/dim}$)**: $2\times$ memory throughput (**$7.5 \times 10^8\text{ vecs/s}$**).
     * **SQ8 ($1\text{ byte/dim}$)**: $4\times$ memory throughput (**$1.5 \times 10^9\text{ vecs/s}$**).
     * **4-bit FastScan ($0.5\text{ bytes/dim}$)**: $8\times$ memory throughput + zero-SRAM registers (**$>2.8 \times 10^9\text{ vecs/s}$**).
  2. **Memory Bus Saturation Metric**:
     $$\text{Bus Efficiency} = \frac{\text{Bytes Read} / \text{Elapsed Time}}{\text{Peak Device Bandwidth}}$$
