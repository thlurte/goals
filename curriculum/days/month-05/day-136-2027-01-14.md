## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Faiss Multi-GPU Architecture: Replicated Coarse Quantizers with Sharded Inverted Lists*
* **Core Microarchitectural Concepts**:
  1. **Replicated vs Sharded Index State**:
     * **Replicated Coarse Centroids ($2\text{ MB}$)**: Stored in high-speed L2/VRAM on every GPU. Each device independently computes query-to-cluster dot products.
     * **Sharded Posting Lists ($10\text{ GB}$ total)**: Evenly split across GPUs ($2.5\text{ GB}$ per device on a 4-GPU system).
  2. **Multi-Stream Overlapped Execution**:
     * Query coarse routing overlaps with asynchronous inverted list memory prefetching, hiding kernel launch latency.
