## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §11.1–11.2 (*Discrete-Time Markov Chains & Transition Probability Matrices*)
* **Theorems & Mathematical Concepts**:
  1. **The Markov Property**:
     * A stochastic process $\{X_n, n \ge 0\}$ with discrete state space $S$ satisfies the Markov property if:
       $$P(X_{n+1} = j \mid X_n = i, X_{n-1} = i_{n-1}, \dots, X_0 = i_0) = P(X_{n+1} = j \mid X_n = i) = p_{ij}$$
  2. **Transition Probability Matrix & Stochastic Properties**:
     * $P = [p_{ij}]_{i,j \in S}$ where $p_{ij} \ge 0$ and every row sums to unity: $\sum_{j \in S} p_{ij} = 1 \iff P \mathbf{1} = \mathbf{1}$.
     * Spectral Property: The spectral radius $\rho(P) = 1$, and $\lambda = 1$ is an eigenvalue with right eigenvector $\mathbf{1} = [1, \dots, 1]^T$.
  3. **State Distribution Evolution**:
     * Let $\mathbf{p}(n) = [P(X_n = 1), \dots, P(X_n = |S|)]$. Then:
       $$\mathbf{p}(n) = \mathbf{p}(n-1) P = \mathbf{p}(0) P^n$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove by mathematical induction that the $n$-step transition probability satisfies $P(X_n = j \mid X_0 = i) = [P^n]_{ij}$, where $P^n$ is the standard matrix power.
  - [ ] **Proof 2**: Use Gershgorin's Circle Theorem to prove that for any row-stochastic matrix $P$, all eigenvalues $\lambda \in \mathbb{C}$ lie in the unit disc $|\lambda| \le 1$.
  - [ ] **Problem 3**: A vector search cache replacement model has state space $S = \{1: \text{L1 Hit}, 2: \text{L2 Hit}, 3: \text{DRAM Miss}\}$ with transition matrix:
    $$P = \begin{bmatrix} 0.80 & 0.15 & 0.05 \\ 0.60 & 0.30 & 0.10 \\ 0.40 & 0.40 & 0.20 \end{bmatrix}$$
    Compute $P^2$ explicitly and calculate the probability that a query starting in L1 experiences a DRAM miss on step 2 ($[P^2]_{13} = 0.8(0.05) + 0.15(0.10) + 0.05(0.20) = 0.065$).

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Billion-Scale Similarity Search with GPUs (Faiss GPU)* §3 (*Shared Memory Query Look-Up Table (LUT) Staging*)
* **Core Microarchitectural Concepts**:
  1. **PQ Asymmetric Distance Computation (ADC) Memory Layout**:
     * In Product Quantization ($M = 16$ subspaces, $K = 256$ centroids per subspace):
     * Query centroid distance table: $16 \times 256 \times 4\text{ bytes} = 16\text{ KB}$ float matrix.
     * Staged in fast on-chip `__shared__` memory (SRAM, $<20\text{ cycle}$ access latency).
  2. **1-Byte Index Scanning**:
     * Vectors are stored as 16-byte quantized codes `uint8_t code[16]`.
     * Threads read compressed codes from global memory with coalesced 128-byte transactions, looking up partial distances from shared memory: $D = \sum_{m=0}^{15} \text{LUT}[m][\text{code}[m]]$.

## 💻 20:30 – 23:00 | Night Hands-On Implementation (2.5 hrs)
* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement GPU PQ ADC Kernel with Shared Memory LUT** in `include/secan/gpu/gpu_pq_adc.cuh`:
     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     constexpr int PQ_M = 16;
     constexpr int PQ_K = 256;

     __global__ void gpu_pq_adc_scan_kernel(
         const float* __restrict__ query_lut,     // [PQ_M, PQ_K]
         const uint8_t* __restrict__ pq_codes,    // [N, PQ_M]
         float* __restrict__ out_distances,       // [N]
         size_t num_vectors
     ) {
         // Stage 16 KB Query LUT into shared memory
         __shared__ float s_lut[PQ_M][PQ_K];
         size_t tid = threadIdx.x;
         size_t total_elements = PQ_M * PQ_K;

         for (size_t i = tid; i < total_elements; i += blockDim.x) {
             size_t m = i / PQ_K;
             size_t k = i % PQ_K;
             s_lut[m][k] = query_lut[i];
         }
         __syncthreads();

         size_t vec_idx = blockIdx.x * blockDim.x + threadIdx.x;
         if (vec_idx >= num_vectors) return;

         const uint8_t* code = pq_codes + vec_idx * PQ_M;
         float dist = 0.0f;

         #pragma unroll
         for (int m = 0; m < PQ_M; ++m) {
             uint8_t cluster_idx = code[m];
             dist += s_lut[m][cluster_idx];
         }

         out_distances[vec_idx] = dist;
     }
     }
     ```
  2. **Benchmark Throughput on SIFT1M**:
     * In `benchmarks/bench_gpu_pq_adc.cu`, verify scanning throughput exceeds **$>1.2 \times 10^9\text{ vectors/sec}$** ($>1{,}200\text{ Mvec/s}$) on device memory.
