## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Billion-Scale Similarity Search with GPUs (Faiss GPU)* §3 (*Shared Memory Query Look-Up Table (LUT) Staging*)
* **Core Microarchitectural Concepts**:
  1. **PQ Asymmetric Distance Computation (ADC) Memory Layout**:
     * In Product Quantization ($M = 16$ subspaces, $K = 256$ centroids per subspace):
     * Query centroid distance table: $16 \times 256 \times 4\text{ bytes} = 16\text{ KB}$ float matrix.
     * Staged in fast on-chip `__shared__` memory (SRAM, $<20\text{ cycle}$ access latency).
  2. **1-Byte Index Scanning**:
     * Vectors are stored as 16-byte quantized codes `uint8_t code[16]`.
     * Threads read compressed codes from global memory with coalesced 128-byte transactions, looking up partial distances from shared memory: $D = \sum_{m=0}^{15} \text{LUT}[m][\text{code}[m]]$.

* **Tasks & Implementation**:
  1. **Implement GPU PQ ADC Kernel with Shared Memory LUT** in `include/secan/gpu/gpu_pq_adc.cuh`:
     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     constexpr int PQ_M = 16;
     constexpr int PQ_K = 256;

     __global__ void gpu_pq_adc_scan_kernel(
         const float* __restrict__ query_lut,     // [PQ_M, PQ_K]
         const uint8_t* __restrict__ pq_codes,    // [N, PQ_M]
         float* __restrict__ out_distances,       // [N]
         size_t num_vectors
     ) {
         // Stage 16 KB Query LUT into shared memory
         __shared__ float s_lut[PQ_M][PQ_K];
         size_t tid = threadIdx.x;
         size_t total_elements = PQ_M * PQ_K;

         for (size_t i = tid; i < total_elements; i += blockDim.x) {
             size_t m = i / PQ_K;
             size_t k = i % PQ_K;
             s_lut[m][k] = query_lut[i];
         }
         __syncthreads();

         size_t vec_idx = blockIdx.x * blockDim.x + threadIdx.x;
         if (vec_idx >= num_vectors) return;

         const uint8_t* code = pq_codes + vec_idx * PQ_M;
         float dist = 0.0f;

         #pragma unroll
         for (int m = 0; m < PQ_M; ++m) {
             uint8_t cluster_idx = code[m];
             dist += s_lut[m][cluster_idx];
         }

         out_distances[vec_idx] = dist;
     }
     }
     ```
