* **Book / Paper**: *vLLM: Efficient Memory Management for Large Language Model Serving with PagedAttention* §4 (*PagedAttention-1 Kernel Architecture*)
* **Core Microarchitectural Concepts**:
  1. **Dynamic Virtual-to-Physical Address Resolution in CUDA**:
     * Query vector $\mathbf{q} \in \mathbb{R}^d$ resides in thread registers throughout the decode step.
     * Thread blocks iterate over logical blocks $b = 0, 1, \dots, \lceil N / 16 \rceil - 1$.
     * Resolve physical block ID from constant memory / device table:
       ```cuda
       uint32_t physical_block_id = block_table[req_id * max_blocks + b];
       const float* k_ptr = k_cache + physical_block_id * (16 * head_dim);
       ```
  2. **Preserving 128-Byte Memory Coalescing**:
     * Within each physical block, 16 token embeddings are stored contiguously.
     * Warps scan through tokens in lock-step, achieving $>90\%$ DRAM memory bus efficiency despite non-contiguous block scattering.
