## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *vLLM: Efficient Memory Management for Large Language Model Serving with PagedAttention* (Kwon et al., SOSP 2023) §1–3
* **Core Microarchitectural Concepts**:
  1. **The KV Cache Memory Bottleneck**:
     * In LLM autoregressive decoding, each token appends Key and Value vectors: $2 \times L \times H \times d \times 2\text{ bytes}$ per token.
     * Traditional serving frameworks pre-allocate contiguous memory for max sequence length (e.g. $8{,}192$ tokens), wasting $60\%–80\%$ of GPU memory on unused capacity (internal fragmentation) and dynamic reservation gaps (external fragmentation).
  2. **PagedAttention Virtual Memory Architecture**:
     * Partitions KV cache into fixed-size physical blocks of 16 tokens ($16 \times 2 \times 4096 \times 2\text{ bytes} = 256\text{ KB}$).
     * Maintains a per-request `BlockTable` mapping logical token positions to physical blocks scattered non-contiguously in VRAM.

  1. **Implement `BlockTableManager` in C++20** in `include/secan/llm/block_table.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <deque>
     #include <cstdint>
     #include <stdexcept>

     namespace secan {
     constexpr size_t BLOCK_SIZE = 16; // 16 tokens per physical block

     class BlockTableManager {
     private:
         size_t total_blocks;
         std::deque<uint32_t> free_blocks;

     public:
         BlockTableManager(size_t num_blocks) : total_blocks(num_blocks) {
             for (uint32_t i = 0; i < num_blocks; ++i) {
                 free_blocks.push_back(i);
             }
         }

         uint32_t allocate_block() {
             if (free_blocks.empty()) throw std::runtime_error("Out of GPU KV Blocks!");
             uint32_t block_id = free_blocks.front();
             free_blocks.pop_front();
             return block_id;
         }

         void free_block(uint32_t block_id) {
             free_blocks.push_back(block_id);
         }

         size_t num_free_blocks() const { return free_blocks.size(); }
     };

     struct RequestBlockTable {
         uint32_t request_id;
         std::vector<uint32_t> physical_block_ids;

         void append_token(size_t current_seq_len, BlockTableManager& manager) {
             if (current_seq_len % BLOCK_SIZE == 0) {
                 physical_block_ids.push_back(manager.allocate_block());
             }
         }
     };
     }
     ```
