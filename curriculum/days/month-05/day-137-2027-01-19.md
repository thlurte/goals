## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Documentation**: *NVIDIA Collective Communications Library (NCCL): Ring AllGather Architecture*
* **Core Microarchitectural Concepts**:
  1. **Ring AllGather Algorithm**:
     * $G$ GPUs are organized in a logical ring topology over NVLink.
     * Each GPU begins with a local buffer of top-$K$ candidate pairs ($K \times 8\text{ bytes}$).
     * In $G-1$ transfer steps, each GPU forwards its chunk to its downstream neighbor, achieving full data exchange with minimal network contention.
  2. **Latency vs Bandwidth in Vector Search Collectives**:
     * Since candidate buffer size is small ($K = 100 \implies 800\text{ bytes}$), collective time is dominated by NVLink latency ($<5\mu\text{s}$), making multi-GPU candidate reduction virtually free.

     #pragma once
     #include <nccl.h>
     #include "secan/gpu/topk_select.cuh"
     #include <vector>

     namespace secan {
     class NcclTopkCollector {
     private:
         int num_gpus;
         std::vector<ncclComm_t> comms;

     public:
         NcclTopkCollector(int n_gpus) : num_gpus(n_gpus), comms(n_gpus) {
             std::vector<int> devs(n_gpus);
             for (int i = 0; i < n_gpus; ++i) devs[i] = i;
             NCCL_CHECK(ncclCommInitAll(comms.data(), n_gpus, devs.data()));
         }

         ~NcclTopkCollector() {
             for (int i = 0; i < num_gpus; ++i) {
                 ncclCommDestroy(comms[i]);
             }
         }

         void all_gather_topk(
             const NeighborPair* d_send_buf, // [K] on each GPU
             NeighborPair* d_recv_buf,       // [G * K] on each GPU
             size_t k,
             cudaStream_t* streams
         ) {
             NCCL_CHECK(ncclGroupStart());
             for (int g = 0; g < num_gpus; ++g) {
                 CUDA_CHECK(cudaSetDevice(g));
                 NCCL_CHECK(ncclAllGather(
                     d_send_buf + g * k,
                     d_recv_buf + g * (num_gpus * k),
                     k * sizeof(NeighborPair),
                     ncclChar,
                     comms[g],
                     streams[g]
                 ));
             }
             NCCL_CHECK(ncclGroupEnd());
         }
     };
     }
