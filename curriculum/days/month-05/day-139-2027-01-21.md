* **Core Microarchitectural Concepts**:
  1. **The Multi-GPU Straggler Bottleneck**:
     * Real-world cluster sizes follow power-law distributions: popular coarse clusters contain up to $15\times$ more vectors than peripheral ones.
     * Naive static cell assignment assigns variable vector workloads, causing idle GPU bubbles during `ncclAllGather` synchronization.
  2. **Greedy Multi-GPU Bin Packing**:
     * Master GPU gathers the sizes $L_1, \dots, L_{nprobe}$ of all probed cells.
     * Sorts cells in descending order and greedily assigns each cell to the GPU with the smallest accumulated vector workload, capping workload variance to $<5\%$.

  1. **Implement Dynamic Multi-GPU Workload Balancer** in `include/secan/gpu/dynamic_load_balancer.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <algorithm>
     #include <numeric>
     #include <cstdint>

     namespace secan {
     struct CellWorkItem {
         uint32_t cell_id;
         size_t num_vectors;
     };

     struct GpuWorkAssignment {
         int gpu_id;
         std::vector<uint32_t> assigned_cells;
         size_t total_vectors{0};
     };

     class DynamicLoadBalancer {
     public:
         static std::vector<GpuWorkAssignment> balance_cells(
             int num_gpus,
             const std::vector<CellWorkItem>& probed_cells
         ) {
             std::vector<CellWorkItem> sorted_cells = probed_cells;
             // Sort cells in descending order of workload
             std::sort(sorted_cells.begin(), sorted_cells.end(), 
                 [](const CellWorkItem& a, const CellWorkItem& b) {
                     return a.num_vectors > b.num_vectors;
                 });

             std::vector<GpuWorkAssignment> assignments(num_gpus);
             for (int g = 0; g < num_gpus; ++g) assignments[g].gpu_id = g;

             // Greedy LPT (Longest Processing Time) bin-packing
             for (const auto& item : sorted_cells) {
                 auto min_it = std::min_element(assignments.begin(), assignments.end(),
                     [](const GpuWorkAssignment& a, const GpuWorkAssignment& b) {
                         return a.total_vectors < b.total_vectors;
                     });
                 min_it->assigned_cells.push_back(item.cell_id);
                 min_it->total_vectors += item.num_vectors;
             }

             return assignments;
         }
     };
     }
     ```
