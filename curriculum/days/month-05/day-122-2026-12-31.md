## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §11.4 (*Stationary Distributions & Left Eigenvector Formulation*)
* **Theorems & Mathematical Concepts**:
  1. **Stationary Distribution Definition**:
     * A probability row vector $\boldsymbol{\pi} = [\pi_1, \dots, \pi_k]$ is stationary if:
       $$\boldsymbol{\pi} P = \boldsymbol{\pi} \quad \text{subject to } \sum_{i=1}^k \pi_i = 1, \pi_i \ge 0$$
     * Formulated as a homogeneous linear system: $\boldsymbol{\pi} (I - P) = \mathbf{0}^T$.
  2. **Perron-Frobenius Theorem for Stochastic Matrices**:
     * For an irreducible, aperiodic Markov chain with transition matrix $P$:
       * $\lambda_1 = 1$ is a simple eigenvalue with strictly positive left eigenvector $\boldsymbol{\pi} > 0$.
       * All other eigenvalues satisfy $|\lambda_i| < 1$.
  3. **Mean Recurrence Time**:
     * For any recurrent state $i \in S$, the expected number of steps until first return satisfies:
       $$E[T_{ii}] = \frac{1}{\pi_i}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that $\operatorname{det}(I - P) = 0$ for any row-stochastic matrix $P$ by showing that $(I - P) \mathbf{1} = \mathbf{0}$, ensuring the null space of $(I - P)^T$ is non-trivial and non-zero stationary vectors exist.
  - [ ] **Proof 2**: Prove that for a symmetric stochastic matrix ($p_{ij} = p_{ji}$ for all $i, j$), the uniform distribution $\boldsymbol{\pi} = \left[ \frac{1}{k}, \dots, \frac{1}{k} \right]$ is always the unique stationary distribution.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *GPU FastScan Architecture & Warp-Level Register LUTs*
* **Core Microarchitectural Concepts**:
  1. **Zero-SRAM Table Lookups via Warp Shuffle (`__shfl_sync`)**:
     * For 4-bit Quantization (16 centroids per subspace):
     * The 16 query-to-centroid distances are stored across the registers of the first 16 threads in a warp.
     * When thread $T$ reads a 4-bit quantized nibble $c \in [0, 15]$, it retrieves the corresponding distance using a single hardware warp shuffle instruction:
       ```cuda
       float dist = __shfl_sync(0xffffffff, centroid_dist, c);
       ```
     * **Advantages**: Zero shared memory consumption, 1-cycle throughput, and zero bank conflicts!

* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement GPU 4-bit FastScan Warp Shuffle Kernel** in `include/secan/gpu/gpu_fastscan_4bit.cuh`:
     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     __global__ void fast_scan_4bit_warp_kernel(
         const float* __restrict__ query_lut_16,  // [M, 16]
         const uint8_t* __restrict__ packed_codes,// [N, M / 2] (2 nibbles per byte)
         float* __restrict__ out_distances,       // [N]
         size_t num_vectors,
         size_t num_subspaces
     ) {
         size_t lane_id = threadIdx.x % 32;
         size_t warp_id = (blockIdx.x * blockDim.x + threadIdx.x) / 32;
         size_t vec_idx = warp_id * 32 + lane_id;

         float total_dist = 0.0f;

         // Iterate through each 4-bit subspace
         for (size_t m = 0; m < num_subspaces; ++m) {
             // Lane 0..15 hold the 16 centroid distances in their register
             float my_centroid_val = (lane_id < 16) ? query_lut_16[m * 16 + lane_id] : 0.0f;

             // Extract 4-bit nibble for this vector
             uint8_t byte_code = (vec_idx < num_vectors) ? packed_codes[vec_idx * (num_subspaces / 2) + (m / 2)] : 0;
             uint8_t nibble = (m % 2 == 0) ? (byte_code & 0x0F) : (byte_code >> 4);

             // Warp shuffle broadcast: fetch centroid value from lane 'nibble'
             float d = __shfl_sync(0xffffffff, my_centroid_val, nibble);
             total_dist += d;
         }

         if (vec_idx < num_vectors) {
             out_distances[vec_idx] = total_dist;
         }
     }
     }
     ```
