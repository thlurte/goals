## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Elements of Information Theory* — Thomas M. Cover & Joy A. Thomas
* **Sections**: §1.1–1.3 (*Shannon Entropy, Self-Information & Maximum Entropy*)
* **Theorems & Mathematical Concepts**:
  1. **Self-Information & Shannon Entropy**:
     * Self-Information of event $x$: $I(x) = -\log_2 p(x)$ (measured in bits).
     * Shannon Entropy of discrete random variable $X$:
       $$H(X) = E[I(X)] = -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x)$$
  2. **Bounds on Discrete Entropy**:
     * Non-negativity: $H(X) \ge 0$, with equality $H(X) = 0 \iff \exists x_0 \text{ s.t. } p(x_0) = 1$.
     * Maximum Entropy:
       $$H(X) \le \log_2 |\mathcal{X}|$$
       with equality if and only if $X$ is uniformly distributed ($p(x) = \frac{1}{|\mathcal{X}|}$ for all $x$).
  3. **Binary Entropy Function**:
     * For $\operatorname{Bernoulli}(p)$: $H_b(p) = -p \log_2 p - (1-p) \log_2(1-p)$, strictly concave on $[0, 1]$ with maximum $H_b(1/2) = 1\text{ bit}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the maximum entropy theorem $H(X) \le \log_2 |\mathcal{X}|$ using Jensen's inequality applied to the strictly concave logarithm function:
    $$H(X) = \sum_{x \in \mathcal{X}} p(x) \log_2 \frac{1}{p(x)} \le \log_2 \left( \sum_{x \in \mathcal{X}} p(x) \frac{1}{p(x)} \right) = \log_2 |\mathcal{X}|$$
  - [ ] **Proof 2**: Derive the second derivative of the binary entropy function $\frac{d^2 H_b}{dp^2} = -\frac{1}{\ln 2} \left( \frac{1}{p} + \frac{1}{1-p} \right) < 0$, proving strict concavity for all $p \in (0, 1)$.
  - [ ] **Problem 3**: In 8-bit Product Quantization with $K = 256$ centroids per subspace, code assignment frequencies are observed with empirical entropy $H(C) = 6.0\text{ bits}$. Compute the code redundancy $R = 1 - \frac{H(C)}{\log_2 256} = 25\%$ and calculate the effective number of utilized centroids $2^{H(C)} = 64$.
