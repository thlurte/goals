## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §10.5 (*Statistical Error Bounds & Non-Asymptotic Confidence Intervals*)
* **Theorems & Mathematical Concepts**:
  1. **Asymptotic Confidence Intervals (CLT)**:
     * By the Central Limit Theorem, the $1-\alpha$ confidence interval for unknown mean $\mu$ is:
       $$\mu \in \left[ \bar{X}_n - z_{\alpha/2} \frac{S_n}{\sqrt{n}}, \bar{X}_n + z_{\alpha/2} \frac{S_n}{\sqrt{n}} \right]$$
       where $S_n = \sqrt{\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X}_n)^2}$ is the sample standard deviation.
  2. **Non-Asymptotic Distribution-Free Confidence Intervals (Hoeffding)**:
     * For any bounded random variables $X_i \in [a, b]$, setting Hoeffding's bound $2\exp\left(-\frac{2n\epsilon^2}{(b-a)^2}\right) = \delta$ guarantees that with probability at least $1-\delta$:
       $$\mu \in \left[ \bar{X}_n - (b-a)\sqrt{\frac{\ln(2/\delta)}{2n}}, \bar{X}_n + (b-a)\sqrt{\frac{\ln(2/\delta)}{2n}} \right]$$
       * Valid for any sample size $n$, regardless of the underlying distribution!
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the non-asymptotic confidence interval width $\epsilon = (b-a)\sqrt{\frac{\ln(2/\delta)}{2n}}$ by algebraic inversion of Hoeffding's two-sided tail inequality.
  - [ ] **Proof 2**: Derive the Student's $t$-statistic distribution $T = \frac{\bar{X}_n - \mu}{S_n / \sqrt{n}} \sim t_{n-1}$ for Gaussian samples using Cochran's Theorem ($S_n^2 \sim \frac{\sigma^2}{n-1}\chi^2(n-1)$ independent of $\bar{X}_n$).
  - [ ] **Problem 3**: In an automated GPU kernel benchmark over $n = 1{,}000$ queries, empirical query latency is $\bar{T} = 0.20\text{ ms}$ with bounded max latency $1.0\text{ ms}$ ($b-a = 1.0$) and sample std $S_n = 0.05\text{ ms}$. Compute both the asymptotic $99\%$ confidence interval ($z_{0.005} = 2.576$) and the non-asymptotic distribution-free $99\%$ Hoeffding interval ($\delta = 0.01$).

     ```cuda
     #pragma once
     #include "secan/gpu/cagra_layout.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     constexpr int NUM_HUB_NODES = 64;

     __device__ inline const uint32_t* get_node_neighbors_cached(
         uint32_t node_id,
         const uint32_t* __restrict__ gmem_adjacency,
         const uint32_t* __restrict__ s_hub_adjacency,
         const uint32_t* __restrict__ s_hub_node_ids
     ) {
         // Check if node is in shared memory hub cache
         #pragma unroll 4
         for (int i = 0; i < NUM_HUB_NODES; ++i) {
             if (s_hub_node_ids[i] == node_id) {
                 return s_hub_adjacency + i * CAGRA_DEGREE;
             }
         }
         return gmem_adjacency + node_id * CAGRA_DEGREE;
     }
     }
     ```
