## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §10.1 (*Moment Generating Inequalities & Chernoff Bounds*)
* **Theorems & Mathematical Concepts**:
  1. **The Chernoff Bound**:
     * For any random variable $X$ and any threshold $a$:
       $$P(X \ge a) = P(e^{tX} \ge e^{ta}) \le \frac{E[e^{tX}]}{e^{ta}} = e^{-ta} M_X(t) \quad (\forall t > 0)$$
     * Taking the infimum over $t > 0$ yields the sharpest exponential tail bound:
       $$P(X \ge a) \le \inf_{t > 0} \exp\left( -(ta - \ln M_X(t)) \right) = \exp\left( -I(a) \right)$$
       where $I(a) = \sup_{t > 0} [ta - \ln M_X(t)]$ is the Legendre-Fenchel convex conjugate (rate function).
  2. **Sub-Gaussian Tail of Rademacher Sums**:
     * Let $S_n = \sum_{i=1}^n X_i$ where $X_i \in \{-1, +1\}$ are independent Rademacher variables.
     * By Hoeffding's Lemma, $M_{X_i}(t) = \cosh(t) \le e^{t^2/2} \implies M_{S_n}(t) \le e^{n t^2 / 2}$.
     * Optimizing $t^* = a/n$ gives:
       $$P(S_n \ge a) \le \exp\left( -\frac{a^2}{2n} \right)$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the generic Chernoff bound $P(X \ge a) \le \inf_{t > 0} e^{-ta} M_X(t)$ by applying Markov's inequality to the monotonically increasing transformation $Y = e^{tX}$.
  - [ ] **Proof 2**: Prove Hoeffding's Lemma $\cosh(t) \le e^{t^2/2}$ by expanding $\cosh(t) = \sum_{k=0}^\infty \frac{t^{2k}}{(2k)!}$ and comparing term-by-term with $e^{t^2/2} = \sum_{k=0}^\infty \frac{t^{2k}}{2^k k!}$ using $(2k)! \ge 2^k k!$.
  - [ ] **Problem 3**: In random hyperplane LSH with $n = 128$ hash bits, let $X$ be the number of matching bits for two orthogonal vectors ($E[X] = 64$). Use the Chernoff bound to compute an upper bound on the false positive collision probability $P(X \ge 96) \le \exp(-2(32)^2 / 128) = e^{-16} \approx 1.12 \times 10^{-7}$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *CAGRA: Highly Parallel Graph Construction and Approximate Nearest Neighbor Search for GPUs* (NVIDIA, 2024) §1–4
* **Core Microarchitectural Concepts**:
  1. **Fixed-Degree Graph Layout for Lock-Step SIMT**:
     * CPU graph search algorithms (e.g. HNSW) use dynamic neighbor arrays with variable degrees ($M \in [16, 64]$).
     * On GPUs, variable-length adjacency lists cause devastating warp divergence and irregular memory reads.
     * **CAGRA Fixed-Degree CSR**: Every node is padded to exactly $d_{\text{out}} = 32$ outgoing edges stored in contiguous device array `uint32_t d_graph[N * 32]`.
     * When a warp expands node $u$, all 32 warp lanes read the 32 neighbor IDs in a **single coalesced 128-byte DRAM transaction**!
  2. **Warp-Cooperative Frontier Expansion**:
     * 1 Warp manages the beam search for 1 query, keeping top candidates in register fragments.

  1. **Implement Fixed-Degree CAGRA GPU Graph Layout** in `include/secan/gpu/cagra_layout.cuh`:
     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <vector>
     #include <cstdint>

     namespace secan {
     constexpr int CAGRA_DEGREE = 32; // Exact warp size for 1-transaction coalesced loading

     class CagraGpuGraph {
     public:
         size_t num_nodes{0};
         GpuBuffer<uint32_t> d_adjacency; // [num_nodes, 32]
         GpuBuffer<float> d_vectors;      // [num_nodes, dim]

         CagraGpuGraph(size_t n, size_t dim)
             : num_nodes(n),
               d_adjacency(n * CAGRA_DEGREE),
               d_vectors(n * dim) {}

         void upload_from_hnsw(const std::vector<std::vector<uint32_t>>& host_neighbors) {
             std::vector<uint32_t> flat_padded(num_nodes * CAGRA_DEGREE, 0xFFFFFFFF);
             for (size_t i = 0; i < num_nodes; ++i) {
                 size_t num_nbrs = std::min<size_t>(host_neighbors[i].size(), CAGRA_DEGREE);
                 for (size_t j = 0; j < num_nbrs; ++j) {
                     flat_padded[i * CAGRA_DEGREE + j] = host_neighbors[i][j];
                 }
             }
             d_adjacency.copy_from_host(flat_padded.data(), flat_padded.size());
         }
     };
     }
     ```
