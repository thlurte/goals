## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §11.3 (*Classification of States: Recurrence, Transience & Absorbing Chains*)
* **Theorems & Mathematical Concepts**:
  1. **Recurrence vs Transience**:
     * First Return Probability: $f_{ii} = P(\exists n \ge 1 : X_n = i \mid X_0 = i)$.
     * Recurrent State: $f_{ii} = 1 \iff \sum_{n=1}^\infty p_{ii}^{(n)} = \infty$ (visited infinitely often with prob 1).
     * Transient State: $f_{ii} < 1 \iff \sum_{n=1}^\infty p_{ii}^{(n)} = \frac{f_{ii}}{1 - f_{ii}} < \infty$.
     * **Class Property**: If $i \leftrightarrow j$ and $i$ is recurrent, then $j$ is recurrent.
  2. **Periodicity**:
     * Period $d(i) = \operatorname{gcd}\{n \ge 1 : p_{ii}^{(n)} > 0\}$. State is aperiodic if $d(i) = 1$.
  3. **Absorbing Chains & The Fundamental Matrix**:
     * Arranging transition matrix in canonical block form:
       $$P = \begin{bmatrix} Q & R \\ 0 & I \end{bmatrix}$$
     * Fundamental Matrix: $N = (I - Q)^{-1} = \sum_{k=0}^\infty Q^k$.
     * $N_{ij}$ is the exact expected number of visits to transient state $j$ starting from $i$ before absorption.
     * Expected time to absorption from state $i$: $\mathbf{t} = N \mathbf{1}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that recurrence is a class property: Given $p_{ij}^{(m)} > 0$ and $p_{ji}^{(k)} > 0$, show that $p_{jj}^{(m+n+k)} \ge p_{ji}^{(k)} p_{ii}^{(n)} p_{ij}^{(m)}$, and sum over $n$ to prove $\sum_{n} p_{jj}^{(n)} = \infty$.
  - [ ] **Proof 2**: Derive the fundamental matrix equation $N = (I - Q)^{-1}$ by summing the geometric series of expectations $E[\sum_{k=0}^\infty \mathbf{1}_{\{X_k = j\}} \mid X_0 = i] = \sum_{k=0}^\infty [Q^k]_{ij}$.
  - [ ] **Problem 3**: In graph beam search early stopping, transient states $S_T = \{1: \text{Exploring}, 2: \text{Refining}\}$ transition to absorbing state $3$ (Convergence) with submatrix:
    $$Q = \begin{bmatrix} 0.6 & 0.2 \\ 0.1 & 0.5 \end{bmatrix}$$
    Compute $I - Q$, its inverse $N = (I - Q)^{-1}$, and the expected number of steps to convergence starting from Exploring ($t_1 = N_{11} + N_{12}$).

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *NVIDIA CUDA C++ Programming Guide: Shared Memory Bank Conflicts & Padding*
* **Core Microarchitectural Concepts**:
  1. **Shared Memory 32-Bank Organization**:
     * Shared memory is divided into 32 banks of 4-byte words. Bank index = `(byte_address / 4) % 32`.
     * If 32 threads in a warp access distinct addresses that map to the same bank, hardware serializes the requests into a 32-way bank conflict stall (32 clock cycles instead of 1).
  2. **Padding Technique for Conflict-Free 2D Access**:
     * Stride $S = 256$ floats aligns with Bank 0 for every row ($256 \equiv 0 \pmod{32}$).
     * By adding a 1-float padding stride: `float s_lut[16][257]`, row $m$ starts at bank `(m * 257) % 32 = m % 32`.
     * Diagonal skewing completely eliminates bank conflicts during vectorized lookups!

     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     constexpr int PADDED_PQ_K = 257; // +1 float padding to skew bank indices

     __global__ void gpu_pq_adc_padded_kernel(
         const float* __restrict__ query_lut,     // [16, 256]
         const uint8_t* __restrict__ pq_codes,    // [N, 16]
         float* __restrict__ out_distances,       // [N]
         size_t num_vectors
     ) {
         __shared__ float s_lut[16][PADDED_PQ_K];
         size_t tid = threadIdx.x;

         // Load LUT with stride skew
         for (size_t m = 0; m < 16; ++m) {
             for (size_t k = tid; k < 256; k += blockDim.x) {
                 s_lut[m][k] = query_lut[m * 256 + k];
             }
         }
         __syncthreads();

         size_t vec_idx = blockIdx.x * blockDim.x + threadIdx.x;
         if (vec_idx >= num_vectors) return;

         const uint8_t* code = pq_codes + vec_idx * 16;
         float dist = 0.0f;

         #pragma unroll
         for (int m = 0; m < 16; ++m) {
             dist += s_lut[m][code[m]];
         }

         out_distances[vec_idx] = dist;
     }
     }
     ```
