* **Core Microarchitectural Concepts**:
  1. **Centroid Interaction Candidate Pruning Mechanics**:
     * Given 32 query tokens, compute distances to all $C=32\text{K}$ centroids.
     * Select top-$k_{\text{centroid}} = 8$ closest centroids per query token.
     * Gather document IDs from selected inverted lists using a 1-byte hit counter table: `uint8_t doc_matches[N_docs]`.
     * Prune document search space from $1{,}000{,}000 \to 1{,}000$ candidates ($99.9\%$ candidate reduction).
  2. **Streaming SIMD MaxSim Re-Ranking**:
     * Iterate only over the 1,000 candidate documents, computing AVX2 MaxSim scores in L1/L2 cache.
