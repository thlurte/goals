  2. **Implement Streaming Ingestion Benchmark** in `scripts/bench_streaming_ingest.py`:
     ```python
     import time
     import numpy as np
     import subprocess
     import json

     # Benchmark streaming write latency: PLAID Inverted Lists vs MUVERA Memtable
     batch_sizes = [10, 50, 100, 500, 1000]
     results = []

     for bs in batch_sizes:
         cmd = f"./build/benchmarks/bench_streaming_ingest --batch_size={bs} --json"
         out = subprocess.check_output(cmd, shell=True)
         res = json.loads(out)
         results.append(res)

     print("Ingestion Benchmark Complete. Logging raw results to data/raw_ingest_metrics.json")
     with open("research/2026-11-late-interaction-lsm/data/raw_ingest_metrics.json", "w") as f:
         json.dump(results, f, indent=2)
     ```
