## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Advanced Systems Reference**: * [Donald E. Knuth, *The Art of Computer Programming, Vol 3: Sorting and Searching*](https://www-cs-faculty.stanford.edu/~knuth/taocp.html) — **§6.4 & §6.5** (*Cache-Conscious Robin Hood Hashing & Multi-Dimensional Inverted Files*)
* **Paper**: *"MUVERA: Multi-Vector Retrieval via Fixed Dimensional Encodings"* (Chakraborty et al., NeurIPS 2024 / arXiv:2405.19504) §1–3
* **Core Microarchitectural Concepts**:
  1. **Fixed Dimensional Encodings (FDE)**:
     * Problem: Variable-length token sets ($L \in [32, 256]$) require costly late-interaction MaxSim loops during search.
     * Solution: Hash tokens into $B$ angular SimHash buckets using random hyperplanes $\mathbf{r}_1, \dots, \mathbf{r}_k$.
     * Sum token embeddings within each bucket: $\mathbf{s}_b = \sum_{\mathbf{t} \in \text{Bucket}(b)} \mathbf{t}$.
     * Concatenate $B$ bucket sums across $R$ independent repetitions: $\mathbf{z}_{\text{doc}} \in \mathbb{R}^{R \cdot B \cdot d}$.
  2. **Asymmetric Query vs Document Encoding**:
     * Document FDE: Sums all tokens in bucket $b$.
     * Query FDE: Multiplies bucket sums by directional gating weights to approximate MaxSim as a single linear inner product!

     ```cpp
     namespace secan {
     class MuveraEncoder {
     public:
         size_t dim{128};
         size_t num_buckets{16};
         size_t num_repetitions{4};
         std::vector<float> random_projections; // R x log2(B) x dim

         MuveraEncoder(size_t dimension, size_t B, size_t R)
             : dim(dimension), num_buckets(B), num_repetitions(R),
               random_projections(R * 4 * dimension) {
             // Initialize random projection planes
         }

         void encode_document_fde(
             const float* doc_tokens,
             size_t num_tokens,
             float* out_fde // Size: R * B * dim
         ) const {
             std::memset(out_fde, 0, num_repetitions * num_buckets * dim * sizeof(float));

             for (size_t r = 0; r < num_repetitions; ++r) {
                 float* r_fde = out_fde + r * num_buckets * dim;
                 for (size_t t = 0; t < num_tokens; ++t) {
                     const float* tok = doc_tokens + t * dim;
                     // Hash token to bucket [0, B-1]
                     uint32_t bucket = hash_token(tok, r);
                     float* bucket_vec = r_fde + bucket * dim;
                     // Accumulate token into bucket sum
                     for (size_t d = 0; d < dim; ++d) {
                         bucket_vec[d] += tok[d];
                     }
                 }
             }
         }

         uint32_t hash_token(const float* tok, size_t rep) const;
     };
     }
     ```
