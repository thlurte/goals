* **Book**: *Intel 64 and IA-32 Architectures Software Developer’s Manual* & *Intrinsics Guide*
* **Core Microarchitectural Concepts**:
  1. **SIMD MaxSim Cross-Lane Reduction**:
     * In Late-Interaction search (ColBERT), calculating $\max_{j} \langle \mathbf{q}_i, \mathbf{d}_j \rangle$ requires computing dot products across all document tokens and finding their maximum.
     * `_mm256_max_ps` compares 8 parallel float inner products in **1 single clock cycle**.
  2. **Branchless Horizontal Max Reduction**:
     * Reduce 8 floats in `__m256` to a single scalar using shuffle permutations:
       ```cpp
       __m128 hi = _mm256_extractf128_ps(ymm, 1);
       __m128 lo = _mm256_castps256_ps128(ymm);
       __m128 m = _mm_max_ps(lo, hi);
       m = _mm_max_ps(m, _mm_shuffle_ps(m, m, _MM_SHUFFLE(1, 0, 3, 2)));
       m = _mm_max_ps(m, _mm_shuffle_ps(m, m, _MM_SHUFFLE(2, 3, 0, 1)));
       float max_val = _mm_cvtss_f32(m);
       ```

* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement AVX2 MaxSim Kernel** in `src/late_interaction/maxsim_avx2.cpp`:
     ```cpp
     #include "secan/distance_avx2.h"
     #include <immintrin.h>
     #include <vector>
     #include <cstddef>

     namespace secan {
     float compute_maxsim_avx2(
         const float* query_tokens, // [num_q, dim]
         size_t num_q,
         const float* doc_tokens,   // [num_d, dim]
         size_t num_d,
         size_t dim = 128
     ) {
         float total_score = 0.0f;

         for (size_t q = 0; q < num_q; ++q) {
             const float* q_vec = query_tokens + q * dim;
             float max_doc_score = -1e9f;

             for (size_t d = 0; d < num_d; ++d) {
                 const float* d_vec = doc_tokens + d * dim;
                 // Compute 128-D dot product with AVX2 FMA
                 float score = dot_product_avx2(q_vec, d_vec, dim);
                 if (score > max_doc_score) {
                     max_doc_score = score;
                 }
             }
             total_score += max_doc_score;
         }
         return total_score;
     }
     }
     ```
