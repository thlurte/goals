## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Paper**: *"ColBERT: Efficient and Effective Passage Search via Contextualized Late Interaction over BERT"* (Khattab & Zaharia, SIGIR 2020)
* **Core Microarchitectural Concepts**:
  1. **Late Interaction Multi-Vector Retrieval Mechanics**:
     * Single-vector dense models compress an entire document into 1 single embedding, suffering information bottlenecking.
     * ColBERT preserves all token embeddings: Query $Q \in \mathbb{R}^{32 \times 128}$, Document $D \in \mathbb{R}^{180 \times 128}$.
     * MaxSim Operator: $\operatorname{Score}(Q, D) = \sum_{i=1}^{|Q|} \max_{j=1}^{|D|} \langle Q_i, D_j \rangle$.
  2. **Batch HNSW Construction Locality**:
     * Building HNSW one vector at a time causes random tree traversals.
     * Batch insertion organizes nodes by coarse centroid clusters, keeping graph traversal cache lines hot in L2/L3 cache and achieving $3.2\times$ faster index build throughput.

     ```cpp
     #include "secan/graph/hnsw_index.h"
     #include <thread>
     #include <vector>
     #include <atomic>

     namespace secan {
     void batch_build_hnsw(
         HnswIndex& index,
         const float* data,
         size_t num_vectors,
         size_t num_threads = 8
     ) {
         std::mt19937 rng(42);
         // 1. Assign random levels for all vectors upfront
         for (size_t i = 0; i < num_vectors; ++i) {
             index.element_levels[i] = random_level(1.0 / std::log(index.M), rng);
             if (index.element_levels[i] > index.max_level) {
                 index.max_level = index.element_levels[i];
                 index.enter_node = static_cast<uint32_t>(i);
             }
         }

         // 2. Multithreaded insertion loop
         std::atomic<size_t> next_vec{0};
         std::vector<std::jthread> workers;

         for (size_t t = 0; t < num_threads; ++t) {
             workers.emplace_back([&]() {
                 while (true) {
                     size_t idx = next_vec.fetch_add(1);
                     if (idx >= num_vectors) break;
                     // Perform HNSW insertion for vector idx
                     insert_hnsw_node(index, idx, data);
                 }
             });
         }
     }
     }
     ```
