## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §5.1–5.2 (*Eigenvalues, Eigenvectors, The Characteristic Equation & Matrix Diagonalization*)
* **Theorems & Mathematical Concepts**:
  1. **Eigenvalue Definition & Characteristic Polynomial**:
     $$\mathbf{A}\mathbf{x} = \lambda \mathbf{x} \iff (\mathbf{A} - \lambda \mathbf{I})\mathbf{x} = \mathbf{0} \implies p(\lambda) = \det(\mathbf{A} - \lambda \mathbf{I}) = 0$$
  2. **Trace & Determinant Invariants**:
     $$\sum_{i=1}^n \lambda_i = \operatorname{tr}(\mathbf{A}) = \sum_{i=1}^n a_{ii}, \quad \prod_{i=1}^n \lambda_i = \det(\mathbf{A})$$
  3. **Matrix Diagonalization**:
     * If $\mathbf{A} \in \mathbb{R}^{n \times n}$ has $n$ linearly independent eigenvectors $\mathbf{x}_1, \dots, \mathbf{x}_n$:
       $$\mathbf{A}\mathbf{S} = \mathbf{A}[\mathbf{x}_1 \dots \mathbf{x}_n] = [\lambda_1 \mathbf{x}_1 \dots \lambda_n \mathbf{x}_n] = \mathbf{S}\mathbf{\Lambda} \implies \mathbf{A} = \mathbf{S} \mathbf{\Lambda} \mathbf{S}^{-1}$$
  4. **Matrix Powers & Exponential Growth**:
     $$\mathbf{A}^k = (\mathbf{S}\mathbf{\Lambda}\mathbf{S}^{-1})^k = \mathbf{S}\mathbf{\Lambda}^k \mathbf{S}^{-1} = \mathbf{S} \operatorname{diag}(\lambda_1^k, \dots, \lambda_n^k) \mathbf{S}^{-1}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that eigenvectors $\mathbf{x}_1, \dots, \mathbf{x}_k$ corresponding to distinct eigenvalues $\lambda_1 \ne \lambda_2 \ne \dots \ne \lambda_k$ are linearly independent by induction.
  - [ ] **Proof 2**: Prove that $\operatorname{tr}(\mathbf{A}) = \sum \lambda_i$ and $\det(\mathbf{A}) = \prod \lambda_i$ by matching polynomial coefficients in $\det(\mathbf{A} - \lambda \mathbf{I}) = \prod_{i=1}^n (\lambda_i - \lambda)$.
  - [ ] **Problem 3**: For matrix $\mathbf{A} = \begin{pmatrix} 4 & 1 \\ 2 & 3 \end{pmatrix}$, compute the eigenvalues $\lambda_1, \lambda_2$, find their eigenvectors, construct eigenvector matrix $\mathbf{S}$ and diagonal matrix $\mathbf{\Lambda}$, and compute $\mathbf{A}^{10}$ explicitly.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Topic**: *Apache Arrow & Lance Columnar File Layouts for High-Throughput Search*
* **Core Microarchitectural Concepts**:
  1. **Immutable SSTable Segment Design**:
     * When `MemTable` fills up, freeze it and flush to an immutable on-disk segment file `seg_0001.bin`.
     * Segment File Format:
       * **Header (64 bytes)**: `Magic (4B) | Version (4B) | NumVectors (8B) | Dim (4B) | Flags (4B) | Padding (40B)`.
       * **Contiguous Vector Array**: `float data[N * D]` (64-byte cache aligned for direct `mmap`).
       * **CSR Graph Adjacency**: `offsets[N+1]`, `neighbors[E]`.
  2. **Zero-Copy Memory-Mapped Access (`mmap`)**:
     * Read path maps immutable segments via `mmap(MAP_SHARED, PROT_READ)` with `MADV_WILLNEED` / `MADV_RANDOM`, letting the Linux page cache manage memory pressure with zero userland memory copies.

     ```cpp
     #include "secan/storage/segment.h"
     #include <fstream>
     #include <vector>
     #include <cstdint>

     namespace secan {
     struct SegmentHeader {
         uint32_t magic{0x53454731}; // 'SEG1'
         uint32_t version{1};
         uint64_t num_vectors{0};
         uint32_t dim{0};
         uint32_t flags{0};
         uint8_t reserved[40]{0};
     };

     void flush_memtable_to_segment(
         const std::string& segment_path,
         const float* vectors,
         size_t num_vectors,
         size_t dim,
         const std::vector<uint32_t>& csr_offsets,
         const std::vector<uint32_t>& csr_neighbors
     ) {
         std::ofstream out(segment_path, std::ios::binary);
         SegmentHeader header;
         header.num_vectors = num_vectors;
         header.dim = static_cast<uint32_t>(dim);

         // 1. Write Header
         out.write(reinterpret_cast<const char*>(&header), sizeof(SegmentHeader));

         // 2. Write 64-byte aligned vector buffer
         out.write(reinterpret_cast<const char*>(vectors), num_vectors * dim * sizeof(float));

         // 3. Write CSR graph topology
         uint64_t num_offsets = csr_offsets.size();
         uint64_t num_neighbors = csr_neighbors.size();
         out.write(reinterpret_cast<const char*>(&num_offsets), 8);
         out.write(reinterpret_cast<const char*>(csr_offsets.data()), num_offsets * sizeof(uint32_t));
         out.write(reinterpret_cast<const char*>(&num_neighbors), 8);
         out.write(reinterpret_cast<const char*>(csr_neighbors.data()), num_neighbors * sizeof(uint32_t));
     }
     }
     ```
