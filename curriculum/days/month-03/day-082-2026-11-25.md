* **Book**: *Optimizing Software in C++* — Agner Fog (Ch 7.5)
* **Core Microarchitectural Concepts**:
  1. **HNSW Graph Search Bottlenecks**:
     * HNSW beam search traverses $500\text{--}2{,}000$ neighbor nodes per query.
     * Two critical microarchitectural bottlenecks:
       * **Visited Set Overhead**: `std::unordered_set` causes dynamic allocations and hash collisions ($>35\%$ query time).
       * **Priority Queue Overhead**: `std::priority_queue` causes pointer indirection and branch mispredictions.
  2. **Bounded Flat Array Heap & 64-Bit Word-Aligned Bitset**:
     * Replace `unordered_set` with a flat bitset: 1 bit per vector ID, checked via `(bitset[id / 64] & (1ULL << (id % 64)))`.
     * Replace heap with `BoundedFlatHeap<K>`: contiguous array on L1 stack with branchless conditional move (`cmov`) operations.

     ```cpp
     #pragma once
     #include <cstdint>
     #include <array>
     #include <algorithm>

     namespace secan {
     template <size_t MaxCapacity>
     class BoundedFlatHeap {
     public:
         struct Entry {
             float dist;
             uint32_t id;
         };

         std::array<Entry, MaxCapacity> data;
         size_t size{0};

         void insert(float dist, uint32_t id) {
             if (size < MaxCapacity) {
                 data[size++] = {dist, id};
                 std::push_heap(data.begin(), data.begin() + size, [](const Entry& a, const Entry& b) {
                     return a.dist < b.dist; // Max-heap
                 });
             } else if (dist < data[0].dist) {
                 std::pop_heap(data.begin(), data.begin() + size, [](const Entry& a, const Entry& b) {
                     return a.dist < b.dist;
                 });
                 data[size - 1] = {dist, id};
                 std::push_heap(data.begin(), data.begin() + size, [](const Entry& a, const Entry& b) {
                     return a.dist < b.dist;
                 });
             }
         }
     };

     class BitsetVisited {
     public:
         std::vector<uint64_t> bits;
         explicit BitsetVisited(size_t max_id) : bits((max_id + 63) / 64, 0ULL) {}

         inline bool test_and_set(uint32_t id) {
             size_t idx = id / 64;
             uint64_t mask = 1ULL << (id % 64);
             if (bits[idx] & mask) return true;
             bits[idx] |= mask;
             return false;
         }

         inline void clear() {
             std::fill(bits.begin(), bits.end(), 0ULL);
         }
     };
     }
     ```
