## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §5.3–5.4 (*Differential Equations, Matrix Exponential $e^{\mathbf{A}t}$ & System Stability*)
* **Theorems & Mathematical Concepts**:
  1. **Linear Systems of Differential Equations**:
     $$\frac{d\mathbf{u}}{dt} = \mathbf{A}\mathbf{u}(t) \quad \text{with initial condition } \mathbf{u}(0)$$
  2. **The Matrix Exponential $e^{\mathbf{A}t}$**:
     $$e^{\mathbf{A}t} = \mathbf{I} + \mathbf{A}t + \frac{(\mathbf{A}t)^2}{2!} + \frac{(\mathbf{A}t)^3}{3!} + \dots = \mathbf{S} \operatorname{diag}\left(e^{\lambda_1 t}, \dots, e^{\lambda_n t}\right) \mathbf{S}^{-1}$$
     * The exact analytic solution: $\mathbf{u}(t) = e^{\mathbf{A}t} \mathbf{u}(0) = \mathbf{S} e^{\mathbf{\Lambda} t} \mathbf{S}^{-1} \mathbf{u}(0) = \sum_{i=1}^n c_i e^{\lambda_i t} \mathbf{x}_i$.
  3. **Dynamical Stability Criterion**:
     * The origin $\mathbf{0}$ is asymptotically stable $\iff \operatorname{Re}(\lambda_i) < 0$ for all eigenvalues of $\mathbf{A}$.
     * Pure imaginary eigenvalues $\lambda = \pm i\omega$ generate undamped periodic oscillations (harmonics).

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Topic**: *Linux `io_uring` Architecture: Submission Queues (SQ), Completion Queues (CQ) & Asynchronous Disk Operations*
* **Core Microarchitectural Concepts**:
  1. **Overcoming System Call Overhead**:
     * Standard POSIX `pread()` executes a synchronous kernel mode transition ($>1.2\ \mu\text{s}$) for every read, blocking thread execution.
     * `io_uring` provides two memory-mapped lockless ring buffers: Submission Queue (SQ) and Completion Queue (CQ).
     * The application places 64 disk read requests directly into the SQ without system calls, issuing a single `io_uring_enter()` to dispatch batch I/O to NVMe controllers.
  2. **Background LSM Compaction Scheduling**:
     * Compaction must run on background worker threads with IO priority throttling (`ioprio_set`) to prevent query thread stalls.
