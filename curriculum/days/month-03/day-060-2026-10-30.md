## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §2.5–2.6 (*The Four Fundamental Subspaces & Fundamental Theorem of Linear Algebra Part 1*)
* **Theorems & Mathematical Concepts**:
  1. **The Four Fundamental Subspaces of Matrix $\mathbf{A} \in \mathbb{R}^{m \times n}$**:
     | Subspace | Notation | Ambient Space | Dimension |
     |:---|:---|:---|:---|
     | **Column Space** | $C(\mathbf{A})$ | $\mathbb{R}^m$ | $r$ (rank) |
     | **Nullspace** | $N(\mathbf{A})$ | $\mathbb{R}^n$ | $n - r$ |
     | **Row Space** | $C(\mathbf{A}^T)$ | $\mathbb{R}^n$ | $r$ (rank) |
     | **Left Nullspace** | $N(\mathbf{A}^T)$ | $\mathbb{R}^m$ | $m - r$ |
  2. **The Fundamental Theorem of Linear Algebra (Part 1)**:
     * Row rank equals column rank: $\operatorname{dim}(C(\mathbf{A}^T)) = \operatorname{dim}(C(\mathbf{A})) = r$.
     * The dimensions of the row space and nullspace sum to $n$; the dimensions of the column space and left nullspace sum to $m$.
  3. **Left Nullspace Mechanics**:
     * $\mathbf{y} \in N(\mathbf{A}^T) \iff \mathbf{A}^T \mathbf{y} = \mathbf{0} \iff \mathbf{y}^T \mathbf{A} = \mathbf{0}^T$.
     * Row operations that zero out rows during elimination produce the exact basis vectors for the left nullspace.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that row rank equals column rank ($\operatorname{dim} C(\mathbf{A}^T) = \operatorname{dim} C(\mathbf{A}) = r$) by showing that row operations preserve the row space and the linear independence of pivot columns.
  - [ ] **Problem 2**: For matrix $\mathbf{A} = \begin{pmatrix} 1 & 3 & 3 & 2 \\ 2 & 6 & 9 & 7 \\ -1 & -3 & 3 & 4 \end{pmatrix}$, compute explicit bases and dimensions for all four fundamental subspaces: $C(\mathbf{A}), N(\mathbf{A}), C(\mathbf{A}^T), N(\mathbf{A}^T)$.
  - [ ] **Problem 3**: For an $m \times n$ matrix with $m > n$ and full column rank $r = n$, determine the dimensions of all four fundamental subspaces and explain why $N(\mathbf{A}) = \{\mathbf{0}\}$.

     ```cpp
     #include <vector>
     #include <cstdint>

     namespace secan {
     struct TokenPosting {
         uint32_t doc_id;
         uint16_t token_idx;
     };

     class TokenCentroidIndex {
     public:
         size_t num_centroids{32768};
         size_t dim{128};
         std::vector<float> centroids; // [num_centroids * dim]
         std::vector<std::vector<TokenPosting>> inverted_lists;

         TokenCentroidIndex(size_t n_centroids, size_t dimension)
             : num_centroids(n_centroids), dim(dimension),
               centroids(n_centroids * dimension),
               inverted_lists(n_centroids) {}

         void add_document_tokens(uint32_t doc_id, const float* doc_tokens, size_t num_tokens) {
             for (size_t t = 0; t < num_tokens; ++t) {
                 const float* tok = doc_tokens + t * dim;
                 // Find closest centroid
                 uint32_t best_c = find_closest_centroid(tok);
                 inverted_lists[best_c].push_back({doc_id, static_cast<uint16_t>(t)});
             }
         }

         uint32_t find_closest_centroid(const float* vec) const;
     };
     }
     ```
