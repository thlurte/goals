* **Topic**: *`hnswlib` SQ8 vs Faiss HNSW+SQ: Architecture & Microarchitectural Memory Savings*
* **Core Microarchitectural Concepts**:
  1. **Quantized Graph Routing Architecture**:
     * FP32 768-D embeddings require $3.1\text{ GB}$ DRAM per 1M vectors, exceeding L3 cache capacity and saturating memory bandwidth.
     * `HNSWSQIndex` quantizes vector storage to SQ8 ($768\text{ bytes}$) or SQ4 ($384\text{ bytes}$).
     * During graph beam traversal, evaluate distances using AVX2 `_mm256_maddubs_epi16`, keeping candidate vectors resident in L2 cache ($4\times$ higher QPS).
  2. **Re-Ranking Pipeline**:
     * Step 1: Traverse HNSW graph using SQ8/SQ4 quantized distance kernel to retrieve top-$2k$ candidates.
     * Step 2: Exact FP32 distance re-ranking on top-$2k$ candidates to restore $>99\%$ Recall@10.

     ```cpp
     #include "secan/graph/hnsw_index.h"
     #include "secan/quantization/scalar_quantizer.h"
     #include "secan/graph/bounded_flat_heap.h"
     #include <vector>

     namespace secan {
     class HnswSqIndex {
     public:
         size_t dim;
         ScalarQuantizer8 sq8;
         HnswIndex graph;
         std::vector<uint8_t> quantized_storage; // N * dim bytes

         HnswSqIndex(size_t dimension, size_t M = 16, size_t ef_c = 200)
             : dim(dimension), sq8(dimension), graph(dimension, M, ef_c) {}

         void train_and_insert(const float* vectors, size_t num_vectors) {
             sq8.train(vectors, num_vectors);
             quantized_storage.resize(num_vectors * dim);
             for (size_t i = 0; i < num_vectors; ++i) {
                 sq8.encode(vectors + i * dim, quantized_storage.data() + i * dim);
                 graph.insert(static_cast<uint32_t>(i), vectors + i * dim);
             }
         }

         std::vector<uint32_t> search(const float* query, size_t k, size_t ef_search) const {
             // Graph beam search evaluating integer SQ8 distances
             return graph.search_quantized(query, quantized_storage.data(), k, ef_search);
         }
     };
     }
     ```
