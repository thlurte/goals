## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §3.4 (*Orthonormal Bases, Orthogonal Matrices $Q$, Gram-Schmidt & $QR$ Factorization*)
* **Theorems & Mathematical Concepts**:
  1. **Orthonormal Vectors & Orthogonal Matrices**:
     * Orthonormal vectors: $\mathbf{q}_i^T \mathbf{q}_j = \delta_{ij} = \begin{cases} 1 & \text{if } i = j \\ 0 & \text{if } i \ne j \end{cases}$.
     * A square matrix $\mathbf{Q}$ with orthonormal columns is an **orthogonal matrix**:
       $$\mathbf{Q}^T \mathbf{Q} = \mathbf{I} \implies \mathbf{Q}^{-1} = \mathbf{Q}^T$$
  2. **Isometry & Angle Preservation**:
     * Length preservation: $\|\mathbf{Q}\mathbf{x}\|_2^2 = \mathbf{x}^T \mathbf{Q}^T \mathbf{Q} \mathbf{x} = \mathbf{x}^T \mathbf{x} = \|\mathbf{x}\|_2^2$.
     * Inner product preservation: $\langle \mathbf{Q}\mathbf{x}, \mathbf{Q}\mathbf{y} \rangle = \mathbf{x}^T \mathbf{Q}^T \mathbf{Q} \mathbf{y} = \langle \mathbf{x}, \mathbf{y} \rangle$.
  3. **The Gram-Schmidt Orthogonalization Process**:
     * Given linearly independent vectors $\mathbf{a}_1, \dots, \mathbf{a}_n$, construct orthogonal vectors $\mathbf{u}_1, \dots, \mathbf{u}_n$:
       $$\mathbf{u}_1 = \mathbf{a}_1, \quad \mathbf{u}_k = \mathbf{a}_k - \sum_{j=1}^{k-1} \frac{\mathbf{u}_j^T \mathbf{a}_k}{\mathbf{u}_j^T \mathbf{u}_j} \mathbf{u}_j \implies \mathbf{q}_k = \frac{\mathbf{u}_k}{\|\mathbf{u}_k\|}$$
  4. **The $QR$ Factorization**:
     $$\mathbf{A} = \mathbf{Q} \mathbf{R} \quad \text{where } \mathbf{R} = \mathbf{Q}^T \mathbf{A} \text{ is upper triangular with } r_{ii} > 0$$
* **Pencil & Paper Problem Set**:

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Paper**: *"RaBitQ: Quantizing High-Dimensional Vectors with a Theoretical Error Bound for Approximate Nearest Neighbor Search"* (Gao & Long, SIGMOD 2024)
* **Core Microarchitectural Concepts**:
  1. **Randomized Orthogonal Quantization Mechanics**:
     * Standard 1-bit Binary Quantization (sign bits) fails catastrophically on correlated or anisotropic embeddings.
     * RaBitQ pre-rotates vectors using a random Haar orthogonal matrix $\mathbf{Q} \in \mathbb{R}^{d \times d}$: $\mathbf{y} = \mathbf{Q}\mathbf{x}$.
     * By spherical symmetry, rotated dimensions become mutually uncorrelated Gaussian variables $\mathcal{N}(0, 1/d)$.
     * Quantize to 1-bit: $b_i = \operatorname{sign}(y_i) \in \{0, 1\}$.
  2. **Hardware POPCNT Asymmetric Distance Estimation**:
     * Query $\mathbf{q}$ is rotated $\mathbf{q}' = \mathbf{Q}\mathbf{q}$ (kept in FP32).
     * Bitwise distance is evaluated via AVX2 XOR + `_mm_popcnt_u64`, executing at $>400\text{ million vectors/sec/core}$!

     ```cpp
     #include "secan/quantization/rabitq.h"
     #include <immintrin.h>
     #include <random>
     #include <vector>
     #include <cmath>

     namespace secan {
     class RaBitQuantizer {
     public:
         size_t dim;
         std::vector<float> Q_matrix; // d x d orthogonal rotation
         std::vector<float> norm_factors;

         RaBitQuantizer(size_t dimension) : dim(dimension), Q_matrix(dimension * dimension) {
             generate_random_orthogonal_matrix();
         }

         void generate_random_orthogonal_matrix() {
             std::mt19937 rng(42);
             std::normal_distribution<float> dist(0.0f, 1.0f);
             // 1. Generate random Gaussian matrix
             for (auto& v : Q_matrix) v = dist(rng);

             // 2. Gram-Schmidt orthogonalization
             for (size_t i = 0; i < dim; ++i) {
                 float* vi = Q_matrix.data() + i * dim;
                 for (size_t j = 0; j < i; ++j) {
                     const float* qj = Q_matrix.data() + j * dim;
                     float dot = 0.0f;
                     for (size_t d = 0; d < dim; ++d) dot += vi[d] * qj[d];
                     for (size_t d = 0; d < dim; ++d) vi[d] -= dot * qj[d];
                 }
                 float norm = 0.0f;
                 for (size_t d = 0; d < dim; ++d) norm += vi[d] * vi[d];
                 norm = std::sqrt(norm);
                 for (size_t d = 0; d < dim; ++d) vi[d] /= norm;
             }
         }

         void encode_vector(const float* vec, uint64_t* out_bits) const {
             // Rotate: y = Q * vec
             std::vector<float> rotated(dim, 0.0f);
             for (size_t r = 0; r < dim; ++r) {
                 for (size_t c = 0; c < dim; ++c) {
                     rotated[r] += Q_matrix[r * dim + c] * vec[c];
                 }
             }

             // Pack sign bits into 64-bit integers
             for (size_t i = 0; i < dim / 64; ++i) {
                 uint64_t word = 0;
                 for (size_t b = 0; b < 64; ++b) {
                     if (rotated[i * 64 + b] >= 0.0f) {
                         word |= (1ULL << b);
                     }
                 }
                 out_bits[i] = word;
             }
         }
     };
     }
     ```
