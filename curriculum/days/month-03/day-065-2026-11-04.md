## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §3.2 (*Projections onto 1D Subspaces & Cauchy-Schwarz from Orthogonal Error*)
* **Theorems & Mathematical Concepts**:
  1. **Projection onto a 1D Line**:
     * To project vector $\mathbf{b}$ onto the line spanned by vector $\mathbf{a}$, find scalar $\hat{x}$ such that error $\mathbf{e} = \mathbf{b} - \hat{x}\mathbf{a} \perp \mathbf{a}$:
       $$\mathbf{a}^T (\mathbf{b} - \hat{x}\mathbf{a}) = 0 \implies \hat{x} = \frac{\mathbf{a}^T \mathbf{b}}{\mathbf{a}^T \mathbf{a}}$$
     * Projection vector $\mathbf{p} = \hat{x}\mathbf{a} = \left( \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}} \right) \mathbf{b} = \mathbf{P} \mathbf{b}$.
  2. **The 1D Projection Matrix $\mathbf{P} = \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}}$**:
     * **Symmetric**: $\mathbf{P}^T = \left(\frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}}\right)^T = \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}} = \mathbf{P}$.
     * **Idempotent**: $\mathbf{P}^2 = \frac{\mathbf{a}\mathbf{a}^T \mathbf{a}\mathbf{a}^T}{(\mathbf{a}^T \mathbf{a})^2} = \frac{\mathbf{a}(\mathbf{a}^T \mathbf{a})\mathbf{a}^T}{(\mathbf{a}^T \mathbf{a})^2} = \mathbf{P}$.
  3. **Cauchy-Schwarz from Error Norm**:
     $$\|\mathbf{e}\|^2 = \|\mathbf{b} - \mathbf{p}\|^2 = \|\mathbf{b}\|^2 - \|\mathbf{p}\|^2 = \|\mathbf{b}\|^2 - \frac{(\mathbf{a}^T \mathbf{b})^2}{\|\mathbf{a}\|^2} \ge 0 \implies (\mathbf{a}^T \mathbf{b})^2 \le \|\mathbf{a}\|^2 \|\mathbf{b}\|^2$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that $\mathbf{P}^2 = \mathbf{P}$ and $\mathbf{P}^T = \mathbf{P}$ for any projection matrix $\mathbf{P} = \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}}$.
  - [ ] **Proof 2**: Prove the Pythagorean relationship $\|\mathbf{b}\|^2 = \|\mathbf{p}\|^2 + \|\mathbf{e}\|^2$ using $\mathbf{p}^T \mathbf{e} = 0$, deriving the Cauchy-Schwarz inequality.
  - [ ] **Problem 3**: For vector $\mathbf{a} = \begin{pmatrix} 1 \\ 2 \\ 2 \end{pmatrix}$, compute the $3 \times 3$ projection matrix $\mathbf{P}$. Compute $\mathbf{p} = \mathbf{P}\begin{pmatrix} 3 \\ 3 \\ 3 \end{pmatrix}$ and verify that error $\mathbf{e} = \mathbf{b} - \mathbf{p}$ is strictly orthogonal to $\mathbf{a}$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Paper**: *"MUVERA: Multi-Vector Retrieval via Fixed Dimensional Encodings"* §4–5
* **Core Microarchitectural Concepts**:
  1. **2-Stage FDE Pipeline Architecture**:
     * Variable-length token representations are converted into single fixed-size FDE vectors $\mathbf{z}_d \in \mathbb{R}^{B \cdot R \cdot d}$.
     * Stage 1 (Fast Approximate MIPS): Search FDEs in an Inner Product HNSW index to retrieve top-$K_c=100$ candidate passages in $<0.4\text{ ms}$.
     * Stage 2 (Exact MaxSim Re-Ranking): Load raw token matrices only for the 100 candidate passages from contiguous memory and compute AVX2 MaxSim.
  2. **Memory Hierarchy Alignment**:
     * FDE embeddings reside in L3/DRAM; raw token buffers are streamed directly into L1/L2 cache during Stage 2 re-ranking.

## 💻 20:30 – 23:00 | Night Hands-On Implementation (2.5 hrs)
* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement MUVERA 2-Stage Retrieval Pipeline** in `src/late_interaction/muvera_pipeline.cpp`:
     ```cpp
     #include "secan/late_interaction/muvera.h"
     #include "secan/graph/hnsw_index.h"
     #include "secan/late_interaction/maxsim_avx2.h"
     #include <vector>
     #include <algorithm>

     namespace secan {
     struct SearchHit {
         uint32_t doc_id;
         float exact_maxsim_score;
     };

     std::vector<SearchHit> search_muvera_pipeline(
         const MuveraEncoder& encoder,
         const HnswIndex& fde_hnsw,
         const float* query_tokens,
         size_t num_q_tokens,
         const float* all_raw_doc_tokens,
         const size_t* doc_offsets,
         const size_t* doc_lengths,
         size_t num_candidates = 100,
         size_t top_k = 10
     ) {
         // 1. Encode query into Query FDE
         std::vector<float> q_fde(encoder.num_repetitions * encoder.num_buckets * encoder.dim);
         encoder.encode_query_fde(query_tokens, num_q_tokens, q_fde.data());

         // 2. Stage 1: Fast MIPS candidate retrieval on FDE graph
         std::vector<uint32_t> candidates = search_hnsw(fde_hnsw, q_fde.data(), num_candidates, 64);

         // 3. Stage 2: Exact AVX2 MaxSim re-ranking on candidate subset
         std::vector<SearchHit> results;
         results.reserve(candidates.size());

         for (uint32_t doc_id : candidates) {
             const float* d_toks = all_raw_doc_tokens + doc_offsets[doc_id] * encoder.dim;
             size_t d_len = doc_lengths[doc_id];
             float score = compute_maxsim_avx2(query_tokens, num_q_tokens, d_toks, d_len, encoder.dim);
             results.push_back({doc_id, score});
         }

         std::partial_sort(results.begin(), results.begin() + top_k, results.end(),
             [](const SearchHit& a, const SearchHit& b) { return a.exact_maxsim_score > b.exact_maxsim_score; });
         results.resize(top_k);
         return results;
     }
     }
     ```
