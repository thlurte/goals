* **Topic**: *Covariance Whitening & Query-Side PCA Acceleration in Vector Search*
* **Core Microarchitectural Concepts**:
  1. **High-Dimensional Hubness Neutralization**:
     * Highly anisotropic embeddings create "hub" nodes with excessive in-degrees ($>100\times k$), trapping graph beam search and skewing distance distributions.
     * ZCA Whitening Transform:
       $$\mathbf{x}_{\text{white}} = \mathbf{\Lambda}^{-1/2} \mathbf{Q}^T (\mathbf{x} - \boldsymbol{\mu})$$
     * Warps the embedding manifold into an isotropic hypersphere ($\operatorname{Cov}(\mathbf{X}_{\text{white}}) = \mathbf{I}$), suppressing hub nodes and restoring uniform graph routing.
  2. **SIMD Vectorized Matrix-Vector Projection**:
     * Evaluate $\mathbf{y} = \mathbf{W}\mathbf{x}$ using AVX2 FMA register unrolling to project queries in $<200\text{ ns}$.

* **Tasks & Implementation**:
  1. **Implement ZCA Covariance Whitener** in `src/transforms/whitening.cpp`:
     ```cpp
     #include "secan/transforms/whitening.h"
     #include "secan/distance_avx2.h"
     #include <vector>
     #include <cmath>

     namespace secan {
     class ZcaWhitener {
     public:
         size_t dim;
         std::vector<float> mean_vec;
         std::vector<float> W_matrix; // d x d whitening matrix: Q * Lambda^(-1/2) * Q^T

         ZcaWhitener(size_t dimension)
             : dim(dimension), mean_vec(dimension, 0.0f), W_matrix(dimension * dimension, 0.0f) {}

         void transform(const float* src, float* dst, size_t num_vectors) const {
             for (size_t i = 0; i < num_vectors; ++i) {
                 const float* x = src + i * dim;
                 float* y = dst + i * dim;

                 // Subtract mean and multiply by whitening matrix W
                 std::vector<float> centered(dim);
                 for (size_t d = 0; d < dim; ++d) centered[d] = x[d] - mean_vec[d];

                 for (size_t r = 0; r < dim; ++r) {
                     float sum = 0.0f;
                     for (size_t c = 0; c < dim; ++c) {
                         sum += W_matrix[r * dim + c] * centered[c];
                     }
                     y[r] = sum;
                 }
             }
         }
     };
     }
     ```
