* **Core Microarchitectural Concepts**:
  1. **PiPNN & HashPrune (Dense GEMM Graph Construction)**:
     * Traditional HNSW/Vamana sequential beam search is memory-latency bound ($O(N \log N)$ pointer chasing).
     * PiPNN partitions datasets into overlapping clusters and evaluates candidate edges using high-throughput dense matrix multiplication (AVX-512 / BLAS / Tensor Cores).
     * **HashPrune**: Online bounded-memory pruning algorithm that merges partition-local candidates into a globally connected, high-quality proximity graph with $10\times\text{–}13\times$ faster build times.
  2. **PLAID Multi-Stage Retrieval Engine**:
     * Stage 1 (Centroid Pruning): Select documents containing centroids mapped by query tokens.
     * Stage 2 (Fast 2-Bit SIMD Filtering): Compute approximate MaxSim scores using 2-bit scalar quantization.
     * Stage 3 (Exact Re-ranking): Decompress full 128-D FP32 token embeddings only for the top-100 candidate documents.

     ```python
     import torch
     import torch.nn as nn
     import torch.nn.functional as F

     class MarginMSEDistillationLoss(nn.Module):
         def __init__(self):
             super().__init__()

         def forward(self,
                     student_pos_score: torch.Tensor, # [B]
                     student_neg_score: torch.Tensor, # [B]
                     teacher_pos_score: torch.Tensor, # [B]
                     teacher_neg_score: torch.Tensor  # [B]
         ) -> torch.Tensor:
             student_margin = student_pos_score - student_neg_score
             teacher_margin = teacher_pos_score - teacher_neg_score
             return F.mse_loss(student_margin, teacher_margin)
     ```
