### 🔹 Part 1: Advanced Theorems & Derivations (Thursday Syllabus)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §3.4 (*Orthonormal Bases, Orthogonal Matrices $Q$, Gram-Schmidt & $QR$ Factorization*)
* **Theorems & Mathematical Concepts**:
  1. **Orthonormal Vectors & Orthogonal Matrices**:
     * Orthonormal vectors: $\mathbf{q}_i^T \mathbf{q}_j = \delta_{ij} = \begin{cases} 1 & \text{if } i = j \\ 0 & \text{if } i \ne j \end{cases}$.
     * A square matrix $\mathbf{Q}$ with orthonormal columns is an **orthogonal matrix**:
       $$\mathbf{Q}^T \mathbf{Q} = \mathbf{I} \implies \mathbf{Q}^{-1} = \mathbf{Q}^T$$
  2. **Isometry & Angle Preservation**:
     * Length preservation: $\|\mathbf{Q}\mathbf{x}\|_2^2 = \mathbf{x}^T \mathbf{Q}^T \mathbf{Q} \mathbf{x} = \mathbf{x}^T \mathbf{x} = \|\mathbf{x}\|_2^2$.
     * Inner product preservation: $\langle \mathbf{Q}\mathbf{x}, \mathbf{Q}\mathbf{y} \rangle = \mathbf{x}^T \mathbf{Q}^T \mathbf{Q} \mathbf{y} = \langle \mathbf{x}, \mathbf{y} \rangle$.
  3. **The Gram-Schmidt Orthogonalization Process**:
     * Given linearly independent vectors $\mathbf{a}_1, \dots, \mathbf{a}_n$, construct orthogonal vectors $\mathbf{u}_1, \dots, \mathbf{u}_n$:
       $$\mathbf{u}_1 = \mathbf{a}_1, \quad \mathbf{u}_k = \mathbf{a}_k - \sum_{j=1}^{k-1} \frac{\mathbf{u}_j^T \mathbf{a}_k}{\mathbf{u}_j^T \mathbf{u}_j} \mathbf{u}_j \implies \mathbf{q}_k = \frac{\mathbf{u}_k}{\|\mathbf{u}_k\|}$$
  4. **The $QR$ Factorization**:
     $$\mathbf{A} = \mathbf{Q} \mathbf{R} \quad \text{where } \mathbf{R} = \mathbf{Q}^T \mathbf{A} \text{ is upper triangular with } r_{ii} > 0$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that an orthogonal matrix $\mathbf{Q}$ preserves Euclidean distances: $\|\mathbf{Q}\mathbf{x} - \mathbf{Q}\mathbf{y}\| = \|\mathbf{x} - \mathbf{y}\|$.
  - [ ] **Problem 2**: Execute the Gram-Schmidt process by hand on vectors $\mathbf{a}_1 = \begin{pmatrix} 1 \\ 2 \\ 2 \end{pmatrix}$ and $\mathbf{a}_2 = \begin{pmatrix} 1 \\ 3 \\ 1 \end{pmatrix}$. Compute orthonormal $\mathbf{q}_1, \mathbf{q}_2$ and write the $3 \times 2$ matrix $\mathbf{Q}$ and $2 \times 2$ upper triangular matrix $\mathbf{R}$.
  - [ ] **Proof 3**: Prove that the subspace projection matrix $\mathbf{P} = \mathbf{A}(\mathbf{A}^T \mathbf{A})^{-1}\mathbf{A}^T$ collapses directly to $\mathbf{P} = \mathbf{Q}\mathbf{Q}^T$ when the columns of $\mathbf{A}$ are replaced by the orthonormal columns of $\mathbf{Q}$.

### 🔹 Part 2: Core Proofs & Problem Sets (Friday Syllabus)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §3.4 (*Least Squares via $QR$ Factorization & Numerical Conditioning*)
* **Theorems & Mathematical Concepts**:
  1. **Least Squares via $QR$ Factorization**:
     * Substitute $\mathbf{A} = \mathbf{Q}\mathbf{R}$ into the Normal Equations $\mathbf{A}^T \mathbf{A} \hat{\mathbf{x}} = \mathbf{A}^T \mathbf{b}$:
       $$(\mathbf{Q}\mathbf{R})^T (\mathbf{Q}\mathbf{R})\hat{\mathbf{x}} = (\mathbf{Q}\mathbf{R})^T \mathbf{b} \implies \mathbf{R}^T (\mathbf{Q}^T \mathbf{Q}) \mathbf{R} \hat{\mathbf{x}} = \mathbf{R}^T \mathbf{Q}^T \mathbf{b}$$
     * Since $\mathbf{Q}^T \mathbf{Q} = \mathbf{I}$, this simplifies to $\mathbf{R}^T \mathbf{R}\hat{\mathbf{x}} = \mathbf{R}^T \mathbf{Q}^T \mathbf{b}$. Multiplying by $(\mathbf{R}^T)^{-1}$:
       $$\mathbf{R} \hat{\mathbf{x}} = \mathbf{Q}^T \mathbf{b} \implies \hat{\mathbf{x}} = \mathbf{R}^{-1} \mathbf{Q}^T \mathbf{b}$$
  2. **Numerical Stability & Condition Numbers**:
     * Forming $\mathbf{A}^T \mathbf{A}$ squares the condition number: $\kappa(\mathbf{A}^T \mathbf{A}) = \kappa(\mathbf{A})^2$, destroying floating point precision.
     * $QR$ maintains $\kappa(\mathbf{R}) = \kappa(\mathbf{A})$, providing unconditional numerical stability.
  3. **Projection via $QR$**:
     $$\mathbf{p} = \mathbf{A}\hat{\mathbf{x}} = (\mathbf{Q}\mathbf{R})(\mathbf{R}^{-1}\mathbf{Q}^T \mathbf{b}) = \mathbf{Q}\mathbf{Q}^T \mathbf{b}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the upper triangular system $\mathbf{R}\hat{\mathbf{x}} = \mathbf{Q}^T \mathbf{b}$ step-by-step from $\mathbf{A}^T \mathbf{A} \hat{\mathbf{x}} = \mathbf{A}^T \mathbf{b}$.
  - [ ] **Problem 2**: Fit the optimal least-squares line $y = C + Dt$ to data points $(0, 1), (1, 3), (2, 2)$ using $QR$ factorization: set up $\mathbf{A}$, compute $\mathbf{Q}, \mathbf{R}$, calculate $\mathbf{Q}^T \mathbf{b}$, and back-solve for $C$ and $D$.
  - [ ] **Problem 3**: Explain why $\kappa(\mathbf{A}^T \mathbf{A}) = \kappa(\mathbf{A})^2$ causes severe catastrophic cancellation when $\mathbf{A}$ has condition number $\kappa(\mathbf{A}) \approx 10^4$ in standard IEEE 754 float32 precision.
