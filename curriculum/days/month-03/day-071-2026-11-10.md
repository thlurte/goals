## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §4.1–4.4 (*The 3 Axioms of Determinants, Permutations, Cofactors & Inverse Formula*)
* **Theorems & Mathematical Concepts**:
  1. **The 3 Axiomatic Properties of Determinants**:
     * **Axiom 1**: $\det(\mathbf{I}) = 1$.
     * **Axiom 2**: Interchanging two rows multiplies the determinant by $-1$.
     * **Axiom 3**: Linearity in every row individually: $\det\begin{pmatrix} t\mathbf{a} + \mathbf{a}' \\ \mathbf{b} \end{pmatrix} = t \det\begin{pmatrix} \mathbf{a} \\ \mathbf{b} \end{pmatrix} + \det\begin{pmatrix} \mathbf{a}' \\ \mathbf{b} \end{pmatrix}$.
  2. **Core Multiplicative & Invertibility Identities**:
     * $\det(\mathbf{A}\mathbf{B}) = \det(\mathbf{A})\det(\mathbf{B})$.
     * $\det(\mathbf{A}^T) = \det(\mathbf{A})$.
     * $\det(\mathbf{A}) \ne 0 \iff \mathbf{A}$ is invertible ($\operatorname{rank}(\mathbf{A}) = n$).
  3. **The Cofactor Matrix & The Adjugate Inverse**:
     * The $(i, j)$ cofactor: $C_{ij} = (-1)^{i+j} \det(\mathbf{M}_{ij})$, where $\mathbf{M}_{ij}$ is the $(n-1)\times(n-1)$ submatrix deleting row $i$ and column $j$.
     * Exact inverse formula:
       $$\mathbf{A} \mathbf{C}^T = (\det \mathbf{A})\mathbf{I} \implies \mathbf{A}^{-1} = \frac{\mathbf{C}^T}{\det \mathbf{A}}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove using Axiom 2 and Axiom 3 that if two rows of $\mathbf{A}$ are identical, then $\det(\mathbf{A}) = 0$.
  - [ ] **Proof 2**: Prove the fundamental cofactor identity $\mathbf{A}\mathbf{C}^T = (\det \mathbf{A})\mathbf{I}$ by showing that the off-diagonal entries represent the cofactor expansion of a matrix with two identical rows.
  - [ ] **Problem 3**: For matrix $\mathbf{A} = \begin{pmatrix} 1 & 0 & 2 \\ 2 & -1 & 3 \\ 4 & 1 & 8 \end{pmatrix}$, compute $\det(\mathbf{A})$ using pivot elimination, construct the $3 \times 3$ cofactor matrix $\mathbf{C}$, and calculate $\mathbf{A}^{-1} = \frac{1}{\det \mathbf{A}}\mathbf{C}^T$.

* **Core Microarchitectural Concepts**:
  1. **LSM-Tree Memory & Storage Architecture for Vector Engines**:
     * Dynamic vector systems require high write ingestion throughput with continuous low-latency queries.
     * Core LSM Components:
       * **Write-Ahead Log (WAL)**: Sequential disk append ensuring ACID durability ($p_{99} < 50\ \mu\text{s}$).
       * **MemTable**: In-memory mutable buffer (dynamic HNSW / flat array) absorbing live inserts.
       * **SSTable**: Flushed immutable disk segment containing frozen vector buffers, adjacency lists, and precomputed PQ tables.
  2. **Zero-Allocation WAL Formatting**:
     * Binary struct: `[4-byte Magic | 8-byte SeqNo | 4-byte DocID | 4-byte Dim | Data Payload | 4-byte CRC32]`.

     ```cpp
     #include "secan/storage/wal.h"
     #include <fstream>
     #include <vector>
     #include <cstdint>
     #include <stdexcept>

     namespace secan {
     class WriteAheadLog {
     public:
         std::ofstream file;
         uint64_t next_seq{0};

         explicit WriteAheadLog(const std::string& path)
             : file(path, std::ios::binary | std::ios::app) {
             if (!file.is_open()) throw std::runtime_error("Failed to open WAL file");
         }

         void append_insert(uint32_t doc_id, const float* vec, size_t dim) {
             uint32_t magic = 0x57414C31; // 'WAL1'
             uint64_t seq = next_seq++;
             uint32_t payload_bytes = dim * sizeof(float);

             file.write(reinterpret_cast<const char*>(&magic), 4);
             file.write(reinterpret_cast<const char*>(&seq), 8);
             file.write(reinterpret_cast<const char*>(&doc_id), 4);
             file.write(reinterpret_cast<const char*>(&dim), 4);
             file.write(reinterpret_cast<const char*>(vec), payload_bytes);
             // Flush to disk
             file.flush();
         }
     };
     }
     ```
