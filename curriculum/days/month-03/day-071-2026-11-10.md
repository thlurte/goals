* **Core Microarchitectural Concepts**:
  1. **LSM-Tree Memory & Storage Architecture for Vector Engines**:
     * Dynamic vector systems require high write ingestion throughput with continuous low-latency queries.
     * Core LSM Components:
       * **Write-Ahead Log (WAL)**: Sequential disk append ensuring ACID durability ($p_{99} < 50\ \mu\text{s}$).
       * **MemTable**: In-memory mutable buffer (dynamic HNSW / flat array) absorbing live inserts.
       * **SSTable**: Flushed immutable disk segment containing frozen vector buffers, adjacency lists, and precomputed PQ tables.
  2. **Zero-Allocation WAL Formatting**:
     * Binary struct: `[4-byte Magic | 8-byte SeqNo | 4-byte DocID | 4-byte Dim | Data Payload | 4-byte CRC32]`.

     ```cpp
     #include "secan/storage/wal.h"
     #include <fstream>
     #include <vector>
     #include <cstdint>
     #include <stdexcept>

     namespace secan {
     class WriteAheadLog {
     public:
         std::ofstream file;
         uint64_t next_seq{0};

         explicit WriteAheadLog(const std::string& path)
             : file(path, std::ios::binary | std::ios::app) {
             if (!file.is_open()) throw std::runtime_error("Failed to open WAL file");
         }

         void append_insert(uint32_t doc_id, const float* vec, size_t dim) {
             uint32_t magic = 0x57414C31; // 'WAL1'
             uint64_t seq = next_seq++;
             uint32_t payload_bytes = dim * sizeof(float);

             file.write(reinterpret_cast<const char*>(&magic), 4);
             file.write(reinterpret_cast<const char*>(&seq), 8);
             file.write(reinterpret_cast<const char*>(&doc_id), 4);
             file.write(reinterpret_cast<const char*>(&dim), 4);
             file.write(reinterpret_cast<const char*>(vec), payload_bytes);
             // Flush to disk
             file.flush();
         }
     };
     }
     ```
