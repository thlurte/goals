## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §5.4–5.5 (*Exponential Distribution, Memoryless Property & The Normal / Gaussian $\mathcal{N}(\mu, \sigma^2)$*)
* **Theorems & Mathematical Concepts**:
  1. **The Exponential Distribution $\operatorname{Exp}(\lambda)$**:
     * $f_X(x) = \lambda e^{-\lambda x}$ ($x \ge 0$) $\implies F_X(x) = 1 - e^{-\lambda x}$.
     * **Mean & Variance**: $E[X] = \frac{1}{\lambda}$, $\operatorname{Var}(X) = \frac{1}{\lambda^2}$.
     * **Continuous Memoryless Property**: For all $s, t > 0$:
       $$P(X > s + t \mid X > s) = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X > t)$$
  2. **The Normal (Gaussian) Distribution $\mathcal{N}(\mu, \sigma^2)$**:
     $$f_X(x) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right)$$
     * **Standardization**: If $X \sim \mathcal{N}(\mu, \sigma^2)$, then $Z = \frac{X - \mu}{\sigma} \sim \mathcal{N}(0, 1)$.
     * **Affine Invariance**: $aX + b \sim \mathcal{N}(a\mu + b, a^2\sigma^2)$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the continuous memoryless property of the Exponential distribution and prove that if a continuous positive variable satisfies $P(X > s+t \mid X > s) = P(X > t)$, its survival function must be $G(t) = e^{-\lambda t}$.
  - [ ] **Proof 2**: Prove $E[Z] = 0$ and $E[Z^2] = 1$ for standard normal $Z \sim \mathcal{N}(0, 1)$ using odd function symmetry and integration by parts on $\int_{-\infty}^\infty z (z e^{-z^2/2})dz$.
  - [ ] **Problem 3**: Let $T_1, \dots, T_k$ represent independent SSD retrieval latencies for $k$ parallel shards where $T_i \sim \operatorname{Exp}(\lambda_i)$. Prove that the fastest shard response $\min(T_1, \dots, T_k) \sim \operatorname{Exp}(\sum_{i=1}^k \lambda_i)$ and that $P(T_1 = \min(T_i)) = \frac{\lambda_1}{\sum \lambda_i}$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* — David B. Kirk & Wen-mei W. Hwu (Ch 16) / NVIDIA WMMA Docs
* **Core Microarchitectural Concepts**:
  1. **NVIDIA Tensor Core Architecture & WMMA API**:
     * Hardware Matrix Multiply-Accumulate (MMA) units execute $D = A \cdot B + C$ on matrix tiles (e.g. $16 \times 16 \times 16$ FP16) in a single clock cycle across a warp.
     * `nvcuda::wmma` API maps warp registers directly to Tensor Core execution fragments:
       ```cuda
       wmma::fragment<wmma::matrix_a, 16, 16, 16, half, wmma::row_major> a_frag;
       wmma::fragment<wmma::matrix_b, 16, 16, 16, half, wmma::col_major> b_frag;
       wmma::fragment<wmma::accumulator, 16, 16, 16, float> c_frag;
       wmma::load_matrix_sync(a_frag, ...);
       wmma::mma_sync(c_frag, a_frag, b_frag, c_frag);
       ```
  2. **Asynchronous Memory Copy (`cuda::memcpy_async`)**:
     * Hardware copy engines bypass SM ALUs, streaming data directly from global DRAM into shared memory while ALUs compute previous tiles.

* **Tasks & Implementation**:
  1. **Implement Double-Buffered Shared Memory Tile Staging** in `src/gpu/flash_attn_tile_loader.cu`:
     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>
     #include <cuda/pipeline>

     namespace secan {
     constexpr int TILE_SIZE = 64;

     // Coalesced double-buffered loading from GMEM to SRAM
     template <typename T>
     __device__ inline void load_tile_async(
         T (*s_dest)[TILE_SIZE],
         const T* g_src,
         int row_stride,
         int tile_rows,
         int tile_cols,
         cuda::pipeline<cuda::thread_scope_block>& pipe
     ) {
         int tid = threadIdx.x;
         int total_threads = blockDim.x;

         for (int i = tid; i < tile_rows * tile_cols; i += total_threads) {
             int r = i / tile_cols;
             int c = i % tile_cols;
             cuda::memcpy_async(&s_dest[r][c], &g_src[r * row_stride + c], sizeof(T), pipe);
         }
     }
     }
     ```
  2. **Benchmark Double-Buffering Overlap**:
