## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §7.1–7.2 (*Markov's Inequality, Chebyshev's Inequality & Cantelli's Bound*)
* **Theorems & Mathematical Concepts**:
  1. **Markov's Inequality**:
     * For any non-negative random variable $X \ge 0$ and any constant $a > 0$:
       $$P(X \ge a) \le \frac{E[X]}{a}$$
     * **Indicator Proof**: Since $a \cdot \mathbf{1}_{\{X \ge a\}} \le X$, taking expectations gives $a P(X \ge a) \le E[X]$.
  2. **Chebyshev's Inequality**:
     * For any random variable $X$ with mean $\mu$ and variance $\sigma^2$:
       $$P(|X - \mu| \ge k\sigma) \le \frac{1}{k^2}$$
     * Apply Markov's inequality to $Y = (X - \mu)^2$ with threshold $a = (k\sigma)^2$.
  3. **Cantelli's One-Sided Inequality**:
     * For any $a > 0$:
       $$P(X - \mu \ge a) \le \frac{\sigma^2}{\sigma^2 + a^2}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive Markov's inequality $P(X \ge a) \le \frac{E[X]}{a}$ using the indicator inequality $a \cdot \mathbf{1}_{\{X \ge a\}} \le X$.
  - [ ] **Proof 2**: Derive Cantelli's one-sided bound $P(X - \mu \ge a) \le \frac{\sigma^2}{\sigma^2 + a^2}$ by applying Markov's inequality to $(X - \mu + u)^2$ for $u > 0$ and minimizing the resulting upper bound $\frac{\sigma^2 + u^2}{(a + u)^2}$ with optimal choice $u^* = \sigma^2 / a$.
  - [ ] **Problem 3**: A vector search query engine has an average latency of $E[T] = 4.0\text{ ms}$ with standard deviation $\sigma = 1.5\text{ ms}$. Use Cantelli's inequality to find an upper bound on the probability that a query experiences tail latency exceeding $20\text{ ms}$ ($P(T \ge 20)$).

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Billion-Scale Similarity Search with GPUs* (Johnson, Douze, Jégou / Faiss GPU, 2019) §1–3
* **Core Microarchitectural Concepts**:
  1. **Contiguous Jagged Inverted List Layout in Device Memory**:
     * Variable-length inverted lists $L_0, \dots, L_{C-1}$ cannot use dynamic linked lists on GPU without devastating pointer-chasing latency and memory fragmentation.
     * **Flat CSR Buffer**: Pack all quantized codes into a single flat contiguous device allocation `d_codes` and store list boundaries in a prefix-sum offset array `d_list_offsets[C+1]`.
  2. **Multi-Probe Warp Stream Scheduling**:
     * When a query probes $nprobe = 32$ centroid clusters, warps stride across the contiguous segments indexed by `d_list_offsets[cluster_id]`, maintaining perfect 128-byte DRAM coalescing.

* **Tasks & Implementation**:
  1. **Implement GPU IVF Jagged Array Layout & Offset Index** in `include/secan/gpu/gpu_ivf_layout.cuh`:
     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <vector>
     #include <numeric>

     namespace secan {
     template <typename CodeT>
     class GpuIvfLayout {
     public:
         size_t num_centroids{0};
         size_t total_vectors{0};
         size_t code_size_bytes{0};

         GpuBuffer<float> d_centroids;      // [num_centroids, dim]
         GpuBuffer<size_t> d_list_offsets;  // [num_centroids + 1]
         GpuBuffer<size_t> d_list_lengths;  // [num_centroids]
         GpuBuffer<CodeT> d_codes;          // [total_vectors * code_size_bytes]
         GpuBuffer<uint32_t> d_vector_ids;  // [total_vectors]

         GpuIvfLayout(size_t n_centroids, size_t n_vectors, size_t code_bytes, size_t dim)
             : num_centroids(n_centroids), total_vectors(n_vectors), code_size_bytes(code_bytes),
               d_centroids(n_centroids * dim),
               d_list_offsets(n_centroids + 1),
               d_list_lengths(n_centroids),
               d_codes(n_vectors * code_bytes),
               d_vector_ids(n_vectors) {}

         void upload_lists(
             const std::vector<std::vector<CodeT>>& host_codes,
             const std::vector<std::vector<uint32_t>>& host_ids
         ) {
             std::vector<size_t> h_offsets(num_centroids + 1, 0);
             std::vector<size_t> h_lengths(num_centroids, 0);
             std::vector<CodeT> flat_codes;
             std::vector<uint32_t> flat_ids;

             for (size_t c = 0; c < num_centroids; ++c) {
                 h_offsets[c] = flat_ids.size();
                 h_lengths[c] = host_ids[c].size();
                 flat_codes.insert(flat_codes.end(), host_codes[c].begin(), host_codes[c].end());
                 flat_ids.insert(flat_ids.end(), host_ids[c].begin(), host_ids[c].end());
             }
             h_offsets[num_centroids] = flat_ids.size();

             d_list_offsets.copy_from_host(h_offsets.data(), num_centroids + 1);
             d_list_lengths.copy_from_host(h_lengths.data(), num_centroids);
             d_codes.copy_from_host(flat_codes.data(), flat_codes.size());
             d_vector_ids.copy_from_host(flat_ids.data(), flat_ids.size());
         }
     };
     }
     ```
