## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §7.6–7.7 (*Covariance, Correlation & Cauchy-Schwarz Bound on $\rho$*)
* **Theorems & Mathematical Concepts**:
  1. **Covariance & Correlation Coefficient**:
     * $\operatorname{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - E[X]E[Y]$.
     * Pearson Correlation: $\rho(X, Y) = \frac{\operatorname{Cov}(X, Y)}{\sigma_X \sigma_Y}$.
  2. **The Cauchy-Schwarz Inequality on Random Variables**:
     * For any random variables with finite second moments:
       $$(\operatorname{Cov}(X, Y))^2 \le \sigma_X^2 \sigma_Y^2 \implies -1 \le \rho(X, Y) \le 1$$
     * **Quadratic Discriminant Proof**: Let $\tilde{X} = X - \mu_X, \tilde{Y} = Y - \mu_Y$. Consider $h(t) = E[(t \tilde{X} + \tilde{Y})^2] = t^2 \sigma_X^2 + 2t \operatorname{Cov}(X, Y) + \sigma_Y^2 \ge 0$. Since $h(t) \ge 0$ for all $t \in \mathbb{R}$, its discriminant $\Delta = 4(\operatorname{Cov}(X, Y))^2 - 4\sigma_X^2 \sigma_Y^2 \le 0$.
  3. **Linear Determinism**:
     * $|\rho(X, Y)| = 1 \iff Y = aX + b$ almost surely for non-zero constant $a$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the Cauchy-Schwarz bound $|\rho(X, Y)| \le 1$ using the non-negativity of the quadratic expectation $h(t) = E[(t \tilde{X} + \tilde{Y})^2] \ge 0$.
  - [ ] **Proof 2**: Prove that if $\rho(X, Y) = 1$, the minimum of $h(t)$ is zero, implying $P\left(Y - \mu_Y = \frac{\sigma_Y}{\sigma_X}(X - \mu_X)\right) = 1$.

Compute $\operatorname{Var}(T_1 + T_2) = 3.70$, and compare against uncorrelated tokens ($\operatorname{Var} = 2.0$).

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *DiskANN: Fast Accurate Billion-Point Nearest Neighbor Search on a Single Node* (Subramanya et al., NeurIPS 2019) §1–4
* **Core Microarchitectural Concepts**:
  1. **Out-of-Core SSD Memory Architecture**:
     * In-DRAM HNSW for 1 billion vectors requires $>1\text{ TB}$ expensive DRAM ($>\$10{,}000$).
     * DiskANN Architecture:
       * **Compressed 1-byte vectors (SQ8)** reside in host DRAM ($1\text{ GB}$ per million vectors).
       * **Full-precision FP32 vectors and Vamana Graph edges** reside on NVMe SSD, packaged into $4\text{ KB}$ aligned sectors.
  2. **Asynchronous Linux `io_uring` Direct I/O**:
     * Bypasses OS kernel page cache using `O_DIRECT` and `posix_memalign`.
     * `io_uring` ring buffers submit batched sector reads directly to NVMe hardware controller queues, achieving $>100{,}000\text{ IOPS}$ at $<1.5\text{ ms}$ latency with zero context switch overhead.

## 💻 20:30 – 23:00 | Night Hands-On Implementation (2.5 hrs)
* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement Vamana $\alpha$-Pruning Algorithm** in `include/secan/graph/vamana.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <algorithm>
     #include <span>

     namespace secan {
     template <typename DistFunc>
     std::vector<uint32_t> vamana_alpha_prune(
         uint32_t node_p,
         std::vector<uint32_t>& candidates,
         const float* dataset,
         size_t dim,
         size_t max_degree,
         float alpha,
         DistFunc dist_fn
     ) {
         // Sort candidate pool by distance to p
         std::sort(candidates.begin(), candidates.end(), [&](uint32_t a, uint32_t b) {
             return dist_fn(dataset + node_p * dim, dataset + a * dim, dim) <
                    dist_fn(dataset + node_p * dim, dataset + b * dim, dim);
         });

         std::vector<uint32_t> kept_neighbors;
         for (uint32_t cand : candidates) {
             if (kept_neighbors.size() >= max_degree) break;
             bool keep = true;
             float d_p_cand = dist_fn(dataset + node_p * dim, dataset + cand * dim, dim);

             for (uint32_t r : kept_neighbors) {
                 float d_r_cand = dist_fn(dataset + r * dim, dataset + cand * dim, dim);
                 if (alpha * d_r_cand <= d_p_cand) {
                     keep = false;
                     break;
                 }
             }
             if (keep) kept_neighbors.push_back(cand);
         }
         return kept_neighbors;
     }
     }
     ```
