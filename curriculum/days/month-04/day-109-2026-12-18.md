## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *DiskANN: Fast Accurate Billion-Point Nearest Neighbor Search on a Single Node* (Subramanya et al., NeurIPS 2019) §1–4 & Hardware Profiling Playbook ([`roadmap.md#part-3`](../../roadmap.md#part-3-verification--tooling-matrix-the-hardware-profiling-playbook))
* **Core Microarchitectural Concepts**:
  1. **Out-of-Core SSD Memory Architecture**:
     * In-DRAM HNSW for 1 billion vectors requires $>1\text{ TB}$ expensive DRAM ($>\$10{,}000$).
     * DiskANN Architecture:
       * **Compressed 1-byte vectors (SQ8)** reside in host DRAM ($1\text{ GB}$ per million vectors).
       * **Full-precision FP32 vectors and Vamana Graph edges** reside on NVMe SSD, packaged into $4\text{ KB}$ aligned sectors.
  2. **Asynchronous Linux `io_uring` Direct I/O & `fio` Baseline**:
     * Bypasses OS kernel page cache using `O_DIRECT` and `posix_memalign`.
     * `io_uring` ring buffers submit batched sector reads directly to NVMe hardware controller queues, achieving $>100{,}000\text{ IOPS}$ at $<1.5\text{ ms}$ latency with zero context switch overhead.
     * Establish raw hardware NVMe latency baseline via `fio --ioengine=io_uring --direct=1 --rw=randread --bs=4k`.

* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement Vamana $\alpha$-Pruning Algorithm** in `include/secan/graph/vamana.h`:
     ```cpp
     #pragma once
     #include <vector>
     #include <algorithm>
     #include <span>

     namespace secan {
     template <typename DistFunc>
     std::vector<uint32_t> vamana_alpha_prune(
         uint32_t node_p,
         std::vector<uint32_t>& candidates,
         const float* dataset,
         size_t dim,
         size_t max_degree,
         float alpha,
         DistFunc dist_fn
     ) {
         // Sort candidate pool by distance to p
         std::sort(candidates.begin(), candidates.end(), [&](uint32_t a, uint32_t b) {
             return dist_fn(dataset + node_p * dim, dataset + a * dim, dim) <
                    dist_fn(dataset + node_p * dim, dataset + b * dim, dim);
         });

         std::vector<uint32_t> kept_neighbors;
         for (uint32_t cand : candidates) {
             if (kept_neighbors.size() >= max_degree) break;
             bool keep = true;
             float d_p_cand = dist_fn(dataset + node_p * dim, dataset + cand * dim, dim);

             for (uint32_t r : kept_neighbors) {
                 float d_r_cand = dist_fn(dataset + r * dim, dataset + cand * dim, dim);
                 if (alpha * d_r_cand <= d_p_cand) {
                     keep = false;
                     break;
                 }
             }
             if (keep) kept_neighbors.push_back(cand);
         }
         return kept_neighbors;
     }
     }
     ```
