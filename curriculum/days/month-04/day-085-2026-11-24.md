## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §1.1–1.4 (*Sample Spaces, Events, Kolmogorov's Axioms & Union Bounds*)
* **Theorems & Mathematical Concepts**:
  1. **The 3 Kolmogorov Axioms of Probability**:
     * **Axiom 1 (Non-negativity)**: For any event $A \subseteq \Omega$, $P(A) \ge 0$.
     * **Axiom 2 (Normalization)**: $P(\Omega) = 1$.
     * **Axiom 3 (Countable Additivity)**: If $A_1, A_2, \dots$ is a sequence of disjoint events ($A_i \cap A_j = \emptyset$ for $i \ne j$), then:
       $$P\left( \bigcup_{i=1}^\infty A_i \right) = \sum_{i=1}^\infty P(A_i)$$
  2. **Core Derived Theorems**:
     * **Complement Rule**: $P(A^c) = 1 - P(A)$.
     * **Inclusion-Exclusion Principle**: $P(A \cup B) = P(A) + P(B) - P(A \cap B)$.
     * **Boole's Inequality (The Union Bound)**: For any arbitrary collection of events $A_1, \dots, A_n$:
       $$P\left( \bigcup_{i=1}^n A_i \right) \le \sum_{i=1}^n P(A_i)$$
     * **Continuity of Probability**: If $E_1 \subseteq E_2 \subseteq \dots$ and $E = \bigcup_{n=1}^\infty E_n$, then $\lim_{n \to \infty} P(E_n) = P(E)$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove $P(\emptyset) = 0$ and $P(A^c) = 1 - P(A)$ directly from Kolmogorov's Axioms 2 and 3.
  - [ ] **Proof 2**: Prove Boole's inequality $P(\bigcup_{i=1}^n A_i) \le \sum_{i=1}^n P(A_i)$ by induction on $n$ using disjointification $B_1 = A_1, B_k = A_k \setminus \bigcup_{j=1}^{k-1} A_j$.
  - [ ] **Problem 3**: In high-dimensional LSH with $K$ hash tables, let $E_i$ be the event that a false positive collision occurs in table $i$. Use Boole's inequality to derive an upper bound on the probability of retrieving at least one false positive candidate across all $K$ tables.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* — David B. Kirk & Wen-mei W. Hwu (Ch 1–2)
* **Core Microarchitectural Concepts**:
  1. **The SIMT Execution Paradigm & Streaming Multiprocessors (SMs)**:
     * CPU design optimizes for **minimum single-thread latency** (huge caches, branch predictors, out-of-order execution pipelines).
     * GPU design optimizes for **maximum aggregate throughput** (thousands of lightweight ALUs, deep hardware multithreading).
     * Streaming Multiprocessor (SM) architecture:
       * 1 Warp = 32 parallel threads executing in lock-step SIMT fashion.
       * Hardware Warp Schedulers: When a warp stalls on a high-latency global memory load ($200\text{--}400\text{ cycles}$), the warp scheduler instantly context switches to another ready warp in **zero cycles** (latency hiding!).
  2. **Device Memory Hierarchy**:
     * Host DRAM $\xrightarrow{\text{PCIe Gen4 / Gen5 } (32\text{--}64\text{ GB/s})}$ GPU HBM / GDDR6 ($>1{,}000\text{ GB/s}$).

* **Tasks & Implementation**:

     ```cmake
     set(CMAKE_CUDA_STANDARD 20)
     set(CMAKE_CUDA_ARCHITECTURES "75;80;86;89;90")
     set(CMAKE_CUDA_FLAGS "${CMAKE_CUDA_FLAGS} --extended-lambda --expt-relaxed-constexpr -Xcompiler=-fPIC")
     ```
  2. **Implement RAII `GpuBuffer<T>` Memory Wrapper** in `include/secan/gpu/gpu_buffer.cuh`:
     ```cuda
     #pragma once
     #include <cuda_runtime.h>
     #include <stdexcept>
     #include <string>

     #define CUDA_CHECK(call) do { \
         cudaError_t err = call; \
         if (err != cudaSuccess) { \
             throw std::runtime_error("CUDA error at " + std::string(__FILE__) + ":" + \
                                      std::to_string(__LINE__) + " - " + cudaGetErrorString(err)); \
         } \
     } while (0)

     namespace secan {
     template <typename T>
     class GpuBuffer {
     public:
         T* d_ptr{nullptr};
         size_t count{0};

         explicit GpuBuffer(size_t n) : count(n) {
             CUDA_CHECK(cudaMalloc(&d_ptr, n * sizeof(T)));
         }

         ~GpuBuffer() {
             if (d_ptr) cudaFree(d_ptr);
         }

         GpuBuffer(const GpuBuffer&) = delete;
         GpuBuffer& operator=(const GpuBuffer&) = delete;

         GpuBuffer(GpuBuffer&& other) noexcept : d_ptr(other.d_ptr), count(other.count) {
             other.d_ptr = nullptr;
             other.count = 0;
         }

         void copy_from_host(const T* h_ptr, size_t n) {
             CUDA_CHECK(cudaMemcpy(d_ptr, h_ptr, n * sizeof(T), cudaMemcpyHostToDevice));
         }

         void copy_to_host(T* h_ptr, size_t n) const {
             CUDA_CHECK(cudaMemcpy(h_ptr, d_ptr, n * sizeof(T), cudaMemcpyDeviceToHost));
         }
     };
     }
     ```
  3. **Verify with `compute-sanitizer`**:
     * Run `compute-sanitizer --leak-check full ./build/tests/test_gpu_buffer` ensuring 0 memory leaks and 0 illegal memory accesses.
