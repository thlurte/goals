## ✍️ 09:00 – 13:00 | Long-Form Technical Essay
* **Essay Number**: **Essay 13**
* **Title**: *"The SIMT Execution Model: Why Naive GPU Distance Kernels Lose to CPU AVX2"*
* **Target File**: `~/personal/goals/essays/essay_13.md`
* **5-Part Standard Structure**:
  1. **Mathematical Foundation**:
     * Kolmogorov probability foundations, inclusion-exclusion, and combinatorial counting.
     * The Law of Total Probability and conditional query routing bounds.
  2. **The Systems Bottleneck**:
     * Latency-oriented CPUs (large L1/L2 caches, deep branch predictors) vs Throughput-oriented GPUs (SIMT warps, massive multithreading).
     * Why single-query naive CUDA kernels suffer $90\%$ stall cycles: PCIe transfer latency ($>15\ \mu\text{s}$), kernel launch overhead ($>4\ \mu\text{s}$), and uncoalesced global DRAM reads ($200\text{--}400\text{ cycles}$).
  3. **The Engine Architecture**:
     * `secan` GPU architecture: RAII `GpuBuffer`, pinned DMA buffers, and shared memory tiled distance pipelines.
  4. **Empirical Benchmarks**:
     * Perf counter comparison: CPU AVX2 single-query ($0.45\text{ ms}$) vs Naive GPU ($1.2\text{ ms}$) vs Batched Tiled GPU ($0.03\text{ ms/query}$ at $B=128$).
  5. **Key Takeaway**:
     * GPUs require high arithmetic intensity and batched parallelism to unlock high throughput: without shared memory reuse and coalesced access, optimized CPU SIMD dominates latency.

* **Implementation Tasks**:
  1. **Custom PyTorch CUDA Extension** in `src/cuda_distance.cu` & `src/binding.cpp`:
     ```cuda
     #include <torch/extension.h>
     #include <cuda_runtime.h>

     __global__ void custom_l2_kernel(const float* __restrict__ a, const float* __restrict__ b,
                                      float* __restrict__ out, int M, int N, int K) {
         int row = blockIdx.y * blockDim.y + threadIdx.y;
         int col = blockIdx.x * blockDim.x + threadIdx.x;
         if (row < M && col < N) {
             float sum = 0.0f;
             for (int k = 0; k < K; ++k) {
                 float diff = a[row * K + k] - b[col * K + k];
                 sum += diff * diff;
             }
             out[row * N + col] = sum;
         }
     }

     torch::Tensor custom_l2_forward(torch::Tensor a, torch::Tensor b) {
         int M = a.size(0);
         int N = b.size(0);
         int K = a.size(1);
         auto out = torch::empty({M, N}, a.options());

         dim3 block(16, 16);
         dim3 grid((N + 15) / 16, (M + 15) / 16);
         custom_l2_kernel<<<grid, block>>>(a.data_ptr<float>(), b.data_ptr<float>(),
                                           out.data_ptr<float>(), M, N, K);
         return out;
     }

     PYBIND11_MODULE(TORCH_EXTENSION_NAME, m) {
         m.def("forward", &custom_l2_forward, "Custom L2 Distance CUDA forward");
     }
     ```
  2. **JIT Compilation and Verification** in `tests/test_cuda_ext.py`:
     ```python
     import torch
     from torch.utils.cpp_extension import load

     custom_cuda = load(
         name="custom_cuda_l2",
         sources=["src/binding.cpp", "src/cuda_distance.cu"],
         extra_cuda_cflags=["-O3"]
     )

     a = torch.randn(64, 128, device="cuda")
     b = torch.randn(1000, 128, device="cuda")

     custom_dist = custom_cuda.forward(a, b)
     ref_dist = torch.cdist(a, b, p=2) ** 2

     max_diff = torch.max(torch.abs(custom_dist - ref_dist)).item()
     print(f"Max Absolute Error: {max_diff:.6e}")
     assert max_diff < 1e-4
     ```
