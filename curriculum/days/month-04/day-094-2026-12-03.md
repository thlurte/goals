## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §4.1–4.3 (*Expectation, Linearity of Expectation & Indicator Random Variables*)
* **Theorems & Mathematical Concepts**:
  1. **Expectation & LOTUS**:
     * Expected Value: $E[X] = \sum_{x} x p_X(x)$ (well-defined when $\sum |x| p_X(x) < \infty$).
     * Law of the Unconscious Statistician: $E[g(X)] = \sum_{x} g(x) p_X(x)$.
  2. **The Fundamental Linearity of Expectation**:
     * For **any** collection of random variables $X_1, \dots, X_n$, regardless of whether they are independent or heavily correlated:
       $$E\left[ \sum_{i=1}^n c_i X_i \right] = \sum_{i=1}^n c_i E[X_i]$$
  3. **Method of Indicator Random Variables**:
     * For any event $A$, define $I_A = \mathbf{1}_A$:
       $$E[I_A] = 1 \cdot P(A) + 0 \cdot P(A^c) = P(A)$$
     * To find the expected count $X = \sum_{i=1}^N I_i$, simply sum the individual event probabilities $E[X] = \sum_{i=1}^N P(A_i)$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove $E[X + Y] = E[X] + E[Y]$ using the joint PMF $p_{X, Y}(x, y) = P(X=x, Y=y)$ and marginalization without assuming independence.
  - [ ] **Problem 2 (Coupon Collector Problem)**: In multi-probe IVF with $N$ clusters, let $T$ be the number of random queries required to sample all $N$ clusters at least once. Decompose $T = \sum_{i=1}^N T_i$ where $T_i \sim \operatorname{Geometric}\left(\frac{N - i + 1}{N}\right)$, and prove that $E[T] = N H_N \approx N \ln N + \gamma N$.
  - [ ] **Problem 3 (LSH Hash Collisions)**: In an LSH table with $M$ buckets, $K$ distinct vectors are inserted. Let $C$ be the number of bucket collisions (pairs mapping to the same bucket). Use indicator variables $I_{ij}$ for all $\binom{K}{2}$ pairs to prove $E[C] = \binom{K}{2} \frac{1}{M}$.

* **Core Microarchitectural Concepts**:
  1. **CUDA Warp Bitmask & Ballot Instructions**:
     * `__ballot_sync(mask, predicate)`: Evaluates boolean predicate across all 32 threads in the active mask, packing results into a single 32-bit register integer `uint32_t active_mask`.
     * `__popc(mask)`: Evaluates single-instruction population count of matching threads.
  2. **Butterfly Shuffle (`__shfl_xor_sync`)**:
     * Exchanging data via XOR lane mask enables in-register Bitonic sorting and all-to-all reduction networks without shared memory.
  3. **Cooperative Groups Framework**:
     * `auto g = cooperative_groups::this_thread_block();` provides explicit type-safe intra-block synchronization primitives.

* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement Batched Multi-Warp Distance Scanner** in `src/gpu/distance_batched_warps.cu`:
     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cooperative_groups.h>
     #include <cuda_runtime.h>

     namespace cg = cooperative_groups;

     namespace secan {
     constexpr int WARP_SIZE = 32;

     // Block processes 1 query; 8 warps in block cooperatively stream database chunks
     __global__ void l2_distance_batched_warps_kernel(
         const float* __restrict__ queries, // [B, dim]
         const float* __restrict__ database,// [N, dim]
         float* __restrict__ distances,     // [B, N]
         size_t num_queries,
         size_t num_database,
         size_t dim
     ) {
         auto block = cg::this_thread_block();
         size_t q_idx = blockIdx.x;
         if (q_idx >= num_queries) return;

         const float* q = queries + q_idx * dim;
         size_t warp_id = threadIdx.x / WARP_SIZE;
         size_t lane_id = threadIdx.x % WARP_SIZE;
         size_t num_warps = blockDim.x / WARP_SIZE;

         // Grid-stride over database vectors by warps
         for (size_t db_idx = warp_id; db_idx < num_database; db_idx += num_warps) {
             const float* d = database + db_idx * dim;
             float thread_sum = 0.0f;

             for (size_t k = lane_id; k < dim; k += WARP_SIZE) {
                 float diff = q[k] - d[k];
                 thread_sum += diff * diff;
             }

             // Butterfly reduction via __shfl_xor_sync
             #pragma unroll
             for (int mask = 16; mask > 0; mask >>= 1) {
                 thread_sum += __shfl_xor_sync(0xffffffff, thread_sum, mask);
             }

             if (lane_id == 0) {
                 distances[q_idx * num_database + db_idx] = thread_sum;
             }
         }
     }
     }
     ```
