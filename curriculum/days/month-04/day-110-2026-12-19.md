## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §7.8 (*The Multivariate Normal Distribution $\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ & Joint Gaussians*)
* **Theorems & Mathematical Concepts**:
  1. **Multivariate Normal Joint PDF**:
     $$f_{\mathbf{X}}(\mathbf{x}) = \frac{1}{(2\pi)^{d/2} \det(\boldsymbol{\Sigma})^{1/2}} \exp\left( -\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu}) \right)$$
     where $\boldsymbol{\Sigma} = E[(\mathbf{X} - \boldsymbol{\mu})(\mathbf{X} - \boldsymbol{\mu})^T] \succ 0$ is symmetric positive definite.
  2. **Affine Transformation Invariance**:
     * If $\mathbf{X} \sim \mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ and $\mathbf{Y} = \mathbf{A}\mathbf{X} + \mathbf{b}$, then $\mathbf{Y} \sim \mathcal{N}(\mathbf{A}\boldsymbol{\mu} + \mathbf{b}, \mathbf{A}\boldsymbol{\Sigma}\mathbf{A}^T)$.
  3. **Zero Covariance Implies Mutual Independence**:
     * For jointly Gaussian variables, $\operatorname{Cov}(X_i, X_j) = 0 \iff X_i \perp X_j$.
     * The covariance matrix $\boldsymbol{\Sigma}$ diagonalizes, factorizing the joint PDF: $f_{\mathbf{X}}(\mathbf{x}) = \prod_{i=1}^d f_{X_i}(x_i)$.
* **Pencil & Paper Problem Set**:

  - [ ] **Proof 2**: Prove that if $\boldsymbol{\Sigma}$ is diagonal ($\sigma_{ij} = 0$ for $i \ne j$), the exponent in the multivariate normal PDF separates into a sum of 1D squares, proving that joint normality + zero correlation implies strict mutual statistical independence.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Block-Max WAND* (Ding & Suel, SIGIR 2011) & *Reciprocal Rank Fusion (RRF)* (Cormack et al., SIGIR 2009)
* **Core Microarchitectural Concepts**:
  1. **Block-Max WAND Early Pruning**:
     * Standard WAND uses a global upper bound $U_t$ per term.
     * Block-Max WAND partitions posting lists into contiguous blocks of 64 documents, caching local max score $U_{t, b}$.
     * Dynamically skips entire document blocks when $\sum_{t} U_{t, b} < \theta$ (current $k$-th best score threshold) using SIMD instructions, eliminating $>80\%$ of posting list decompressions.
  2. **Reciprocal Rank Fusion (RRF) Mechanics**:
     $$\operatorname{RRF\_Score}(d) = \frac{1}{60 + r_{\text{dense}}(d)} + \frac{1}{60 + r_{\text{sparse}}(d)}$$
     * Fuses heterogeneous non-calibrated ranking scores (BM25 vs Cosine similarity) with zero hyperparameter tuning.

* **Target Repository**: `/home/ahmed/personal/secan`
* **Tasks & Implementation**:
  1. **Implement Block-Max WAND & RRF Fusion Engine** in `include/secan/hybrid/hybrid_engine.h`:
     ```cpp
     #pragma once
     #include "secan/graph/hnsw.h"
     #include <unordered_map>
     #include <vector>
     #include <algorithm>

     namespace secan {
     struct HybridResult {
         uint32_t doc_id;
         float rrf_score;
     };

     class HybridSearchEngine {
     public:
         static std::vector<HybridResult> reciprocal_rank_fusion(
             const std::vector<uint32_t>& dense_ranked_ids,
             const std::vector<uint32_t>& sparse_ranked_ids,
             size_t top_k,
             float k_rrf = 60.0f
         ) {
             std::unordered_map<uint32_t, float> scores;

             for (size_t r = 0; r < dense_ranked_ids.size(); ++r) {
                 scores[dense_ranked_ids[r]] += 1.0f / (k_rrf + static_cast<float>(r + 1));
             }
             for (size_t r = 0; r < sparse_ranked_ids.size(); ++r) {
                 scores[sparse_ranked_ids[r]] += 1.0f / (k_rrf + static_cast<float>(r + 1));
             }

             std::vector<HybridResult> results;
             results.reserve(scores.size());
             for (const auto& [id, s] : scores) {
                 results.push_back({id, s});
             }

             std::sort(results.begin(), results.end(), [](const auto& a, const auto& b) {
                 return a.rrf_score > b.rrf_score;
             });

             if (results.size() > top_k) results.resize(top_k);
             return results;
         }
     };
     }
     ```
