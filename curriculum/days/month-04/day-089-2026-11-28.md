## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §2.6–2.7 (*Pairwise vs Mutual Independence, Conditional Independence & Simpson's Paradox*)
* **Theorems & Mathematical Concepts**:
  1. **Independence of Events**:
     * Two events $A$ and $B$ are independent $\iff P(A \cap B) = P(A) P(B)$.
     * If $P(B) > 0$, this is equivalent to $P(A \mid B) = P(A)$.
  2. **Mutual vs Pairwise Independence**:
     * Events $A_1, \dots, A_n$ are **mutually independent** $\iff$ for every sub-collection $S \subseteq \{1, \dots, n\}$:
       $$P\left( \bigcap_{i \in S} A_i \right) = \prod_{i \in S} P(A_i)$$
     * Pairwise independence ($P(A_i \cap A_j) = P(A_i)P(A_j)$ for all $i \ne j$) does **not** imply mutual independence.
  3. **Simpson's Paradox**:
     * A conditional inequality can reverse when conditioned on a marginal confounder:
       $$P(A \mid B, C) > P(A \mid B^c, C) \quad \text{and} \quad P(A \mid B, C^c) > P(A \mid B^c, C^c)$$
       yet marginal probability satisfies $P(A \mid B) < P(A \mid B^c)$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Construct Bernstein's classic tetrahedron example: 4 faces painted {1: Red, 2: Green, 3: Blue, 4: Red+Green+Blue}. Let $R, G, B$ be the events of rolling a face containing that color. Prove that $R, G, B$ are pairwise independent ($P(R \cap G) = P(R)P(G) = 1/4$), but NOT mutually independent ($P(R \cap G \cap B) = 1/4 \ne 1/8$).
  - [ ] **Proof 2**: Prove that if $A$ and $B$ are independent, then $A^c$ and $B^c$ are also independent: $P(A^c \cap B^c) = P(A^c)P(B^c)$.
  - [ ] **Problem 3**: Construct a numerical example of Simpson's Paradox in vector retrieval benchmarking: show that Index $A$ achieves higher Recall@10 than Index $B$ on short queries ($C$) and on long queries ($C^c$), yet Index $B$ appears superior on the aggregated dataset due to unequal query type distributions.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* — David B. Kirk & Wen-mei W. Hwu (Ch 5)
* **Core Microarchitectural Concepts**:
  1. **Shared Memory Architecture & Bank Conflicts**:
     * Shared memory is divided into 32 independent banks of 4-byte width (bank $k$ stores words at byte address $4 \times (32 \cdot i + k)$).
     * **Bank Conflict**: Occurs when multiple threads in a warp access different memory addresses residing in the same physical bank, causing the hardware to serialize access (up to $32\times$ slowdown!).
     * **Broadcast**: When all 32 threads in a warp read the exact same memory word, the hardware broadcasts the value in a single clock cycle with **0 bank conflicts**.
  2. **Tiled Memory Reuse**:
     * Loading database vectors repeatedly from global DRAM saturates HBM bus bandwidth.
     * By staging tiles into `__shared__ float s_tile[TILE_M][TILE_K]`, threads reuse each loaded float $16\text{--}32\times$, elevating the kernel from memory-bound to compute-bound!

* **Tasks & Implementation**:
  1. **Implement Shared Memory Tiled L2 Distance Kernel** in `src/gpu/distance_tiled.cu`:
     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     constexpr int TILE_DIM = 32;

     __global__ void l2_distance_tiled_kernel(
         const float* __restrict__ queries, // [num_queries, dim]
         const float* __restrict__ database,// [num_database, dim]
         float* __restrict__ distances,     // [num_queries, num_database]
         size_t num_queries,
         size_t num_database,
         size_t dim
     ) {
         __shared__ float s_queries[TILE_DIM][TILE_DIM];
         __shared__ float s_database[TILE_DIM][TILE_DIM];

         size_t q_idx = blockIdx.y * TILE_DIM + threadIdx.y;
         size_t db_idx = blockIdx.x * TILE_DIM + threadIdx.x;

         float accum = 0.0f;

         for (size_t tile = 0; tile < (dim + TILE_DIM - 1) / TILE_DIM; ++tile) {
             size_t k_q = tile * TILE_DIM + threadIdx.x;
             size_t k_db = tile * TILE_DIM + threadIdx.y;

             if (q_idx < num_queries && k_q < dim)
                 s_queries[threadIdx.y][threadIdx.x] = queries[q_idx * dim + k_q];
             else
                 s_queries[threadIdx.y][threadIdx.x] = 0.0f;

             if (db_idx < num_database && k_db < dim)
                 s_database[threadIdx.y][threadIdx.x] = database[db_idx * dim + k_db];
             else
                 s_database[threadIdx.y][threadIdx.x] = 0.0f;

             __syncthreads();

             #pragma unroll
             for (int k = 0; k < TILE_DIM; ++k) {
                 float diff = s_queries[threadIdx.y][k] - s_database[k][threadIdx.x];
                 accum += diff * diff;
             }
             __syncthreads();
         }

         if (q_idx < num_queries && db_idx < num_database) {
             distances[q_idx * num_database + db_idx] = accum;
         }
     }
     }
     ```
