## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §6.1–6.3 (*Moments & Moment Generating Functions (MGF)*)
* **Theorems & Mathematical Concepts**:
  1. **Moment Generating Functions (MGF)**:
     * Definition: $M_X(t) = E\left[e^{tX}\right]$ (for $t$ in an open neighborhood around 0).
     * **Moment Generation via Derivatives**:
       $$E[X^n] = \left. \frac{d^n}{dt^n} M_X(t) \right|_{t=0}$$
  2. **MGF of Independent Sums & Gaussian Distribution**:
     * If $X, Y$ are independent, $M_{X+Y}(t) = E[e^{t(X+Y)}] = E[e^{tX}] E[e^{tY}] = M_X(t) M_Y(t)$.
     * **Standard Normal**: $Z \sim \mathcal{N}(0, 1) \implies M_Z(t) = e^{t^2/2}$.
     * **General Normal**: $X \sim \mathcal{N}(\mu, \sigma^2) \implies M_X(t) = \exp\left( \mu t + \frac{1}{2}\sigma^2 t^2 \right)$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive $M_Z(t) = e^{t^2/2}$ for $Z \sim \mathcal{N}(0, 1)$ by completing the square in the exponent: $\int_{-\infty}^\infty e^{tz - z^2/2}dz = e^{t^2/2} \int_{-\infty}^\infty e^{-(z-t)^2/2}dz = \sqrt{2\pi} e^{t^2/2}$.
  - [ ] **Proof 2**: Differentiate $M_Z(t) = e^{t^2/2}$ four times to derive the standard Gaussian moments: $E[Z] = 0, E[Z^2] = 1, E[Z^3] = 0, E[Z^4] = 3$ (proving Gaussian excess kurtosis is exactly 0).
  - [ ] **Problem 3**: In high-dimensional dot product retrieval $S = \sum_{i=1}^d Q_i K_i$ where $Q_i, K_i \sim \mathcal{N}(0, 1/\sqrt{d})$ are i.i.d., compute the MGF $M_S(t)$ and show that $S \xrightarrow{d} \mathcal{N}(0, 1)$ as $d \to \infty$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Topic**: *CUDA Shared Memory Architecture: XOR Swizzling & Eliminating Bank Conflicts*
* **Core Microarchitectural Concepts**:
  1. **The 32-Way Transpose Bank Conflict**:
     * Shared memory has 32 banks (4-byte width per bank).
     * In FlashAttention, computing $S_{ij} = Q_i K_j^T$ requires reading row vectors from $Q$ and column vectors from $K^T$.
     * Loading column vectors $K[k][n]$ with a row stride of 64 causes all 32 threads in a warp to access the same memory bank (Bank 0), creating a **32-way bank conflict** and serializing execution into 32 separate clock cycles.
  2. **XOR Swizzled Memory Addressing**:
     * Apply bitwise XOR permutation to column indices: `s_col = col ^ (row % 32)`.
     * Rotates physical bank addresses across all 32 warp lanes, restoring single-cycle parallel SRAM throughput.

* **Tasks & Implementation**:
  1. **Implement Swizzled Shared-Memory Block GEMM** in `src/gpu/flash_attn_gemm_tile.cu`:
     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     constexpr int TILE_M = 32;
     constexpr int TILE_N = 32;
     constexpr int TILE_K = 32;

     // XOR Swizzling helper to eliminate SRAM bank conflicts
     __device__ inline int swizzle_idx(int row, int col) {
         return (row * TILE_K) + (col ^ (row % 32));
     }

     __device__ inline void compute_block_gemm_tile(
         const float* __restrict__ s_Q, // [TILE_M, TILE_K]
         const float* __restrict__ s_K, // [TILE_N, TILE_K]
         float (*s_S)[TILE_N],          // [TILE_M, TILE_N]
         float scale_factor
     ) {
         int tx = threadIdx.x % TILE_N;
         int ty = threadIdx.x / TILE_N;

         if (ty < TILE_M) {
             float accum = 0.0f;
             #pragma unroll
             for (int k = 0; k < TILE_K; ++k) {
                 float q_val = s_Q[ty * TILE_K + k];
                 float k_val = s_K[tx * TILE_K + k]; // Transposed lookup
                 accum += q_val * k_val;
             }
             s_S[ty][tx] = accum * scale_factor;
         }
     }
     }
     ```
