## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §1.5–1.6 (*Combinatorics: Permutations, Combinations $\binom{n}{k}$ & Binomial Theorem*)
* **Theorems & Mathematical Concepts**:
  1. **Permutations & Combinations**:
     * Number of $k$-permutations of $n$ distinct items: $P(n, k) = \frac{n!}{(n-k)!}$.
     * Number of $k$-element subsets (combinations): $\binom{n}{k} = \frac{n!}{k!(n-k)!}$.
  2. **The Binomial Theorem & Pascal's Identity**:
     $$(x + y)^n = \sum_{k=0}^n \binom{n}{k} x^k y^{n-k}$$
     * **Pascal's Identity**: $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$.
     * **Total Subsets**: $\sum_{k=0}^n \binom{n}{k} = (1 + 1)^n = 2^n$.
  3. **Multinomial Partitions**:
     $$\binom{n}{n_1, n_2, \dots, n_r} = \frac{n!}{n_1! n_2! \dots n_r!} \quad \text{where } \sum_{i=1}^r n_i = n$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove Pascal's identity $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$ both algebraically and by a combinatorial partition of subsets containing vs not containing a distinguished element $x_0$.
  - [ ] **Proof 2**: Prove the Binomial Theorem by mathematical induction on $n$.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* — David B. Kirk & Wen-mei W. Hwu (Ch 3)
* **Topic**: *Grid/Block/Thread Hierarchy & GPU Floating Point Numeric Formats*
* **Core Microarchitectural Concepts**:
  1. **CUDA Thread Indexing Mechanics**:
     * 1D Linear Mapping: `size_t idx = blockDim.x * blockIdx.x + threadIdx.x;`
     * 2D Matrix Mapping: `size_t r = blockDim.y * blockIdx.y + threadIdx.y; size_t c = blockDim.x * blockIdx.x + threadIdx.x;`
  2. **Floating-Point Silicon Bit Formats**:
     * **FP32 (IEEE 754)**: 1 sign, 8 exponent, 23 mantissa bits (dynamic range $\approx 10^{\pm 38}$, eps $\approx 1.19 \times 10^{-7}$).
     * **FP16 (IEEE 754)**: 1 sign, 5 exponent, 10 mantissa bits (dynamic range $[-65504, +65504]$, underflows at $6.1 \times 10^{-5}$). Requires dynamic loss scaling!
     * **BF16 (BFloat16)**: 1 sign, 8 exponent, 7 mantissa bits (matches FP32 dynamic range, eliminates gradient underflows in DL training).
     * **TF32 (TensorFloat-32)**: 1 sign, 8 exponent, 10 mantissa bits (19-bit internal hardware format for NVIDIA Ampere/Hopper Tensor Cores).

     ```cuda
     #pragma once
     #include "secan/gpu/gpu_buffer.cuh"
     #include <vector>

     namespace secan {
     template <typename T>
     class PinnedHostBuffer {
     public:
         T* h_ptr{nullptr};
         size_t count{0};

         explicit PinnedHostBuffer(size_t n) : count(n) {
             CUDA_CHECK(cudaHostAlloc(&h_ptr, n * sizeof(T), cudaHostAllocDefault));
         }

         ~PinnedHostBuffer() {
             if (h_ptr) cudaFreeHost(h_ptr);
         }

         void copy_to_device_async(GpuBuffer<T>& gpu_buf, cudaStream_t stream) {
             CUDA_CHECK(cudaMemcpyAsync(gpu_buf.d_ptr, h_ptr, count * sizeof(T),
                                        cudaMemcpyHostToDevice, stream));
         }
     };
     }
     ```
