## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Topic**: *NVIDIA CUDA C++ Programming Guide §5: Silicon Memory Architecture*
* **Core Microarchitectural Concepts**:
  1. **GPU Memory Latency & Bandwidth Hierarchy**:
     * **Registers**: 0 cycles, $>20\text{ TB/s}$ aggregate bandwidth, private to thread.
     * **Shared Memory (SRAM)**: $1\text{--}3\text{ cycles}$, $>10\text{ TB/s}$, explicit programmer-managed cache shared across block threads.
     * **L1 / L2 Cache**: $30\text{--}60\text{ cycles}$, hardware managed.
     * **Global Memory (HBM3 / GDDR6X)**: $200\text{--}400\text{ cycles}$, $1.0\text{--}3.3\text{ TB/s}$, accessible by all threads.
  2. **Batching to Amortize PCIe & Launch Overheads**:
     * Launching a GPU kernel takes $\approx 3\text{--}5\ \mu\text{s}$ CPU driver overhead. Batching $B \ge 64$ queries amortizes kernel launch cost to $<0.05\ \mu\text{s}$ per query.

  1. **Implement Batched GPU L2 Distance Kernel** in `src/gpu/distance_batch.cu`:
     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     // 1 Block computes distance for 1 query across all database vectors
     __global__ void l2_distance_batch_kernel(
         const float* __restrict__ queries, // [num_queries, dim]
         const float* __restrict__ database,// [num_database, dim]
         float* __restrict__ distances,     // [num_queries, num_database]
         size_t num_queries,
         size_t num_database,
         size_t dim
     ) {
         size_t q_idx = blockIdx.x;
         if (q_idx >= num_queries) return;

         const float* q = queries + q_idx * dim;

         // Threads in block grid-stride over database vectors
         for (size_t db_idx = threadIdx.x; db_idx < num_database; db_idx += blockDim.x) {
             const float* d = database + db_idx * dim;
             float sum = 0.0f;
             for (size_t k = 0; k < dim; ++k) {
                 float diff = q[k] - d[k];
                 sum += diff * diff;
             }
             distances[q_idx * num_database + db_idx] = sum;
         }
     }
     }
     ```
