## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §4.4–4.6 (*LOTUS, Variance, Covariance & Sum of Random Variables*)
* **Theorems & Mathematical Concepts**:
  1. **Variance & Standard Deviation**:
     * $\operatorname{Var}(X) = E\left[(X - E[X])^2\right] = E[X^2] - (E[X])^2 \ge 0$.
     * **Scaling Property**: $\operatorname{Var}(aX + b) = a^2 \operatorname{Var}(X) \implies \sigma_{aX+b} = |a|\sigma_X$.
  2. **Covariance & Correlation**:
     * $\operatorname{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - E[X]E[Y]$.
     * $\rho(X, Y) = \frac{\operatorname{Cov}(X, Y)}{\sigma_X \sigma_Y} \in [-1, 1]$.
  3. **Variance of Sums**:
     $$\operatorname{Var}\left( \sum_{i=1}^n X_i \right) = \sum_{i=1}^n \operatorname{Var}(X_i) + 2 \sum_{1 \le i < j \le n} \operatorname{Cov}(X_i, X_j)$$
     * If $X_1, \dots, X_n$ are uncorrelated, variance is strictly additive: $\operatorname{Var}(\sum X_i) = \sum \operatorname{Var}(X_i)$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove $\operatorname{Var}(aX + b) = a^2 \operatorname{Var}(X)$ by expanding $E[(aX + b - E[aX + b])^2]$.
  - [ ] **Proof 2**: Derive the variance expansion formula $\operatorname{Var}(X + Y) = \operatorname{Var}(X) + \operatorname{Var}(Y) + 2\operatorname{Cov}(X, Y)$ from first principles.
  - [ ] **Problem 3**: Let $\mathbf{x} \in \mathbb{R}^d$ be a random vector with i.i.d. coordinates $X_i \sim \mathcal{N}(0, 1)$. Let $S = \|\mathbf{x}\|_2^2 = \sum_{i=1}^d X_i^2$. Compute $E[S]$ and $\operatorname{Var}(S) = 2d$, and compute the coefficient of variation $\frac{\sigma_S}{E[S]} = \sqrt{\frac{2}{d}} \to 0$ as $d \to \infty$ (proving spherical shell concentration!).

* **Book**: *Programming Massively Parallel Processors (PMPP)* — David B. Kirk & Wen-mei W. Hwu (Ch 7)
* **Core Microarchitectural Concepts**:
  1. **Constant Memory (`__constant__`) & Warp Broadcast**:
     * $64\text{ KB}$ read-only memory space with dedicated constant cache.
     * When all threads in a warp read query vector floats simultaneously, the constant cache serves the load in **1 clock cycle** via hardware broadcast.
  2. **Fused SFU Instructions (`__rsqrtf`)**:
     * Cosine similarity requires normalizations: $\frac{\mathbf{q} \cdot \mathbf{d}}{\|\mathbf{q}\| \|\mathbf{d}\|}$.
     * Using NVIDIA Special Function Unit (SFU) reciprocal square root intrinsic `__rsqrtf(x)` evaluates $1/\sqrt{x}$ in **1 clock cycle** (vs 14 cycles for `1.0f / sqrtf(x)`).

* **Tasks & Implementation**:
  1. **Implement Fused GPU Cosine Similarity Kernel** in `src/gpu/distance_fused_cosine.cu`:
     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include "secan/gpu/warp_reduction.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     // Fused single-pass Cosine Similarity: computes dot product, ||q||^2, and ||d||^2 simultaneously
     __global__ void cosine_similarity_fused_kernel(
         const float* __restrict__ queries, // [B, dim]
         const float* __restrict__ database,// [N, dim]
         float* __restrict__ similarities,  // [B, N]
         size_t num_queries,
         size_t num_database,
         size_t dim
     ) {
         size_t global_warp_id = (blockIdx.x * blockDim.x + threadIdx.x) / 32;
         size_t lane_id = threadIdx.x % 32;

         size_t total_pairs = num_queries * num_database;
         if (global_warp_id >= total_pairs) return;

         size_t q_idx = global_warp_id / num_database;
         size_t db_idx = global_warp_id % num_database;

         const float* q = queries + q_idx * dim;
         const float* d = database + db_idx * dim;

         float dot = 0.0f;
         float q_norm_sq = 0.0f;
         float d_norm_sq = 0.0f;

         for (size_t k = lane_id; k < dim; k += 32) {
             float q_val = q[k];
             float d_val = d[k];
             dot += q_val * d_val;
             q_norm_sq += q_val * q_val;
             d_norm_sq += d_val * d_val;
         }

         dot = warp_reduce_sum(dot);
         q_norm_sq = warp_reduce_sum(q_norm_sq);
         d_norm_sq = warp_reduce_sum(d_norm_sq);

         if (lane_id == 0) {
             float inv_norm = __rsqrtf(q_norm_sq * d_norm_sq + 1e-12f);
             similarities[q_idx * num_database + db_idx] = dot * inv_norm;
         }
     }
     }
     ```
