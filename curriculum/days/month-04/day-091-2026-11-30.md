  1. **Falsifiable Hypotheses Formulation**:
     * **Hypothesis $H_1$ (In-VRAM Throughput Frontier)**: For datasets fitting within GPU VRAM ($\le 32\text{ GB}$), batched GPU IVF-PQ with shared-memory FastScan achieves $\ge 12\times$ higher query throughput (QPS) at Recall@10 $\ge 0.95$ compared to NVMe-based DiskANN due to $1.5\text{ TB/s}$ HBM bus bandwidth.
     * **Hypothesis $H_2$ (Cost-Efficiency & Out-of-Core Scaling)**: For datasets exceeding host DRAM and GPU VRAM by $\ge 4\times$ ($100\text{M}$ to $1\text{B}$ vectors), asynchronous `io_uring` DiskANN maintains $p_{99}$ query latency $\le 5.0\text{ ms}$ at $<10\%$ the hardware memory cost.
  2. **Implement Baseline Benchmark Harness** in `scripts/bench_gpu_vs_disk_baseline.py`:
     ```python
     import subprocess
     import json
     import numpy as np

     batch_sizes = [1, 8, 32, 128, 512]
     datasets = ["sift1m", "deep10m"]

     results = []
     for ds in datasets:
         for b in batch_sizes:
             cmd = f"./build/benchmarks/bench_gpu_ivf --dataset={ds} --batch={b} --json"
             out = subprocess.check_output(cmd, shell=True)
             data = json.loads(out)
             results.append({
                 "dataset": ds,
                 "batch_size": b,
                 "qps": data["qps"],
                 "p99_latency_ms": data["p99_latency_ms"],
                 "recall_at_10": data["recall_at_10"]
             })

     with open("research/2026-12-three-paths-spine/results/gpu_baseline.json", "w") as f:
         json.dump(results, f, indent=2)
     ```
