## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book**: *Introduction to Probability* — Dimitri P. Bertsekas & John N. Tsitsiklis
* **Sections**: §2.1–2.3 (*Conditional Probability, Multiplication Rule & Law of Total Probability*)
* **Theorems & Mathematical Concepts**:
  1. **Conditional Probability & The Multiplication Rule**:
     * For any event $B$ with $P(B) > 0$:
       $$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$
     * **Multiplication Rule**:
       $$P(A_1 \cap A_2 \cap \dots \cap A_n) = P(A_1) P(A_2 \mid A_1) P(A_3 \mid A_1 \cap A_2) \dots P(A_n \mid A_1 \cap \dots \cap A_{n-1})$$
  2. **The Law of Total Probability**:
     * If events $A_1, \dots, A_n$ form a partition of sample space $\Omega$ ($A_i \cap A_j = \emptyset, \bigcup A_i = \Omega$), then for any event $B$:
       $$P(B) = \sum_{i=1}^n P(A_i \cap B) = \sum_{i=1}^n P(A_i) P(B \mid A_i)$$
  3. **Gambler's Ruin Difference Equation**:
     * State probability $p_i$ of reaching fortune $N$ starting from $i$:
       $$p_i = p \cdot p_{i+1} + q \cdot p_{i-1} \implies p_i = \frac{1 - (q/p)^i}{1 - (q/p)^N} \quad (\text{for } p \ne q)$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Law of Total Probability $P(B) = \sum_{i=1}^n P(A_i) P(B \mid A_i)$ using Kolmogorov's Axiom 3 and disjoint decomposition $B = \bigcup_{i=1}^n (B \cap A_i)$.
  - [ ] **Proof 2**: Derive the analytical solution to the Gambler's Ruin difference equation $p_i = p \cdot p_{i+1} + (1-p) \cdot p_{i-1}$ with boundary conditions $p_0 = 0$ and $p_N = 1$.
  - [ ] **Problem 3**: In approximate vector search routing, a query visits cluster $C_1, C_2, C_3$ with probabilities $0.5, 0.3, 0.2$. The conditional recall given cluster visit is $0.98, 0.85, 0.60$. Compute the total expected query Recall@10.

## 📖 07:30 – 08:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* — David B. Kirk & Wen-mei W. Hwu (Ch 4)
* **Core Microarchitectural Concepts**:
  1. **Streaming Multiprocessors (SMs) & Warp Divergence**:
     * 1 Warp consists of 32 threads executing the exact same instruction simultaneously on SIMT hardware pipelines.
     * When threads within a single warp branch on conditional paths (`if (threadIdx.x < 16)`), the hardware disables inactive threads and serializes execution paths, halving instruction throughput.
  2. **Theoretical vs Achieved Occupancy**:
     * Occupancy is the ratio of active warps per SM to the hardware maximum (e.g. 64 warps per SM on Ampere/Hopper).
     * High register allocation per thread (e.g. $>64\text{ registers}$) restricts the number of resident blocks, throttling memory latency hiding.

* **Tasks & Implementation**:
  1. **Implement Naive CUDA L2 Distance Kernel** in `src/gpu/distance_naive.cu`:
     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     // Naive kernel: 1 thread computes the L2 distance between query and 1 database vector
     __global__ void l2_distance_naive_kernel(
         const float* __restrict__ queries, // [num_queries, dim]
         const float* __restrict__ database,// [num_database, dim]
         float* __restrict__ distances,     // [num_queries, num_database]
         size_t num_queries,
         size_t num_database,
         size_t dim
     ) {
         size_t q_idx = blockIdx.y;
         size_t db_idx = blockIdx.x * blockDim.x + threadIdx.x;

         if (q_idx < num_queries && db_idx < num_database) {
             const float* q = queries + q_idx * dim;
             const float* d = database + db_idx * dim;

             float sum = 0.0f;
             for (size_t k = 0; k < dim; ++k) {
                 float diff = q[k] - d[k];
                 sum += diff * diff;
             }
             distances[q_idx * num_database + db_idx] = sum;
         }
     }
     }
     ```
