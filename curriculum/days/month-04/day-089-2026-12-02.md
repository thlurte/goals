## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* — David B. Kirk & Wen-mei W. Hwu (Ch 4)
* **Core Microarchitectural Concepts**:
  1. **Streaming Multiprocessors (SMs) & Warp Divergence**:
     * 1 Warp consists of 32 threads executing the exact same instruction simultaneously on SIMT hardware pipelines.
     * When threads within a single warp branch on conditional paths (`if (threadIdx.x < 16)`), the hardware disables inactive threads and serializes execution paths, halving instruction throughput.
  2. **Theoretical vs Achieved Occupancy**:
     * Occupancy is the ratio of active warps per SM to the hardware maximum (e.g. 64 warps per SM on Ampere/Hopper).
     * High register allocation per thread (e.g. $>64\text{ registers}$) restricts the number of resident blocks, throttling memory latency hiding.

  1. **Implement Naive CUDA L2 Distance Kernel** in `src/gpu/distance_naive.cu`:
     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     // Naive kernel: 1 thread computes the L2 distance between query and 1 database vector
     __global__ void l2_distance_naive_kernel(
         const float* __restrict__ queries, // [num_queries, dim]
         const float* __restrict__ database,// [num_database, dim]
         float* __restrict__ distances,     // [num_queries, num_database]
         size_t num_queries,
         size_t num_database,
         size_t dim
     ) {
         size_t q_idx = blockIdx.y;
         size_t db_idx = blockIdx.x * blockDim.x + threadIdx.x;

         if (q_idx < num_queries && db_idx < num_database) {
             const float* q = queries + q_idx * dim;
             const float* d = database + db_idx * dim;

             float sum = 0.0f;
             for (size_t k = 0; k < dim; ++k) {
                 float diff = q[k] - d[k];
                 sum += diff * diff;
             }
             distances[q_idx * num_database + db_idx] = sum;
         }
     }
     }
     ```
