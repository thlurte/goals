## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book**: *Programming Massively Parallel Processors (PMPP)* — David B. Kirk & Wen-mei W. Hwu (Ch 6)
* **Advanced Architecture Reference**: John L. Hennessy & David A. Patterson, *Computer Architecture: A Quantitative Approach* (6th ed).
* **Core Microarchitectural Concepts**:
  1. **Global Memory Coalescing Hardware Protocol**:
     * When all 32 threads in a warp execute a load instruction, the GPU memory controller analyzes the 32 addresses:
       * **Coalesced Load**: Adjacent threads access consecutive 4-byte memory addresses (`threadIdx.x * 4`). The entire warp load is fulfilled in a **single 128-byte DRAM transaction** ($100\%$ bus efficiency).
       * **Strided / Uncoalesced Load**: Adjacent threads access addresses with large stride ($D \times 4$). The warp request fragments into **32 independent 32-byte transactions**, wasting $87.5\%$ of memory bus bandwidth!
  2. **Memory Layout Transformation (AOS vs SOA)**:
     * Storing database vectors in Array-of-Structures (`struct Vector { float d[128]; }`) creates uncoalesced memory access when multiple warps iterate through dimensions.
     * Structure-of-Arrays (contiguous dimension matrices) ensures perfect warp coalescing.

     ```cuda
     #include "secan/gpu/gpu_buffer.cuh"
     #include <cuda_runtime.h>

     namespace secan {
     // Coalesced layout: 32 threads in a warp process consecutive database vectors
     __global__ void l2_distance_coalesced_kernel(
         const float* __restrict__ queries, // [num_queries, dim]
         const float* __restrict__ database,// [num_database, dim]
         float* __restrict__ distances,     // [num_queries, num_database]
         size_t num_queries,
         size_t num_database,
         size_t dim
     ) {
         size_t q_idx = blockIdx.y;
         size_t db_idx = blockIdx.x * blockDim.x + threadIdx.x;

         if (q_idx < num_queries && db_idx < num_database) {
             const float* q = queries + q_idx * dim;
             float sum = 0.0f;

             // Loop over dimension: each thread in warp loads database[db_idx * dim + k]
             // Consecutive threads load db_idx, db_idx+1, ... (coalesced 128-byte segments!)
             for (size_t k = 0; k < dim; ++k) {
                 float d_val = database[db_idx * dim + k];
                 float diff = q[k] - d_val;
                 sum += diff * diff;
             }
             distances[q_idx * num_database + db_idx] = sum;
         }
     }
     }
     ```
