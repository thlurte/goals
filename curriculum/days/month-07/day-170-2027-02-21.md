### 🔹 Part 1: Advanced Theorems & Derivations (Thursday Syllabus)
* **Book / Paper**: *GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints* — Joshua Ainslie et al. (2023) §2–3
* **Theorems & Mathematical Concepts**:
  1. **Attention Head Topology & Partitioning**:
     * Query Heads: $H_q$; Key/Value Heads: $H_{kv}$; Group Factor: $G = \frac{H_q}{H_{kv}}$.
     * **Multi-Head Attention (MHA)**: $H_{kv} = H_q$ ($G = 1$).
     * **Grouped-Query Attention (GQA)**: $1 < H_{kv} < H_q$ ($G \in [4, 8]$).
     * **Multi-Query Attention (MQA)**: $H_{kv} = 1$ ($G = H_q$).
  2. **KV-Cache Memory Bandwidth Reduction**:
     $$\text{KV Traffic Ratio} = \frac{2 B H_{kv} L d}{2 B H_q L d} = \frac{1}{G}$$
     * For $G = 8$ (e.g. LLaMA-3 70B), KV memory traffic and cache footprint decrease by **$87.5\%$**.
  3. **Autoregressive Decoding Arithmetic Intensity**:
     $$\text{Intensity}_{\text{GQA}} = \frac{2 B H_q d}{2 B (H_q + 2 H_{kv}) L d \times \text{sizeof(FP16)}} = \frac{G}{(G + 2) L \times 2} \text{ FLOPs/byte}$$
     * Achieves a $\frac{3G}{G + 2}\times$ improvement in operational intensity over MHA during single-token decoding.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that broadcasting one Key/Value head across $G$ Query heads preserves exact dot-product linearity: Show that for query group $\{Q_{g}\}_{g=1}^G$, computing $S_g = Q_g K^T$ independently is algebraically identical to a batched GEMM with $K$ broadcasted along head dimension.
  - [ ] **Proof 2**: Derive the operational intensity formula $\text{Intensity}_{\text{GQA}} = \frac{G}{(G+2)L \times 2}$ for autoregressive token decoding ($N=1$ new token, context length $L$).
  - [ ] **Problem 3**: For a 70B parameter LLM ($H_q = 64, H_{kv} = 8, d = 128, L = 8192$) at batch size $B = 32$, calculate the total KV cache footprint in FP16 for (a) MHA ($8.59\text{ GB}$) vs (b) GQA ($1.07\text{ GB}$, $8\times$ VRAM savings).

### 🔹 Part 2: Core Proofs & Problem Sets (Friday Syllabus)
* **Book / Topic**: *Causal Masking Geometry & Lower Triangular Matrix Tiling*
* **Theorems & Mathematical Concepts**:
  1. **Causal Attention Masking Polyhedron**:
     * Logit mask: $M_{ij} = 0$ if $j \le i$, and $-\infty$ if $j > i$.
     * In tiled FlashAttention with block dimensions $B_r \times B_c$:
       * **Sub-diagonal Tiles** ($i B_r \ge (j+1) B_c$): Fully dense matrix multiply ($100\%$ active).
       * **Diagonal Tiles** ($i B_r < (j+1) B_c \land (i+1) B_r > j B_c$): Partial causal mask applied in thread registers.
       * **Super-diagonal Tiles** ($ (i+1) B_r \le j B_c $): Completely skipped ($0$ FLOPs, $0$ SRAM loads).
  2. **Causal FLOPs Halving Theorem**:
     $$\text{Total Active Tiles} = \frac{1}{2} \left( \frac{N}{B} \right) \left( \frac{N}{B} + 1 \right) \approx \frac{N^2}{2 B^2}$$
     $$\text{Causal FLOPs} = 2 N^2 d \quad (50\% \text{ reduction vs non-causal attention})$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that super-diagonal tiles with $j > i \frac{B_r}{B_c}$ have attention weight $P^{(j)} = \mathbf{0}$, proving that skipping them introduces zero numerical perturbation.
  - [ ] **Proof 2**: Derive the exact active tile formula $N_{\text{active}} = \frac{1}{2} K (K + 1)$ where $K = N / B$, and show that as $K \to \infty$, the fraction of skipped computation approaches exactly $50\%$.
  - [ ] **Problem 3**: For sequence length $N = 8192$ and block size $B = 128$ ($K = 64$ blocks), compute the exact number of active tiles ($N_{\text{active}} = 2{,}080$) vs full grid ($4{,}096$), saving $49.2\%$ of GPU compute cycles.
