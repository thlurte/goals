## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *NVIDIA Collective Communications Library (NCCL): Ring & Tree Algorithms on NVLink*
* **Core Microarchitectural Concepts**:
  1. **Direct P2P Memory Over NVLink**:
     * Enable direct device-to-device memory access with `cudaDeviceEnablePeerAccess(peer_device, 0)`.
     * NVLink 4.0 provides $900\text{ GB/s}$ bidirectional bandwidth per GPU, completely bypassing host PCIe buses.
  2. **NCCL High-Priority Streams**:
     * Launch NCCL collective operations on dedicated CUDA priority streams (`cudaStreamCreateWithPriority`) to prevent head-of-line blocking behind long compute kernels.
