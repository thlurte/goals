### 🔹 Part 1: Advanced Theorems & Derivations (Thursday Syllabus)
* **Book / Topic**: *Queueing Systems: Theory and Applications* — Leonard Kleinrock Ch 2 (*Little's Law & M/M/m Capacity Analysis*)
* **Theorems & Mathematical Concepts**:
  1. **Little's Law in Concurrent Token Serving**:
     $$N_{\text{active}} = \lambda \cdot W_{\text{latency}}$$
     * Where $\lambda$ is request arrival rate and $W_{\text{latency}}$ is end-to-end response time.
  2. **Memory-to-Compute Batch Size Crossover Theorem**:
     * In single-token decoding with batch size $B$, weights $W_{\text{model}}$, and context $L$:
       $$\text{Memory Time } T_{\text{mem}}(B) = \frac{W_{\text{model}} + 4 B H_{kv} L d}{\beta_{\text{DRAM}}}$$
       $$\text{Compute Time } T_{\text{comp}}(B) = \frac{2 B \cdot W_{\text{model\_FLOPs}} + 4 B H_{q} L d}{\Pi_{\text{TensorCore}}}$$
     * **Crossover Point $B^*$**: The batch size where $T_{\text{mem}}(B^*) = T_{\text{comp}}(B^*)$:
       * For $B < B^*$: **Memory-bound regime** (latency constant $\approx W / \beta$, tokens/sec scales linearly $\propto B$).
       * For $B > B^*$: **Compute-bound regime** (tokens/sec saturates at $\Pi / \text{FLOPs}$, latency scales linearly $\propto B$).
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the crossover batch size formula $B^* = \frac{W / \beta}{\frac{2 W_{\text{FLOPs}}}{\Pi} - \frac{4 H_{kv} L d}{\beta}}$ step-by-step from the Roofline equations.
  - [ ] **Proof 2**: Prove that with PagedAttention, the maximum achievable token throughput $\lim_{B \to \infty} T(B) = \frac{\Pi_{\text{peak}}}{4 H_q L d}$ is strictly bounded by Tensor Core arithmetic capacity.
  - [ ] **Problem 3**: For an NVIDIA RTX 4090 / A100 ($\Pi = 312\text{ TFLOPS}, \beta = 1.5\text{ TB/s}$) serving an 8B model ($W = 16\text{ GB}$) at context $L = 2048, d = 128$: compute the exact crossover batch size $B^* \approx 84$.

### 🔹 Part 2: Core Proofs & Problem Sets (Friday Syllabus)
* **Book / Topic**: *Spectral Sparsification of Graphs* — Joshua Batson, Daniel A. Spielman & Nikhil Srivastava (2011)
* **Theorems & Mathematical Concepts**:
  1. **Spectral Graph Sparsification Theorem**:
     * For any connected graph $G = (V, E)$ and approximation factor $\epsilon \in (0, 1)$, there exists a sparse subgraph $H = (V, E_H, \tilde{w})$ with at most $|E_H| = \mathcal{O}(n / \epsilon^2)$ edges such that:
       $$(1 - \epsilon) \mathbf{x}^T L_G \mathbf{x} \le \mathbf{x}^T L_H \mathbf{x} \le (1 + \epsilon) \mathbf{x}^T L_G \mathbf{x} \quad \forall \mathbf{x} \in \mathbb{R}^n$$
  2. **Foster's Effective Resistance Theorem**:
     * Let $R_{\text{eff}}(u, v) = (\mathbf{e}_u - \mathbf{e}_v)^T L^+ (\mathbf{e}_u - \mathbf{e}_v)$ be the electrical effective resistance:
       $$\sum_{e = (u, v) \in E} w_e R_{\text{eff}}(u, v) = n - 1$$
     * Sampling edges with probability $p_e \propto w_e R_{\text{eff}}(e)$ guarantees exact spectral preservation of the ACORN graph while pruning $65\%$ of redundant 2-hop edges.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove Foster's Theorem by evaluating the trace $\operatorname{Tr}(L^+ L) = \operatorname{Tr}(I - \frac{1}{n}\mathbf{1}\mathbf{1}^T) = n - 1$.
  - [ ] **Proof 2**: Prove that if $H$ spectrally approximates $G$ within $\epsilon$, then the second eigenvalues satisfy $(1-\epsilon)\lambda_2(G) \le \lambda_2(H) \le (1+\epsilon)\lambda_2(G)$, preserving search conductance $\phi(H) \ge \frac{1-\epsilon}{2}\lambda_2(G)$.
  - [ ] **Problem 3**: For an ACORN predicate graph with $N = 100{,}000$ vertices and 2-hop expanded degree $D = 120$ ($6 \times 10^6$ edges), compute the target sparsified edge count for $\epsilon = 0.25$ ($|E_H| \approx 1.6 \times 10^6$ edges, saving $73.3\%$ RAM).
