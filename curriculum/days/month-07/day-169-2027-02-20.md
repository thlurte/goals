### 🔹 Part 1: Theory & Concepts (Monday Syllabus)
* **Book / Paper**: *FlashAttention-2: Faster Attention with Better Parallelism and Work Partitioning* — Tri Dao (2023) §2–3
* **Theorems & Mathematical Concepts**:
  1. **FlashAttention-1 vs FlashAttention-2 Loop Inversion**:
     * **FA-1 (Outer $K,V$, Inner $Q$)**: Requires writing intermediate output tiles $O_i$ and scaling statistics $(m_i, \ell_i)$ back to shared memory / HBM across outer loop iterations.
     * **FA-2 (Outer $Q$, Inner $K,V$)**: Query tile $Q_i$ and output accumulator $O_i$ remain resident in **thread registers** across the entire inner loop over $K_j, V_j$, writing to HBM only once at block completion.
  2. **FA-2 Online Softmax Rescaling Formulation**:
     * For block $j$ with logit tile $S^{(j)} = Q_i K_j^T \in \mathbb{R}^{B_r \times B_c}$:
       $$m^{(j)} = \max(m^{(j-1)}, \text{rowmax}(S^{(j)}))$$
       $$\tilde{P}^{(j)} = \exp(S^{(j)} - m^{(j)})$$
       $$\ell^{(j)} = e^{m^{(j-1)} - m^{(j)}} \ell^{(j-1)} + \text{rowsum}(\tilde{P}^{(j)})$$
       $$O^{(j)} = \operatorname{diag}\left( e^{m^{(j-1)} - m^{(j)}} \right) O^{(j-1)} + \tilde{P}^{(j)} V_j$$
     * **Final Output Normalization**: At block completion, divide accumulator only once:
       $$O = \operatorname{diag}(\ell^{(N_c)})^{-1} O^{(N_c)}$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that the FA-2 unnormalized accumulator $O^{(j)} = \sum_{k=1}^j \operatorname{diag}(e^{-m^{(j)}}) e^{S^{(k)}} V_k$ satisfies $O = \operatorname{diag}(\ell^{(N_c)})^{-1} O^{(N_c)} = \operatorname{softmax}(Q K^T) V$.
  - [ ] **Proof 2**: Derive the reduction in non-matmul FLOPs: Show that by delaying division by $\ell$ until the end, FA-2 eliminates $N_c$ elementwise matrix scalings, reducing non-matmul arithmetic by $2\times$.
  - [ ] **Problem 3**: For sequence length $N = 4096$, head dimension $d = 128$, and block size $B_r = B_c = 128$, compute total HBM memory transactions: show that FA-2 achieves the theoretical minimum memory traffic of $4 N d \text{ elements} = 4 \times 4096 \times 128 \times 2\text{ bytes} = 4.19\text{ MB}$.

### 🔹 Part 2: Properties & Geometric Symmetries (Tuesday Syllabus)
* **Book / Topic**: *Parallel Complexity & The Hong-Kung I/O Lower Bound* — Jia-Wei Hong & H.T. Kung
* **Theorems & Mathematical Concepts**:
  1. **Work-Span Model for Tiled GEMM**:
     * Total Work: $T_1 = 2 M N K = \mathcal{O}(M N K)$.
     * Critical Path (Span): $T_\infty = \mathcal{O}(\log K)$ for parallel tree reduction.
     * Theoretical Parallelism: $\mathcal{P} = \frac{T_1}{T_\infty} = \mathcal{O}\left( \frac{M N K}{\log K} \right)$.
  2. **The Hong-Kung I/O Complexity Lower Bound**:
     * For any matrix multiplication algorithm computing $C = A B$ with fast memory capacity $S$:
       $$Q \ge \Omega\left( \frac{M N K}{\sqrt{S}} \right) \text{ memory transfers}$$
     * **FlashAttention Optimality**: FlashAttention-2 achieves this fundamental limit with $Q = \mathcal{O}\left( \frac{N^2 d}{\sqrt{S}} \right)$, proving asymptotic I/O optimality.
  3. **Brent's Scheduling Theorem**:
     * Execution time on $P$ processors satisfies:
       $$T_P \le \frac{T_1 - T_\infty}{P} + T_\infty \le \frac{T_1}{P} + T_\infty$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the Hong-Kung bound using the Loomis-Whitney inequality: Show that the maximum computational volume achievable with $S$ data items is bounded by $V \le S^{3/2}$, requiring $\lceil 2 M N K / S^{3/2} \rceil$ I/O epochs of size $S$, yielding $Q \ge \frac{2 M N K}{\sqrt{S}}$.
  - [ ] **Proof 2**: Prove Brent's theorem: Show that scheduling greedy work units across $P$ processors divides idle processor capacity by at most $(T_1 - T_\infty) / P$.
  - [ ] **Problem 3**: For attention with sequence length $N = 8192$, head dim $d = 128$, and GPU SRAM size $S = 100\text{ KB}$ ($50{,}000\text{ FP16 elements}$): compute minimum Hong-Kung I/O $Q_{\min} \approx \frac{8192^2 \times 128}{\sqrt{50000}} \approx 38.4\text{ MB}$, compared to standard attention HBM I/O $Q_{\text{std}} = 2 N^2 + 4 N d \approx 2 \times 8192^2 \times 2\text{ bytes} \approx 268.4\text{ MB}$ ($>7\times$ memory reduction).

### 🔹 Part 3: Core Theorems & Derivations (Wednesday Syllabus)
* **Book / Topic**: *Accuracy and Stability of Numerical Algorithms* — Nicholas J. Higham & Maxim Milakov (2018)
* **Theorems & Mathematical Concepts**:
  1. **Floating-Point Error Analysis of Softmax**:
     * Naive Softmax $\operatorname{softmax}(x_i) = \frac{e^{x_i}}{\sum e^{x_k}}$ causes immediate floating-point overflow when $\max(x_i) > 88.72$ (FP32) or $\max(x_i) > 11.09$ (FP16).
     * **Safe Softmax Invariant**: Subtracting running maximum $m = \max(x)$ guarantees:
       $$x_i - m \le 0 \implies 0 < \exp(x_i - m) \le 1.0$$
       strictly eliminating overflow and bounding the sum $\ell \in [1, N]$.
  2. **Forward Error Bound of Online Rescaling**:
     * Let $\hat{\ell}_N$ be the online computed denominator after $N$ elements with machine epsilon $u = 2^{-11}$ (FP16) or $u = 2^{-24}$ (FP32).
     * **Theorem**: The relative error is bounded by:
       $$\left| \frac{\hat{\ell}_N - \ell_N}{\ell_N} \right| \le \gamma_{2N} = \frac{2 N u}{1 - 2 N u} = 2 N u + \mathcal{O}(u^2)$$
     * (Online softmax has identical numerical forward stability to traditional 2-pass softmax).
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that the dynamic rescaling identity $e^{m_1 - m_2} \sum_{i=1}^{k_1} e^{x_i - m_1} + \sum_{j=1}^{k_2} e^{y_j - m_2} = \sum_{i=1}^{k_1} e^{x_i - m_2} + \sum_{j=1}^{k_2} e^{y_j - m_2}$ holds algebraically with zero exact mathematical error.
  - [ ] **Proof 2**: Derive the backward error bound for FP16 accumulator scaling showing that maintaining running row maximums in FP32 registers prevents underflow in intermediate tiles.
  - [ ] **Problem 3**: For attention logit vector $\mathbf{s} = [14.0, 85.0, 42.0, 88.0]^T$, compare (a) Naive softmax exponentials (overflowing FP16 max value $65504$) vs (b) Safe online softmax scaled by $m = 88.0$ with maximum term $e^{88-88} = 1.0$.
