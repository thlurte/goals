  1. **Mathematical Foundation**:
     * FlashAttention-2 loop inversion and unnormalized accumulator formulation.
     * Hong-Kung I/O lower bound $\Omega(M N K / \sqrt{S})$ and Loomis-Whitney inequality.
     * Online softmax numerical forward error bound $\gamma_{2N} \approx 2 N u$.

     * FlashAttention-1 shared-memory write stalls and inter-warp synchronization barriers.
     * Sequence-level warp partitioning assigning independent row slices to warps.
     * Causal mask polyhedral geometry skipping $>49\%$ of tile evaluations.
  3. **The Engine Architecture**:
     * `secan` Attention suite: `flash_attn_v2_fwd_kernel`, `flash_attn_v2_gqa_kernel`, and PyTorch C++ extension bindings.

     * GQA ($G=8$) latency reduction ($4.8\times$ speedup during autoregressive decoding).
  5. **Key Takeaway**:
     * Eliminating synchronization barriers and keeping accumulator state strictly inside registers allows attention algorithms to reach theoretical hardware limits.

* **Workspace**: `~/personal/dl-track/flash-attention-v2`
* **Implementation Tasks**:
  1. **FlashAttention-2 & GQA Tiled Simulator in Pure PyTorch** in `src/flash_attn_sim.py`:
     ```python
     import torch
     import math
     from typing import Tuple

     def flash_attention_v2_sim(
         Q: torch.Tensor, # [B, H_q, N, D]
         K: torch.Tensor, # [B, H_kv, N, D]
         V: torch.Tensor, # [B, H_kv, N, D]
         Br: int = 64,
         Bc: int = 64,
         is_causal: bool = False
     ) -> torch.Tensor:
         B, H_q, N, D = Q.shape
         H_kv = K.shape[1]
         G = H_q // H_kv
         scale = 1.0 / math.sqrt(D)

         O = torch.zeros_like(Q)
         # Outer loop over Q blocks (Br)
         for i in range(0, N, Br):
             Q_block = Q[:, :, i:i+Br, :] # [B, H_q, Br, D]
             m = torch.full((B, H_q, Q_block.shape[2]), float("-inf"), device=Q.device)
             l = torch.zeros((B, H_q, Q_block.shape[2]), device=Q.device)
             acc_O = torch.zeros_like(Q_block)

             # Inner loop over K, V blocks (Bc)
             for j in range(0, N, Bc):
                 if is_causal and (j * Bc > (i + 1) * Br):
                     continue # Skip super-diagonal tiles

                 # Broadcast K, V across G query heads
                 K_block = K[:, :, j:j+Bc, :].repeat_interleave(G, dim=1) # [B, H_q, Bc, D]
                 V_block = V[:, :, j:j+Bc, :].repeat_interleave(G, dim=1) # [B, H_q, Bc, D]

                 S_block = torch.matmul(Q_block, K_block.transpose(-1, -2)) * scale

                 if is_causal:
                     mask = (torch.arange(i, i + Q_block.shape[2], device=Q.device)[:, None] >=
                             torch.arange(j, j + K_block.shape[2], device=Q.device)[None, :])
                     S_block = torch.where(mask[None, None, :, :], S_block, float("-inf"))

                 m_prev = m
                 m_new = torch.maximum(m_prev, torch.max(S_block, dim=-1).values)
                 P_tilde = torch.exp(S_block - m_new[:, :, :, None])
                 P_tilde = torch.nan_to_num(P_tilde, 0.0)

                 alpha = torch.exp(m_prev - m_new)
                 l = alpha * l + torch.sum(P_tilde, dim=-1)
                 acc_O = alpha[:, :, :, None] * acc_O + torch.matmul(P_tilde, V_block)
                 m = m_new

             O[:, :, i:i+Br, :] = acc_O / l[:, :, :, None]

         return O
     ```
