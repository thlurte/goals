### 🔹 Part 1: Theory & Concepts (Monday Syllabus)
* **Book / Topic**: *Optimization of Collective Communication in MPICH* — Rajeev Thakur et al. & Prunhas Patarasuk (2009)
* **Theorems & Mathematical Concepts**:
  1. **The Hockney $(\alpha, \beta)$ Communication Model**:
     * Latency to transmit $S$ bytes across an interconnect with startup latency $\alpha$ and bandwidth $B = 1/\beta$:
       $$T(S) = \alpha + \beta S$$
  2. **Ring Collective Communication Complexities ($P$ GPUs, $S$ total bytes)**:
     * **Ring AllGather**: Each GPU begins with $S/P$ bytes; shifts in $P-1$ steps:
       $$T_{\text{AllGather}} = (P - 1)\alpha + \left(\frac{P - 1}{P}\right) \beta S$$
     * **Ring ReduceScatter**: Reduces $S/P$ chunks across ring in $P-1$ steps:
       $$T_{\text{ReduceScatter}} = (P - 1)\alpha + \left(\frac{P - 1}{P}\right) \beta S$$
     * **Ring AllReduce**:
       $$T_{\text{AllReduce}} = 2(P - 1)\alpha + 2\left(\frac{P - 1}{P}\right) \beta S$$
  3. **Distributed Top-$k$ Communication Complexity**:
     * In distributed ANN search over $P$ shards, each GPU produces local top-$k$ tuples (ID, score: $8\text{ bytes}$).
     * Total AllGather payload $S = 8 \cdot B \cdot k \cdot P\text{ bytes}$.
     * Communication overhead is $\mathcal{O}(P \alpha + B k \beta)$, which is $<0.5\%$ of local compute time.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the Ring AllGather time formula by summing transmission times over $P-1$ ring phases where each phase transmits $S/P$ bytes.
  - [ ] **Proof 2**: Prove that communicating local top-$k$ candidates ($8 B k P$ bytes) is strictly faster than centralized gathering by a factor of $\frac{N_{\text{shards}}}{k}$ when $N_{\text{shards}} \gg k$.
  - [ ] **Problem 3**: For $P = 8$ GPUs connected via NVLink ($\alpha = 1.0\ \mu\text{s}$, Bandwidth $= 450\text{ GB/s}$), query batch $B = 64$, and top-$k = 100$, compute the total AllGather communication time $T_{\text{comm}} \approx 7.8\ \mu\text{s}$.

### 🔹 Part 2: Properties & Geometric Symmetries (Tuesday Syllabus)
* **Book / Topic**: *Parallel Processing and Scaling Laws* — Gene Amdahl & John L. Gustafson
* **Theorems & Mathematical Concepts**:
  1. **Strong Scaling vs Weak Scaling**:
     * **Amdahl's Law (Fixed Dataset Size $N$)**:
       $$\text{Speedup } S_{\text{strong}}(P) = \frac{1}{s + \frac{1 - s}{P}} \le \frac{1}{s}$$
       Where $s$ is the serial fraction (query dispatch, IPC latency, and top-$k$ merger).
     * **Gustafson's Law (Scaled Dataset $N \propto P$)**:
       $$\text{Speedup } S_{\text{weak}}(P) = P - s(P - 1) = (1 - s)P + s$$
  2. **Optimal Sharding Cardinality Theorem**:
     * Total query latency on $P$ shards: $T(P) = \frac{T_{\text{scan}}}{P} + P \cdot \alpha_{\text{comm}}$.
     * Differentiating with respect to $P$ yields the optimal shard count:
       $$P^* = \sqrt{\frac{T_{\text{scan}}}{\alpha_{\text{comm}}}}$$
     * Proves that network startup latency $\alpha$ dictates the scaling limit of distributed vector databases.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive Amdahl's and Gustafson's laws from first principles, contrasting fixed-size latency limits against scaled-size throughput.
  - [ ] **Proof 2**: Derive the optimal shard count $P^* = \sqrt{T_{\text{scan}} / \alpha_{\text{comm}}}$ by minimizing total query latency $T(P)$.
  - [ ] **Problem 3**: For a 100M vector dataset ($T_{\text{scan}} = 16\text{ ms}$ on 1 GPU) with NVLink collective latency $\alpha = 1.5\ \mu\text{s}$, calculate $P^* \approx 103\text{ GPUs}$ and compute parallel scaling efficiency $E(P) = S(P)/P$ on $P = 4$ GPUs ($E(4) \ge 97.5\%$).

### 🔹 Part 3: Core Theorems & Derivations (Wednesday Syllabus)
* **Book / Paper**: *ColPali: Efficient Document Retrieval with Vision Language Models* — Manuel Févry et al. (2024) §3–4
* **Theorems & Mathematical Concepts**:
  1. **Visual Multi-Vector MaxSim Operator**:
     * Query tokens $\mathbf{Q} = \{\mathbf{q}_i\}_{i=1}^{|Q|} \subset \mathbb{R}^d$; Document visual tokens $\mathbf{D} = \{\mathbf{d}_j\}_{j=1}^{|D|} \subset \mathbb{R}^d$ ($|D| = 1030$ for $448 \times 448$ SigLIP patches):
       $$\operatorname{Score}_{\text{MaxSim}}(\mathbf{Q}, \mathbf{D}) = \sum_{i=1}^{|Q|} \max_{j=1}^{|D|} \left( \mathbf{q}_i^T \mathbf{d}_j \right)$$
  2. **Centroid-Based Upper Bound Pruning Theorem**:
     * Let $\mathbf{c}_k$ be the Voronoi centroid of cluster $\mathcal{C}_k$ with bounding radius $r_k = \max_{\mathbf{d} \in \mathcal{C}_k} \|\mathbf{d} - \mathbf{c}_k\|_2$:
       $$\operatorname{Score}_{\text{MaxSim}}(\mathbf{Q}, \mathbf{D}) \le \sum_{i=1}^{|Q|} \max_{k \in \operatorname{Centroids}(\mathbf{D})} \left( \mathbf{q}_i^T \mathbf{c}_k + r_k \right)$$
     * Enables pruning $>95\%$ of unpromising candidate documents using only centroid inner products before exact token evaluation.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Centroid Upper Bound Theorem using Cauchy-Schwarz inequality on normalized query vectors ($\|\mathbf{q}_i\|_2 = 1$).
  - [ ] **Proof 2**: Prove that the ColPali MaxSim operator is invariant under query token permutations but strictly non-commutative between Query and Document token sets.
  - [ ] **Problem 3**: For a multimodal document collection with $N = 10^5$ PDF pages ($1030$ tokens per page, $d = 128$), compute total raw FP16 storage ($10^5 \times 1030 \times 128 \times 2\text{ bytes} \approx 26.37\text{ GB}$) vs centroid index footprint ($16$ centroids/page $\implies 409.6\text{ MB}$, a $64\times$ memory reduction).
