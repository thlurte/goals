## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *Sequence-Level Warp Partitioning: Eliminating Inter-Warp Barriers in FlashAttention-2*
* **Core Microarchitectural Concepts**:
  1. **Elimination of Inter-Warp Synchronizations**:
     * FA-1 split $K, V$ blocks across 4 warps within a thread block, requiring shared memory atomic reductions and `__syncthreads()` to merge $(m, \ell)$ statistics across warps.
     * FA-2 assigns distinct rows of $Q$ ($B_r / 4$ rows per warp) to each of the 4 warps. Warps process independent sequence rows with **zero inter-warp communication**.
  2. **Warp-Level Tensor Core Pipelines**:
     * Each warp issues `mma.sync` instructions on its private sub-tile, keeping intermediate accumulator matrices in thread registers without shared memory contention.
