## 📖 05:30 – 06:30 | Systems & Architecture Reading (60 min)
* **Book / Paper**: *FlashAttention-2 with Grouped-Query Attention: SRAM Broadcasting Architecture*
* **Core Microarchitectural Concepts**:
  1. **SRAM KV Tile Re-Use Across Query Groups**:
     * Load one $K, V$ tile for head $h_{kv}$ into shared memory once.
     * The thread block loops through all $G$ associated query heads $\{Q_{g}\}$, evaluating attention outputs against the same resident $K, V$ SRAM buffer without re-fetching from HBM.
  2. **Thread Block Work Distribution**:
     * Grid dimension `(seq_len / Br, H_kv, batch_size)`.
     * Each thread block handles 1 full group of $G$ query heads, maximizing shared memory data reuse.
