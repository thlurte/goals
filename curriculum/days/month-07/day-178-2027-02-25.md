## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book / Topic**: *Online Computation and Competitive Analysis* — Allan Borodin & Ran El-Yaniv Ch 3 (*The Paging Problem & Sleator-Tarjan Theorem*)
* **Theorems & Mathematical Concepts**:
  1. **Competitive Ratio of Online Paging**:
     * For fast GPU cache capacity $k$ physical blocks and slow Host RAM:
       $$\operatorname{Cost}_{\text{LRU}}(\sigma) \le k \cdot \operatorname{Cost}_{\text{OPT}}(\sigma) + \mathcal{O}(k)$$
     * **Sleator-Tarjan Lower Bound**: No deterministic online caching algorithm can achieve a competitive ratio strictly less than $k$.
  2. **Effective Tiered Access Latency Model**:
     * Let $h$ be the GPU VRAM page hit rate, $T_{\text{VRAM}}$ be VRAM read latency, and $T_{\text{PCIe}}$ be PCIe migration latency:
       $$T_{\text{eff}} = h \cdot T_{\text{VRAM}} + (1 - h) \cdot (T_{\text{PCIe}} + T_{\text{VRAM}})$$
     * With attention power-law locality ($P(\text{access}) \propto \Delta t^{-0.8}$), empirical hit rate $h \ge 0.93 \implies T_{\text{eff}} \le 1.12 \cdot T_{\text{VRAM}}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Sleator-Tarjan theorem: Partition request sequence $\sigma$ into maximal phases containing at most $k$ distinct pages, and show LRU incurs at most $k$ faults per phase while OPT must incur at least 1 fault.
  - [ ] **Proof 2**: Derive the condition under which asynchronous page prefetching completely hides PCIe transfer latency: $T_{\text{compute}}(\text{Token}_{t}) \ge T_{\text{PCIe}}(\text{Page}_{t+1})$.
  - [ ] **Problem 3**: For PCIe 5.0 $\times 16$ with effective bidirectional bandwidth $58\text{ GB/s}$, compute the transfer time for a 16-token physical block ($32\text{ KB}$): $t_{\text{xfer}} = \frac{32 \times 10^3}{58 \times 10^9} = 0.55\ \mu\text{s}$, verifying that transfer finishes within the single-token decode time ($\approx 8\text{ ms}$).

     ```cuda
     #pragma once
     #include <cuda_runtime.h>
     #include <vector>
     #include <list>
     #include <unordered_map>

     namespace secan {
     struct HeterogeneousPagedCache {
         half* d_gpu_pool;       // GPU VRAM pool
         half* h_pinned_pool;    // Pinned Host DRAM pool
         cudaStream_t stream_transfer;
         std::list<int> lru_list;
         std::unordered_map<int, std::list<int>::iterator> lru_map;

         void evict_lru_to_host(int phys_gpu_block, int host_block) {
             cudaMemcpyAsync(
                 h_pinned_pool + host_block * 16 * 128,
                 d_gpu_pool + phys_gpu_block * 16 * 128,
                 16 * 128 * sizeof(half),
                 cudaMemcpyDeviceToHost,
                 stream_transfer
             );
         }
     };
     }
     ```
