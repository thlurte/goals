## 🌅 06:00 – 07:30 | Pure Mathematics (90 min)
* **Book / Paper**: *ColPali: Efficient Document Retrieval with Vision Language Models* — Manuel Févry et al. (2024) §3–4
* **Theorems & Mathematical Concepts**:
  1. **Visual Multi-Vector MaxSim Operator**:
     * Query tokens $\mathbf{Q} = \{\mathbf{q}_i\}_{i=1}^{|Q|} \subset \mathbb{R}^d$; Document visual tokens $\mathbf{D} = \{\mathbf{d}_j\}_{j=1}^{|D|} \subset \mathbb{R}^d$ ($|D| = 1030$ for $448 \times 448$ SigLIP patches):
       $$\operatorname{Score}_{\text{MaxSim}}(\mathbf{Q}, \mathbf{D}) = \sum_{i=1}^{|Q|} \max_{j=1}^{|D|} \left( \mathbf{q}_i^T \mathbf{d}_j \right)$$
  2. **Centroid-Based Upper Bound Pruning Theorem**:
     * Let $\mathbf{c}_k$ be the Voronoi centroid of cluster $\mathcal{C}_k$ with bounding radius $r_k = \max_{\mathbf{d} \in \mathcal{C}_k} \|\mathbf{d} - \mathbf{c}_k\|_2$:
       $$\operatorname{Score}_{\text{MaxSim}}(\mathbf{Q}, \mathbf{D}) \le \sum_{i=1}^{|Q|} \max_{k \in \operatorname{Centroids}(\mathbf{D})} \left( \mathbf{q}_i^T \mathbf{c}_k + r_k \right)$$
     * Enables pruning $>95\%$ of unpromising candidate documents using only centroid inner products before exact token evaluation.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Centroid Upper Bound Theorem using Cauchy-Schwarz inequality on normalized query vectors ($\|\mathbf{q}_i\|_2 = 1$).
  - [ ] **Proof 2**: Prove that the ColPali MaxSim operator is invariant under query token permutations but strictly non-commutative between Query and Document token sets.
  - [ ] **Problem 3**: For a multimodal document collection with $N = 10^5$ PDF pages ($1030$ tokens per page, $d = 128$), compute total raw FP16 storage ($10^5 \times 1030 \times 128 \times 2\text{ bytes} \approx 26.37\text{ GB}$) vs centroid index footprint ($16$ centroids/page $\implies 409.6\text{ MB}$, a $64\times$ memory reduction).
