### 🔹 Part 1: Theory & Concepts (Monday Syllabus)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §2.1–2.4 (*Convex Sets, Affine Sets, Hyperplanes, Halfspaces & Polyhedra*)
* **Theorems & Mathematical Concepts**:
  1. **Affine vs Convex Sets**:
     * An affine set contains the entire line passing through any two points: $\theta x_1 + (1-\theta)x_2 \in C$ ($\forall \theta \in \mathbb{R}$).
     * A convex set contains the line segment between any two points: $\theta x_1 + (1-\theta)x_2 \in C$ ($\forall \theta \in [0, 1]$).
  2. **Hyperplanes, Halfspaces & Polyhedra**:
     * Hyperplane: $\{x \in \mathbb{R}^n \mid a^T x = b\}$ ($a \ne 0$). Both affine and convex.
     * Halfspace: $\{x \in \mathbb{R}^n \mid a^T x \le b\}$. Convex, but not affine.
     * Polyhedron: Intersection of finitely many halfspaces and hyperplanes:
       $$\mathcal{P} = \{x \in \mathbb{R}^n \mid A x \preceq b, \; C x = d\}$$
  3. **Preservation of Convexity**:
     * The intersection of any arbitrary (possibly infinite) family of convex sets $\bigcap_{\alpha \in A} C_\alpha$ is convex.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that the intersection of any collection of convex sets $C = \bigcap_{\alpha} C_\alpha$ is convex: let $x, y \in C$, then for any $\theta \in [0, 1]$, $\theta x + (1-\theta)y \in C_\alpha$ for all $\alpha$, hence $\theta x + (1-\theta)y \in C$.
  - [ ] **Proof 2**: Prove that the Euclidean ball $B(x_c, r) = \{x \mid \|x - x_c\|_2 \le r\}$ is convex using the triangle inequality for norms: $\|\theta x + (1-\theta)y - x_c\|_2 \le \theta\|x - x_c\|_2 + (1-\theta)\|y - x_c\|_2 \le r$.
  - [ ] **Problem 3**: In vector quantization partitioning with $K$ centroids $\{c_1, \dots, c_K\}$, prove that each Voronoi cell $V_i = \{x \mid \|x - c_i\|_2 \le \|x - c_j\|_2, \; \forall j \ne i\}$ is a convex polyhedron by expanding the squared norm inequality into halfspaces $2(c_j - c_i)^T x \le \|c_j\|^2 - \|c_i\|^2$.

### 🔹 Part 2: Properties & Geometric Symmetries (Tuesday Syllabus)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §3.1–3.4 (*Convex Functions, First/Second-Order Conditions & Epigraphs*)
* **Theorems & Mathematical Concepts**:
  1. **Convex Function Definition**:
     * $f: \mathbb{R}^n \to \mathbb{R}$ is convex if $\operatorname{dom} f$ is convex and $\forall x, y \in \operatorname{dom} f, \theta \in [0, 1]$:
       $$f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y)$$
  2. **First-Order & Second-Order Conditions**:
     * **First-Order (Differentiable)**: $f(y) \ge f(x) + \nabla f(x)^T (y - x)$ for all $x, y$. (Tangent hyperplane is a global underestimator).
     * **Second-Order (Twice Differentiable)**: $\nabla^2 f(x) \succeq 0$ for all $x \in \operatorname{dom} f$.
  3. **Epigraph & Sublevel Sets**:
     * $\operatorname{epi} f = \{(x, t) \in \mathbb{R}^{n+1} \mid x \in \operatorname{dom} f, f(x) \le t\}$.
     * **Theorem**: $f$ is convex $\iff \operatorname{epi} f$ is a convex set.
     * All $\alpha$-sublevel sets $S_\alpha = \{x \in \operatorname{dom} f \mid f(x) \le \alpha\}$ of a convex function are convex.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Derive the first-order condition: from $f(x + \theta(y-x)) \le (1-\theta)f(x) + \theta f(y)$, divide by $\theta > 0$ to get $\frac{f(x + \theta(y-x)) - f(x)}{\theta} \le f(y) - f(x)$, and take the limit $\theta \to 0^+$.
  - [ ] **Proof 2**: Prove that the quadratic function $f(x) = \frac{1}{2} x^T P x + q^T x + r$ is convex if and only if the matrix $P$ is positive semidefinite ($P \succeq 0$).
  - [ ] **Problem 3**: In InfoNCE / softmax contrastive loss, the log-sum-exp function is $f(\mathbf{x}) = \ln\left(\sum_{i=1}^m e^{x_i}\right)$. Prove that $f$ is convex by computing its Hessian $\nabla^2 f(\mathbf{x}) = \operatorname{diag}(\mathbf{z}) - \mathbf{z}\mathbf{z}^T$ (where $z_i = \frac{e^{x_i}}{\sum e^{x_k}}$) and using Cauchy-Schwarz to show $\mathbf{v}^T \nabla^2 f(\mathbf{x}) \mathbf{v} = \sum z_i v_i^2 - (\sum z_i v_i)^2 \ge 0$.

### 🔹 Part 3: Core Theorems & Derivations (Wednesday Syllabus)
* **Book**: *Convex Optimization* — Stephen Boyd & Lieven Vandenberghe
* **Sections**: §4.1–4.4 (*Convex Optimization Problems: Standard Form, LP, QP & SOCP*)
* **Theorems & Mathematical Concepts**:
  1. **Standard Form Convex Problem**:
     $$\min_{x} f_0(x) \quad \text{subject to} \quad f_i(x) \le 0 \; (i=1,\dots,m), \quad A x = b$$
     * $f_0, f_1, \dots, f_m$ are convex functions; equality constraints must be strictly affine.
  2. **Global Optimality Theorem**:
     * For any convex optimization problem, **every locally optimal point is globally optimal**.
     * Furthermore, if the objective $f_0$ is strictly convex, the global optimum is unique.
  3. **Convex Problem Hierarchy**:
     * **Linear Program (LP)**: $\min c^T x \text{ s.t. } G x \preceq h, A x = b$.
     * **Quadratic Program (QP)**: $\min \frac{1}{2} x^T P x + q^T x \text{ s.t. } G x \preceq h, A x = b$ ($P \succeq 0$).
     * **Second-Order Cone Program (SOCP)**: $\min f^T x \text{ s.t. } \|A_i x + b_i\|_2 \le c_i^T x + d_i$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Global Optimality Theorem: Suppose $x^*$ is a local optimum, and $\exists y$ feasible with $f_0(y) < f_0(x^*)$. Show that $z = (1-\theta)x^* + \theta y$ is feasible for all $\theta \in [0, 1]$ and satisfies $f_0(z) \le (1-\theta)f_0(x^*) + \theta f_0(y) < f_0(x^*)$ for all $\theta \in (0, 1]$, contradicting local optimality.
  - [ ] **Proof 2**: Cast the maximum-margin vector hyperplane problem (SVM) $\min \frac{1}{2}\|\mathbf{w}\|_2^2 \text{ s.t. } y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1$ explicitly as a standard Quadratic Program (QP).
  - [ ] **Problem 3**: In optimal vector quantization bit allocation, formulate the problem of minimizing total mean-squared reconstruction error $\sum_{j=1}^m \sigma_j^2 2^{-2 b_j}$ subject to total bit budget $\sum_{j=1}^m b_j \le B$ and non-negativity $b_j \ge 0$ as a convex program, and show that its objective Hessian is strictly positive diagonal.
