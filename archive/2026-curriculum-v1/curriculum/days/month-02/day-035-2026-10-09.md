* **Book**: [Fedor G. Pikus, *The Art of Writing Efficient Programs*](https://www.packtpub.com/product/the-art-of-writing-efficient-programs/9781800208117) (Packt 2021)
* **Primary Systems Reading**: **Chapter 9 (§9.1–9.4)**: *High-Performance Modern C++: Move Semantics, Object Lifetimes & `std::span`*
* **Seminal Systems Papers & Guides**:
  * [Brendan Gregg, *Systems Performance: Enterprise and the Cloud (2nd ed)*](https://www.brendangregg.com/systems-performance-2nd-edition-book.html) — **Ch 6 (§6.1–6.6)** (*CPUs: PMU Hardware Counters, IPC & Flame Graphs*).
  * [Ahmad Yasin (Intel), *A Top-Down Method for Performance Analysis and Counters Architecture*](https://sites.google.com/site/analysismethods/yasin-pubs) (ISPASS 2014) — Top-Down Microarchitecture Analysis (TMA).
* **Core Microarchitectural & Profiling Concepts**:
  1. **Zero-Copy Memory Views with C++20 `std::span` (Pikus §9.1–9.3)**:
     * Passing `std::vector` or raw pointers creates heap allocation overhead or obscures buffer length metadata.
     * `std::span<const uint8_t>` is a 16-byte non-owning wrapper (`pointer + size`) passed by value directly in 2 CPU registers (`rdi`, `rsi` under System V AMD64 ABI), enabling zero-cost buffer slicing without heap traffic.
  2. **Eliminating Allocation in the Search Critical Path (Pikus §9.4)**:
     * Pre-allocating query scratch buffers and returning lightweight `std::span` views over memory-mapped database regions guarantees **0 malloc/free calls during query execution**.
  3. **PMU Hardware Counters & Stall Cycle Analysis (Gregg §6.1–6.6)**:
     * Measure instruction-level performance using PMU architectural events:
       $$\text{IPC} = \frac{\text{instructions}}{\text{cycles}}, \quad \text{CPI} = \frac{1}{\text{IPC}} = \frac{\text{cycles}}{\text{instructions}}$$
     * Hardware stall cycle ratio and cache miss penalties:
       $$\text{Stall Cycle \%} = \frac{\text{Resource-Stalled Cycles}}{\text{Total CPU Cycles}} \times 100\%$$
     * Profiling CLI invocation:
       ```bash
       perf stat -e cycles,instructions,cache-references,cache-misses,L1-dcache-loads,L1-dcache-load-misses,LLC-load-misses ./bin/secan_bench_sq8
       ```

     ```cpp
     #pragma once
     #include <span>
     #include <vector>
     #include <cstdint>
     #include <cstddef>

     namespace secan {
     class QuantizedDatasetSQ8 {
     public:
         QuantizedDatasetSQ8(size_t num_vectors, size_t dim, std::vector<uint8_t> data)
             : n_(num_vectors), dim_(dim), data_(std::move(data)) {}

         [[nodiscard]] std::span<const uint8_t> get_vector(size_t idx) const noexcept {
             return std::span<const uint8_t>(data_.data() + idx * dim_, dim_);
         }

         [[nodiscard]] std::span<const uint8_t> get_block(size_t start_idx, size_t count) const noexcept {
             return std::span<const uint8_t>(data_.data() + start_idx * dim_, count * dim_);
         }

         [[nodiscard]] size_t size() const noexcept { return n_; }
         [[nodiscard]] size_t dim() const noexcept { return dim_; }

     private:
         size_t n_{0};
         size_t dim_{0};
         std::vector<uint8_t> data_;
     };
     }
     ```
