### 🔹 Part 1: Theory & Concepts (Monday Syllabus)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §3.1 (*Orthogonal Vectors, Lengths, Angles & Subspace Orthogonality*)
* **Theorems & Mathematical Concepts**:
  1. **Inner Products and Norms in $\mathbb{R}^n$**:
     * Length $\|\mathbf{x}\| = \sqrt{\mathbf{x}^T \mathbf{x}}$. Cosine angle: $\cos \theta = \frac{\mathbf{x}^T \mathbf{y}}{\|\mathbf{x}\| \|\mathbf{y}\|}$.
  2. **Pythagorean Theorem in $\mathbb{R}^n$**:
     $$\|\mathbf{x} + \mathbf{y}\|^2 = (\mathbf{x} + \mathbf{y})^T (\mathbf{x} + \mathbf{y}) = \|\mathbf{x}\|^2 + 2\mathbf{x}^T \mathbf{y} + \|\mathbf{y}\|^2 = \|\mathbf{x}\|^2 + \|\mathbf{y}\|^2 \iff \mathbf{x}^T \mathbf{y} = 0$$
  3. **The Cauchy-Schwarz Inequality**:
     $$|\mathbf{x}^T \mathbf{y}| \le \|\mathbf{x}\| \|\mathbf{y}\| \quad \text{with equality } \iff \mathbf{x} = c \mathbf{y}$$
  4. **Subspace Orthogonality**:
     * Subspaces $V, W \subseteq \mathbb{R}^n$ are orthogonal ($V \perp W$) $\iff \mathbf{v}^T \mathbf{w} = 0$ for all $\mathbf{v} \in V, \mathbf{w} \in W$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove the Cauchy-Schwarz Inequality by considering the quadratic polynomial $p(t) = \|t \mathbf{x} - \mathbf{y}\|^2 = t^2 \|\mathbf{x}\|^2 - 2t(\mathbf{x}^T \mathbf{y}) + \|\mathbf{y}\|^2 \ge 0$ and asserting non-positive discriminant $\Delta \le 0$.
  - [ ] **Proof 2**: Prove the Triangle Inequality $\|\mathbf{x} + \mathbf{y}\| \le \|\mathbf{x}\| + \|\mathbf{y}\|$ using the Cauchy-Schwarz inequality.
  - [ ] **Problem 3**: Find the orthogonal complement $S^\perp$ of the subspace $S = \operatorname{span}\{\langle 1, 2, -1 \rangle^T, \langle 2, 1, 1 \rangle^T\} \subset \mathbb{R}^3$.

### 🔹 Part 2: Properties & Geometric Symmetries (Tuesday Syllabus)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §3.2 (*Projections onto 1D Subspaces & Cauchy-Schwarz from Orthogonal Error*)
* **Theorems & Mathematical Concepts**:
  1. **Projection onto a 1D Line**:
     * To project vector $\mathbf{b}$ onto the line spanned by vector $\mathbf{a}$, find scalar $\hat{x}$ such that error $\mathbf{e} = \mathbf{b} - \hat{x}\mathbf{a} \perp \mathbf{a}$:
       $$\mathbf{a}^T (\mathbf{b} - \hat{x}\mathbf{a}) = 0 \implies \hat{x} = \frac{\mathbf{a}^T \mathbf{b}}{\mathbf{a}^T \mathbf{a}}$$
     * Projection vector $\mathbf{p} = \hat{x}\mathbf{a} = \left( \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}} \right) \mathbf{b} = \mathbf{P} \mathbf{b}$.
  2. **The 1D Projection Matrix $\mathbf{P} = \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}}$**:
     * **Symmetric**: $\mathbf{P}^T = \left(\frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}}\right)^T = \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}} = \mathbf{P}$.
     * **Idempotent**: $\mathbf{P}^2 = \frac{\mathbf{a}\mathbf{a}^T \mathbf{a}\mathbf{a}^T}{(\mathbf{a}^T \mathbf{a})^2} = \frac{\mathbf{a}(\mathbf{a}^T \mathbf{a})\mathbf{a}^T}{(\mathbf{a}^T \mathbf{a})^2} = \mathbf{P}$.
  3. **Cauchy-Schwarz from Error Norm**:
     $$\|\mathbf{e}\|^2 = \|\mathbf{b} - \mathbf{p}\|^2 = \|\mathbf{b}\|^2 - \|\mathbf{p}\|^2 = \|\mathbf{b}\|^2 - \frac{(\mathbf{a}^T \mathbf{b})^2}{\|\mathbf{a}\|^2} \ge 0 \implies (\mathbf{a}^T \mathbf{b})^2 \le \|\mathbf{a}\|^2 \|\mathbf{b}\|^2$$
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that $\mathbf{P}^2 = \mathbf{P}$ and $\mathbf{P}^T = \mathbf{P}$ for any projection matrix $\mathbf{P} = \frac{\mathbf{a}\mathbf{a}^T}{\mathbf{a}^T \mathbf{a}}$.
  - [ ] **Proof 2**: Prove the Pythagorean relationship $\|\mathbf{b}\|^2 = \|\mathbf{p}\|^2 + \|\mathbf{e}\|^2$ using $\mathbf{p}^T \mathbf{e} = 0$, deriving the Cauchy-Schwarz inequality.
  - [ ] **Problem 3**: For vector $\mathbf{a} = \begin{pmatrix} 1 \\ 2 \\ 2 \end{pmatrix}$, compute the $3 \times 3$ projection matrix $\mathbf{P}$. Compute $\mathbf{p} = \mathbf{P}\begin{pmatrix} 3 \\ 3 \\ 3 \end{pmatrix}$ and verify that error $\mathbf{e} = \mathbf{b} - \mathbf{p}$ is strictly orthogonal to $\mathbf{a}$.

### 🔹 Part 3: Core Theorems & Derivations (Wednesday Syllabus)
* **Book**: *Introduction to Linear Algebra* — Gilbert Strang
* **Sections**: §3.3 (*Projections onto Subspaces, The Normal Equations & Projection Matrix $\mathbf{P}$*)
* **Theorems & Mathematical Concepts**:
  1. **The Normal Equations for Subspace Projection**:
     * To project vector $\mathbf{b} \in \mathbb{R}^m$ onto the column space $C(\mathbf{A})$ where $\mathbf{A} \in \mathbb{R}^{m \times n}$, we seek $\mathbf{p} = \mathbf{A}\hat{\mathbf{x}}$ such that the error vector $\mathbf{e} = \mathbf{b} - \mathbf{A}\hat{\mathbf{x}} \perp C(\mathbf{A})$:
       $$\mathbf{A}^T (\mathbf{b} - \mathbf{A}\hat{\mathbf{x}}) = \mathbf{0} \implies \mathbf{A}^T \mathbf{A} \hat{\mathbf{x}} = \mathbf{A}^T \mathbf{b}$$
  2. **Invertibility of $\mathbf{A}^T \mathbf{A}$**:
     * $N(\mathbf{A}^T \mathbf{A}) = N(\mathbf{A})$. If $\mathbf{A}$ has full column rank ($r = n$), then $\mathbf{A}^T \mathbf{A}$ is an invertible $n \times n$ symmetric positive definite matrix.
  3. **The Subspace Projection Matrix $\mathbf{P}$**:
     $$\mathbf{P} = \mathbf{A}(\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T$$
     * **Symmetric**: $\mathbf{P}^T = \left(\mathbf{A}(\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T\right)^T = \mathbf{A} (\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T = \mathbf{P}$.
     * **Idempotent**: $\mathbf{P}^2 = \mathbf{A}(\mathbf{A}^T \mathbf{A})^{-1} (\mathbf{A}^T \mathbf{A}) (\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T = \mathbf{A}(\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T = \mathbf{P}$.
     * **Exact Mapping**: For any $\mathbf{v} \in C(\mathbf{A})$, $\mathbf{P}\mathbf{v} = \mathbf{v}$. For any $\mathbf{w} \in N(\mathbf{A}^T)$, $\mathbf{P}\mathbf{w} = \mathbf{0}$.
* **Pencil & Paper Problem Set**:
  - [ ] **Proof 1**: Prove that $N(\mathbf{A}^T \mathbf{A}) = N(\mathbf{A})$ by showing that $\mathbf{A}^T \mathbf{A} \mathbf{x} = \mathbf{0} \implies \mathbf{x}^T \mathbf{A}^T \mathbf{A} \mathbf{x} = 0 \implies \|\mathbf{A}\mathbf{x}\|^2 = 0 \implies \mathbf{A}\mathbf{x} = \mathbf{0}$.
  - [ ] **Proof 2**: Prove algebraically that $\mathbf{P} = \mathbf{A}(\mathbf{A}^T \mathbf{A})^{-1}\mathbf{A}^T$ satisfies $\mathbf{P}^2 = \mathbf{P}$ and $\mathbf{P}^T = \mathbf{P}$.
  - [ ] **Problem 3**: Project vector $\mathbf{b} = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}$ onto the subspace spanned by columns of $\mathbf{A} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{pmatrix}$. Compute $\mathbf{A}^T \mathbf{A}$, solve for $\hat{\mathbf{x}}$, and verify that error $\mathbf{e} = \mathbf{b} - \mathbf{A}\hat{\mathbf{x}}$ is orthogonal to both columns of $\mathbf{A}$.
