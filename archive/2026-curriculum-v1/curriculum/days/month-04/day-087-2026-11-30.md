* **Core Microarchitectural Concepts**:
  1. **The SIMT Execution Paradigm & Streaming Multiprocessors (SMs)**:
     * CPU design optimizes for **minimum single-thread latency** (huge caches, branch predictors, out-of-order execution pipelines).
     * GPU design optimizes for **maximum aggregate throughput** (thousands of lightweight ALUs, deep hardware multithreading).
     * Streaming Multiprocessor (SM) architecture:
       * 1 Warp = 32 parallel threads executing in lock-step SIMT fashion.
       * Hardware Warp Schedulers: When a warp stalls on a high-latency global memory load ($200\text{--}400\text{ cycles}$), the warp scheduler instantly context switches to another ready warp in **zero cycles** (latency hiding!).
  2. **Device Memory Hierarchy**:
     * Host DRAM $\xrightarrow{\text{PCIe Gen4 / Gen5 } (32\text{--}64\text{ GB/s})}$ GPU HBM / GDDR6 ($>1{,}000\text{ GB/s}$).

  2. **Implement RAII `GpuBuffer<T>` Memory Wrapper** in `include/secan/gpu/gpu_buffer.cuh`:
     ```cuda
     #pragma once
     #include <cuda_runtime.h>
     #include <stdexcept>
     #include <string>

     #define CUDA_CHECK(call) do { \
         cudaError_t err = call; \
         if (err != cudaSuccess) { \
             throw std::runtime_error("CUDA error at " + std::string(__FILE__) + ":" + \
                                      std::to_string(__LINE__) + " - " + cudaGetErrorString(err)); \
         } \
     } while (0)

     namespace secan {
     template <typename T>
     class GpuBuffer {
     public:
         T* d_ptr{nullptr};
         size_t count{0};

         explicit GpuBuffer(size_t n) : count(n) {
             CUDA_CHECK(cudaMalloc(&d_ptr, n * sizeof(T)));
         }

         ~GpuBuffer() {
             if (d_ptr) cudaFree(d_ptr);
         }

         GpuBuffer(const GpuBuffer&) = delete;
         GpuBuffer& operator=(const GpuBuffer&) = delete;

         GpuBuffer(GpuBuffer&& other) noexcept : d_ptr(other.d_ptr), count(other.count) {
             other.d_ptr = nullptr;
             other.count = 0;
         }

         void copy_from_host(const T* h_ptr, size_t n) {
             CUDA_CHECK(cudaMemcpy(d_ptr, h_ptr, n * sizeof(T), cudaMemcpyHostToDevice));
         }

         void copy_to_host(T* h_ptr, size_t n) const {
             CUDA_CHECK(cudaMemcpy(h_ptr, d_ptr, n * sizeof(T), cudaMemcpyDeviceToHost));
         }
     };
     }
     ```
