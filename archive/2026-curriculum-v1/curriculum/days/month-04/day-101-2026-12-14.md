* **Advanced Systems Reference**: * [David B. Kirk & Wen-mei W. Hwu, *Programming Massively Parallel Processors (4th ed)*](https://www.elsevier.com/books/programming-massively-parallel-processors/kirk/978-0-323-91231-0) — **Ch 8 & Ch 9** (*Work-Efficient Parallel Scan & Warp-Shuffle Reduction for In-SRAM MaxSim*)
* **Book / Paper**: *FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness* (Dao et al., 2022) §1–3
* **Core Microarchitectural Concepts**:
  1. **The Attention HBM Memory Bottleneck**:
     * Standard Attention computes $S = Q K^T \in \mathbb{R}^{N \times N}$, writes $S$ to slow GPU HBM ($1.5\text{ TB/s}$), reads $S$ to compute $P = \operatorname{softmax}(S)$, writes $P$ to HBM, and reads $P$ to compute $O = P V$.
     * Materializing intermediate $N \times N$ attention matrices causes $\mathcal{O}(N^2)$ memory traffic, throttling execution on memory bandwidth.
  2. **FlashAttention IO Complexity Reduction**:
     * Stages $Q, K, V$ into fast on-chip SRAM ($100\text{ KB}$ shared memory per SM, $>19\text{ TB/s}$).
     * Fuses Matmul, Online Softmax, and Output accumulation in SRAM without ever writing $S$ or $P$ to HBM.
     * Reduces HBM IO accesses from $\mathcal{O}(N d + N^2) \to \mathcal{O}\left(\frac{N^2 d^2}{M}\right)$ where $M$ is SRAM size!

     ```python
     import torch
     import time
     import json
     import matplotlib.pyplot as plt
     from src.flash_attn_pure import flash_attention_v1_reference

     seq_lens = [512, 1024, 2048, 4096, 8192]
     head_dim = 64
     batch_size = 4
     num_heads = 8

     results = []

     for n in seq_lens:
         Q = torch.randn(batch_size, num_heads, n, head_dim, device="cuda")
         K = torch.randn(batch_size, num_heads, n, head_dim, device="cuda")
         V = torch.randn(batch_size, num_heads, n, head_dim, device="cuda")

         # Warmup
         for _ in range(5):
             _ = torch.nn.functional.scaled_dot_product_attention(Q, K, V)
         torch.cuda.synchronize()

         # Measure PyTorch Native SDPA
         t0 = time.perf_counter()
         for _ in range(20):
             _ = torch.nn.functional.scaled_dot_product_attention(Q, K, V)
         torch.cuda.synchronize()
         sdpa_time_ms = (time.perf_counter() - t0) / 20.0 * 1000.0

         # Measure FlashAttention-1 Custom Kernel
         t0 = time.perf_counter()
         for _ in range(20):
             _ = flash_attention_v1_reference(Q, K, V)
         torch.cuda.synchronize()
         fa_time_ms = (time.perf_counter() - t0) / 20.0 * 1000.0

         results.append({
             "seq_len": n,
             "sdpa_ms": sdpa_time_ms,
             "flash_attn_ms": fa_time_ms,
             "speedup": sdpa_time_ms / fa_time_ms
         })

     with open("research/2026-12-three-paths-spine/results/attention_scaling.json", "w") as f:
         json.dump(results, f, indent=2)

     # Plot Fig 2: Latency vs Sequence Length
     plt.figure(figsize=(8, 5))
     plt.plot(seq_lens, [r["sdpa_ms"] for r in results], marker="o", label="Standard SDPA (PyTorch)")
     plt.plot(seq_lens, [r["flash_attn_ms"] for r in results], marker="s", label="FlashAttention-1 (Ours)")
     plt.xlabel("Sequence Length (N)")
     plt.ylabel("Forward Latency (ms)")
     plt.title("Attention Forward Execution Time vs Sequence Length")
     plt.legend()
     plt.grid(True)
     plt.savefig("research/2026-12-three-paths-spine/figures/fig2_flashattn_latency_memory.png", dpi=300)
     ```
